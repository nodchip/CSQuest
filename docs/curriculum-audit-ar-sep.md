# 原典との範囲照合：AR-SEP

[CS2023 印字 p.109（PDF 109ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-ar-sep.md)を2026-11-05に照合した。トピック１とその子 a〜d、例示学習成果１は Non-core。原典の親項目「実装上の判断が及ぼす環境影響」を追加し、データセンターでの AI 利用や成果１の CPU・GPU 等は例示として扱う。台帳はトピック５行、成果１行で、親子の重複を今後の集計で検討する。

項目の範囲と区分の照合であり、教材の正確性や学習成果の達成を検証したものではない。架空の条件と実際の環境影響との差は別途評価が必要。
