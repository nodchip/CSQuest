# 原典との範囲照合：SF-Evaluation

[CS2023 印字 pp.295–296（PDF 295〜296ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-sf-evaluation.md)を2026-11-05に照合した。トピック１〜７と成果１〜６は CS Core、トピック７〜９と成果７・８は KA Core。原典がトピック７を両区分に記載するため、区分で別々に識別する。台帳はトピック10行、成果８行。

範囲と区分の照合であり、教材の正確性や学習成果の達成は別途評価する。依頼1097はブラウザーの時計を用いる限定例で、汎用性能分析ツールや代表的システムの実験設計は未評価。
