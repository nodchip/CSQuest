# SF-Resource：資源管理

出典：[CS2023 SF-Resource](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p. 294。固定の仕事を操作したことは、実装能力や一般の方式の性能を保証しない。

## トピック

| 番号 | 区分 | 内容と現状 |
|---:|---|---|
| 1 | CS Core | CPU、メモリ、ディスク、帯域などの資源。依頼14・40・103で処理順序、アドレス変換、キャッシュの固定例。資源全般の比較は未対応 |
| 2 | CS Core | 先着、優先度、公平、プリエンプティブなどの割当て。依頼14・134・176・177で固定例。一般の方式は未対応 |
| 3 | KA Core | 方式の利点・欠点。依頼14・176・177で完了時間や飢餓の固定例。多様な負荷と一般的比較は未対応 |

## 例示学習成果

| 番号 | 区分 | 内容と現状 |
|---:|---|---|
| 1 | CS Core | 有限資源の割当てによる管理を定義。依頼14・40はそれぞれ固定例。資源全般と自由な定義は未対応 |
| 2 | CS Core | 代表的な割当て・スケジューリングの動作を説明。依頼14・176・177で固定例を比較。自由な説明は未対応 |
| 3 | CS Core | 代表的な方式を開発し性能を評価。固定模型の操作のみで、実プログラムの開発・実測は未対応 |
| 4 | KA Core | 代表的な方式の長所・短所を説明。依頼176・177で切替費用と飢餓を比較。一般の説明は未対応 |
