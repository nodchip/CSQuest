# 集いの後：谷の名簿と記録

原典：[CS2023 最終報告書](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印刷ページ117–118、DM-Relational と DM-Querying。二つの依頼は固定例の一部を操作する教材です。

| 依頼 | 操作 | 限界 |
| --- | --- | --- |
| 二つの名簿を照らし合わせる | 番号の重複しない二つの名簿で和・共通・左差を作る。空の結果と差の左右を入れ替える例を含む。 | SQL の作成・実行、重複保持、NULL、除算、関係代数全般は扱わない。 |
| 届け先の記録を守る | 荷物・届け先番号の一意性、参照先の存在、参照中の届け先削除を試す。 | 単一番号と空欄なしの模型。この帳面は参照中の削除を拒否するが、他の削除規則もある。複合キー、NULL、SQL、すべての整合性制約は扱わない。 |

物語の一区切りと四地域の後、「届け先の発送札を作る」「二つの名簿を照らし合わせる」の異なる二件を達成すると「届け先の記録を守る」が現れます。以前の依頼にも戻れます。依頼はそれぞれ画面内に条件を示します。

2026-11-10、実装担当と別の search_review が原典・模型をレビューしました。左右を入れ替えた差の例と、制約違反と有効だが目的に合わない変更を区別するよう指摘し、修正しました。画面接続後の再レビューでは、各場面が別の帳面であることを明示するよう指摘し、修正後にコードを再確認しました。独立担当自身によるブラウザ操作は行っていません。390・1,200 CSS px と、幅320px・150%表示を213 CSS pxで模擬したブラウザで、解放条件、誤答、途中保存、六つと三つの場面を確認しました。実際のブラウザ倍率、スクリーンリーダー実機、利用者本人の評価、公開後の確認は未実施です。
