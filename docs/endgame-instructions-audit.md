# SE-Construction：名前と説明の固定例（部分対応）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.245–246、SE-Construction 3b コメント・3c 命名に関連する導入。工房の既存デバッグ依頼は状態追跡、リファクタリングは動作と互換性を扱う。旧依頼 555 `style-scroll.js` は集計の名前・コメントと動きを照合するため、関連教材として重複がある。今回の固定例は数量の単位、真偽値の意味、手順の理由、仕様変更後の古い説明と手順の差に焦点を当てる。

参考：[Google 工程指針：命名](https://google.github.io/styleguide/pyguide.html#316-naming)、[コメントの指針](https://google.github.io/styleguide/pyguide.html#38-comments-and-docstrings)。命名・説明には複数の適切な選択肢があり、ここでは提示された候補のうち依頼で与えた条件に最も合うものを選ぶ。固定例は実際のコード編集、自由な名前・コメントの作成や一般的な規約適用・レビューを評価しない。SE 全体の完成を示さない。

実装担当とは別の `review_candidate` が原典、指針、固定例の正答、誤答と保存履歴、分類と開放を確認し、最初の時間の表現が曖昧である点を指摘した。出発までの時間と単位を明記する修正後に再確認し、関連６テストが成功した。一般的な記述能力を評価したものではなく、レビュー担当はブラウザを操作していない。

`scripts/endgame-instructions.playwright.js` は集いと４地域の達成状態を用意した検証用記録から、213・390・1200 px 幅で分類経由の到達、キーボード操作、誤答案内、途中保存・再開、段階開放と達成後の再開を確認した。新規開始からこの依頼への通し操作、実際のスクリーンリーダー音声や利用者による面白さの評価は未確認。
