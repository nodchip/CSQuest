# 分母照合：SEP-IP

[CS2023 印字 pp.277–278](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=277) と[候補台帳](coverage-sep-ip.md)を 2026-11-10 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core トピック 1〜5 は知的財産権、無形のデジタル知的財産、法的基礎、代表的ソフトウェアライセンス、剽窃と著作者。KA Core 6〜12 は哲学的基礎、著作権・特許・営業秘密・商標と保護する権利、フェアユース・first sale を含む制限、執行に関わる法と条約、海賊版と DRM 等の技術的保護、オープンソース運動の道徳・法的基礎、他者のデータを用いるシステム。番号付き子はなく、12 行の番号・区分を確認した。原典は法制度が地域によって異なることを説明しており、特定法域の制度を普遍化しない。

CS Core 成果 1〜8 はデジタル著作権侵害への法令・判例の説明と批評、無形のデジタル財産の例、ライセンス選択、著作物の合法的・倫理的利用の擁護、ライセンス解釈、fair use の議論、剽窃検出の倫理、言換え・著者偽装・不適切な出典等の特定。KA Core 9〜17 は哲学的基礎、ソフトウェア特許の対立、4 種の保護・義務、適切な文脈での法的保護の理由、fair use と first sale、オープンソースと修理する権利等への影響、海賊版の国際性、DRM を複数の関係者の視点で批評、回避禁止法の議論。17 行をトピックと別に追跡する。

台帳中の番号付き依頼は旧教材で、現行冒険への到達を示さない。現行冒険の SEP-IP 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。法域別の判断、実際の分析、自由な批評や説明は固定例だけで評価しない。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
