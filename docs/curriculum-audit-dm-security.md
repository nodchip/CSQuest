# 分母照合：DM-Security

[CS2023 印字 p.121](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の DM-Security と[台帳](coverage-dm-security.md)を2026-11-04に照合した。

トピック10件（1〜10）と学習成果５件（1〜5）を追跡する。括弧内の例は各項目の範囲に含める。原典では成果５の未知データの探索もこの単位に列挙されており、DM-Analytics の類似成果とは別の原典上の成果として残す。

トピック１〜４と成果１〜３は CS Core、トピック５〜８と成果４・５は KA Core、トピック９・10は Non-core。分母の照合は教材や実際の安全性の完成を保証しない。
