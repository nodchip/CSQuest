# 完成率の分母の照合：FPL-Scripting

[CS2023 印字 pp.133–134（PDF 133〜134ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の FPL-Scripting と[項目別台帳](coverage-fpl-scripting.md)を2026-11-05に照合した。トピックと例示学習成果はいずれも CS Core。

原典３はシステムコマンド、３a は OS との接点を挙げる。台帳では双方を「システムコマンドと OS との接点」の１行で追跡し、重複を避けて１件と数える。候補 ID を機械的に扱えるよう、従来の `3・3a` を `3` に変更した。両方の内容は同じ行の要約に残す。原典の区分を明確にするため、全行に CS Core 列を追加した。

トピックの分母候補は９件（１〜９）、例示学習成果は２件（１・２）。これは範囲と区分の照合であり、各教材の正確性や分野の完成を意味しない。実際のスクリプト記述・実行は行わず、代替操作とその限界を別途評価する。
