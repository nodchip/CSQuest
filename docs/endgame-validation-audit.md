# 仕立て屋の試験と仕様の依頼

CS2023 SE-Validation（印字246–248ページ）を参照。袋の受付条件を０〜４個の札で試し、規定の境界で試作品が１個を拒む不具合と４個を受け付ける不具合を調べる。試した履歴の任意の札を報告でき、複数例の一致は全入力の正しさの証明としない。

別の依頼では指定された整数１〜４個について、旅人の希望・書かれた仕様・道具の動きを比べる。仕様に照らす検証と、目的に照らす妥当性確認の違いを扱う。架空の希望と固定例であり、実際の利用者調査ではない。

２件達成後の依頼では、仕様変更による４個の受付を予定された変更、３個の拒否を既存動作の崩れとして区別する。修正版の０・３・４・５個を確かめるが、他の入力の正しさは証明しない。実コードの変更や一般の互換性・回帰試験の全体は未対応。

独立レビューで原典、期待値、不一致報告、結果と試行前後の文言を確認し、過去の報告対象の選択、結果の振り返り、未試行時の表現を修正・再確認した。`tests/endgame-validation.test.js` と `scripts/endgame-validation.playwright.js` は誤答、途中保存と再開、別々の２件による応用の開放、達成を検証する。実際のスクリーンリーダー音声は未検証。
