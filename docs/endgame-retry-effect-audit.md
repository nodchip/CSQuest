# 再送した依頼の効果：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字220〜222頁 PDC-Communication 5b の冪等性・再試行に関連する固定例。現行の塔の通信路の番号付き重複排除と異なり、ここではアプリケーションが依頼を受け取った後の効果を比較する。
- [RFC 9110 §9.2.2](https://www.rfc-editor.org/rfc/rfc9110.html#section-9.2.2) は、同じ要求を繰り返したときの意図された効果が１回と同じである性質と、別の記録や返事は同一とは限らないことを説明する。ここは HTTP 自体の実行ではない。
- 固定例は初回依頼が処理された後に返事だけ消え、同じ依頼の再送と返事が届く。点灯状態の設定は２回でも点灯、無条件の加算は０→１→２。番号Ｋを保持する単一の動作中の塔は２度受信するが同じ番号の加算を再適用せず１に保つ。
- 一般に返事なしだけでは初回処理の有無は不明。要求効果と受信回数・応答・別の副作用は別であり、番号を使う固定模型は再起動・記録消失・同時到着・異なる内容での番号再利用や一般の一度だけの実行を保証しない。実通信・実 API・自由な設計は未評価。
