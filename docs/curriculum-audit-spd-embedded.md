# 完成率の分母の照合：SPD-Embedded

[CS2023 印字 pp.305–306（PDF 305〜306ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の SPD-Embedded と[項目別台帳](coverage-spd-embedded.md)を2026-11-05に照合した。トピック・例示学習成果はいずれも KA Core。

原典１の本文には組込みシステム固有の特徴の導入があり、２つの子項目だけでは全体の導入を追跡できないため、`1-本体` を追加した。原典５の本文にはハードとソフトのリアルタイムシステム自体の比較があり、子項目５aの適時性とは区別して `5-本体` を追加した。５a の要約は原典の適時性に合わせた。両本体の教材を確認したところ、1325 の組込み機器の固定例と 760 のハード・ソフト・期限なしの分類が対応するため、いずれも部分と記録した。

２・３・７は子項目を束ねる見出しとして扱い、子を数える。４、６、８〜11は子を持たない独立項目として数える。例は該当項目の範囲に含め、別項目には数えない。

トピックの分母候補は30件（1-本体・1a〜1b、2a〜2c、3a〜3h、4、5-本体・5a〜5e、6、7a〜7d、8〜11）。例示学習成果は10件（1〜10）。

これは原典との範囲・区分の照合であり、各教材の内容や正答の検証、分野全体の完成を意味しない。実機の設計・実装や自由な説明を求める成果は、固定模型による代替とその限界を別途評価する必要がある。
