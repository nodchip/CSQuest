# 分母照合：SEC-Crypto

[CS2023 印字 pp.260–261](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=260) と[候補台帳](coverage-sec-crypto.md)を 2026-11-11 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core トピック 1〜7 は暗号の観点、数学的基礎、共通鍵・公開鍵、暗号部品、古典暗号、ケルクホフスの原理と検証されたライブラリ、現実への応用。KA Core 8〜11 は追加の数学、共通鍵、公開鍵、完全性・認証。原典 12〜15 はそれぞれ暗号プロトコル、攻撃者の能力、量子・耐量子暗号、ブロックチェーンと暗号資産を列挙する。台帳の 12a〜12g・13a〜13d・14a〜14b・15a〜15b は**原典に番号付き子のない列挙を個別に追跡する便宜上の候補**であり、親の総合的な範囲を保持し、独立した原典番号として重複集計しない。例を追跡することは原典が各例をすべて必修とする意味ではない。トピック台帳は 26 行。

CS Core 成果 1〜4 は安全性とプライバシーでの暗号の役割、独自暗号の危険、素数の重要性、古典暗号の実装と解析。KA Core 5〜12 は鍵管理、性能比較、共通鍵・公開鍵の方式と解析、安全性比較、鍵交換と失敗の緩和、部品・プロトコルの応用、量子暗号と量子計算の影響。成果 12 行を別に追跡する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行の中継塔には AES-GCM・SHA-256 と改変検出の一部評価があるが、一般的な安全性・鍵管理・実装能力の達成を意味しない。各現行行の到達・正確性・操作・保存・独立レビューは別途確認する。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
