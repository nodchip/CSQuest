# 庭の灯り絵の依頼

CS2023 GIT-Fundamentals（印字ページ155–156）の解像度・縦横比に関連する固定模型。横8・縦4の比率を持つ図形見本を中央配置し、全体表示・切り抜き・縦横別の伸縮を切り替える。4×2と4×4の枠では、全体・余白・形をそれぞれ独立に判断する。

別の依頼では、同じ表示幅の4×2と8×4の格子に１画素幅の線を描いて比べる。画素数だけで画質が保証されるわけではなく、拡大で元の情報が自動的に増えるわけでもない。選択肢から行と列を指定する大きな操作も用意する。

独立レビューで寸法、切り抜きや余白、画素の比較条件を確認。滑らかな見本を画素画像と説明しないよう修正し、大きな操作の結果を通知するようにした。`tests/endgame-image.test.js` は枠の性質と訂正、`scripts/endgame-image.playwright.js` は誤答、描画、復元、比較の同じ表示幅、達成を複数の画面幅で検証する。

この依頼は解像度と縦横比の一例であり、実画像の標本化・量子化、補間、色、ディスプレイの物理的な画素密度、一般的な画質評価の全体は未対応。実スクリーンリーダーを使った確認も未実施。

## 消えた星を探す

基礎２依頼の後に開く。4×4 の離散画像を各2×2区画の左上だけを残して2×2に縮め、それぞれを2×2に複製して4×4に広げる模型。プレイヤーは残す画素を選び、拡大は一操作で行う。異なる２枚が同じ白い縮小結果になる例と、紫一色が元どおりになる例を比べる。元の控えなど追加情報がある場合も明示し、すべての画像が復元不能とは言わない。

原典 GIT-Fundamentals の5b・5cと成果10に関連する部分的な例。独立レビューで座標、複製、文章、開放条件を確認。`tests/endgame-resample.test.js` と `scripts/endgame-resample.playwright.js` は誤選択の訂正、保存、各画像の結果、基礎２件による開放と達成を検証する。連続信号、アンチエイリアス、量子化や再標本化の一般理論、実画像の品質は未対応。
