# 分母照合：DM-Core

[CS2023 印字 pp.115–116](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf)の DM-Core と[台帳](coverage-dm-core.md)を2026-11-04に照合した。原典に親子構造はなく、トピック12件（CS Core １〜11、KA Core 12）、例示学習成果９件（CS Core １〜９）をそれぞれ追跡する。括弧内の例は項目を説明する例であり別の分母としない。

分母照合は教材全体の完成を保証しない。完成と記録された学習成果６および関連するトピック５の検証範囲は[項目別評価](curriculum-assessment-dm-data-core.md)に記録する。他の項目の完成判定はこの照合では行っていない。
