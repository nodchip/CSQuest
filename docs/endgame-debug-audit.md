# 工房の数え装置とデバッグ

[CS2023 SDF-Practices、印字232〜233ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=232) の開発環境とデバッグ、および SDF-Fundamentals の実行追跡に関わる固定模型。赤だけを数えるはずの装置が全色を数える不具合について、一手ずつ状態と期待値を比較し、途中停止の直前・直後を調べる。応用では条件を選び直し、通常入力・青のみ・空入力を試す。

実際の IDE やプログラミング言語の操作、一般の不具合発見・修正、自由な説明は評価しない。３例の成功だけで全入力の正しさは証明できないことも画面に表示する。該当項目は部分対応である。

実装担当とは別の coverage_next が原典、実行状態、停止位置、修正と検証、保存・開放を確認し、修理前を指す文章と有限の試験の限界を指摘した。修正後に再確認した。独立担当によるブラウザ操作は行っていない。`tests/endgame-debug.test.js` は初めての不一致・停止前後・条件変更・空入力を検証する。`scripts/endgame-debug.playwright.js` は集いと４地域の達成状態を用意した記録から、誤操作、保存・再開、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
