# 鍛冶街の手元の記憶棚

[CS2023 AR-Memory（印字104〜105ページ）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の CS Core 1、5、5a〜5c に関連する、２枠・空から始まる読取り専用の固定模型。番地とブロック、直接対応、完全連想と LRU、時間・空間局所性の例を操作する。完全連想で複数の空枠があるときは小さい番号から使うのは本模型の規則。二つの基礎依頼の達成後、同じ容量・幅・参照列で配置方法を比較する依頼が開く。

同じ番地を再利用した後の LRU 更新、近接番地のブロック共有、競合する番地による直接対応と完全連想の違いを検証した。局所性は傾向で、ヒットや高速化を保証しない。固定例は一般のキャッシュ設計、他の置換方式、書込み方式、先読み、階層全体や実機での時間・性能を扱わず、項目は部分対応である。

実装担当と別の coverage_next が原典、模型の方式と期待結果、画面の説明、自足性、誤操作、保存と開放をコード上で独立確認した。独立担当自身のブラウザー操作は行っていない。`tests/endgame-cache.test.js` は実装と別に期待値を定め、ヒット後の置換や誤りを検証する。`scripts/endgame-cache.playwright.js` は物語と４地域の達成状態を用意した別ブラウザー記録から、誤操作、途中保存、再挑戦、段階の開放、完了を検証する。実際のスクリーンリーダー音声は未確認。
