# HCI-Evaluation の対応状況

出典: [CS2023, HCI-Evaluation](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 178–179。原典を要約した作業用一覧。依頼60の架空の記録は実際の利用者調査を実施したことを意味しない。

## トピック

| 番号 | 分類 | 要約 | 現状 |
|---:|---|---|---|
| 1 | CS Core | 利用者による形成的・総括的な評価、対象、研究上の倫理 | 依頼60で形成的評価と観察、依頼532で架空の共有同意と保存期限を例示。実際の倫理審査や総括的評価の実施は未対応 |
| 2 | KA Core | 質的・量的・混合の方法、利用者中心の試験、ヒューリスティック評価、標本と一般化 | 架空４人の時間と観察を比較し、一般化の限界を扱う。分析手法や実際の参加者による評価は未対応 |
| 3 | KA Core | 目的、仮説、倫理審査、事前登録、被験者内・被験者間の計画 | 依頼530で測定・人数・分析を選び変更を明示。依頼531で順序効果、依頼533で被験者間・被験者内の参加者割当を比較。倫理審査や一般の実験計画・影響の評価は未対応 |
| 4 | KA Core | 環境・社会・安全性・プライバシーなどへの影響 | 未着手 |
| 5 | Non-core | 統計分析と可視化、効果量 | 依頼529で対応のある架空４人の平均差と条件付きの厳密な置換検定を比較。一般の検定や標準化効果量は未対応 |
| 6 | Non-core | データの保存・共有、機微性と識別可能性 | 依頼532で架空の同意範囲、元記録の閲覧、期限と集計候補を比較。実データの管理や匿名性評価は未対応 |

## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | CS Core | 形成的評価と総括的評価の違いと役割を議論 | 依頼60で試作品の改善に用いる例と違いを提示。自由な議論は未対応 |
| 2 | KA Core | 設計の段階に合う評価方法を選択 | 試作品の固定例のみ。多様な段階と方法は未対応 |
| 3 | KA Core | 質的・量的な方法を併用する利点を議論 | 時間の平均と操作の観察を比較。自由な議論や体系的な質的分析は未対応 |
| 4 | KA Core | 設計の広い影響を評価 | 未着手 |
| 5 | KA Core | 目的・仮説・研究設計を正当化して評価を計画 | 依頼530・531・533で固定候補から計画、試す順序と参加者の割当を選ぶ。実際の研究計画の作成と倫理審査は未対応 |
| 6 | KA Core | 利用者評価を実施し、研究設計に見合う結論を出す | 架空の小標本から限定的な結論を選ぶ例。実際の評価の実施は未対応 |
| 7 | Non-core | 統計検定の選択と実施 | 依頼529で対応のある固定４組の両側置換検定を操作。一般の検定選択・実データは未対応 |
| 8 | Non-core | 統計計画を含む研究の事前登録 | 依頼530で候補から計画を封じ、記録後の分析変更と明示を操作。実際の登録・研究計画の記述は未対応 |

４人は架空であり、時間と観察は教材用の固定値。２種類の実施順序を同数にしても、順序や練習の影響を完全には排除できない。結果を一般化したり、観察だけから原因を証明したりしない。

依頼529は４人が両案を試す架空の２記録を扱う。各人の組内の向きが独立・等確率で入れ替わる帰無模型を仮定し、差の合計の絶対値が観測値以上の16組を数える。実験順序の影響や無作為化の妥当性は実験次第であり、この模型が実際のデータに適用できることは保証しない。

依頼530は時間差・４人・両側検定の計画を仮に封じ、架空の４件を見た後の片側への変更を明示する。差の向きの独立・等確率の入れ替えを仮定した模型で、外部登録や実際の倫理審査は行わない。

依頼531は案内板自体の難しさが同じで、全員が２回目に４秒速くなると仮定した架空の４人の記録。全員Ａ→Ｂでは平均差４秒、２人ずつの逆順では平均差０秒となる。この条件での相殺を示すもので、実験順序の均衡だけであらゆる交絡や持ち越しを除けるとは主張しない。

依頼532は架空の３人のうち集計共有に同意した２人だけを候補に含め、元記録のアクセス・期限と２時点を比較する。集計候補は終了時に作成して期限後も保持するという固定の仮定であり、少人数集計の安全性、実際の同意取得、保管・削除や倫理審査を保証しない。

依頼533は４人の時間を14・18・30・34秒とし、同じ人にはＡもＢも同時間、順序効果なしと仮定する。速い２人をＢ、遅い２人をＡに分けた場合と、全員が両方を試す場合の平均を比べる。実際の参加者、割当の無作為化、順序・疲労・持ち越しや統計的推論は扱わない。
