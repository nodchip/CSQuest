# 庭園の二本の光：照合記録

[CS2023 印字191–192頁 MSF-Linear](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 4 は生成・線形独立と基底を扱う。[MIT の一次教材](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/0bbc30e3f1d7933ea07a2d2e9ab050d9_MIT18_06SCF11_Ses1.9sum.pdf)を参照。旧依頼297 `src/vector-span.js` を現行冒険へ再利用し、新たな範囲達成を主張しない。

u=(1,0), v=(0,1) なら 2u+v=(2,1) で零になる係数は共に０のみ。u=(1,1), v=(2,2) なら 2u=v=(2,2)、2u−v=0 で一次従属。任意の実数 a,b に対し au+bv=(a+2b,a+2b) なので (1,0) は作れない。画面の有限候補を試しただけで不可能とは結論せず一般の式を示す。固定例は任意の空間や自由な計算・証明を評価しない。
