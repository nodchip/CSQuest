# GIT-Physical: 物理コンピューティング

参照：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.164–165。固定模型を操作する体験と、現実の回路やプログラムを作成する学習成果を区別します。

依頼220の閾値と揺れの比較は、[Texas Instruments, Understanding Schmitt Triggers](https://www.ti.com/document-viewer/lit/html/scea046) のヒステリシスとノイズに関する説明を参考にした離散値の固定模型です。実際の電子回路や特定部品の特性を再現するものではありません。

依頼221・222は、[Analog Devices, Analog to Digital Conversion](https://wiki.analog.com/university/courses/electronics/text/chapter-20) の標本化・有限の出力値の説明を参考にした固定模型です。依頼221で４以上を最大の印に丸める振る舞いはこの模型の規則であり、実機の範囲外入力の挙動や安全性を示すものではありません。依頼222は５つの離散時刻を扱い、連続時間の再構成を評価しません。
