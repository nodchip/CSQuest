# 分母照合：FPL-Logic

## トピック

KA Core 1〜8：全称・存在量化、一階・高階論理、論理結合子と単純な関係による複合関係、Horn 節・事実・目標・副目標、単一化とそのアルゴリズムおよび表明・式評価との比較、関係と関数の混合、カット・バックトラック・非決定性、閉世界・開世界の仮定。

Non-core 9〜14：反復処理に伴う変数コピーの記憶負荷、部分計算の保存と探索木の枝刈り、等式論理・ナローイング・待機・意味的単一化を使う関数型との統合、高階・制約・帰納論理プログラミング、オブジェクト指向など他パラダイムとの統合、差分リスト・利用者定義データ構造・集合取得などの発展的構造。

原典のトピックは 1〜14 がそれぞれ独立した番号で、別番号の子項目はない。各項目内の列挙や括弧内の例を、それぞれ別の番号として重複計上しない。

## 例示学習成果

KA Core 1〜5：論理言語で通常のアルゴリズムを実装する、節・関係・カットの暗黙探索を用いるアルゴリズムを論理言語で実装する、一階述語論理と Horn 節の対応を例示する、単一化のアルゴリズムと問い合わせ簡約における引数渡しを例示する、関係・関数・再帰を交える論理プログラムについて単一化とバックトラックによる実行・引数渡しを例示する。原典は最後の成果の例として階乗・フィボナッチや主体間の関係を挙げる。

Non-core 6：フィボナッチなどの単純なプログラムを例に再計算の負荷と実行負荷の改善を示す。

トピック 14 件と成果 6 件は別々に追跡する。台帳の番号・区分と照合し、原典の例を項目全体の代わりとはしない。
