# 工房の札と箱で再帰を追う

[CS2023 SDF-Fundamentals、印字230〜231ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=230) の再帰と制御の流れに関連する固定模型。空列は０、空でない列は先頭と残りの合計を足す手順を、呼出しと戻りを表示して操作する。有限で循環しない箱では札を１、空箱を０とし、すべての子の結果を加える。別の依頼では空の場合と残りへ進む規則を修理し、３つの列を試す。

この例では各呼出しで列が短くなるか有限な箱の子へ進む。基底条件だけでは停止は保証されず、同じ入力を呼び続ける規則では該当入力が繰り返される。有限回の試験は全入力の正しさの証明ではない。[MIT の再帰教材](https://ocw.mit.edu/ans7870/6/6.005/s16/classes/10-recursion/index.html) も参照した。固定の操作例であり、実言語での関数の設計・記述、任意の入力や環境のスタック制限、一般の停止性・性能は未評価である。関連項目は部分対応である。

実装担当と別の coverage_next が原典、空列と復帰、全枝と空箱、進捗しない呼出し、誤操作と保存・開放をコード上で確認した。独立担当自身のブラウザー操作は行っていない。`tests/endgame-recursion.test.js` は戻り値、全枝、空列と進まない列を検証し、`scripts/endgame-recursion.playwright.js` は集いと４地域の達成状態を用意した記録から誤操作、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
