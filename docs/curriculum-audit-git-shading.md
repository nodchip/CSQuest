# 分母照合：GIT-Shading

[CS2023 印字 pp.159–160](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=159) と[候補台帳](coverage-git-shading.md)を 2026-11-10 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

すべて KA Core。原典トピック 1 はレンダリング方程式の解と近似、その例の 1a〜1d は分布レイトレーシング・パストレーシング、フォトンマッピング、双方向パストレーシング、メトロポリス光輸送である。例を個別追跡するが、これらのみで親全体を尽くすとはしない。原典 2 は時間・レンズ位置・連続周波数がレンダリングに及ぼす影響という一つの番号であり、台帳の 2a〜2c は便宜上の分割候補である。**原典に 2a〜2c の子番号はない**ため、同一の原典 2 を三つの独立番号として重複計上しない。原典の 3〜13 は順にシャドウマッピング、遮蔽カリング、BSDF とマイクロファセット、表面下散乱、面光源、階層的深度バッファ、画像ベース描画、非写実的描画、リアルタイム描画、GPU、視覚の順応・ノイズ感度・ちらつき融合。台帳の 18 行は親の範囲と例・分割として対応する。

成果 1〜8 はレンダリング方程式の推定、完全性・一致性・不偏性等の議論、帯域と計算量の分析、描画 API によるシェーディングの実装、芸術技法の実装方法、画像に用いた技法の識別、画素単位での実装、BRDF・反射・屈折を用いたレイトレーサーの作成。すべて KA Core で、8 行の番号・区分を確認した。

台帳中の番号付き依頼は旧教材の記録で、現行冒険への到達を示さない。現行冒険の GIT-Shading 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実描画 API・実レンダラー・一般の推定・自由な説明や実装は固定模型だけで評価しない。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
