# 分かれる門の状態：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字93〜95頁の AL-Models（有限オートマトンと非決定性）に関連する固定例。旧依頼561 `src/subset-automaton.js` の機械を使い、現行の関所で複数の到達状態と入力終了後の受理を操作する。現行の合図機は１状態ずつ遷移する決定的な例である。
- [Cornell の NFA 講義](https://www.cs.cornell.edu/courses/cs6861/2024sp/Handouts/ACLec2-6.pdf) は、入力をすべて読んだ後に少なくとも１経路が受理状態に到達すれば受理することを説明する。
- 初期Ａ、受理Ｃ、ε 遷移なし。Ａは赤→Ａ・Ｂ、青→Ａ、Ｂは青→Ｃ（赤は行き先なし）、Ｃは両方とも行き先なし。赤は {Ａ,Ｂ} で不受理、赤青は {Ａ,Ｃ} で受理、赤青赤は {Ａ,Ｂ} で不受理。全経路の受理は不要。
- 空集合から次の記号を読んでも空集合だが、初期Ａが両記号で自身に遷移するため出題３語から空集合へ到達せず、空集合の実操作は未評価。固定の３語と機械であり、任意の NFA・ε 遷移・一般の部分集合構成や等価性の証明・実装を評価しない。旧教材・本教材の存在を原典全体の完成としない。

2026-11-11、実装担当と別の `signed_review` が原典と Cornell の NFA 講義に照らし、固定機械の遷移の合併・受理条件・画面・保存・開放を独立レビューした。出題語から空集合へ到達しない限界も確認した。親担当が準備済み記録から幅 213・390・1200 px の関所の分類に到達し、誤答、キーボード、途中保存・再開、開放条件、達成後の保存をブラウザ確認した。新規開始からの通し操作、スクリーンリーダー音声、利用者による面白さは未確認。
