# AR-Organization: 機能構成

参照：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) p.106。依頼158は、取出し・値の読取り・実行と書込みの３段階を持つ簡略化した機械で、後の命令が前の結果を使う固定例です。対策なし、１拍の待機、実行結果の転送を比べます。ステージ構成や転送経路は実機一般を表すものではありません。

| KA Core トピック | 対応と不足 |
| --- | --- |
| 1 単純なデータパス、パイプライン、ハザードの検出と待機・転送等による解決 | 依頼158で１つのデータ依存と２つの対策を操作。一般のデータパス設計、他のハザードは未対応 |
| 2 固定回路・マイクロプログラムによる制御 | 依頼73で架空の取出し・解読・実行の順序を操作。制御装置の実装は未対応 |
| 3 命令パイプライン | 依頼158で３段階の固定例。実機の段階構成・メモリアクセス・分岐は未対応 |
| 4 命令レベル並列性 | 依頼158で命令の段階を重ねる例。一般的な並列性と制約は未対応 |

| KA Core 例示学習成果 | 対応と不足 |
| --- | --- |
| 1 データパスの代替実装を比較 | 依頼158で待機・転送を固定例で比較。実際の複数のデータパス構成は未対応 |
| 2 整数加算に必要な制御信号を２方式で作る | 未対応 |
| 3 パイプラインとハザードを使って命令レベル並列性を論じる | 依頼158でデータ依存の一例。一般のハザードや自由な説明能力の評価は未対応 |
| 4 データパスと制御を含むプロセッサを設計 | 依頼1229で固定計算路の入力・書戻し・書込み制御を４命令で選択。自由な回路設計、取出しや分岐は未対応 |
| 5 所定の実装について平均 CPI を計算 | 依頼158は２命令の拍数を比較。一般の命令列・メモリ系・平均 CPI は未対応 |
