# 分母照合：SPD-SEP/Mobile

[CS2023 最終報告書 印字 pp.309–310](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=309) の SPD-SEP/Mobile と[候補台帳](coverage-spd-sep-mobile.md)を 2026-11-10 に照合した。これは原典項目の範囲と区分の照合であり、教材の完成・正確性、操作と保存、独立レビューを証明しない。

## トピック

すべて Non-core の 5 件：1 はプライバシーとデータ保護、2 はモバイル設計のアクセシビリティ、3 はセキュリティとサイバーセキュリティ、4 はモバイル技術の社会的影響、5 は AI とアルゴリズムの倫理的利用。番号 1〜5 は独立し、原典に番号付き子項目はない。

## 例示学習成果

すべて Non-core の 5 件：1 はモバイルアプリにおける利用者のプライバシーとデータ保護を守る倫理的責任の理解と遵守、2 は障害のある人が効果的に利用できるモバイルアプリの設計、3 はモバイル開発における各種の脅威を軽減する安全なコーディングの実践、4 は通信の仕方・人間関係・精神的健康を含む社会的影響の分析、5 はモバイルアプリでの AI 利用に関する倫理的配慮と偏りのない公平なアルゴリズムの理解。

トピック 5 件と成果 5 件を別々に追跡する。番号・区分は候補台帳と一致し、親子の重複はない。原典の目標は実際の設計や実践を含み、限定的な操作だけで一般的な公平性・安全性・アクセシビリティを保証したとは判定しない。

## 現行の冒険との区別

台帳中の番号付き依頼は旧教材の記録で、この原典照合だけでは現行の冒険からの到達・操作を確認したことにならない。現行の冒険に関する SPD-SEP/Mobile の項目別評価は、この記録時点では未作成である。未作成は教材不存在の証明ではない。実際の開発、障害のある利用者による評価、社会的影響の調査と自由な説明は固定例だけで直接評価したとは扱わず、代替体験と残る範囲を別途確認する。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・文脈と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
