# SF-Overview：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.292–293。全項目は CS Core で Non-core は列挙されていない。[追跡方法](coverage-status.md)の「部分」は限定例、「未照合」は対応の十分性が未確認であることを示す。実コードの記述と自由記述の能力は直接評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | CS Core | ゲート、記憶、接続、データ経路、制御など | 部分 | 依頼06・37の回路、73の命令処理、265の記憶。部品全体の統合は未評価。 |
| 2 | CS Core | 論理部品、論理式の簡単化、積和形 | 部分 | 依頼06で指定回路を構築。一般の簡単化と積和形は未評価。 |
| 3 | CS Core | プログラミング抽象化、インターフェース、ライブラリ | 部分 | 依頼518で道具の呼出しと枠組みへの登録を比較。一般の抽象化、API 設計や実ライブラリの利用は未評価。 |
| 4 | CS Core | アプリと OS サービスの連携、遠隔手続き呼出し | 部分 | 依頼54の装置への要求は固定例。遠隔手続き呼出しや一般の連携は未評価。 |
| 5 | CS Core | パイプラインと段階の重なり | 部分 | 依頼158の３段階と依存の模型。一般の解析と実機は未評価。 |
| 6 | CS Core | 規模と性能のスケーリング | 部分 | 依頼437で固定量と一人あたり固定の規模を比較。一般の性能や実測は未評価。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | CS Core | 計算機の基本部品と歴史を説明 | 部分 | 回路と記憶の固定例がある。歴史全体と自由な説明は未評価。 |
| 2 | CS Core | 基本部品から単純な論理回路を設計 | 部分 | 依頼06・37で指定回路と加算器を構築。任意の設計は未評価。 |
| 3 | CS Core | 層の境界と詳細の隠蔽を説明 | 部分 | 依頼54でアプリと装置への要求を扱う。一般の階層や自由な説明は未評価。 |
| 4 | CS Core | ハードウェア・OS・VM・アプリの階層を説明 | 部分 | 依頼54・135は異なる一部の境界を扱う。全階層の連携は未評価。 |
| 5 | CS Core | 階層間の誤りの検出・通知・処理を説明 | 部分 | 依頼200で失敗の固定例を扱う。一般の層間伝播は未評価。 |
| 6 | CS Core | 階層化と誤り処理を使うプログラムを構築 | 未照合 | 対応する代替体験の十分性は未確認。実コードの記述は対象外。 |
| 7 | CS Core | トレース等で階層化プログラムの不具合を特定 | 部分 | 依頼247は固定記録の照合。実際のデバッグツールは評価しない。 |
| 8 | CS Core | 強・弱スケーリングの違いを理解 | 部分 | 依頼437で４人数・２仕事量の模型を比較。実測や一般の分析は未評価。 |

依頼437の前提・数値は [PDC-Evaluation](pdc-evaluation.md)、依頼135は [OS-Virtualization](os-virtualization.md) を参照。固定例のテストは原典項目全体の検証を意味しない。
