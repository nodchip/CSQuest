# 原典との範囲照合：GIT-Visualization

[CS2023 印字 pp.156–157](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の GIT-Visualization を [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)と照合した。全トピックと例示学習成果は KA Core。台帳に欠けていた区分列と、技法・パイプライン・高次元データ・知覚と認知・設計と評価の親５行を追加した。トピック25行、成果７行には親子の重複があるため、行数を独立項目数や完成率として扱わない。

原典のトピック１は科学データの可視化と情報可視化、成果１はデータ可視化と情報可視化の比較と表現されている。台帳はこの違いを保持し、体系的な比較は未照合とする。３cのパン・ズーム・選択、６cのゲシュタルトによる群化、成果３の精度と性能、成果６の有用性評価手順、成果７の応用例の体系的比較などは、既存の限定的な例では満たしたと判断しない。

これは項目の範囲と区分の照合であり、各教材の正確性、実利用者による評価、自由な実装や設計能力、教材全体の完成を証明しない。

同日、依頼111に近さと類似の手がかりを比較する固定例を追加し、６cを部分対応とした。その他の原則や利用者ごとの知覚は未評価。

同日、依頼111に固定時系列の間引きによる表示点数と最大値の比較を追加し、成果３を部分対応とした。実行速度や一般の可視化手法の性能は未評価。

同日、依頼60に可視化の比較目的に沿った評価計画の選択を追加し、成果６を部分対応とした。実際の調査や自由な計画立案は未評価。

同日、依頼1162に位置を持つ風と村別集計の対応の比較を追加し、成果１を部分対応とした。両領域の厳密な区分や自由な説明は評価しない。

同日、依頼1162に風・医療画像・数学・地理・温度分布の固定目的に合う表示を選ぶ例を追加し、成果７を部分対応とした。実データや幅広い応用は未評価。
