## 教材と正答

命令選択では、整数の入力を２倍して１増やす仕事を２種類の架空機関の札で組む。基本機関の最少枚数は２、組合せ札を持つ機関では１。入力−２・０・３の試行に加え、判定は札の並びを一次式として計算する。[Cornell の命令パターン](https://www.cs.cornell.edu/courses/cs4120/2022sp/notes/tiles/)を参考とする。

並べ替えは１刻１枚発行、各読取りの２刻後から結果を使える固定模型。１・２刻目に読取り、３刻目に独立した札、４刻目に足し算を出せる。読取りの直後に依存する足し算を出す操作は拒む。これは発行に必要な刻数であり、完了時間や実 CPU の性能ではない。[Cornell の命令スケジューリングの講義](https://www.cs.cornell.edu/courses/cs4120/2011fa/lectures/lec39-fa11.pdf)を参考とする。

生成 AI の提案を想定した比較は、あらかじめ作った３候補を試す模型である。入力０では一例に合わせた候補Ｂも正しく見えるが、−２・３では期待と異なる。候補Ｃは表示された手順から整数上の仕様と一致する。有限の試験だけで一般の正しさは証明できない。実際の生成 AI は呼び出さず、出力の傾向や品質は評価しない。[GitHub の提案の利用に関する説明](https://docs.github.com/en/copilot/responsible-use/inline-suggestions)も参照。
