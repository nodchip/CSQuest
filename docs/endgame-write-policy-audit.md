# AR-Memory：手元の写しと書込み方式

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.104–105、AR-Memory 5c。旧依頼574 `src/write-policy.js` の１枠・２記録の固定模型を現行の鍛冶街に再利用するため、旧教材と独立の範囲として重複計上しない。現行の `endgame-cache.js` は読取り専用のヒット・ミスであり、書込み方式は扱わない。

棚は空で次段の書庫 A・B は０。先に A を読み込み、棚にある A に１、２を続けて書くため、書込みは両方ヒットし、書込みミス時の割当方式は扱わない。ライトスルーは２回とも次段へ反映するため、追出し前後 A は２、次段への書込みは２回。ライトバックは棚だけ更新し dirty とし、B を読む際に dirty の A を外す前に２を書き戻すため、追出し前 A は０、後は２、書込みは１回。B の読み込みは書込みに数えない。[Cornell のキャッシュ教材](https://courses.cs.cornell.edu/cs3410/2026sp/notes/caches.html) を参照。

書庫はこの模型でキャッシュの次段であり、永続ストレージを意味しない。書込み回数はこの固定列の次段への回数で、実機の遅延・他の割当方針・複数コアの一貫性・障害時の永続性・一般の性能や実装を評価しない。AR-Memory 全体の完成を示さない。
