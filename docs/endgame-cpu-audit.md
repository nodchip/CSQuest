# 鍛冶街の計算道具と命令実行

[CS2023 AR-Assembly、印字103〜104ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=103) の命令取得・解読・実行に関連する架空の計算道具。取得時に次の命令の番地 PC を１進め、解読後に読み込み・加算・条件分岐・表示を実行する。条件分岐は実行時に PC を書き換える。番地４の固定データを変え、同じ命令列の結果も比べる。

１命令１番地、制限のない小さい整数、固定番地の読み取りだけを用いた模型。実際の ISA や機械語、汎用メモリの読み書き、オーバーフロー、割り込み、パイプライン、複数コア、同期や SIMD は扱わない。関連項目は部分対応である。

実装担当と別の coverage_next が原典、PC 更新と各命令、条件の成立・不成立、結果、保存と開放を確認した。独立担当自身のブラウザ操作は行っていない。`tests/endgame-cpu.test.js` は取得時の状態、分岐とデータ変更の結果を検証し、`scripts/endgame-cpu.playwright.js` は集いと４地域の達成状態を用意した記録から、誤操作、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
