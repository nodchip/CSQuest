# FPL-Aspect：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.136。すべて Non-core。[既存調査](fpl-execution-analysis.md#fpl-aspectnon-core)と依頼を照合した。原典に例示学習成果の列挙はない。3 と 4 の子項目を追う。

| 番号 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|
| 1 | アスペクト | 部分 | 323で共通の記録をまとめる固定模型。実際の設計や織込みは未評価。 |
| 2 | ジョインポイント | 部分 | 323で操作実行を節目とする。他の節目や実言語は未評価。 |
| 3a | 実行前のアドバイス | 部分 | 323で実行前の記録を選ぶ。一般のアドバイスは未評価。 |
| 3b | 正常・例外・終了後のアドバイス | 部分 | 323で正常後と失敗を含む終了後を比較。例外時のみの指定は未評価。 |
| 3c | 周囲のアドバイス | 部分 | 324で固定の引出しを実行するか拒否。一般の置換や複数アドバイスは未評価。 |
| 4a | ポイントカット指定子 | 部分 | 323で書込みまたは全操作を選ぶ固定例。実際の指定子や構文は未評価。 |
| 5 | 静的・動的ウィービング | 未照合 | 対応教材を要照合。 |
| 6 | 注釈や IDE などの代替手段 | 未照合 | 対応教材を要照合。 |

323・324は記録が必ず成功し、固定の操作と順序を使う。[AspectJ Programming Guide](https://eclipse.dev/aspectj/doc/latest/progguide/progguide.html)を参考とするが、実際の構文や権限管理の安全性を評価しない。
