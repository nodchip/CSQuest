# FPL-Aspect：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.136。すべて Non-core。[既存調査](fpl-execution-analysis.md#fpl-aspectnon-core)と依頼を照合した。原典に例示学習成果の列挙はない。３の子項目と、４の本体・子項目を追う。

| 番号 | 区分 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | Non-core | アスペクト | 部分 | 323で共通の記録をまとめる固定模型。実際の設計や織込みは未評価。 |
| 2 | Non-core | ジョインポイント | 部分 | 323で操作実行を節目とする。他の節目や実言語は未評価。 |
| 3a | Non-core | 実行前のアドバイス | 部分 | 323で実行前の記録を選ぶ。一般のアドバイスは未評価。 |
| 3b | Non-core | 正常・例外・終了後のアドバイス | 部分 | 323で正常後、例外後、どちらでも実行する終了後を比較。例外の型や実言語での指定は未評価。 |
| 3c | Non-core | 周囲のアドバイス | 部分 | 324で固定の引出しを実行するか拒否。一般の置換や複数アドバイスは未評価。 |
| 4-本体 | Non-core | ポイントカット | 部分 | 323で選んだ操作の節目に記録を適用。一般の節目の集合と実言語は未評価。 |
| 4a | Non-core | ポイントカット指定子 | 部分 | 323で書込みまたは全操作を選ぶ固定例。実際の指定子や構文は未評価。 |
| 5 | Non-core | 静的・動的ウィービング | 部分 | 1247で準備時・読込み時・実行中の織込みと、既存の処理の有効化を固定模型で比較。実処理系や一般的な実装は未評価。 |
| 6 | Non-core | 注釈や IDE などの代替手段 | 部分 | 1248で手作業と注釈を読む生成ツールの固定模型を比較。実言語の注釈処理や IDE は未評価。 |

323・324は記録が必ず成功し、固定の操作と順序を使う。[AspectJ Programming Guide](https://eclipse.dev/aspectj/doc/latest/progguide/progguide.html)を参考とするが、実際の構文や権限管理の安全性を評価しない。

1247は [AspectJ の読込み時織込みの説明](https://eclipse.dev/aspectj/doc/released/devguide/ltw.html)を参考に、読込み時と、読込み済みの実行中への織込み、あらかじめ組み込んだ処理の有効化を区別する架空の４方式を扱う。`tests/aspect-weaving.test.js` は各段階の組込み状態と２回の更新・途中復元を検査する。実際の AspectJ に実行中の新規織込みが備わると主張せず、実処理系、進行中の呼出し、性能や複数アスペクトの順序は評価しない。

1248は [Oracle の注釈の説明](https://docs.oracle.com/javase/tutorial/java/annotations/)を参考に、目印から記録付きの包みを生成する架空のツールと手作業を比較する。`tests/annotation-ledger.test.js` は生成前・生成後・目印追加後・再生成後の結果と復元を検査する。注釈そのものが直接動作を変更するとは扱わず、実際の言語・注釈処理・IDE・性能は評価しない。
