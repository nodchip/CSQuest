# DM-Internals の対応状況

出典: [CS2023 DM-Internals](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 119–120。原典を要約した作業用一覧。依頼35はトランザクションの原子性と永続性の固定例であり、実際の DBMS の実装や運用を評価しない。

## トピック

| 番号 | 分類 | 内容と現状 |
|---:|---|---|
| 1 | KA Core | DB のバッファ管理 | 未着手 |
| 2 | KA Core | トランザクション管理：分離水準、ACID、直列化可能性、分散トランザクション | 依頼35で原子性と永続性の一例。整合性、分離性、分離水準、直列化可能性、分散処理は未対応 |
| 3 | KA Core | 並行性制御：二相ロック、デッドロック対策、クォーラムによる整合性モデル | 依頼16・30は一般的な排他とデッドロックの固定例。DB の二相ロックや対策、クォーラムは未対応 |
| 4 | KA Core | 復旧マネージャーとバッファマネージャーの関係 | 未着手。依頼35は復旧結果を仮定し、その仕組みを扱わない |
| 5 | Non-core | 楽観的並行性制御とタイムスタンプ方式 | 未着手 |
| 6 | Non-core | 先行ログと ARIES による復旧 | 未着手 |

## 例示学習成果

| 番号 | 分類 | 内容と現状 |
|---:|---|---|
| 1 | KA Core | DBMS によるバッファプール管理を説明 | 未着手 |
| 2 | KA Core | 正しいトランザクション管理の四つの性質を説明 | 依頼35は原子性と永続性の一例のみ。整合性と分離性、および自由記述による説明は未対応 |
| 3 | KA Core | 直列化可能性の原理を概説 | 未着手 |

依頼35では、A=10・B=2 から３枚を移す。別々に保存した更新の途中で中断すると A=7・B=2 が残る。まとめて確定するモデルでは、確定前の中断で A=10・B=2 に戻り、再試行して確定した後の中断では A=7・B=5 が残る。実際の復旧機構や同時実行は扱わず、結果がこのように復旧することを仮定している。
