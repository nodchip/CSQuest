# 完成率の分母の照合：SPD-Common

[CS2023 印字 p.302（PDF 302ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の SPD-Common と[台帳](coverage-spd-common.md)を2026-11-04に照合した。

原典は対象プラットフォーム全体の概要を述べた後、入力・資源・要件・出力を列挙する。子項目だけでは概要が残らないため、`1-本体` を追加して数える。`1b` は資源制約の分類見出しとして重複させず、その４種類を数える。その他の番号２〜５は個別に数える。

トピックの分母候補は12件（1-本体、1a、1b-i〜1b-iv、1c、1d、2〜5）。例示学習成果は４件（1〜4）。いずれも原典では CS Core。この照合では教材内容、達成判定や正答の完成までは検証していない。`1-本体` の教材の有無も未照合。
