# OS-Scheduling：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.209–210。[既存の調査](os-scheduling.md)、依頼の実装とテストを照合した。状態は[追跡方法](coverage-status.md)に従う。固定の仕事・時刻の模型は実 OS の一般の性能や自由な説明を直接評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 対応例と残る範囲 |
|---|---|---|---|---|
| 1 | KA Core | プリエンプティブ・非プリエンプティブな方式 | 部分 | 依頼176・569・623で途中到着、残り時間や鐘による交代を比較。一般の割込みや実 OS の費用は未評価。 |
| 2 | KA Core | スケジューラと方針 | 部分 | 依頼14・134・569・625で先着、ラウンドロビン、優先度、最短仕事と役割を操作。多段階方式や一般の負荷は未評価。 |
| 3 | KA Core | 対称型マルチプロセッサのスケジューリングとキャッシュ一貫性 | 部分 | 依頼624で２炉の割当てとキャッシュ親和性を比較。一貫性の実装や一般の設計は未評価。 |
| 4 | KA Core | タイマー | 部分 | 依頼623で２刻の鐘と仕事の譲渡を比較し、１つの時計を再設定して複数の予定を管理。実際の遅延、取消し、複数 CPU は未評価。 |
| 5 | KA Core | 公平性と飢餓 | 部分 | 依頼177で固定優先度と待機時間に応じた上昇の固定例。一般の公平性や無限の飢餓の保証は未評価。 |
| 6 | Non-core | 省エネルギー・リアルタイムのスケジューリング | 部分 | 依頼133・632で固定仕事の期限を比較。省エネルギーや一般のリアルタイム方針は未評価。 |
| 7 | Non-core | 協調的スケジューリング | 部分 | 依頼623で自発的な譲渡を比較。futex やユーザー空間スケジューラの具体的な仕組みは未評価。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | KA Core | 一般的な方式の優先度・性能・公平性を比較 | 部分 | 依頼14・134・569で固定仕事の完了時刻と優先度を比較。多様な負荷・公平性や自由な議論は未評価。 |
| 2 | KA Core | 方式とアプリケーション分野の関係 | 部分 | 依頼632で期限と初回応答を優先する２方針を比較。一般の用途と自由な説明は未評価。 |
| 3 | KA Core | 短期・中期・長期・I/O スケジューラの違い | 部分 | 依頼625で受付、CPU、退避・復帰、ディスク要求の選択を操作。一般の実装と自由な説明は未評価。 |
| 4 | KA Core | 非対称・対称マルチプロセッシングの適否を評価 | 部分 | 依頼626で仕事数と故障の２方式を比較。一般の性能と障害対応は未評価。 |
| 5 | KA Core | プロセスとスレッドの適否を評価 | 部分 | 依頼627で共有・通信・終了後の固定例を比較。一般の選択や障害は未評価。 |
| 6 | KA Core | プリエンプション・期限付き方式が有益な状況 | 部分 | 依頼133・176・632で期限・途中到着・応答を比較。一般の適用条件や自由な列挙は未評価。 |
| 7 | Non-core | 他の OS 機構や計算機以外への順序付けの応用 | 部分 | 依頼625でディスク要求の先着順と距離優先を比較。ネットワーク、計画、計算機外への一般化は未評価。 |

各依頼の時刻、固定仮定と出典は [スケジューリングの記録](os-scheduling.md) を参照。`tests/timer-scheduling.test.js`、`tests/cache-affinity.test.js`、`tests/scheduler-roles.test.js`、`tests/multiprocessor-roles.test.js`、`tests/process-thread-choice.test.js`、`tests/scheduler-goals.test.js` 等は模型を検査する。個別の例は全負荷での保証ではない。
