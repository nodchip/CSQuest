# GIT-SEP: グラフィックス・対話技術と社会

出典：[CS2023 印字 pp.165–166](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf)。トピックと例示学習成果は KA Core。固定例の達成は実環境での倫理・安全・法的評価の完了を意味しない。

| トピック | 対応と不足 |
|---|---|
| 1a–b 没入・対話・物理技術のアクセシビリティ、運動・視覚・聴覚 | 依頼22・117・350・351は操作や字幕などの固定例。没入・物理環境での支援技術や多様な利用者による評価は未対応 |
| 2a 部屋のスキャン・身体寸法・カメラ等の私的データ取得 | 依頼352で室内の道しるべに必要な位置と手紙・持ち物の記録を比較。実際のスキャン、身体寸法、アクセス制御は未対応 |
| 2b–c 没入時に目をそらしにくいこと、本人や周囲の危険 | 未対応 |
| 2d 顔認識の倫理上の問題 | 未対応 |
| 2e 誤ったデータや正しいデータによる誤解を招く可視化 | 依頼111・112で棒の下端と集計範囲の固定例。補間・平滑化やエイリアシング等は未対応 |
| 2f 健康情報などのプライバシー | 依頼352は室内の固定例。健康情報の扱いは未対応 |
| 2g 画像処理の偏り、偽画像、肌色・髪型に関する誤認識 | 未対応 |
| 3 グラフィックスの知的財産法と生成 AI の訓練・生成画像 | 依頼269・270でソフトウェアの利用条件と出典の固定例。生成 AI と著作権の分析は未対応 |
| 4 この分野の現在・過去の貢献者 | 未対応 |

| 例示学習成果 | 対応と不足 |
|---|---|
| 1 位置タグに内在するセキュリティの議論 | 依頼352は室内の位置情報が機微になりうると説明。位置タグの攻撃・議論は未対応 |
| 2 顔認識の倫理と使用条件の議論 | 未対応 |
| 3 透かし入り画像のニューラルネットワーク訓練に関する著作権の議論 | 未対応 |

依頼352は架空の部屋で、道しるべに入口と壁の位置の両方が必要という規則を置く。手紙・持ち物を除外しても位置情報そのもののリスクは残り、同意だけでも保護は保証されない。実際の XR の機微なデータ、利用者の意図と同意について [W3C WebXR Device API](https://www.w3.org/TR/webxr/#security-privacy-and-comfort-considerations) を参照。
