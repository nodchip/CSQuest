# MSF-Linear：光の矢印と内積

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.191–192、MSF-Linear 1a・1c のベクトルの内積と角度。旧依頼50 `src/vectors.js` の基準と３つの候補を現行庭園に再利用するため、旧教材と独立の範囲として重複計上しない。現行庭園の加算・スカラー倍・基底とは異なり、内積と向きを扱う。

基準 a=(2,1)、候補 b=(1,0)、(1,−2)、(−2,−1) の内積はそれぞれ 2、0、−5。いずれも非零で、角度はそれぞれ約26.6°、90°、180°。最後は反対向きであり、狭い意味の鈍角とはしない。非零ベクトルでは a・b=|a||b|cosθ なので、符号と角度を結びつけられる。零ベクトルとの角度は定義しない。[MIT の内積の教材](https://ocw.mit.edu/courses/8-01sc-classical-mechanics-fall-2016/3891edd63171dec6d589b6586d29e551_CsHQ35j_1kY.pdf) も参照。

３つの固定された２次元ベクトルのみで、任意次元・自由な計算や一般の証明は評価しない。MSF-Linear 全体の完成を示さない。

この教材は符号から90°との大小を選ぶもので、数値として角度を計算しない。原典の学習成果1cについては角度計算への前提練習にとどまり、数値計算や一般的な公式の適用は未評価。
