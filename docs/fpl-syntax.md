# FPL の翻訳・構文解析・意味解析の対応

原典 CS2023 pp.139–141。依頼75は、固定された３つの算術式について、演算子を選んで左右の部分を抽象構文木として結び、規則に基づく構造と値を比較する。プレイヤーが文法や実コードを記述する演習ではない。

## FPL-Translation トピック

| 区分・番号 | 原典の対象 | 対応 |
|---|---|---|
| CS Core 1–4 | インタプリタ・コンパイラ・JIT、中間コード、それぞれの長短、クロスコンパイラ | 未対応 |
| CS Core 5 | BNF・拡張 BNF による文脈自由文法 | 依頼309で２規則の文法の導出を操作。一般の文法記述は未対応 |
| CS Core 6 | 簡単な文の構文木 | 固定した算術式の抽象構文木のみ。具体構文木は未対応 |
| CS Core 7–8 | ネイティブ・仮想機械での実行、翻訳の各段階 | 未対応 |
| KA Core 9 | オブジェクトや関数の実行時表現 | 依頼52・65はクロージャ・動的な振る舞いの固定例。実行時表現は未対応 |
| KA Core 10 | 安全なコンパイラ開発 | 未対応 |

例示学習成果: CS Core 1、3、5 は未対応。2 は構造構築と値を分けて表示する一例のみで、構文・解析と意味・評価の一般的区別は未評価。4 は固定した抽象構文木のみで、任意の式や具体構文木は未対応。6 は算術式の優先順位・結合の固定例のみで、一般の曖昧性や条件文は未対応。KA Core 7 の到達可能性とガベージコレクションは未対応。

## FPL-Syntax トピックと成果

Non-core トピック 1–3 は正規文法・文脈自由文法、走査・解析、正規表現による字句解析で、未対応。4 のトークンは画面上で個別の数・演算子を扱う固定例のみ。5 の解析方式・先読み表、6 の言語理論・導出・曖昧性・文法変換、7 の誤り回復、8 の生成器はいずれも未対応。例示学習成果 1–3 は未対応。4 は算術式の優先順位・左結合と別の木の比較のみで、曖昧性や構文定義の一般的な分析は未対応。

## FPL-Semantics トピックと成果

Non-core トピック 1 の抽象構文木は固定された演算子と数の木のみで、具体構文との比較全般は未対応。2 の表現の構築は固定例のみで、一般の走査・変換は未対応。3–8 のうち、依頼306で値渡し・参照渡しの固定例。一般のスコープ・束縛、静的意味解析、左辺値・右辺値、他の呼出し・引数渡し方式、属性文法は未対応。例示学習成果 1 は固定の木の組立てのみで、任意の小言語の木を描く能力を評価しない。2–3 は未対応。
