# 工房の体験版：操作の設計

2026-11-06 の対話で選んだ方針に基づく。対象は体験版の開始から最初の依頼、その後の選択まで。本編の依頼全体の参照調査は対象外。

| 場所 | 体験 |
| --- | --- |
| P1 タイトル | 新しく始める、保存した冒険を続ける、表示設定を開く |
| P2 世界の紹介 | 世界と工房の概要を知り、次へ進む |
| P3 人物と依頼 | リラとノノの全身・役割を知り、依頼を受ける |
| P4 依頼 | 手順を選んで試し、失敗を直す |
| P5 達成画面 | 中央のダイアログで達成を知り、戻るか記録を見直す |
| P6 次の選択 | ノノと話すか外を見る。選択の結果を読む |
| P7 設定 | 文字の大きさ・コントラストを選んでタイトルへ戻る |

| UI | 場所 | 表示・操作 | 接続 |
| --- | --- | --- | --- |
| U1 | P1 | 始める・続きから・設定 | N1 → P2 / 保存した P2–P6 / P7 |
| U2 | P2 | 世界の概要・次へ | N2 → P3 |
| U3 | P3 | 人物の全身、名前、役割、会話・手伝う | N2 → P4 |
| U4 | P4 | 道・手順の追加と削除・実行・手がかり | N3 → S1、N4 |
| U5 | P4 / P5 | 失敗の記録、達成と戻る・記録を見る | N4 → P5 / P4 / P6 |
| U6 | P6 | 二つの選択と結果 | N2 → S1、U6 |
| U7 | P7 | 表示設定・戻る | N5 → S2 / P1 |
| U8 | P1–P7 | 保存できない・読み込めない案内 | N1–N5 |

| 処理 | 役割と接続 |
| --- | --- |
| N1 | 体験版専用の記録を確認し、選択された開始・再開先を表示。既存の本編データは読み書きしない → S1、P2–P6 |
| N2 | 場面と人物・選択肢を表示し、現在の場面を記録 → S1、U2 / U3 / U6 |
| N3 | 手順を更新し保存 → S1、U4 |
| N4 | 既存 `runScenarios` で結果を求め、保存。成功時は P5、失敗時は P4 → S1、U5 |
| N5 | 体験版専用の表示設定を読み書き → S2、U7 |

| 記録 | 内容・読み手 |
| --- | --- |
| S1 | 体験版専用 localStorage：場面、手順、実行済みか、選択結果 → N1–N4 |
| S2 | 体験版専用 localStorage：文字の大きさとコントラスト → N1、N5 |

達成のダイアログは背景を操作できない独立した場所。閉じると依頼画面へ戻り、キーボードのフォーカスも戻す。保存が使えない場合は現在の画面で続けられるが、再開できないことを案内する。未検証の保存データは自動で上書きしない。
