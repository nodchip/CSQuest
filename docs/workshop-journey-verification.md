# 工房から旅立つ体験版：検証記録

2026-11-06。体験版の範囲は工房の最初の依頼、工房周辺３件、水辺の村の最初の依頼。CS2023 との対応と範囲の限界は [学習内容の根拠](workshop-journey-curriculum.md) を参照。

- 幅390×高さ844、文字大きめ・高コントラストで開始から木立・水路・村の依頼まで操作し、村から戻って残した森の依頼を達成。工房・森・木立では失敗を修正し、水辺では片方だけ到着する並びを修正した。水路も失敗と修正を別途確認。成功ダイアログ内の両ボタンが表示領域内に入り、横方向のはみ出しはない。
- 森と木立、森と水路の２通りで旅立ちを確認。森を２回達成しても件数は１のまま。水路の途中で再読込して手順が復元された。
- キーボードで最初の依頼を達成し、達成表示を閉じた後に再表示ボタンへフォーカスが戻ることを確認。保存不能と壊れた保存記録をブラウザで模擬し、警告と元のデータの保護を確認。
- 公開用のクリーンな `main` から作成した分離環境で、Node テスト 3701 件、Python テスト８件、教材台帳の検査、例題 SQL、ビルドが成功。元の作業ツリーは別件の未公開変更のため教材台帳の検査に不一致があり、公開には含めていない。
- 風景 `data/art/river-village.png` は「水辺の家、橋、遠くの灯り、夕暮れ、絵本風、水彩、文字なし」、人物 `data/art/mizuho.png` は「灯りを持つ水辺の村の世話役の全身、青緑の外套、絵本風、背景透過、文字なし」を画像生成ツールに指示して制作。

面白さの評価はプレイヤーの確認を待つ。公開後の URL と実環境確認は別途行う。
