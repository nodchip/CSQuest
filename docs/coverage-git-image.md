学びの道「遺跡の絵巻を読み解く」は、画素と色から分割、形態操作、フィルタ、補完へ19依頼を案内する。最後の728はしきい値による分割後に収縮と膨張を組み合わせる固定例。道の達成は画像処理全体の網羅を意味しない。

依頼808は市松 [3,1;1,3] と横縞 [3,3;1,1] の２×２画像。未正規化 DFT の一様成分は８、市松の両方向成分と横縞の上下成分は４。成分を０か１で選び、逆変換は４で割る。元の81種の小さい画像に対する直接式と、２入力・全16選択の空間側の独立式を照合した。一様のみなら全て２、模様のみなら１と−１。実画像、表示のための負値の処理、一般の複素成分・境界条件は未評価。参考：[University of Edinburgh: Frequency Filters](https://homepages.inf.ed.ac.uk/rbf/HIPR2/freqfilt.htm)。

依頼809は４×４画像で、一様値３、列方向 [0,1,0,-1] と行方向 [1,-1,1,-1] を重ねる。非零の未正規化 DFT は (0,0)=48、(0,1)=−8i、(0,3)=8i、(2,0)=16。各成分を０・１で選び16で割る逆変換を、全16選択について独立した波の合成式と照合した。共役対の片方だけを残す場合に虚部が生じる。固定画像と選択で、一般画像、複素重み、実表示や境界の影響は未評価。参考：[MIT: Fourier Analysis](https://visionbook.mit.edu/image_processing_fourier.html)。

依頼810は信号 ±２ と独立な雑音 ±１ または ±３ がそれぞれ等確率の模型。観測値に一定倍率を掛け、各４通りの平均二乗誤差を比べる。信号の二乗平均４に対し雑音の二乗平均は１・９で、最小倍率はそれぞれ ４/５・４/13、最小誤差は ４/５・36/13。５候補と両場面を独立した式 ４(１−倍率)²＋雑音の二乗平均×倍率² で照合。これは単一実数成分でぼけなし・分布既知の例で、実画像の復元、PSF・スペクトルの推定や各事例での優位性を保証しない。参考：[Stanford: Wiener Filtering](https://web.stanford.edu/class/archive/ee/ee264/ee264.1072/mylecture12.pdf)。
