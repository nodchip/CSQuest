学びの道「遺跡の絵巻を読み解く」は、画素と色から分割、形態操作、フィルタ、補完へ22依頼を案内する。最後の728はしきい値による分割後に収縮と膨張を組み合わせる固定例。道の達成は画像処理全体の網羅を意味しない。

依頼808は市松 [3,1;1,3] と横縞 [3,3;1,1] の２×２画像。未正規化 DFT の一様成分は８、市松の両方向成分と横縞の上下成分は４。成分を０か１で選び、逆変換は４で割る。元の81種の小さい画像に対する直接式と、２入力・全16選択の空間側の独立式を照合した。一様のみなら全て２、模様のみなら１と−１。実画像、表示のための負値の処理、一般の複素成分・境界条件は未評価。参考：[University of Edinburgh: Frequency Filters](https://homepages.inf.ed.ac.uk/rbf/HIPR2/freqfilt.htm)。

依頼809は４×４画像で、一様値３、列方向 [0,1,0,-1] と行方向 [1,-1,1,-1] を重ねる。非零の未正規化 DFT は (0,0)=48、(0,1)=−8i、(0,3)=8i、(2,0)=16。各成分を０・１で選び16で割る逆変換を、全16選択について独立した波の合成式と照合した。共役対の片方だけを残す場合に虚部が生じる。固定画像と選択で、一般画像、複素重み、実表示や境界の影響は未評価。参考：[MIT: Fourier Analysis](https://visionbook.mit.edu/image_processing_fourier.html)。

依頼810は信号 ±２ と独立な雑音 ±１ または ±３ がそれぞれ等確率の模型。観測値に一定倍率を掛け、各４通りの平均二乗誤差を比べる。信号の二乗平均４に対し雑音の二乗平均は１・９で、最小倍率はそれぞれ ４/５・４/13、最小誤差は ４/５・36/13。５候補と両場面を独立した式 ４(１−倍率)²＋雑音の二乗平均×倍率² で照合。これは単一実数成分でぼけなし・分布既知の例で、実画像の復元、PSF・スペクトルの推定や各事例での優位性を保証しない。参考：[Stanford: Wiener Filtering](https://web.stanford.edu/class/archive/ee/ee264/ee264.1072/mylecture12.pdf)。

依頼811は一様・縦縞・市松の２×２ブロックを直交正規化 DCT し、一様係数を保存、他３係数を刻み１・４・８・16で量子化する。中間値は０から離れる方へ丸める模型独自の規則。縞と市松の一様成分は20、非零の模様成分は−４。刻み８では−８へ復元され、16では０になり、ともに平均二乗誤差４だが非零係数は２・１個。81入力の変換をコサイン基底と照合し、全12条件を検査。非零係数数は実際のバイト数ではなく、JPEG の８×８、量子化表や符号化・実画像は未評価。参考：[Cornell: JPEG の DCT と量子化](https://www.cs.cornell.edu/zeno/papers/cdp/cdpsurvey.html)。

依頼812では量子化済みの２×２係数３組 [20,−4,0,0]・[20,0,0,0]・[24,0,0,−4] を扱う。一様成分の差は20・０・４、模様は (０,−４)・終端・終端・(２,−４)。受信側で元の３組を復元し、末尾の０を途中まで数えてから終端にする12通りと、誤った差・連長・途中記録を検査。７個の抽象的な印は実際のビット数を表さず、JPEG の８×８・長い連長・符号化・ヘッダーや圧縮率は未評価。参考：[Cornell: JPEG の DCT、差分と連長](https://www.cs.cornell.edu/zeno/papers/cdp/cdp_rtij96.pdf)。

依頼813は [8,12,8,12] の最下位ビットを [1,0,1,0] にして [9,12,9,12] とする固定例。そのまま、１画素のビット反転、２×２ DCT の模様を刻み８で量子化して画素を整数に丸める場合、別画像 [14,14,14,14] に既知の印を入れる場合の不一致は０・１・２・０。全256値で上位ビットの保持と変化量を検査。単純な鍵なし方式であり、一致は真正性の証明ではなく、他の透かし方式や実 JPEG の耐性を一般化しない。参考：[KIT: LSB watermarking](https://ies.iar.kit.edu/ies/download/lehre/idc/IDC-13-Dirty-Paper-Codes.pdf)、[Purdue: watermarking](https://engineering.purdue.edu/~ace/water2/digwmk.html)。
