# 港の荷物と並列作業の時間

[CS2023 PDC-Evaluation、印字224〜225ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=224) の性能、オーバーヘッド、拡張性に関連する固定模型。６個と12個の荷物を一人で数えた後、同じ数を均等に分担したときの経過時間と速度向上を比較する。人数の増加に応じた直列の調整時間がある場合も試す。

一人当たりの速度は同じ、準備は２分で分担不可、各荷物は１分、均等分担でき、調整ありの場合は作業前に増員１人当たり１分の直列時間が必要という仮定。所要時間は作業者ごとの時間の和ではなく、全作業の完了までの経過時間である。６個の調整ありでは２人と３人がともに６分であり、いずれも最短として受理する。実プログラムの測定、通信、エネルギーや一般の拡張性の証明は未評価で、関連項目は部分対応である。

実装担当と別の coverage_next が原典、時間と速度向上、同率最短、説明、誤答と保存・開放をコード上で確認した。独立担当自身のブラウザー操作は行っていない。`tests/endgame-parallel-performance.test.js` は独立した期待時間、同率の両解、試行とやり直しを検証し、`scripts/endgame-parallel-performance.playwright.js` は集いと４地域の達成状態を用意した記録から誤答、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
