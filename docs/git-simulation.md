# GIT-Simulation: シミュレーション

参照：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.161。以下の固定例は知識単位全体や実際のシミュレータを作成する能力の達成を示しません。

依頼211の衝突応答は、[OpenStax University Physics Volume 1, 9.4](https://openstax.org/books/university-physics-volume-1/pages/9-4-types-of-collisions) の一次元の弾性衝突・一体になる衝突と運動量保存を参照した。依頼は質量が等しく、外力を無視できる固定例である。

依頼213の移流は、[Fedkiw, Stam, Jensen, Visual Simulation of Smoke](https://www.graphics.stanford.edu/papers/smoke/) の煙の移流と数値的な拡散に関する説明を参考にした、一定速度・一次元・線形補間の固定模型である。論文の煙ソルバー全体を再現するものではない。

依頼214のばねの力は、[OpenStax University Physics Volume 1, 5.6](https://openstax.org/books/university-physics-volume-1/pages/5-6-common-forces) のフックの法則を参照した。数値更新は質量・ばね定数・刻みを１にした半陰的オイラー法の固定例である。

依頼215の高さの差に応じた土の移動は、[Št'ava ほか、Interactive Terrain Modeling Using Hydraulic Erosion](https://www.cs.purdue.edu/cgvlab/www/resources/papers/Stava-2008-Interactive_Terrain_Modeling_Using_Hydraulic_Erosion.pdf) の斜面の閾値と物質輸送を参考にした、３列・整数・逐次更新の独自の簡略模型である。同論文の侵食モデルを再現するものではない。

依頼845は、初期列 F と置換 F → F[+F]F[-F]F を３世代適用し、F で前進、＋・−で45度回転、括弧で位置・向きを保存して復元する。各世代の F は１・５・25・125個。前世代のすべての F を同時に置き換え、生成した記号を同じ世代で再展開しない。[Northwestern University の講義資料](https://users.cs.northwestern.edu/~ago820/cs351/lsys.pdf)の L システムとタートル描画を参照。固定規則の二次元図であり、植物の実際の成長や任意の規則・角度・三次元形状は評価しない。

依頼847は反時計回りの頂点 A=(0,0)、B=(4,0)、C=(1,3) の三角形と整数格子点を使い、各有向辺に対する外積の符号を調べる。３値のいずれかが負なら外側、すべて正なら内側、負がなくゼロが１つなら辺、２つなら頂点とする。辺と頂点を接触に含める。20点を別の不等式で照合する。[Stanford の講義資料](https://web.stanford.edu/class/cs148/materials/class_03_rasterization_and_shading.pdf)の半平面の考え方を参照。固定された非退化の二次元図であり、三次元での平面からの距離、浮動小数点誤差、運動や衝突後の応答は扱わない。

依頼848は固定線分 A=(0,1)・B=(4,1) と、各端点を整数格子に置く線分 C→D の位置関係を調べる。向きの符号に加えて、端点が線分の範囲に入るかと同一直線上の重なりを確認し、内部での交差、一点での端への接触、長さを持つ重なり、離れを区別する。端点の同一位置はこの依頼では無効とする。400通りの順序付き端点の組を、水平線との交差を求める別の方法で照合した。[Princeton の幾何基本処理](https://algs4.cs.princeton.edu/91primitives/)を参照。固定された２次元の整数範囲であり、一般の退化線分、３次元、浮動小数点誤差、連続的な運動や応答は扱わない。

依頼849は初期位置 (1,2,3)、初期速度 (0,1,1) の３羽に、速度合わせ・集合・分離の３規則を選んで同時に１刻み適用する。速度合わせと集合は距離２以内の他の鳥、分離は距離１以内の鳥を参照し、それぞれの向きを −1・0・+1 に簡略化して加算する。速度を −2〜+2 に制限してから位置を更新する。[Craig Reynolds の Boids](https://www.red3d.com/cwr/boids/) の３規則を参考にした独自の一次元模型で、元の連続的な三次元モデルを再現するものではない。８組合せの速度と位置を独立した期待値で照合した。長期の群れ、障害物、視野角や衝突は未評価。

依頼850は壁を通る流れが０の２×２区画で、通路 AB・AC・BD・CD の値を使い各区画の流出−流入を計算する。基準 A の圧力を０にして他３区画の値を選び、各通路の圧力差を流れから引く。[Fedkiw ほかの煙のシミュレーション](https://graphics.stanford.edu/papers/smoke/smoke.pdf)の圧力投影を参考に、密度と時間刻みを１とする独自の離散模型を用いた。初期流れ (1,0,0,1) に対して圧力 (0,1,0,1) は流れを０にし、(3,-1,1,1) に対して (0,2,0,2) は出入りの差を０にしつつ循環 (1,-1,1,-1) を残す。各64組の圧力候補を照合。一般の圧力方程式の解法、移流、粘性、温度や煙全体の実装能力は評価しない。

依頼851は位置 (0,3,6) の３粒について、隣り合う距離をそれぞれ２にする制約を交互に３巡修正する。左の粒は固定し、右の２粒は同じ重さとして、左の制約は中間粒のみ、右の制約は両粒を等しく反対向きに移動する。左から始めると最終距離は (2.25,2)、右から始めると (2,2.375)。共通の粒の修正で別の制約がずれ得る。[Müller ほかの Position Based Dynamics](https://doi.org/10.2312/PE/vriphys/vriphys06/071-080) の位置を直接修正する考え方を参考にした固定の一次元模型であり、速度更新、外力、衝突、一般の収束や布の実装は評価しない。

依頼852は端を０に固定した一次元５地点で、水面の偏差の波を３刻み更新する。初期の一つ前と現在を同じ列とし、中央差分の係数 (cΔt/Δx)² を 1/2 に固定する。初期列 (0,0,4,0,0) では３刻み目に (0,-1,0,-1,0)、(0,4,0,0,0) では (0,-2,-1,2,0) になる。[UCAR の浅水波の資料](https://staff.cgd.ucar.edu/islas/teaching/4_Shallow_water.pdf)にある、静止状態近傍の線形化された浅水波と波動方程式を参考にした模型である。全６刻みを独立した期待値で照合。流速や水深、摩擦、非線形の浅水方程式、境界の一般性、任意の刻みの安定性は評価しない。

依頼853は長さ２ m の質量のない剛体棒の両端に各１ kg の粒があり、静止状態から上下に大きさ２ N·s の衝撃を加える固定の二次元模型である。全質量２ kg、中心まわりの慣性モーメント２ kg m² に対し、重心速度は衝撃を質量で割り、角速度は中心からの位置と衝撃の外積を慣性モーメントで割る。中心への衝撃では回転せず、端では向きに応じて角速度 ±1 rad/s。0.5秒後の剛体の姿勢を描く。[OpenStax の角運動量とトルク](https://openstax.org/books/university-physics-volume-1/pages/11-summary)を参考にし、６条件を独立した期待値と照合。相手物体、衝撃の導出、摩擦、変形、重力、３次元の回転は扱わない。

依頼854は、時刻０・１・２の基準値を (0,4,0) に固定し、保持、直線補間、重み 3u²−2u³ の補間を比較する。３時刻と３方式の９条件を予想し、時間0.25刻みの９点を離散的に再生する。保持は境界で値が飛び、直線は連続だが折れ目で傾きが変わり、滑らかな補間は基準点で傾きが０となる。[Cornell の値ノイズの解説](https://people.ece.cornell.edu/land/courses/ece5760/FinalProjects/s2026/ec769_adl94_km776/ec769_adl94_km776/ec769_adl94_km776/index.html)の基準値間の補間を参考にした独自の１次元固定例。乱数生成、多次元、複数周波数、Perlin の勾配ノイズや実際の炎は扱わない。
