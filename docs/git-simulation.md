# GIT-Simulation: シミュレーション

参照：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.161。以下の固定例は知識単位全体や実際のシミュレータを作成する能力の達成を示しません。

依頼211の衝突応答は、[OpenStax University Physics Volume 1, 9.4](https://openstax.org/books/university-physics-volume-1/pages/9-4-types-of-collisions) の一次元の弾性衝突・一体になる衝突と運動量保存を参照した。依頼は質量が等しく、外力を無視できる固定例である。

依頼213の移流は、[Fedkiw, Stam, Jensen, Visual Simulation of Smoke](https://www.graphics.stanford.edu/papers/smoke/) の煙の移流と数値的な拡散に関する説明を参考にした、一定速度・一次元・線形補間の固定模型である。論文の煙ソルバー全体を再現するものではない。

依頼214のばねの力は、[OpenStax University Physics Volume 1, 5.6](https://openstax.org/books/university-physics-volume-1/pages/5-6-common-forces) のフックの法則を参照した。数値更新は質量・ばね定数・刻みを１にした半陰的オイラー法の固定例である。
