# GIT-Simulation: シミュレーション

参照：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.161。以下の固定例は知識単位全体や実際のシミュレータを作成する能力の達成を示しません。

| KA Core トピック | 対応と不足 |
| --- | --- |
| 1 衝突の検出と応答：符号付き距離場、球同士、三角形と点、辺同士 | 依頼94で一次元の壁と移動の固定例。列挙された形状や一般的な応答は未対応 |
| 2 ノイズによる手続き型アニメーション | 未対応 |
| 3 粒子系：積分法、質点ばね、位置ベースの力学、群れなどの規則、剛体 | 依頼209で１粒子・一定加速度の前進オイラー法と半陰的オイラー法を操作。その他の力・系や一般的な安定性は未対応 |
| 4 格子による流体：半ラグランジュ移流、圧力投影 | 未対応 |
| 5 高さ場：地形の輸送・侵食、水面の波紋・浅水 | 未対応 |
| 6 規則ベースの系：L システム、空間占有、ライフゲームなど | 未対応 |

| KA Core 例示学習成果 | 対応と不足 |
| --- | --- |
| 1 単純なニュートン力学による粒子運動のアルゴリズムを実装 | 依頼209で固定された２方式の更新と刻みを比較。実際のアルゴリズム作成は未評価 |
| 2 軌道を含む流体表現のシミュレーション方法の基本的な考えを比較 | 依頼209は１粒子の定加速度運動のみ。流体や方法の一般比較は未対応 |
| 3 操作可能な煙のソルバーを実装 | 未対応 |
