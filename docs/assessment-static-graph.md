# 既存評価と公開入口の静的 import の照合

`curriculum-assessments.json` の各評価に記録された `src/*.js` と、`index.html` の外部 module script を起点に静的 import をたどったソースを照合する。

```powershell
python scripts/assessment_static_graph.py > assessment-graph.json
python -m unittest discover -s tests -p assessment_static_graph_test.py
```

出力には入口、グラフに入ったモジュール、解決できなかった import、評価ごとの記録状態・記載ソース・グラフ内の記載ソースを含む。リダイレクト先は作業ツリー外など任意の場所を指定できる。各評価は記載ソースの一部がグラフ内にあるか、そうでなければ「到達性未確認」と集計する。

2026-11-10 の調査時点では、評価 65 件すべてにおいて、記載された `src/*.js` が静的グラフ内に見つからなかった。数値はソース変更により変わるため、現状は上記コマンドの出力を優先する。グラフに含まれなかったことは、動的 import や別の画面からの到達、別実装による教材の存在を否定しない。また、グラフに入ったこともプレイヤーが実際に到達・操作できることや学習成果が十分に評価されることを保証しない。旧評価の「完了」は、その評価当時の対象・根拠として扱い、現行の冒険の完成と同一視しない。

この照合は正規表現による限定的な静的スキャンであり、JavaScript 構文解析ではない。相対パスの静的 import / re-export を対象とし、動的 import、インラインスクリプト、実行時分岐は追跡しない。コメントや文字列を誤って import とみなす可能性もある。未解決の import が出た場合は結果を完全なグラフとして扱わない。公開環境の状態、ブラウザでの到達、教材の妥当性、保存、レビューの有無は別途確認する。
