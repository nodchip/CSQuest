## トピック

CS Core 1〜9 は学習の三形式、限界、単純な教師あり学習、過学習、前処理、表現、評価、基本ニューラルネットワーク、倫理。KA Core 10〜16 は最適化、アンサンブル、深層学習、評価、強化学習、応用、倫理。15 は**二つ以上の応用**を求め、15a の医療・経済・視覚・言語・ロボット・ゲーム等は例である。Non-core 17〜35 は統計的推定、教師あり、過学習、実験、ベイズ、深層学習、表現、クラスタリング、グラフ、半教師あり、グラフィカルモデル、アンサンブル、学習理論、強化学習、解釈可能性、推薦、ハードウェア、応用、倫理を挙げる。

台帳の147行は親項目とその子項目を含む。1a.i・1a.ii は1a の分類・回帰、5a.i・5b.i は前処理・欠損処理の含意、13d.i は交差検証による調整、20f.i〜iii は評価の内訳である。親の要約と子を独立した教材要件として機械的に合算しない。親には15の「二つ以上」など子の列挙だけでは失われる条件もある。区分と各番号は台帳と一致し、区分補正は行わない。
