# 集いのデバッグ

現在は無効。ローカルで再度使う場合は `src/debug-gathering-state.js` の `GATHERING_DEBUG_ENABLED` を `true` にし、確認後に `false` に戻す。

ローカルサーバーで `debug-gathering.html` を開き、「デバッグ記録を作って始める」を押す。タイトルの「続きから」を選び、灯花の街の「依頼を見る」→「市場とギルドを手伝う」→「ギルドの荷物を届ける」を達成すると、カエデの知らせが現れる。

デバッグ中は画面上部の「デバッグを終了して通常の冒険へ」で通常モードに戻る。通常記録とは別の `csquest-debug-gathering-v1` を使う。デバッグ画面で再度開始すると、この専用記録は初期化される。

デバッグ中に「デバッグ記録をあと１件の状態に戻す」を押すと、専用記録を初期化して灯花の街に戻る。達成のダイアログが開いている間も同じ操作ができる。

幅390px・1280pxのブラウザで依頼の達成から知らせの表示まで操作し、通常記録が変更されず、デバッグ終了で通常モードに戻ることを確認した。
