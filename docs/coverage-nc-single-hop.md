# NC-SingleHop：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.200。[既存の調査](nc-single-hop.md)と依頼を照合した。状態は[追跡方法](coverage-status.md)を参照。

## トピック

| 番号 | 区分 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | KA Core | 変調、帯域、通信媒体 | 部分 | 278 は振幅と周波数を変える固定波形。帯域と実媒体は未評価。 |
| 2 | KA Core | 符号化とフレーミング | 部分 | 78 の封、277 の区切りとエスケープ。一般の符号化と実通信は未評価。 |
| 3 | KA Core | 媒体アクセス制御 | 部分 | 275・276 は衝突と再送時刻の固定例。実乱数や方式全般は未評価。 |
| 4 | KA Core | Ethernet と Wi-Fi | 部分 | 273 の学習スイッチ、317 の無線接続先切替え。実フレームと規格全体は未評価。 |
| 5 | KA Core | スイッチング、全域木、VLAN | 部分 | 273・274・570・571 の学習、転送範囲とループ回避。BPDU 交換や実装は未評価。 |
| 6 | KA Core | データセンター・キャンパス等の LAN トポロジー | 部分 | 827 で２学び舎・集約塔・書庫の接続と上り道の冗長化を比較。実際の階層、容量、ループ防止や運用は未評価。 |
