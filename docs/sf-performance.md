# SF-Performance の対応状況

出典: [CS2023 SF-Performance](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 294–295。原典を要約した作業用一覧。固定モデルのクリアから、実機の性能評価や自由な説明能力の達成を主張しない。

## トピック

| 番号 | 分類 | 要約 | 状況 |
|---:|---|---|---|
| 1 | CS Core | 光速と計算機、メモリ・ディスク・ネットワークの遅延 | 依頼25：架空の近い棚と遠い書庫の固定時間のみ。実システムの遅延は未対応 |
| 2 | CS Core | キャッシュと時間的・空間的局所性の影響 | 依頼25の時間的局所性と依頼103のブロックによる空間的局所性の固定例 |
| 3 | CS Core | データベース・OS・分散システム・計算機でのキャッシュと一貫性 | 依頼104で単一の共有値と無効化の固定例。実プロトコルと各システムへの応用は未対応 |
| 4 | CS Core | プロセッサのメモリ階層の導入 | 未着手 |
| 5 | KA Core | 平均メモリアクセス時間の式 | 依頼103で４固定例の平均を計算。一般的な構成は未対応 |
| 6 | KA Core | 仮想化と分離の理由 | 未着手 |
| 7 | KA Core | 仮想メモリによる間接参照 | 未着手 |
| 8 | KA Core | 仮想メモリと仮想マシンの実装方法 | 未着手 |

## 例示学習成果

| 番号 | 分類 | 要約 | 状況と限界 |
|---:|---|---|---|
| 1 | CS Core | メモリ、ディスク、ネットワークの遅延の内訳を説明 | 未着手 |
| 2 | CS Core | 局所性と性能の関係を説明 | 依頼25で時間的局所性、依頼103で空間的局所性と容量の固定例を比較。自由な説明は未対応 |
| 3 | CS Core | 平均アクセス時間、容量・ヒット率・時間の関係を計算・説明 | 依頼25・103でヒット数、合計・平均時間とブロックサイズを比較。一般式と総容量の比較は未対応 |
| 4 | KA Core | 実行環境の分離・保護の重要性を説明 | 未着手 |
| 5 | KA Core | 間接参照と共有資源による専用環境の見かけを説明 | 未着手 |
| 6 | KA Core | 別 VM で動く二つのアプリの性能分離を評価 | 未着手 |

依頼25は、完全連想・容量２・LRU・読み込み専用の抽象的な棚を使う。ヒット時間１、ミス時の合計時間６は架空の単位。両列とも A・B・C を２回ずつ要求するが、A B A B C C は３ヒット・合計21、A B C A B C は０ヒット・合計36。実際のキャッシュの階層、並列性、書き込み、一貫性や実測値は対象外。
