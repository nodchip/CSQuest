依頼738は [Sprite LFS の論文](https://web.stanford.edu/~ouster/cgi-bin/papers/lfs.pdf) のチェックポイントによる復旧を参考に、本文・対応表・復旧点を順に永続化する簡略模型。各書込みの完了と復旧点の原子的な切替を仮定し、復旧点以降のログ走査や実ファイルシステム全般は扱わない。

依頼739は [Linux nfs(5)](https://man7.org/linux/man-pages/man5/nfs.5.html) の close-to-open を参考に、書き手が閉じて更新を送り、読み手が開き直して確認する固定模型。開いたままの読み手は古い写しを使うと仮定し、実装全般や同期された同時アクセスは表現しない。

依頼743では [OSTEP のジャーナリング](https://pages.cs.wisc.edu/~remzi/OSTEP/file-journaling.pdf) を参考に、権限・名前解決・空き棚の選択と、確定前後の中断および復旧を組み合わせる。本文が先に永続化され、管理情報の記録・確定・書込みが順序どおり完了すると仮定する。一般のファイルシステムや同時更新・装置故障は未評価。

依頼744は [Linux fscrypt の脅威モデル](https://docs.kernel.org/filesystems/fscrypt.html) を参考に、鍵のない装置の一時点の記録、鍵を入れた後のアクセス権、非名前メタデータ、別に作った平文の写しを比較する概念模型。暗号処理を行わず、鍵を外す際には参照と平文キャッシュを消せたと仮定する。改ざん、複数時点の観察や鍵管理の安全性は未評価。`tests/encrypted-files.test.js` で状態と観察の組合せを検査する。

依頼745は [Linux tmpfs](https://docs.kernel.org/filesystems/tmpfs.html) と [proc(5)](https://man7.org/linux/man-pages/man5/proc.5.html) を参考に、プロセスの終了後、一時ファイルシステムの切離し後、保存に成功した記録の再起動後を比較する固定模型。終了状態の回収、新しい tmpfs の接続、保存成功を仮定し、実 API や障害は扱わない。`tests/special-filesystems.test.js` で状態と操作を検査する。

関連検査は `tests/files.test.js`、`tests/snapshot-blocks.test.js`、`tests/mount-overlay.test.js`、`tests/mapped-file.test.js`、`tests/fs-journal.test.js`、`tests/log-structured.test.js`、`tests/log-checkpoint.test.js`、`tests/distributed-file.test.js`。各模型の範囲に限る。

依頼976は [OSTEP のファイル配置と局所性](https://pages.cs.wisc.edu/~remzi/Classes/537/Fall2021/Book/file-ffs.pdf)を参考に、４枚の巻物の連続・分散配置を、距離に費用を置く円盤と移動費用０の水晶で比較する。`tests/file-layout-device.test.js` は４条件の距離・費用・途中記録を検査。回転待ち、キャッシュ、並列性、実機の速度やフラッシュの書換え・摩耗は評価しない。

依頼977は [Linux mmap(2)](https://man7.org/linux/man-pages/man2/mmap.2.html) と [msync(2)](https://man7.org/linux/man-pages/man2/msync.2.html) を参考に、仮の４バイト頁の開始位置、共有と私的な写し、書戻しを比較する。私的書込みで１頁をコピーし、共有の書戻しは同期要求の成功まで起きないと仮定する。実際には同期前の書戻しもあり得る。競合、外部からのファイル変更、部分頁、実 API や障害は扱わない。`tests/mmap-page-lab.test.js` で４条件と状態・保存を検査する。
