# 魔石の分割整列：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 232 頁の SDF-Algorithms トピック２・成果３、および AL-Foundational の整列（同 89 頁）の一部。現行の文庫では探索、灯花の街では挿入・選択や併合の操作がある。旧依頼909 `src/quick-partition.js` の３分割模型を現行冒険へ接続した。
- 参考：[Princeton Algorithms, Quicksort](https://algs4.cs.princeton.edu/23quicksort/) は基準より小さい・等しい・大きい３組への分割と、小さい組と大きい組の再分割を説明する。本教材は配列内交換ではなく組を作る模型である。
- 各再分割で基準自身を除く残りの札について小・等・大の三値判定を１回と数え、等しい値も数える。分割１回ではなく、終了までの全分割の合計。固定列 1〜7 の先頭基準は21回、中央基準は10回、重複を含む [4,2,4,1,3,4,5] の先頭基準は８回。等しい４は３枚とも残る。
- 固定例の操作と比較回数は、任意長への実装、一般の停止・正当性・計算量の証明や実時間、実装全般の安定性を評価しない。旧教材の存在を全体の完成とはみなさない。

2026-11-11、実装担当と別の `signed_review` が原典と [Princeton のクイックソート資料](https://algs4.cs.princeton.edu/23quicksort/index.php) に照らし、３分割・固定比較回数・画面・保存・開放を独立レビューした。監査の再分割対象を小さい組と大きい組に明確化し、再レビューした。親担当が準備済み記録から幅 213・390・1200 px の文庫の分類に到達し、誤答、キーボード、途中保存・再開、開放条件、達成後の保存をブラウザ確認した。新規開始からの通し操作、スクリーンリーダー音声、利用者による面白さは未確認。
