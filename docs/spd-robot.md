# SPD-Robot の対応状況

出典: [CS2023 SPD-Robot](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 304–305。原典を要約した作業用一覧。すべて KA Core。固定シミュレーションの達成は、実機の開発や安全性を示さない。

## トピック

| 番号 | 要約 | 状況 |
|---:|---|---|
| 1 | ロボットの種類と機器 | 未着手 |
| 2 | センサー、組込み計算、動作器 | 依頼28：前方１マスの完全な観測と格子上の向き・移動を操作。実機や観測処理は未対応 |
| 3 | ロボット用言語とライブラリ | 未着手 |
| 4 | ROS 等のソフトウェア構成 | 未着手 |
| 5 | プラットフォームの制約と設計 | 依頼28：架空の移動回数と操作回数の制限。現実の制約や設計は未対応 |
| 6 | 物理・シミュレーションとの接続 | 依頼28：固定格子の簡略シミュレーションのみ。外部システムや実機との接続は未対応 |
| 7 | 順・逆運動学、動力学、経路計画、把持 | 依頼28：二つの固定通路で移動を選択。一般の経路計画や運動学は未対応 |
| 8 | 安全性と相互作用 | 障害物への移動による失敗のみ。実環境や人との安全な相互作用は未対応 |

## 例示学習成果

| 番号 | 要約 | 状況と限界 |
|---:|---|---|
| 1 | 所与のロボットプラットフォームでアプリを設計・実装 | 未着手。依頼28はゲーム内操作のみ |
| 2 | Arduino ロボットを組み立て、迷路を進むようプログラム | 未着手。実機や実言語は扱わない |
| 3 | ロボット用言語・技法と汎用開発を比較 | 未着手 |
| 4 | ロボットの設計と物理・模擬系の接続理由を説明 | 固定の格子シミュレーションの操作のみ。実際の接続と自由な説明は未対応 |
| 5 | ROS の構成要素と接続を設計 | 未着手 |
| 6 | ロボットのプラットフォーム制約を議論 | 依頼28：移動・操作回数の固定制限のみ。現実の制約と自由な議論は未対応 |

依頼28では４×３の固定格子上で、前方１マスを正確に観測し、90度回転または一歩移動する。移動は最大６回、操作は最大30回。観測誤差、連続空間、慣性、制動、人との接触や実機の安全はモデル化していない。
