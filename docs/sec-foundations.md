# SEC-Foundations の対応状況

出典: [CS2023, Security, SEC-Foundations](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 257–258。原典を要約した作業用一覧。部分的な体験は項目全体の達成を意味しない。

## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | CS Core | システムへの攻撃可能性を評価 | 限定的な過剰許可のテスト例のみ。一般的な脅威分析は未対応 |
| 2 | CS Core | 識別した脅威に対する保護を設計・開発 | 固定された役割・場所の許可を選択する試作のみ。実システムの設計・開発は未対応 |
| 3 | KA Core | プライバシー被害の回避方法を説明 | 未着手 |
| 4 | KA Core | 安全性とプライバシーの原則を組み込んだシステムの開発 | 未着手 |
| 5 | KA Core | アクセス制御モデルの機能と性能を比較 | 依頼490で２方式による同じ読取り方針の表現を比較。実際の性能や一般のモデルは未対応 |
| 6 | KA Core | 機械学習を使ったセキュリティ低下の例 | 未着手 |
| 7 | KA Core | 機械学習を使った防御改善の例 | 未着手 |
| 8 | KA Core | ソフトウェアへ影響するハードウェアの脆弱性を説明 | 未着手 |

城門の依頼では本人確認の成否を既知として扱う。認証情報の発行・検証・失効や、実運用での安全性を再現・評価するものではない。
