# 原典との範囲照合：SF-Resource

[CS2023 印字 p.294（PDF 294ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-sf-resource.md)を2026-11-05に照合した。トピック１・２と成果１〜３は CS Core、トピック３と成果４は KA Core。プロセッサ・メモリ・帯域や先着・優先度などは例示であり、対象をそれだけに限定しない。台帳はトピック３行、成果４行。

範囲と区分の照合であり、教材の正確性や学習成果の達成は別途評価する。成果３のスケジューリング方式の開発は、固定例の操作で直接証明しない。
