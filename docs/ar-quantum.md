# AR-Quantum の対応

CS2023 p.108 の AR-Quantum は KA Core。依頼74は、単一量子ビットを初期状態 0 から H、途中操作、H の順で扱う理想化した固定例で、重ね合わせ、干渉、測定、H と Z を部分的に扱う。途中測定は測定結果を区別せず集計した密度行列で計算する。測定の一回の結果を生成するものではない。依頼610は15の因数分解について、理想化した16通りの周期探索の測定結果と古典的な後処理を扱う。量子回路は実行せず、周期は小さい入力を古典的に列挙する。

例示学習成果の大半は未達であり、干渉に関する成果は固定例のみである。各項目の不足を以下に示す。

依頼676のもつれ状態は (|00⟩+|11⟩)/√2、混合は |00⟩ と |11⟩ を各 1/2 で用意する。どちらも Z 測定では 00・11 が半々だが、X 測定では前者が 00・11 半々、後者は４結果が各 1/4。A の X 反転は Z 測定の相関を反転するが、この例の B の周辺確率を変えない。理想的な密度行列と H⊗H により確率を計算し、全８条件を期待値と比較した。実際の測定回数・雑音、一般の局所操作や通信不能定理の証明は扱わない。参考：[IBM Quantum、複数の量子系](https://quantum.cloud.ibm.com/learning/en/courses/basics-of-quantum-information/multiple-systems/quantum-information)。

依頼677は |00⟩ から H、X、Z と制御 NOT を最大５枚並べ、３種類のベル状態を作る。振幅を追跡し、全体の符号だけが異なる場合も同じ状態として受け入れる。各ゲートの自己逆性と長さ４までの全操作列のノルム、制御方向と順序、３つの目標を検査した。複素位相と実機の雑音は未対応。参考：[IBM Quantum、ベル状態の回路](https://quantum.cloud.ibm.com/learning/en/courses/use-a-qc-today/quantum-mechanics-basics)。

依頼678は送信状態 Q と共有対 A・B の３量子ビットを用いる。A と B のベル状態を準備し、Q 制御の NOT と Q の H の後、Q・A の測定結果を選択する。測定値 A が１なら X、Q が１なら Z を B に適用すると、B は送信状態と全体位相を除き一致する。４入力と全４結果の確率・修正を検査した。画面は測定結果を乱数で生成せず４例を指定し、学習用に状態の振幅を表示する。未知状態の１回の測定で振幅を読めることを意味しない。古典通信を要し元の状態の複製は残らないが、この固定例だけで複製不能定理や一般の安全性を証明しない。参考：[IBM Quantum、量子テレポーテーション](https://quantum.cloud.ibm.com/learning/en/courses/utility-scale-quantum-computing/teleportation)。

依頼679は依頼677・678のゲートと転送計算を再利用する遺跡探索。空の |0⟩ に制御 NOT をかける固定の写し方について、入力 |0⟩・|1⟩ では２つの複製と一致し、|+⟩・|−⟩ では一致しないことを比較する。２量子ビットの出力と理想的な２複製の内積の絶対値の二乗を一致度として表示する。４例だけでは一般の定理の証明にはならず、線形性による理由を結果に記す。一般の複素振幅、近似複製や実機は扱わない。参考：[IBM Quantum、量子情報の制限](https://quantum.cloud.ibm.com/learning/en/courses/basics-of-quantum-information/quantum-circuits/limitations-on-quantum-information)。
