# AR-Quantum の対応

CS2023 p.108 の AR-Quantum は KA Core。依頼74は、単一量子ビットを初期状態 0 から H、途中操作、H の順で扱う理想化した固定例で、重ね合わせ、干渉、測定、H と Z を部分的に扱う。途中測定は測定結果を区別せず集計した密度行列で計算する。測定の一回の結果を生成するものではない。依頼610は15の因数分解について、理想化した16通りの周期探索の測定結果と古典的な後処理を扱う。量子回路は実行せず、周期は小さい入力を古典的に列挙する。

例示学習成果の大半は未達であり、干渉に関する成果は固定例のみである。各項目の不足を以下に示す。

依頼676のもつれ状態は (|00⟩+|11⟩)/√2、混合は |00⟩ と |11⟩ を各 1/2 で用意する。どちらも Z 測定では 00・11 が半々だが、X 測定では前者が 00・11 半々、後者は４結果が各 1/4。A の X 反転は Z 測定の相関を反転するが、この例の B の周辺確率を変えない。理想的な密度行列と H⊗H により確率を計算し、全８条件を期待値と比較した。実際の測定回数・雑音、一般の局所操作や通信不能定理の証明は扱わない。参考：[IBM Quantum、複数の量子系](https://quantum.cloud.ibm.com/learning/en/courses/basics-of-quantum-information/multiple-systems/quantum-information)。
