# 空の中継塔と霧の関所：検証記録

- `tests/tower-gate.test.js` で、谷の３依頼による開通、６依頼と合流の条件、誤操作、段階的な操作、途中履歴の検証、未知・破損・長すぎる履歴の拒否を確認した。
- 独立したブラウザ環境で、新規開始から工房・水辺の村・港・森の文庫・風車の里・山・谷を実際に操作し、空の中継塔と霧の関所の６依頼、共通の出来事まで進んだ。ユーザーの保存領域は使用していない。
- 別の独立環境で訪問順を入れ替え、各依頼の途中で再読み込みし、誤操作・見直し・達成後の結果と６件目より前の節目非表示を確認した。二地域から旅先を選び、現在地への重複表示がないことと、再読み込み後に元の場所にとどまれることを確認した。
- 320px と 1280px で、拡大文字・高コントラスト・動きを抑える設定の下、６依頼をキーボードで達成。達成画面の見出しと二つの選択肢が画面内に収まり、ページの横方向のはみ出しがないことを確認した。誤操作の説明が画面内に表示され、達成後の「操作を見直す」で画面が意図せず下へ移動しないことも確認した。
- 古い形式の保存を読み込み、途中保存・再開を確認。破損した保存を上書きせず保護することと、保存失敗時に注意を表示して以前の記録を維持することを確認した。複数タブでの同時編集・競合防止は確認していない。
- 画像４点の風景、全身、表情とポーズを確認し、会話中の顔表示を調整した。自動検査や一人の操作確認は、プレイヤーにとっての楽しさを証明しない。
