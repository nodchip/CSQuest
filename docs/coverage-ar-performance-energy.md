# AR-Performance-Energy：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.106–107。[既存の調査](ar-performance-energy.md)と依頼を照合した。状態は[追跡方法](coverage-status.md)を参照。4 は子項目で追う。

## トピック

| 番号 | 区分 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | KA Core | 性能、電力、記憶、通信の費用の評価 | 部分 | 161 は架空の所要時間・平均電力・エネルギー。記憶・通信や実測は未評価。 |
| 2 | KA Core | 分岐予測、投機、順序外実行、Tomasulo 法 | 部分 | 159・160 は予測と投機結果の固定例。順序外実行と Tomasulo 法は未評価。 |
| 3 | KA Core | ベクトルプロセッサと GPU の改良 | 未照合 | 対応教材を要照合。 |
| 4a | KA Core | マルチスレッド支援：競合 | 部分 | 814 は競合と比較交換の抽象模型。実機の支援は未評価。 |
| 4b | KA Core | マルチスレッド支援：ロック実装 | 部分 | 814 はロックと原子的操作の模型。実機実装は未評価。 |
| 4c | KA Core | マルチスレッド支援：２点間同期 | 未照合 | ハードウェア支援を含む対応を要照合。 |
| 4d | KA Core | マルチスレッド支援：バリア実装 | 部分 | 90 は２人の到着を待つ固定模型。ハードウェア支援や実装全般は未評価。 |
| 5 | KA Core | スケーラビリティ | 部分 | 437 は強・弱スケーリングの固定模型。実機の構成と測定は未評価。 |
| 6 | KA Core | VLIW/EPIC、アクセラレータ等 | 部分 | 163 は専用機械と汎用機械の費用模型。VLIW/EPIC と実機は未評価。 |
| 7 | KA Core | 電圧・周波数の動的調整 | 未照合 | 対応教材を要照合。 |
| 8 | KA Core | ダークシリコン | 未照合 | 対応教材を要照合。 |

## 例示学習成果

| 番号 | 区分 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | KA Core | 性能とエネルギー効率の指標を論じる | 部分 | 161 は架空の時間・電力・エネルギーの比較。自由な説明と実測は未評価。 |
| 2 | KA Core | 投機実行図を分析し判断を記述する | 部分 | 160 は固定例の仮結果と確定を操作。一般の図と自由記述は未評価。 |
| 3 | KA Core | GPU の性能・電力ベンチマーク図を作る | 未照合 | 実測と図の作成に相当する教材を要照合。 |

| 5 | KA Core | 代替アーキテクチャの設計選択を提案 | 部分 | 163 は固定の費用と仕事量から選ぶ。一般的な設計提案は未評価。 |
| 6 | KA Core | 電圧・周波数の動的調整の要点を挙げる | 未照合 | 対応教材を要照合。 |
