# 分母照合：SEP-Communication

[CS2023 印字 pp.279–280](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=279) と[候補台帳](coverage-sep-communication.md)を 2026-11-10 に照合した。原典との範囲照合であり教材の完成・内容・操作・独立レビューの検証ではない。

CS Core トピック 1〜6 は口頭・文章・電子的な連絡、コードや文書等の技術資料、関係者に応じた伝達、ツールを含む協働と対立解決、伝達のアクセシビリティと包摂、自然言語の違いを含む文化的配慮。KA Core 7・8 は伝達手段を選ぶ要因のトレードオフと、倫理・アクセシビリティ等の懸念を伝えて問題を解く・提案すること。原典の導入は発信だけでなく関係者の意見を聞きフィードバックを活用することも重視する。番号付き子はなく、8 件を別々に追跡する。

CS Core 成果 1〜7 は、簡潔・正確な技術文書の形式と図表・参照の重要性、文書の正確性・簡潔さ・曖昧さ・対象者の分析、対象者に応じたアクセシブルな正式発表、包摂的で多様な意見を尊重する交流の計画、効果的な伝達の性質、チーム内の伝達と対立解決、多様・異文化のチームの成果に影響する方法。KA Core 成果 8・9 は、多様な遠隔チームで働く際の自身の強み・弱みの評価と、繊細な倫理的懸念を伝える方法の選択。番号・区分は台帳の 9 行と一致する。トピックと成果は別に数える。

番号付き依頼は旧教材の記録であり、現行冒険への到達を意味しない。現行冒険の SEP-Communication の項目別評価は記録時点で未作成。未作成は教材不存在の証明ではない。実際の対話・文書・発表・協働や自由な議論は固定例だけで評価しない。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
