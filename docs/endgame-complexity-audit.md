# 文庫で本を探す回数

[CS2023 AL-Complexity、印字91〜93ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=91) の入力規模と基本操作の回数に関連する固定例。順番探索では４冊・８冊、二分探索では７冊・15冊を調べ、先頭・末尾・不在の位置や入力の大きさと比較回数の関係を確かめる。応用では７冊の棚で同じ番号を二つの方法で探す。１冊の番号との比較を１回と数え、実時間とは区別する。

有限例の観察であり、O 記法の定義、一般の成長率・最悪や平均の導出、空間量、実時間の測定や自由な説明は扱わない。該当項目は部分対応である。

実装担当と別の coverage_next が原典、手順と比較回数、画面の説明、履歴と開放条件を確認した。独立担当自身のブラウザ操作は行っていない。`tests/endgame-complexity.test.js` は各例の回数と誤操作を検証し、`scripts/endgame-complexity.playwright.js` は集いと４地域の達成状態を用意した記録から、キーボード操作、誤答、途中復元、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
