# FPL-Types の対応状況

出典: [CS2023 FPL-Types](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 136–138。原典を要約した作業用一覧。固定例の達成は実際の言語で型を利用する能力全体を示さない。

依頼24は「数」と「灯り」だけの二段の操作を、入力・出力の型と二つの入力例で検査する。型検査の成功と二例の結果が一致しても、一般の正しさの証明にはならない。

依頼509は型を指定して作る袋と数専用の袋を比較し、数または灯りを２つ入れて届ける。別の型を選んだ袋には入らないとする独自の型模型であり、共通の親型や和型、実言語での型検査・消去・推論は扱わない。[TypeScript のジェネリクス](https://www.typescriptlang.org/docs/handbook/2/generics.html)を参照。

依頼510は数の道で数の２倍、灯りの道で選択した道具を適用する。独自の静的規則は両道の操作を検査し、不適合なら実行前に拒否する。動的な規則は実際に通った道を検査する。灯りに数用道具を置くと、数の道は静的には拒否・動的には成功し、灯りの道は動的に型エラーになる。灯り用道具に直すと静的検査を通る。実言語には他の解析や両方式の併用があり、任意のプログラムや型付き言語全般に一般化しない。[Cornell の型検査講義](https://www.cs.cornell.edu/courses/cs312/2002fa/lectures/lec18.htm)を参照。

依頼511は数の横・縦を要求する読み取り専用の位置型に対し、同名、灯りを追加して派生宣言した型、同じ項目で別名の型、横が文字の型を比較する。完全な構造一致・名前一致と、必要な項目に基づく受入れ・明示的な派生を含む名前による受入れを区別する。固定された読み取り専用記録の模型で、更新可能な型、関数型、実言語の代入規則や振る舞いの置換は評価しない。[Cornell の記録の幅サブタイプ](https://www.cs.cornell.edu/courses/cs4160/2020sp/sf/plf/terse/Sub.html)、[TypeScript の型互換性](https://www.typescriptlang.org/docs/handbook/type-compatibility)を参照。

依頼595では灯り２値（月・太陽）と魔石３値（月・星・雨）から、両方を持つ組を６通り、種類の印と片方の値を持つ荷物を５通り構築する。灯りの月と魔石の月はタグによって別の和型の値となる。[Cornell の積型と和型](https://www.cs.cornell.edu/courses/cs3110/2016fa/l/04-data/notes.html)を参照。有限の固定模型で一般の型規則、他の構成子や実言語での型定義は扱わない。

依頼596は依頼595の灯り２値から魔石３値への道を選ぶ。各入力の出力の有無と複数性で関数か判定し、同じ出力を共有してもよいことを比較する。全関数は３×３＝９通り、逆向きは２×２×２＝８通り。[OpenStax の関数の定義](https://openstax.org/books/algebra-and-trigonometry/pages/3-1-functions-and-function-notation)を参照。有限集合の停止する全関数を扱う模型で、非停止・例外、一般の関数型や実言語の開発は未対応。

依頼597では列を空、または石と残りの列の組として構築する。月→星と星→月→星を先頭への追加で作り、石と残り／空を選んで最後まで開く。[Cornell の再帰的な型](https://courses.cs.cornell.edu/cs3110/2021sp/textbook/data/recursive_variants.html)を参照。２種類・最大３個の列に限り、一般の再帰型や実言語の型定義は未評価。

依頼764は [Cornell の型推論](https://courses.cs.cornell.edu/cs4120/2023sp/notes/typeinf/index.html) と [単一化](https://www.cs.cornell.edu/courses/cs3110/2009fa/Lectures/lec26a.htm) を参考に、用意された未知の型、基本型、袋、道具の等式を選んで代入・分解・削除する。矛盾と有限型の循環を区別し、決める必要のない型は未知のまま残せる。`tests/type-unification.test.js` は全ての合法な操作順で結果を検査し、独立した有限の型割当ても試す。式から制約を生成する工程、一般の型推論・再帰型・サブタイプや実装能力は扱わない。[論理プログラミングの単一化](fpl-logic.md)とも関連するが、ここでは型の等式を扱う。

依頼765は [Cornell の型制約](https://courses.cs.cornell.edu/cs3110/2021sp/textbook/interp/constraints.html) と [単一化](https://courses.cs.cornell.edu/cs3110/2021sp/textbook/interp/unification.html) を参考に、道具の型を「品の型から新しい結果型 β への道具」と等しくする条件を選び、依頼764の単一化を使って整理する。数の道具と数は結果が数、同型を返す道具と灯りは結果が灯り、数の道具と灯りは衝突、未知の道具を自分に適用すると有限型では循環する。`tests/type-application.test.js` で条件・全合法順・結果・途中復元を検査する。固定された単一の適用であり、一般の式からの制約生成、多相的な一般化、再帰型や実装能力は未評価。

依頼766は [Cornell の進行と保存](https://www.cs.cornell.edu/courses/cs4160/2020sp/sf/plf/terse/Types.html) を参考に、数・灯り・加算・条件分岐からなる閉じた式の固定例を一手ずつ動かす。正常な規則では、型が付く式は値か次の一手があり、一手の前後で型が変わらない。型の合わない式、使わない分岐の不一致、型を変える故障、動作が欠けた故障を比較する。`tests/type-safety.test.js` は生成した有限の式について正常な規則の進行と保存を検査し、固定例と途中復元を照合する。有限の検査は一般の型安全性の証明ではなく、証明や自由記述の能力は評価しない。

依頼767は依頼766の正常な規則を対象とし、型付けの導出に沿う帰納法の各場合を用意された選択肢から選ぶ。数・灯りの値、加算の中身と分岐の条件が値または進む場合、加算と道の選択の保存を確認し、任意の有限手数に保存を繰り返して進行とつなぐ。`tests/type-safety-proof.test.js` は各段階の誤答・正答と途中復元を検査する。閉じた４構成の言語に限り、別の言語の証明や自由に証明を組み立てる能力は評価しない。

依頼768は [Cornell の Curry–Howard 対応](https://courses.cs.cornell.edu/cs3110/2021sp/textbook/adv/curry-howard.html) を参考に、含意・連言・選言を関数・積・タグ付き和として表示する。仮定、組の構築と分解、関数の適用、和の導入と場合分けで証明木を作り、５つの目標について対応する型の構築も見比べる。`tests/curry-howard.test.js` は別の自然演繹チェッカーと真理値表、誤った枝・仮定の範囲・途中復元を検査する。原子命題３つと限定された構築規則の模型であり、任意の論理・型理論や実言語のプログラム作成は評価しない。
