## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | CS Core | 取引・蓄積データの脅威への対策を評価 | 部分 | 27・194で収集と閲覧、196で重なる集計を比較。一般の脅威分析は未評価。 |
| 2 | CS Core | 広範な監視における収集の役割を説明 | 部分 | 988で記録項目と保存期間を変更し、架空のログ調査と不要な私的情報の収集を比較。大規模な監視システムと自由な説明は未評価。 |
| 3 | CS Core | 匿名性と仮名性の概念・目的を区別 | 部分 | 27で実名・番号と対応表・個人に結び付かないと仮定した合計を比較。332で名前を除いた記録からの推測を扱う。一般の評価と自由な説明は未評価。 |
| 4 | CS Core | 差分プライバシーや E2E 暗号化の影響を説明 | 部分 | 196で二値回答の１回・２回の確率比と限界を比較。E2E 方式や自由な説明は未評価。 |
| 5 | CS Core | 文化によるプライバシー等の違いを特定 | 部分 | 1307で二つの架空の村と村内の希望を比較。実在する文化の比較や個々の文化を代表する結論は未評価。 |
| 6 | KA Core | 法的保護の哲学的基礎を議論 | 未照合 | 関連体験の対応は未確認。 |
| 7 | KA Core | 法令や法を超える原則を批評 | 未照合 | 法域を指定した比較と自由な批評は未確認。 |
| 8 | KA Core | 適切な表現の自由を可能にする戦略 | 未照合 | 関連体験の対応は未確認。 |

依頼27・194・196・332・333の前提は [SEP-Privacy](sep-privacy.md)、[DM-Security](dm-security.md)、[DM-SEP](dm-society.md) を参照。`tests/privacy.test.js`、`tests/data-privacy-security.test.js`、`tests/aggregate-inference.test.js`、`tests/quasi-identifiers.test.js`、`tests/privacy-release.test.js` は各固定模型の判定・復元等を検査するが、実運用の安全性を証明しない。

依頼988の出典、７日間の仮定と検証・限界は [SEP-Security](coverage-sep-security.md) を参照。固定された門の記録であり、広範な監視の実際の影響全体は扱わない。

依頼1307は [UNESCO の無形文化遺産の倫理原則](https://ich.unesco.org/en/ethics-and-ich-00866) の対話・参加と同意、および [世界人権宣言](https://www.ohchr.org/en/UDHR/Documents/60UDHR/DECLARATION.pdf) の12・19・20条を参考とする。村、条件と判断は架空で、現実の文化や法的義務を一般化しない。`tests/cultural-archive-privacy.test.js` で全選択肢と聞き取り・復元を検査。

依頼1308は [国連の平和的集会とデジタル技術に関する指針](https://www.ohchr.org/sites/default/files/2024-03/Toolkit-law-enforcement-Component-on-Digital-Technologies.pdf) の監視による萎縮への懸念を参考とする。架空の集会準備で記録・掲示・保存を比較し、具体的な法的評価、実際の行動変化や人数だけの公開の匿名性は証明しない。`tests/assembly-privacy.test.js` で全８設定の指摘、聞き取りと保存を検査。
