| 3 | CS Core | 技術による保護 | 部分 | 194で通信保護の仮定を切替。E2E 暗号化や差分プライバシーの比較は未照合。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | CS Core | 取引・蓄積データの脅威への対策を評価 | 部分 | 27・194で収集と閲覧、196で重なる集計を比較。一般の脅威分析は未評価。 |
| 2 | CS Core | 広範な監視における収集の役割を説明 | 未照合 | 実際の監視システムと自由な説明は未確認。 |
| 3 | CS Core | 匿名性と仮名性の概念・目的を区別 | 部分 | 27で番号の結び付き、332で名前を除いた記録からの推測を扱う。概念・目的の区別そのものは未評価。 |
| 4 | CS Core | 差分プライバシーや E2E 暗号化の影響を説明 | 未照合 | 194の通信保護は E2E 方式や差分プライバシーの評価ではない。 |
| 5 | CS Core | 文化によるプライバシー等の違いを特定 | 未照合 | 対応する文化比較は未確認。 |
| 6 | KA Core | 法的保護の哲学的基礎を議論 | 未照合 | 関連体験の対応は未確認。 |
| 7 | KA Core | 法令や法を超える原則を批評 | 未照合 | 法域を指定した比較と自由な批評は未確認。 |
| 8 | KA Core | 適切な表現の自由を可能にする戦略 | 未照合 | 関連体験の対応は未確認。 |

依頼27・194・196・332・333の前提は [SEP-Privacy](sep-privacy.md)、[DM-Security](dm-security.md)、[DM-SEP](dm-society.md) を参照。`tests/privacy.test.js`、`tests/data-privacy-security.test.js`、`tests/aggregate-inference.test.js`、`tests/quasi-identifiers.test.js`、`tests/privacy-release.test.js` は各固定模型の判定・復元等を検査するが、実運用の安全性を証明しない。
