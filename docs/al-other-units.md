一覧は学習内容の計画と未完了の可視化を目的とする。トピック中に複数の細目がある行は、実装時に細目ごとに検証が必要。原典の例示学習成果に明示された分類を記し、別の依頼で似た操作を扱っていても、十分な対応が確認できない項目は未着手としている。

依頼69は固定した８冊の昇順の本について、「探す本が存在するなら候補範囲内にある」という条件を各段階で判定する。一冊余分に除く手順では番号10を失う反例を示し、存在しない番号11では候補が空でも条件付きの約束が成立する。有限の試行は一般的な証明を代替しない。

依頼334では４・８個について、全要素の走査、２列の全組合せ、１個になるまで半分にする回数を比較する。これらの規則は線形・二次・対数の固定例であり、２点だけで一般の漸近的な性質を証明するものではない。参考：[NIST: big-O notation](https://xlinux.nist.gov/dads/HTML/bigOnotation.html)。

依頼335は石の個数 n が４・８・16のとき、8n と n² の固定の操作回数を比較する。n が１以上なら 8n ≤ 8n² であり、線形の作業にも二次の O 上限が成り立つ。実行時間の測定、一般の証明の構築や Θ の形式的な検証は未対応。参考：[NIST: big-O notation](https://xlinux.nist.gov/dads/HTML/bigOnotation.html)。

依頼336は４個の石について、候補一つの合計確認と16通りの全探索を比較する。肯定の候補は検証でき、失敗した一候補だけでは解なしと結論できない。固定例は P と NP の関係、NP 完全性や他の解法の不在を証明しない。参考：[Cornell: Subset Sum is NP-complete](https://www.cs.cornell.edu/courses/cs4820/2018fa/lectures/subset_sum.pdf)。

依頼337は依頼336と同じ２つの４個の石について、直前の行から石を使わない・一度使う場合の到達可能な合計を記録する。目標を W とした表の O(nW) の大きさは W の二進表現の長さに対する多項式時間を保証しない。一般の再帰式の導出や最適な領域使用は未対応。参考：[Cornell: Subset Sum](https://www.cs.cornell.edu/courses/cs4820/2018fa/lectures/subset_sum.pdf)。

依頼338では部分和の到達可能性の表を逆向きにたどり、９の門で１組、５の門で２組の石を復元する。前の行を残す場合の固定例であり、省領域化した場合の実装や再計算費用の比較は未対応。参考：[UC San Diego: Dynamic Programming](https://cseweb.ucsd.edu/classes/sp16/cse202-a/DynamicProgramming.pdf)。

依頼339は初期容量１から８冊を追加し、倍増では移動７回、１枠ずつでは28回となる模型を操作する。新規書込みは各８回で、確保・解放の費用は数えない。一般の n 回の追加では倍増時のコピー回数は 2n 未満だが、固定例の達成は一般的な証明能力を評価しない。参考：[MIT: Amortization](https://live.ocw.mit.edu/courses/6-046j-design-and-analysis-of-algorithms-spring-2015/13e2c7d165259712327af0af312a068e_MIT6_046JS15_lec05.pdf)。

依頼340では１回３個の仮想の印を９回積み立て、実際の書込み９回と移動15回を支払う。各段階で残高と累積費用の一致を検証する。確保・解放や削除、一般的な会計法の証明能力は未評価。参考：[MIT: Amortization](https://live.ocw.mit.edu/courses/6-046j-design-and-analysis-of-algorithms-spring-2015/13e2c7d165259712327af0af312a068e_MIT6_046JS15_lec05.pdf)。

依頼341は同じ部分和を全行保持または１行ずつの保持と再計算で復元する。０〜９の各状態を毎回調べる固定模型では、最大保持行数５・状態更新40と、最大２行・状態更新100を比較する。他の復元方法や実メモリ・実行時間は扱わない。参考：[UC San Diego: Dynamic Programming](https://cseweb.ucsd.edu/classes/sp16/cse202-a/DynamicProgramming.pdf)。

依頼342は４・８冊を半分に分割し、合流時の書戻しのみを数える。T(1)=0、T(n)=2T(n/2)+n の模型で、各段の書戻しを比較する。具体的な並べ替え・比較回数・一般的な漸化式の証明は扱わない。参考：[MIT: Merge Sort](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/1869dbf640ded6b31f1bd369d2001ef5_MIT6_006S20_r03.pdf)。

依頼343は n=4・8 の厳密な４分の１比較から、正の n における n/n²→0 と n²/n²=1 の固定例を扱う。有限個の試験自体は極限を証明しない。小さい ω や一般の関数の証明は未対応。参考：[Cornell: Asymptotic Analysis](https://www.cs.cornell.edu/jeh/book%20July%202018.pdf)。
