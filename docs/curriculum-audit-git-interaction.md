# 原典との範囲照合：GIT-Interaction

[CS2023 印字 pp.162–163](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)を照合した。トピック１〜３は KA Core、４〜８は Non-core。親５行を追加し、親子26トピック行・成果6行とした。親子は重複するため、行数を独立項目数や完成率としない。

音声入力、手・身体のジェスチャー、触覚グローブ・外骨格、脳と計算機のインターフェース、視線追跡ヘッドセット、AR 眼鏡、自然言語インターフェースは未照合。触覚装置５aと成果５は依頼1298の振動の固定模型として部分対応としたが、実際の出力とアプリ作成は評価しない。この範囲照合は教材の正確性や全教材の完成を証明しない。
