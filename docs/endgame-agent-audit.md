# 観測所の案内人形

[CS2023 AI-Introduction、印字67〜68ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=67) のエージェント、観測、意思決定に関連する固定模型。天気に応じた人形の規則を設定して試し、雲だけでは天気が決まらない２場面で追加観測を使い、雨の確率が20％と50％の場合に既知の損失の期待値を比べる。

追加観測は確実で観測中に状態は変わらず費用はないという仮定。期待損失は与えられた確率と損失の下での平均であり、毎回の結果を保証しない。模型における固定規則は実データからの学習ではない。実際の学習、未知の確率推定、人間の判断や一般の AI の能力は評価せず、関連項目は部分対応である。

実装担当と別の coverage_next が原典、天気ごとの規則、部分観測の仮定、期待損失の計算、誤答と保存・開放をコード上で確認した。独立担当自身のブラウザー操作は行っていない。`tests/endgame-agent.test.js` は試行の無効化、追加観測、選択の境界を検証し、`scripts/endgame-agent.playwright.js` は集いと４地域の達成状態を用意した記録から誤答、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
