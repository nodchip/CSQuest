# AR-Representation：符号と絶対値と２の補数

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.103、AR-Representation 3。旧依頼461 `src/signed-formats.js` の４ビット表現・３例を現行の鍛冶街に再利用し、旧教材と独立した範囲として重複計上しない。現行の整数教材は符号なしと２の補数の読み・加算を扱い、符号と絶対値との比較は扱わない。

４ビットの符号と絶対値では左端を符号、残りを4・2・1の大きさとし、−3は1011、負の符号の０は1000、−8は表せない。範囲は−7〜7、0000と1000はいずれも数として０。４ビットの２の補数では左端を−8、残りを4・2・1とし、−3は1101、1000は−8、０は0000だけ、範囲は−8〜7。[Cornell の数値表現の教材](https://www.cs.cornell.edu/courses/cs3410/2025fa/notes/numbers.html) を参照。

４ビット・３つの固定目的の模型であり、一般のビット幅、任意の変換、実際の言語や機器の整数・例外処理、自由な説明の能力は評価しない。AR-Representation 全体の完成を示さない。

2026-11-11、実装担当と別の `signed_review` が原典と [Cornell の数値表現教材](https://courses.cs.cornell.edu/cs3410/2026sp/notes/numbers.html) に照らし、固定値・範囲・画面・保存・開放・フォーカスを独立レビューした。親担当が準備済み記録から幅 213・390・1200 px の鍛冶街の分類に到達し、誤答、キーボード、途中保存・再開、開放条件、達成後の保存をブラウザ確認した。新規開始からの通し操作、スクリーンリーダー音声、利用者による面白さは未確認。
