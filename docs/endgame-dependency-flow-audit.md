# AL-Foundational：依存関係の順序（部分対応）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.88–90、AL-Foundational 15b のトポロジカルソートに関する入口。現在の街の依頼は札の整列を扱う。旧依頼56 `src/topology.js` は祭りの準備と循環の固定例を既に扱うため、新しい範囲として二重計上しない。今回は一列、２つの可能な開始順、循環とその先で待つ仕事を現行冒険で操作する。

矢印Ａ→ＢはＡを終えてからＢを行う意味。循環の例はＡ→Ｂ、Ｂ→Ｃ、Ｃ→Ｂ、Ｃ→Ｄ。Ａを終えた後、ＢとＣは互いに先行を要求し、ＤはＣの後なので待つ。Ｄ自体が循環の一員だとはしない。固定例は [Princeton の有向グラフとトポロジカル順序](https://algs4.cs.princeton.edu/42digraph/) を参考にした。

自由な依存関係の入力、任意のグラフの実装・正しさや計算量の証明・一般的な計画・自由な説明は評価しない。依頼を終えたことは AL 全体の完成を意味しない。

実装担当とは別の `review_candidate` が原典とトポロジカル順序の一次資料、固定例の順序・循環、画面の説明、誤答・不正履歴、分類と開放、旧記録の既定値を確認した。関連７テストも成功した。一般の実装や証明の能力を確認したものではなく、レビュー担当自身はブラウザを操作していない。

`scripts/endgame-dependency-flow.playwright.js` は集いと４地域の達成状態を用意した検証用記録から、213・390・1200 px 幅で分類経由の到達、キーボード操作、誤答案内、途中保存・再開、段階開放と達成後の再開を確認した。新規開始からこの依頼への通し操作、実際のスクリーンリーダー音声や利用者による面白さの評価は未確認。
