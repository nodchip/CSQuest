| 5 | 単純な翻訳からの最適化機会と各手法 | 部分 | 207・208で固定の不要書込み、833で割当てと退避の固定例。命令選択、一般の割当てと自由な議論は未評価。 |

783・790・789 の独立した照合と限定条件は [FPL-Systems](coverage-fpl-systems.md)・[FPL-Translation](coverage-fpl-translation.md) の台帳を参照。

833は４値が各時点に必要かを示す２種類の表から重なる組を選び、２レジスタへの割当てと退避数を考える。鎖は０個、三角形を含む場合は１個で足りる。各場合の重なる組の選択64通りと配置81通りを独立した期待値と照合し、旧途中記録の復元も検査する。[Princeton の生存変数と干渉グラフ](https://www.cs.princeton.edu/courses/archive/spr04/cos598C/lectures/09-Dataflow-3x1.pdf)と [Cornell の割当て講義](https://www.cs.cornell.edu/courses/cs412/2008sp/lectures/lec33.pdf)を参考とする。各時点の生存値は与えられ、棚には各値に別領域があり必要時に出し入れできると仮定する。実プログラムの生存変数解析、実機の命令制約・退避命令の生成・実測性能や一般の最適化は扱わない。
