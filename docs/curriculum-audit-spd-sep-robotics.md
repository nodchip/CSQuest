# 分母照合：SPD-SEP/Robotics

[CS2023 最終報告書 印字 pp.311–312](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=311) の SPD-SEP/Robotics と[候補台帳](coverage-spd-sep-robotics.md)を 2026-11-10 に照合した。これは原典項目の範囲と区分の照合であり、教材の完成・正確性、操作と保存、独立レビューを証明しない。

## トピック

すべて Non-core の 5 件：1 はロボットのアルゴリズムにおける公平性・透明性・説明責任、2 はロボットの意思決定におけるバイアスの緩和、3 はロボットと共有する空間における公共の安全、4 はデータ保護法の遵守、5 は医療ロボットに関する患者の同意と信頼。番号 1〜5 は独立しており、原典に番号付き子項目はない。

## 例示学習成果

すべて Non-core の 5 件：1 はロボットのアルゴリズムのバイアスを特定し緩和策を提案、2 は倫理と公平性の観点からロボットシステムを評価・批評し、必要に応じて改善を提案、3 は意思決定におけるバイアスの実例を分析し削減策を考案、4 は公共空間におけるリスクを評価し安全対策を提案、5 は医療へのロボット導入の有効性に患者の同意と信頼が及ぼす影響を評価する。

トピック 5 件と成果 5 件を別々に追跡する。番号・区分は候補台帳と一致し、親子の重複はない。

## 現行の冒険との区別

台帳中の番号付き依頼は旧教材の記録で、この原典照合だけでは現行の冒険からの到達・操作を確認したことにならない。現行の冒険に関する SPD-SEP/Robotics の項目別評価は、この記録時点では未作成である。未作成は教材不存在の証明ではない。現実の事例分析、倫理的な評価、実機の安全性や法令遵守、自由な提案は固定例だけで直接評価したとは扱わず、代替体験と残る範囲を別途確認する。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・成果と候補台帳を確認した。これは原典範囲のレビューであり、資料や教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
