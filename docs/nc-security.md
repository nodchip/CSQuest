# NC-Security：ネットワークの安全性

出典：[CS2023 NC-Security](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 200–201。すべて KA Core。原典の要約と教材の対応状況であり、固定模型の達成は実ネットワークの安全性を保証しない。

## トピック

| 番号 | 内容 | 現状と限界 |
|---:|---|---|
| 1 | 脅威、脆弱性、対策の導入 | 依頼180で３経路と対策、279で外部通信の制御の固定例。一般の脅威モデルは未対応 |
| 2 | サービス妨害、なりすまし、盗聴、迂回、中間者、改変、経路攻撃など | 依頼261で鍵交換時の差し替え、262・263で改変と再送の固定例。他の攻撃や実環境は未対応 |
| 3a | TLS などの暗号による対策 | 依頼261で認証された公開値を仮定した交換、262で認証の固定例。TLS や実暗号は未対応 |
| 3b | 安全な通信路、経路、DNS、VPN、DMZ、ゼロトラスト、匿名通信、隔離 | 依頼274で VLAN ごとの固定転送。実際のネットワーク構成や各方式は未対応 |
| 3c | 監視、侵入検知、ファイアウォール、なりすまし・DoS 対策等 | 依頼279で接続記録を使う門番、280でしきい値と誤警報・見逃しの固定模型。DoS 対策や実際の設定は未対応 |

## 例示学習成果

| 番号 | 内容 | 現状と限界 |
|---:|---|---|
| 1 | ネットワーク安全性の脅威モデルを説明 | 依頼261・279の固定した攻撃者や通信のみ。一般の脅威モデルや自由な説明は未対応 |
| 2 | ネットワーク固有の対策を説明 | 依頼274・279で固定の転送分離と接続記録を操作。一般の説明は未対応 |
| 3 | 事例からネットワーク安全性を分析 | 依頼261・279は小さな架空の事例。実事例や体系的な分析は未対応 |

依頼279は３設定で、外向きの依頼、記録前後の返事、別の相手からの新規伝令を比較する。記録は一つの相手との対応を理想化し、IP・ポート、接続確立、タイムアウト、偽装や内容の安全性を扱わない。参考：[NIST SP 800-41 Rev. 1](https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=901083) §2.1.2。

依頼280は正解が既知の８件の通信で、しきい値と誤警報・見逃しの件数を比較する。現実の検知性能や通信の安全性を保証しない。参考：[NIST SP 800-94](https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=50951)。

依頼280では同じ正常通信４件を１組または10組に繰り返し、危険な４件を固定して、警報中の危険な通信と誤警報を比べる。しきい値４では３／５と３／23になる。複製による固定例で、実際の頻度や将来の検知性能は推定しない。`tests/intrusion-threshold.test.js` は３しきい値と２組数の件数・旧記録を検査する。
