# SEP-Economies：コンピューティングの経済の項目別対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.283。[既存調査](sep-economies.md)と依頼・検査を照合。状態は[追跡方法](coverage-status.md)に従い、「未照合」は未実装の証拠ではない。「部分」は関連する固定例を示し、項目全体の修得を意味しない。実際の社会調査・法的判断・自由な説明や文章作成は固定例だけでは直接評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | KA Core | 経済モデル、独占、ネットワーク効果、知識・注意の経済 | 部分 | 依頼364で四人の伝令網の接続と相互運用を比較。市場支配、規制、知識や注意の経済は未対応 |
| 2 | KA Core | 価格と提供方式：サブスクリプション、フリーミアム、ライセンス等 | 部分 | 依頼269で架空のソフトウェア利用条件を比較。価格戦略の比較は未対応 |
| 3 | KA Core | 計算資源へのアクセス差、熟練労働の需給と品質 | 部分 | 依頼358で利用条件の異なる四人の申請経路を比較。労働需給と品質は未対応 |
| 4 | KA Core | 自動化・AI と雇用、開発者、利用者への影響 | 未照合 | 対応例を要照合。 |
| 5 | KA Core | 注意やデータに依存する経済の倫理、同意・収集・利用規約 | 部分 | 依頼194・352で架空の収集範囲を比較。注意の経済や利用規約の分析は未対応 |
