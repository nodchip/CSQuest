# 記録の鎖を残す：教材監査

[CS2023 FPL-Functional 印字131–133頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=131) の不変データと共有について、旧依頼590 `src/persistent-list.js` の固定模型を現行の森の文庫で操作する。先頭 A(1)→B(2)→C(3)、先頭追加 X(0)→A の後、B を直接９に書き換えると古い版も [1,9,3]。古い版を残す方式では新しい P(1)→D(9)→C を作り古い版 [1,2,3] を保ち、変更していない C を共有する。この更新で作る節は２個で、先頭追加 X は別の操作で既に作られている。

永続構造による旧版の保持と構造共有は [Okasaki, Purely Functional Data Structures](https://www.cs.cmu.edu/~rwh/students/okasaki.pdf) を参照。２方式と固定された操作の比較であり、全ての永続構造に同じ新規節数を主張しない。任意位置の更新、一般的な実装、メモリ管理、並行処理、計算量や実測は未評価。各依頼は同じ初期状態から始め、別の依頼の内容を参照しなくても操作できる。

## 独立レビューと動作確認

実装担当と別の担当が２方式の旧版と新版、先頭追加と更新時の節数、末尾共有、保存・開放・焦点を確認。集いと４地域の達成状態を用意した記録から幅 213・390・1200 px で誤操作、キーボード、途中保存・再開と達成を確認。冒険開始からの通し到達は含まない。
