# FPL-Logic: 論理プログラミング

参照：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) p.133。依頼146は、変数と有限の項の単一化について、４つの固定例を操作するものです。変数の対応を後続の比較に適用し、定数の衝突と自己参照を検査します。実際の言語処理系を再現するものではありません。

| トピック | 対応状況 |
| --- | --- |
| 単一化 | 依頼146で部分的に体験。一般の入力や証明は未対応 |
| 量化子、一階述語、複合関係、Horn 節と問い合わせ | 未対応 |
| 関係と関数、カット、バックトラック、非決定性、閉世界・開世界 | 未対応 |
| 記憶や部分計算、等式論理、制約・帰納論理、他パラダイムとの統合、発展的構造 | 未対応 |

例示された学習成果のうち、単一化による変数の対応を限定的に扱います。論理プログラムの作成、暗黙の探索、述語論理と Horn 節の関係、再帰とバックトラック、計算量の改善は未対応です。
