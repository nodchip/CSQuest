# FPL-Logic: 論理プログラミング

参照：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) p.133。依頼146は、変数と有限の項の単一化について、４つの固定例を操作するものです。変数の対応を後続の比較に適用し、定数の衝突と自己参照を検査します。依頼147では、一歩の道の事実と「一歩の道が２本つながるなら二歩で届く」という規則から、問い合わせに対する複数の答えを導きます。依頼148では、経由地の候補を試し、対応を戻して別の候補を探索します。実際の言語処理系を再現するものではありません。

| トピック | 対応状況 |
| --- | --- |
| 単一化 | 依頼146で部分的に体験。一般の入力や証明は未対応 |
| Horn 節と問い合わせ | 依頼147で一つの肯定的な規則と有限の事実から複数の答えを導く例。一般の節・再帰・実言語は未対応 |
| 量化子、一階述語、複合関係 | 一般的な扱いは未対応 |
| バックトラック、非決定性 | 依頼148で固定の有限候補の成功・失敗後に対応を戻す例。一般の探索やカットは未対応 |
| 関係と関数、カット、閉世界・開世界 | 一般的な扱いは未対応。依頼148は表示した事実から導けないことと現実に存在しないことを区別 |
| 記憶や部分計算、等式論理、制約・帰納論理、他パラダイムとの統合、発展的構造 | 未対応 |

例示された学習成果のうち、単一化による変数の対応、事実・規則からの導出と探索の戻りを限定的に扱います。論理プログラムの作成、一般の暗黙の探索、述語論理と Horn 節の一般的な関係、再帰、計算量の改善は未対応です。
