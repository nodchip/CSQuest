# FPL-Logic: 論理プログラミング

参照：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) p.133。依頼146は、変数と有限の項の単一化について、４つの固定例を操作するものです。変数の対応を後続の比較に適用し、定数の衝突と自己参照を検査します。依頼147では、一歩の道の事実と「一歩の道が２本つながるなら二歩で届く」という規則から、問い合わせに対する複数の答えを導きます。依頼148では、経由地の候補を試し、対応を戻して別の候補を探索します。依頼149は、基本規則と再帰規則で一歩以上の道を導く固定例です。実際の言語処理系を再現するものではありません。

| トピック | 対応状況 |
| --- | --- |
| 単一化 | 依頼146で部分的に体験。一般の入力や証明は未対応 |
| Horn 節と問い合わせ | 依頼147で一つの肯定的な規則と有限の事実から複数の答えを導く例。依頼149で再帰的な関係を導く例。一般の節・実言語は未対応 |
| 量化子、一階述語、複合関係 | 539・682で全称・存在の固定例。一般的な扱いは未評価 |
| バックトラック、非決定性、カット | 依頼148で固定の有限候補の成功・失敗後に対応を戻す例。依頼150で最初の候補の直後のカットによる枝刈りと解の消失を比較。一般の探索やカットの範囲は未対応 |
| 関係と関数、閉世界・開世界 | 776で関数結果と目標を比較する固定例、148で表示した事実から導けないことと現実に存在しないことを区別。一般的な扱いは未評価 |
| 記憶や部分計算、等式論理、制約・帰納論理、他パラダイムとの統合、発展的構造 | 776で２規則の待機・狭義化と結果の等式条件。一般の等式理論や他の項目は未評価 |

例示された学習成果のうち、単一化による変数の対応、事実・規則からの導出、探索の戻りと再帰的な関係を限定的に扱います。論理プログラムの作成、一般の暗黙の探索、述語論理と Horn 節の一般的な関係、循環する関係の停止、計算量の改善は未対応です。

依頼150のカットの解釈には [SWI-Prolog の cut の説明](https://www.swi-prolog.org/pldoc/man?predicate=%21%2F0)を参照しました。

依頼776は [Curry の待機と狭義化](https://www.curry-lang.org/docs/tutorial/html/curry-tutorial.Ch3.S14.html) を参考に、未知の自然数に対して０なら点灯、後続なら消灯する２規則を操作する。外部の束縛を待つ場合と、既存の単一化器を使って０・後続の各枝を作り、結果を目標と比べる場合を区別する。後続の内部変数は未知の自然数のまま残る。`tests/narrowing.test.js` は両枝の70通りの操作順、各目標、不正操作と途中復元を検査する。固定の２規則であり、一般の意味的単一化・探索戦略や実言語での実装は評価しない。[項目別台帳](coverage-fpl-logic.md)も参照。
