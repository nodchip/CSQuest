# FPL: 実行・解析・コード生成の対応状況

参照：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.136、138–139、142–144。番号は原典本文の番号で、FPL-Analysis のトピックは原典どおり 4 から始まります。以下は既存教材との限定的な関連を示すもので、単位や学習成果の達成を意味しません。プログラムや自由記述を作成する能力はゲーム操作で直接評価していません。

## FPL-Aspect（Non-core）

| トピック | 対応と不足 |
| --- | --- |
| 1 アスペクト | 依頼323で複数操作に共通する記録をまとめる固定模型。一般的な設計は未対応 |
| 2 ジョインポイント | 依頼323で操作の実行を節目として扱う固定模型。他の種類は未対応 |
| 3 アドバイス：前、後（finally・正常終了・例外）、周囲 | 依頼323で実行前・正常終了後・終了後（失敗時も）の記録、依頼324で周囲から元の処理へ進むか拒否する固定例を比較。例外のみや周囲の一般的な使い方は未対応 |
| 4 ポイントカットと指定子 | 依頼323で書込み操作か全操作かを選ぶ固定模型。実際の指定子や構文は未対応 |
| 5 静的・動的なウィービング | 1247で準備・読込み・実行中の架空の織込みと有効化を比較。実処理系は未評価 |
| 6 注釈や IDE などの代替手段 | 1248で目印を読む架空の生成ツールと手作業を比較。実言語や IDE は未評価 |

依頼323では記録自体は必ず成功すると仮定し、成功・失敗の引出、成功する預入と閲覧を比較します。依頼324では許可証の有無によって固定の引出を実行するか拒否します。実際の権限管理やアドバイスの競合は扱いません。織込みの固定模型は1247で扱います。参考：[AspectJ Programming Guide](https://eclipse.dev/aspectj/doc/latest/progguide/progguide.html)。

この単位の本文に例示学習成果は列挙されていません。

| 5 実行時配置、活性化記録・静的データ・呼出しスタック・ヒープ、制御フローへの翻訳、反復・再帰・末尾呼出し・引数渡し | 依頼33・199で再帰と値を写す呼出しの固定例。783で固定の減算ループを分岐・ジャンプに対応、784で末尾呼出しと枠の再利用、785で命令・大域・枠・ヒープを一体で操作。一般の低水準への翻訳と他の引数渡しは未評価 |
| 6 メモリ管理：高水準データの確保とアクセス、復帰時の自動解放、ヒープの手動管理、到達可能性に基づく自動回収 | 依頼171で参照喪失、201・202で到達可能性と参照カウントの循環、786で棚の再利用と世代付きキーを確認。一般の確保・解放・回収機構は未評価 |
| 7 グリーンコンピューティング | 依頼91・161で製造や使用時エネルギーの限定模型。言語処理系との関係は未対応 |

| 2 大域データ・コード・ヒープ・スタックと再帰・メモリ管理の関係を説明 | 依頼33に再帰の固定例。配置全体と説明は未対応 |

依頼782は１棚を１単位とする固定模型。３種類の読取りと二つの札が同じ棚を指す例を操作する。実機の命令規則や境界外アクセスは扱わない。[項目別台帳](coverage-fpl-systems.md)を参照。
