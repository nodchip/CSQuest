# DM-Analytics：データ分析の対応状況

出典: [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.121–122。原典のトピック・例示学習成果はいずれも KA Core。多くは固定された架空データで、依頼549・550には公開 Iris データの固定的な分割を使う例もある。一般的な分析能力を直接評価しない。

| トピック | 内容と現状 |
|---|---|
| 1 | 探索的データ分析の目的、表現、記述統計、可視化。依頼47・111〜114で代表値、図、集計、度数と四分位範囲の固定例。一般のデータ探索は未対応 |
| 2 | 問題とデータの理解、準備、モデル化、評価、配備、利用者の受容を含む分析のライフサイクル。未対応 |
| 3 | データマイニング・機械学習の分類、クラスタリング、関連、回帰。依頼17・115・380で最近傍分類、回帰とクラスタリング、549・550で Iris の分類の固定例。関連分析と一般的な適用は未評価 |
| 4 | データの取得とガバナンス。依頼27で収集項目と閲覧範囲の架空例。一般の取得・管理は未対応 |
| 5 | データの安全性とプライバシー。依頼27で必要な情報と閲覧範囲の固定例。実データの保護や一般の設計は未対応 |
| 6 | 公平性と偏り。依頼118で集団別の分類指標を比較する固定例。現実の公平性の分析は未対応 |
| 7 | データ分析における可視化。依頼111〜113で表示・尺度・条件別集計・度数の固定例。一般的な可視化の設計は未対応 |
| 8 | 同一実体の記録の照合・名寄せ。依頼127で確認済み番号と名前を比べ、同一・別・保留を選ぶ固定例。誤った番号や実データの照合は未対応 |

| 例示学習成果 | 内容と現状 |
|---|---|
| 1–2 | 可視化を含む複数の探索手法の説明と適用。依頼47・111〜114で固定例を操作。未知の実データへの適用と自由な説明は未対応 |
| 3–4 | 基本的な機械学習・データマイニング手法と適用場面を説明し、複数手法を適用。依頼17・115・380と549・550で固定例を扱う。一般的な選択と実データ全般への適用は未評価 |
| 5 | データの取得・利用・変更における法的・倫理的な考慮。依頼27・127で架空の情報収集と照合の影響に触れる。法的判断や実例の分析は未対応 |
| 6 | 収集・利用における公平性と偏り。依頼118で分類指標とその限界の固定例。収集過程を含む実データの分析は未対応 |

依頼127は、確認済み番号が正しく１人に１つずつ割り当てられていると仮定する。番号が同じで表記が異なる２記録、名前が同じで番号が異なる２記録、片方の番号がない同名の２記録を、それぞれ統合・別人・確認待ちとする。現実には番号の誤り、変更、照合に伴う本人への影響や取得可能な情報を考慮する必要がある。

項目別の再照合は [coverage-dm-analytics.md](coverage-dm-analytics.md) を参照。
