# 庭園の光とフィルター

[CS2023 GIT-Fundamentals、印字155〜156ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=155) の色モデルに関連する有限模型。赤・緑・青の光を有無だけで重ね、理想化したシアン・マゼンタ・黄のフィルターで白い光から成分を除く。応用では緑と青を両方の方法で作って比較する。色見本のほか、色名・成分の有無・選択状態を文字で表示する。

二値の理想化モデルに限定し、CMYK の黒、HSV、実際の照明・表示器・インクや人の色覚を扱わない。該当項目は部分対応である。

実装担当と別の coverage_next が原典、加法と理想化した減法の結果、表示、保存と開放条件を確認した。独立担当によるブラウザ操作は行っていない。`tests/endgame-color.test.js` は色の組み合わせと記録の無効化を検証し、`scripts/endgame-color.playwright.js` は集いと４地域の達成状態を用意した記録から、文字表示、誤操作、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
