# PDC-Algorithms：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.225–227。[追跡方法](coverage-status.md)に従う。KA Core の３は列挙された応用領域から１つ以上を選ぶ構成だが、各選択肢を追跡する。下記の固定模型は、実プログラムの作成・実行能力を直接評価しない。実験の前提と検証の詳細は [既存記録](pdc-algorithms.md) にある。

関連する検査には `tests/parallel-scan.test.js`、`tests/pipeline-average.test.js`、`tests/parallel-matrix.test.js`、`tests/parallel-bfs-lab.test.js`、`tests/parallel-sat.test.js`、`tests/parallel-rays.test.js` がある。テストはそれぞれの模型の範囲を対象とし、原典の全分野の達成を保証しない。

依頼974は [CMU の両端キューと仕事の横取り](https://www.cs.cmu.edu/afs/cs/academic/class/15418-s19/www/lectures/06_progperf1.pdf)を参考に、２人・４仕事で末尾からの取得と待機中の先頭からの引き受けを比較する。`tests/work-stealing.test.js` は仕事の保存、同時進行、再生・達成条件を検査。固定仕事・引き受け費用０の模型で、実スレッドや一般の性能・進行保証は未評価。

依頼975は [CMU の負荷分散とスケジューリング費用](https://www.cs.cmu.edu/afs/cs/academic/class/15210-f17/www/concurrency.html)を参考に、依頼974の仕事で１回の引き受け準備を０・５・６刻みとする固定条件を比較する。`tests/work-stealing-cost.test.js` は同時進行、準備時間、保存と達成を検査。青だけが待つ模型で、実際の通信・同期費用や一般の最適性は未評価。

依頼1157は [CS2023 の PDC 分類表](https://csed.acm.org/pdc-cs-core/)を参考に６つの依頼と代表的な働き手、通信、用途、目的を対応付ける。分類は相互排他的ではなく、実装や一般的な設計能力の評価ではない。`tests/pdc-landscape.test.js` は分類の構成、保存と達成条件を検査する。
