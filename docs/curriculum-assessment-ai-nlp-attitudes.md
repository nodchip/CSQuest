# AI-NLP：信念・欲求・意図の文の評価

評価日：2026-11-05。[CS2023 印字 p.80](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の Non-core トピック３d と、[ACL の自然言語における心的状態の研究](https://aclanthology.org/W09-3708/)を参照し、依頼1331を確認した。

判定は「部分」。３つの固定文の「思っている」「通りたい」「通るつもり」を、それぞれ信念・希望・意図として区別する。文から道の実際の状態や行動の実現を断定しない。自然言語全般の曖昧さ、入れ子の文、否定、自動解析や実際の人の心的状態は扱わない。

`tests/agent-bdi-courier.test.js` の３テストは元の再計画と、文・回答の９組合せおよび以前の記録の復元を検査する。ローカル版の390px幅で誤答・３文・元の達成・再読み込みを確認した。これらは一般的な言語理解や実際の人の心を推定する能力を示さない。
