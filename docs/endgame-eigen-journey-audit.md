# 庭園の鏡と固有ベクトル：照合記録

[CS2023 印字191–192頁 MSF-Linear](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 7a・7b は固有値・固有ベクトルと幾何的意味を扱う。[MIT の固有値教材](https://live.ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/1999c9f4accdbef05571a1014438f8dd_MIT18_06SCF11_Ses2.8sum.pdf)は90度回転と複素固有値を示す。旧依頼298 `src/eigen-directions.js` を現行冒険に再利用し、新たな範囲達成を主張しない。

東 (1,0)、北 (0,1)、北東 (1,1)、零 (0,0) を固定例とする。伸縮 (x,y)→(2x,y) の結果は (2,0)、(0,1)、(2,1)、(0,0)。射影 (x,y)→(x,0) は (1,0)、(0,0)、(1,0)、(0,0)。北は後者で非零の固有ベクトル、固有値０。零ベクトルは固有ベクトルとしない。90度回転 (x,y)→(−y,x) は非零実ベクトルに直交し長さを保つため実固有ベクトルを持たない。有限例だけでは一般性を証明せず、画面に直交性と矛盾を示す。任意行列・複素固有値・自由な計算は未評価。
