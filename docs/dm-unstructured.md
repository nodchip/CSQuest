# DM-Unstructured：半構造・非構造データの対応状況

出典: [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.122–123。この単位はすべて Non-core で、原典に独立した例示学習成果の列挙はない。

| トピック | 内容と現状 |
|---|---|
| 1a–c | 非構造データのベクトル化と保存、N グラム付き TF-IDF、Word2Vec、配列型・配列データベース。依頼120で単語ごとの生の出現回数と IDF による単純な得点、依頼121で隣接する２語の組を比較。N グラムを使う TF-IDF、埋め込み、ベクトル保存、配列データベースは未対応 |
| 2a | JSON などの半構造データの保存、入れ子の符号化と圧縮。未対応 |
| 2b | B 木、スキップ索引、Bloom filter、転置索引とビットマップ圧縮、空間充填曲線を用いる索引。依頼120で単語から巻物へたどる転置索引の固定例。半構造データ、圧縮、他の索引は未対応 |
| 2c | OLTP・OLAP の問い合わせ処理、挿入・選択・更新・削除のトレードオフと製品の事例。未対応 |

依頼120では４冊 A=[月草,解毒]、B=[月草,月草]、C=[薬草]、D=[炎] を使用。月草の出現文書数は２、解毒は１。IDF を log₂(４/文書数) とするとそれぞれ１と２。TF を文書中の出現回数とし、検索語の TF×IDF を加算した得点は A=３、B=２。索引に同じ文書を重複して載せないことと、単語の頻度を別に扱う。これは TF-IDF と検索順位の一方式の模型であり、自然言語の分割、異なる重み付け、類似度、順位の有効性の評価は扱わない。
