# DM-Unstructured：半構造・非構造データの対応状況

出典: [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.122–123。この単位はすべて Non-core で、原典に独立した例示学習成果の列挙はない。

| トピック | 内容と現状 |
|---|---|
| 1a–c | 非構造データのベクトル化と保存、N グラム付き TF-IDF、Word2Vec、配列型・配列データベース。依頼120で単語ごとの生の出現回数と IDF による単純な得点、依頼121で隣接する２語の組を比較。依頼120で隣接２語の TF-IDF の固定例。一般の N グラム、埋め込み、ベクトル保存、配列データベースは未対応 |
| 2a | JSON などの半構造データの保存、入れ子の符号化と圧縮。依頼189でリストの値・境界・有効性の固定模型。実バイト表現や圧縮は未評価 |
| 2b | B 木、スキップ索引、Bloom filter、転置索引とビットマップ圧縮、空間充填曲線を用いる索引。依頼120で単語から巻物へたどる転置索引の固定例。依頼120で固定語の Bloom filter を扱う。半構造データへの適用、圧縮、他の索引は未対応 |
| 2c | OLTP・OLAP の問い合わせ処理、挿入・選択・更新・削除のトレードオフと製品の事例。未対応 |

依頼120では４冊 A=[月草,解毒]、B=[月草,月草]、C=[薬草]、D=[炎] を使用。月草の出現文書数は２、解毒は１。IDF を log₂(４/文書数) とするとそれぞれ１と２。TF を文書中の出現回数とし、検索語の TF×IDF を加算した得点は A=３、B=２。索引に同じ文書を重複して載せないことと、単語の頻度を別に扱う。これは TF-IDF と検索順位の一方式の模型であり、自然言語の分割、異なる重み付け、類似度、順位の有効性の評価は扱わない。

項目別の再照合は [coverage-dm-unstructured.md](coverage-dm-unstructured.md) を参照。

依頼120の別の４冊では、隣接する「月 → 草」が A に２回、B に１回、逆順の C と D に０回現れる。出現文書数２から IDF を log₂(４/２)＝１とし、TF-IDF は A＝２、B＝１。分割済みの固定例で、自然言語の分割や検索品質は未評価。参考：[Stanford の TF-IDF の説明](https://nlp.stanford.edu/IR-book/html/htmledition/tf-idf-weighting-1.html)。

依頼120の Bloom filter は、６個の印と各語２位置の固定割当てを使う。登録した２語の印は必ず点灯し、未登録の「薬草」も両位置が点灯して候補に残る一方、「炎」は消えた印で除外できる。候補は元の索引で照合し、この例から一般の性能や実装の安全性を保証しない。参考：[RocksDB の Bloom filter](https://rocksdb.org/blog/2014/09/12/new-bloom-filter-format.html)。
