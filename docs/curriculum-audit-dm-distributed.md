# 完成率の分母の照合：DM-Distributed

[CS2023 印字 p.122（PDF 122ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の DM-Distributed と[台帳](coverage-dm-distributed.md)を2026-11-04に照合した。

原典の１と２は分散 DBMS と並列 DBMS を表す分類見出しとし、その下に列挙された内容を採用する。トピックの分母候補は８件（1a〜1e、2a〜2c）、すべて Non-core。原典はこの単位に独立した例示学習成果を列挙していないため、成果は０件である。０件は未調査や完成率100％を意味しない。

この照合は対象番号と要約の分母候補を確認したもので、教材の十分性、正答、検証や学習成果の完成を証明しない。
