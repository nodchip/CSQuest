# 星鉄の鍛冶街・風待ちの駅：教材と範囲

参考： [Computer Science Curricula 2023 最終報告書](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm) の Architecture and Organization（AR）と Operating Systems（OS）、[Operating Systems: Three Easy Pieces（著者による公開版）](https://pages.cs.wisc.edu/~remzi/OSTEP/)。各依頼は題材を小さな固定例にした導入であり、分野の網羅、大学水準の習熟、一般的な状況への適用力を評価するものではない。

| 依頼 | 扱うことと判定 | 扱わないこと・限界 |
|---|---|---|
| 灯りの数 | ３ビットの位の値を足して５と３を表す | 負数、小数、一般の表現や演算回路 |
| 命令の動き | 単純な逐次処理における命令の取得・解読・実行 | 実際の命令セット、パイプライン、割り込み |
| 記憶の箱 | アドレスと値を区別し、指定場所を読み書き | バイト順、アドレス変換、実際の機械命令 |
| 手元の棚 | １枠のキャッシュに対するヒットとミス、ミス後の入れ替え | 複数階層、配置方式、書込み方針、性能測定 |
| 到着順 | FCFS の固定された到着時刻に基づく順序 | 同時到着、平均待ち時間や他の方針との比較 |
| 交代 | 二つの仕事に同じ時間量を順に割り当てるラウンドロビンの例 | 切替費用、到着時刻の変化、量子の選択と性能 |
| 台車 | 一つの資源の排他利用と解放、どちらの仕事からでもよい | 実装方法、複数資源のデッドロック、公平性の保証 |
| 荷物の場所 | 空き区画への連続配置と重複防止 | 仮想記憶、ページング、断片化の評価、実 OS の配置方式 |

依頼内の比喩は限定されたモデルであり、例えば実際の OS が常に連続した物理領域に仕事を割り当てるという意味ではない。
