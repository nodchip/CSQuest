# 三つの花壇の札：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字187〜188頁の MSF-Discrete 1d・4a（有限集合と包除原理）の固定例。既存の２集合の教材に対し、３集合すべての共通部分を足し戻す体験を現行の庭園に加えた。
- [Cornell の包除原理講義](https://pi.math.cornell.edu/~bazse/2019_Fall_MAT344/Lec_08.pdf) は３集合の和で３つの大きさを足し、各対の共通部分を引き、３つの共通部分を足す式を説明する。
- 札はＡ={1,4,5,7}、Ｂ={2,4,6,7}、Ｃ={3,5,6,7}。各４枚、各対の共通はそれぞれ{4,7}・{5,7}・{6,7}で２枚、３つの共通は{7}の１枚。ＡまたはＢは６枚、２つ以上に入る札は{4,5,6,7}の４枚、３つの対の共通枚数の合計は６。全体は 4+4+4−2−2−2+1=7。
- 札７は各集合の加算で３回、各対の減算で３回引かれ０回になるため、全共通を１回足し戻す。有限例のみで、任意の集合の証明や一般的な問題の自由な解法は評価しない。旧教材・本教材の存在を分野の完成とはしない。
