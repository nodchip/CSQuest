# 集いの後：駅の仕事と道具の記憶

原典：[CS2023 最終報告書](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印刷ページ209–210。二つの依頼は、既存の駅と鍛冶街で OS の考え方を固定例として操作します。

| 依頼 | 操作 | 限界 |
| --- | --- | --- |
| 仕事の順番を比べる | 一台の作業台で到着順と１刻ずつの交代制を、それぞれ三組の仕事について試し、完了時刻を比べる。 | 仕事がない時間、切替費用、複数 CPU、優先度、実 OS の割込みや一般の公平性・性能分析は扱わない。 |
| 道具ごとの番号札を調べる | 道具ごとの表で仮想ページ番号から物理棚の枠を調べ、対応なしを確かめる。 | ページ内の位置、共有、ページ置換、実 OS やハードウェアの処理と性能は扱わない。対応なしの理由は特定しない。 |

2026-11-10、実装担当と別の catalog が原典・模型・画面をレビューし、実行順と完了時刻を独立計算しました。到着と再投入の境界のテストと、実行前の状態・各模型の前提を示す説明を追加しています。場面切替時の文言を修正し、同担当がコードを再確認しました。独立担当自身によるブラウザ操作は行っていません。

進行済みの検証用記録を用い、390・1,200 CSS px と、幅320px・150%表示を213 CSS pxで模擬したブラウザで、誤答、途中保存、両依頼の達成と地域間の移動を確認しました。実際のブラウザ倍率、スクリーンリーダー実機、利用者本人の評価、公開後の確認は未実施です。
