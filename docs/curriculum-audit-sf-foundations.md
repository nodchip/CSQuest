# 原典との範囲照合：SF-Foundations

[CS2023 印字 pp.293–294（PDF 293〜294ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-sf-foundations.md)を2026-11-05に照合した。トピック１〜10と例示学習成果１〜10はすべて CS Core で、各行に区分を明記した。状態機械の信号や TCP 接続の例は原典の例示である。台帳はトピック10行、成果10行。

範囲と区分の照合であり、教材の正確性や学習成果の達成は別途評価する。特に成果８・９の実際のコード作成と性能評価は、ゲーム内の固定模型によって直接評価しない。
