# NC-SingleHop：単一区間の通信

出典：[CS2023 NC-SingleHop](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p. 200。すべて KA Core。以下は原典の要約と教材の対応であり、固定例をクリアしても実ネットワークの設計・運用能力を保証しない。

## トピック

| 番号 | 内容 | 現状と限界 |
|---:|---|---|
| 1 | 変調、帯域、通信媒体の導入 | 未着手 |
| 2 | 符号化とフレーミング | 依頼78で区間ごとの封を操作。実際のフレーム区切りや符号化は未対応 |
| 3 | 媒体アクセス制御、ランダムアクセスと予定されたアクセス | 未着手 |
| 4 | Ethernet と Wi-Fi | 依頼273で有線スイッチのアドレス学習の固定模型。実際のフレーム形式や Wi-Fi は未対応 |
| 5 | スイッチング、全域木、VLAN | 依頼273で３口の学習と転送の固定模型。全域木、VLAN や実装は未対応 |
| 6 | データセンターやキャンパスなどの LAN トポロジー | 未着手 |

## 例示学習成果

| 番号 | 内容 | 現状と限界 |
|---:|---|---|
| 1 | 変調、帯域、媒体の基本を説明 | 未着手 |
| 2 | 媒体アクセス制御プロトコルを詳しく説明 | 未着手 |
| 3 | 符号化とフレーミングの兼ね合いを理解 | 依頼78は封の付替えの固定例。符号化と兼ね合いは未対応 |
| 4 | Ethernet の実装を詳しく説明 | 依頼273は学習と転送の固定例のみ。実際の詳細な実装は未対応 |
| 5 | スイッチングを説明 | 依頼273で未登録宛先への転送、学習、移動後の再学習を操作。一般的な説明や自由記述は未対応 |
| 6 | LAN トポロジーの一種を説明 | 依頼273は１台の中継器と２端末の固定構成。一般のトポロジーの説明は未対応 |

依頼273は単一ネットワーク、３口、Ａ・Ｂ２端末の模型。送信元を入力口に対応づけ、宛先が未登録なら入力以外に転送する。端末が移動しても次の送信元フレームまで古い表が残る例で、タイマー、VLAN、ループ防止、実フレームやアドレスの認証は扱わない。参考：[Cisco、アドレス学習と転送](https://www.cisco.com/c/en/us/td/docs/switches/lan/c9000/lyr2-fwd/cdp-lldp-mac-udld/cdp-lldp-mac-udld-configuration-guide/configure-mac.html)。
