# AI-Planning の対応

原典: CS2023 p.78。依頼85は２種類の小さな迷宮を持つ。状態は場所・鍵の有無・残り時間、操作は隣接する部屋への移動、目的は鍵を持って門に到達すること。鍵は祭壇に到着すると取得し、各移動の時間は１。２つ目では鍵を取って入口に戻らなければならず、同じ場所でも鍵を持つ前後で状態が異なる。独立した幅優先探索で、鍵を考慮した最短移動回数がそれぞれ３・４であることを確認する。

| Non-core トピック | 内容と状態 |
|---:|---|
| 1 | 命題・一階論理の復習。依頼72で命題の推論の固定例。一般の論理は未対応 |
| 2 | 計画の操作と状態表現。依頼85で与えられた位置・鍵・時間・移動を操作。一般の状態表現を設計する課題は未対応 |
| 3 | 全順序計画。依頼85で移動を順に選ぶ固定例。一般の計画手法は未対応 |
| 4–10 | 半順序計画、計画グラフ、階層、計画言語、複数エージェント、MDP、条件付き・連続・確率的な再計画。未対応 |
