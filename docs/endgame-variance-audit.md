# 観測所の分散の依頼：対応と検証

## 原典と対象

[CS2023 最終報告書](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=190) 印字190ページ、MSF-Statistics の CS Core トピック1および例示学習成果1dを対象とする。成果1dは分散だけでなく四分位範囲の理解・説明・計算も含むため、この依頼群だけでは部分対応である。

[Penn State STAT 500](https://online.stat.psu.edu/stat500/Lesson01) の母分散の定義では、母集団全体の各値と母平均の差を２乗し、その合計を母集団の大きさで割る。教材の４日分は調べる対象の全体と仮定し、４で割る。標本から母分散を推定するときの分母や、分散の単位にも注意が必要である。固定した少数の数列による練習であり、一般のデータでの自由な計算や説明能力の証明ではない。

## 対応と検証

`observatory-variance-deviation`、`observatory-variance-variance`、`observatory-variance-compare` で、固定された４日分の記録の平均との差、母分散、２組の分散の比較を操作する。観測所で統計の３依頼のうち異なる２件を達成すると前２件が開き、さらにその２件で比較が開く。各依頼内に必要な説明があり、他の依頼の画面を見比べる必要はない。

実装担当とは別の `review_candidate` が原典と母分散の定義、固定例、説明、保存と段階条件を照合した。地域の分類と地図の達成判定への登録漏れを指摘し、修正後にコードと単体テストを再確認した。レビュー担当自身はブラウザを操作していない。

`tests/endgame-variance.test.js` は独立した分散の期待値、誤答、途中履歴、リセット、完了後の入力を検査する。正答後の同じ回答履歴は受け入れるが、「確かめる」までは進まない。画面では正答後に回答ボタンを無効にする。`tests/late-region-quest-groups.test.js` は分類・開放と地図の全達成判定を検査する。

`scripts/endgame-variance.playwright.js` は、集いと４地域などの達成を用意した検証用の保存記録から、地域の分類を開いて３依頼を操作する。213・390・1200 px 幅でキーボードによる依頼と回答の選択、誤答への案内、途中保存・再開、２件での段階開放、依頼達成、達成後の再開を確認した。新規開始からの全行程をこの検証で通したわけではない。

2026-11-10、GitHub Pages に反映された `8f09072` でも、同スクリプトを独立した検証用記録で再実行し、３幅すべて成功した。

- 導入から分散の依頼までの通し操作、実際のスクリーンリーダー音声および利用者による面白さの評価は未確認。
