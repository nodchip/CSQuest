# FPL-Types：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 136–138。[追跡方法](coverage-status.md)に従う。原典の16トピック・18例示学習成果とトピックの子項目を記録する。親子を集計時に重複させない。「未照合」は未実装の証拠ではなく、「部分」は項目全体の達成を意味しない。固定例の限界は [詳細](fpl-types.md) を参照。
