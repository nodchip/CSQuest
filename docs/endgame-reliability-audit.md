# 風車の里の信頼性と作業時間

CS2023 SF-Reliability（印字296ページ）の冗長性の固定例として、元は同一の三枚の控えのうち最大一枚が変わる前提で、多数の色に訂正する。二枚が同じ誤りになる反例も含む。独立した故障の確率や一般の符号訂正は扱わない。

SF-Foundations と SF-Evaluation（印字293–295ページ）の固定例として、各１刻の準備台と確認台を使い、先の刻までに準備された荷物を確認する。３荷物を６刻と４刻、１荷物を２刻で終える例を作り、全体と最初の完了時刻を比べる。荷物の処理順は自由。全荷物が最初からあり、切り替え費用・待ち刻はない。実測や一般的な速度向上は未対応。

独立レビューで条件・結果と原典を確認し、番号順以外で最初に終わる荷物の時刻を正しく数えるよう修正した。元の控えを保持し、重複した準備の誤りを個別に示す修正も再確認した。`tests/endgame-reliability.test.js` と `scripts/endgame-reliability.playwright.js` で誤答・操作・保存・達成を検証する。実際のスクリーンリーダー音声や利用者による楽しさの評価は未実施。
