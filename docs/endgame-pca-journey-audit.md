# 観測所の主成分：照合記録

[CS2023 印字191–192頁 MSF-Linear](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 8 は PCA を扱う。[Penn State の主成分分析教材](https://online.stat.psu.edu/stat505/Lesson11)は単位方向での分散最大と固有ベクトルを説明する。旧依頼300 `src/pca-axis.js` を現行冒険に再利用し、新たな範囲達成を主張しない。

各組４点、平均０、共分散は４点で割る。斜めの C=[[2.5,2],[2,2.5]] は固有値4.5と0.5、右上がり軸の保持18・残差２。横の C=[[4,0],[0,1]] は固有値４と１、横軸の保持16・残差４。４候補以外を含む単位方向 v=a e₁+b e₂ で a²+b²=1、保持量=4vᵀCv≤4λmax を示し、最大固有値軸で等号。軸の符号を逆にしても同じ直線。固定例であり一般の PCA 実装・標準化・任意データ・自由な導出は評価しない。
