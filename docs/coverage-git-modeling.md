# GIT-Modeling：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.158–159。すべて KA Core。[追跡方法](coverage-status.md)に従い、原典の子項目と例示学習成果を区別する。既存模型の前提と検査は [記録](git-modeling.md) を参照。固定例の操作は一般の形状やモデリングツールを実装する能力を直接評価しない。
