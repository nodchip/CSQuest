関連検査には `tests/bezier.test.js`、`tests/tessellation.test.js`、`tests/shape-csg.test.js`、`tests/ray-bounds.test.js` がある。各固定模型に限った検査であり、原典の全範囲を証明しない。

依頼1174は [Stanford の空間分割の解説](https://graphics.stanford.edu/papers/tpurcell_thesis/tpurcell_thesis_lowres.pdf)を参考に、1173の３つの値を含む固定の３次元格子を８分割し、空でない領域を再分割する。`tests/sparse-octree.test.js` は64点の一対一の座標対応、占有、保存と達成を検査。ノード数はバイト数ではなく、透明性は転送関数に依存する。723の距離場は `tests/signed-distance.test.js` の格子と境界までの距離で確認した。

依頼1175は [Prusinkiewicz の L システムの図形への応用](https://algorithmicbotany.org/papers/graphical.gi86.html)を参考に、F の同時書換えとタートル描画、枝の保存・復元を操作する。コッホ曲線は線分長を世代ごとに３分の１にする。`tests/lsystem-garden.test.js` は各世代の本数、両端、分岐の復帰と保存・達成を検査する。有限段・固定規則の模型であり、極限や実植物を検証しない。
