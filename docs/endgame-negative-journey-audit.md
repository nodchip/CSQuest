# 返礼のある道と負の重み：教材監査

[CS2023 AL-Foundational 印字88–90頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=88) の最短経路と探索を扱う固定例。旧 `src/negative-paths.js` の依頼138を再利用して現行の山に接続。現行の道数・所要時間と A* の依頼は非負の重みで、今回の負の重みとは前提が異なる。

有向辺は S→A=2、S→B=5、B→A=−4、A→G=2。閉路はない。未確定の最小候補を確定し、確定済みを再検討せず G 確定で終了する方式は S,A,G を選び４で終了する。一方で S→B→A→G は５−４＋２＝３。旧模型は未到達の出発点からの緩和を行わず、各周に４辺を各１回調べて、更新のない周で終了する。辺の順序を変えてもこの有限 DAG では G=3 に到達する。

負辺があれば確定型が必ず失敗するという主張ではない。負辺は架空の費用の返礼で、所要時間ではない。負閉路の検出、任意グラフ、実装能力、一般の正しさの証明や計算量は未評価。到達可能な負閉路が目的地に到達できる場合、有限な最小費用を持たないことがある。[MIT の Bellman–Ford 講義](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/5edb13fb34cbe7f4cdccc13d131772e7_MIT6_006F11_lec17.pdf) を参照。
