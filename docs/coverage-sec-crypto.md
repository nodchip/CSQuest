原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.260–261。[既存調査](sec-crypto.md)の教材・検証と照合した。列挙例が多い 12–15 は、その例を個別に追跡する。子項目の存在は原典が例のすべてを必須としているという意味ではない。自由な説明や実際に暗号プログラムを書く能力は直接評価しない。

## 例示学習成果

| 番号 | 区分 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | CS Core | 安全性とプライバシーを支える暗号の役割を説明 | 部分 | 58の鍵再利用、602の署名検証。自由な説明と役割全般は未評価。 |
| 2 | CS Core | 独自暗号を考案する危険を議論 | 部分 | 598で小さな方式の探索と選択。実方式の評価や自由な議論は未評価。 |
| 3 | CS Core | 素数の重要性と暗号での利用 | 部分 | 599の小さい RSA の因数と指数。一般の安全性や自由な説明は未評価。 |
| 4 | CS Core | 古典暗号の実装と暗号解析 | 部分 | 426で６通りの候補を操作。実コードの実装や一般の解析は直接評価しない。 |
| 5 | KA Core | 鍵の安全な管理を説明 | 部分 | 609で鍵の生成・配布・漏えい後の切替えと廃棄の模型。実運用は未評価。 |

600〜603の Web Crypto は実験用の固定データまたは一時鍵を使う。602・603の本人と公開鍵の対応、616の確認済み鍵と暗号の正しい動作は模型の仮定であり、実際の本人認証・鍵管理や安全性の証明ではない。既知の試験値、操作・保存の検査と各例の出典・前提は [詳細](sec-crypto.md)に記す。
