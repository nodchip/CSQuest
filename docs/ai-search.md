## 例示学習成果

原典では成果５に KA Core の明示があり、他の成果にはこの欄で分類が付されていない。以下の番号は原典に対応する。

| 番号 | 内容と現状 |
|---:|---|
| 1 | パズルの状態空間を設計：未着手 |
| 2 | 見積もりを使わない探索を選択・実装し計算量を評価：依頼08・21・42は固定例の操作のみ |
| 3 | 見積もりを設計して探索を選択・実装：依頼42は与えられた見積もりの操作のみ |
| 4 | 許容性と最適性を評価：依頼42で与えられた見積もりの性質を提示。プレイヤーによる一般的な判定は未対応 |
| 5 | 対戦ゲームにミニマックスを適用（KA Core）：未着手 |
| 6 | 遺伝的アルゴリズムを設計・実装：未着手 |
| 7 | 焼きなましのスケジュールを設計・実装：未着手 |
| 8 | A*・ビーム探索の設計・実装と費用・探索数の比較：依頼42で A* と最小費用探索の固定例を比較。実装とビーム探索は未対応 |
| 9 | ミニマックスとアルファ・ベータ枝刈り：未着手 |
| 10 | 遺伝的アルゴリズムと他の探索の比較：未着手 |
| 11 | ヒューリスティック探索の適用性を比較：依頼42の固定例のみ |
| 12 | パズルの制約充足モデルと後戻り探索：未着手 |

依頼42では S→A=2、S→B=1、A→C=2、A→G=7、B→C=4、B→G=9、C→G=2 の一方向道路を使う。見積もりは S=6、A=4、B=6、C=2、G=0。全経路を独立に列挙し各地点の最短費用を求め、見積もりが過大でなく各道路で整合することをテストする。見積もりなしと A* は共に費用６の経路を見つけ、終点以外の展開数はそれぞれ４・３。
