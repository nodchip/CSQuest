# AI-Search の対応状況

依頼370の追加試験では、既存の木の各辺の費用を１とし、同じ見積もりを使う A* の待機列を操作する。幅１のビームが B を捨てる一方、A* は B を保持し、S・A・B・C・X・E を展開して G を選び、S→B→E→G に到達する。同点はアルファベット順。ビームは各深さの候補を一括生成し、幅１では３地点、幅２では５地点を展開するが、終了時点が異なるため一般的な性能比較ではない。E の見積もり３は実際の残り１歩を上回り、一般の A* の最適性を保証しない。参考：[Berkeley の A*](https://inst.eecs.berkeley.edu/~cs188/textbook/search/informed.html)、[IJCAI のビーム探索](https://ijcai.org/proceedings/2005/50)。

出典: [CS2023 AI-Search](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 68–69。原典を要約した作業用一覧。依頼42〜45・49は探索、対戦、制約充足の限定された例であり、実言語での探索実装能力を評価しない。

依頼42では S→A=2、S→B=1、A→C=2、A→G=7、B→C=4、B→G=9、C→G=2 の一方向道路を使う。見積もりは S=6、A=4、B=6、C=2、G=0。全経路を独立に列挙し各地点の最短費用を求め、見積もりが過大でなく各道路で整合することをテストする。見積もりなしと A* は共に費用６の経路を見つけ、終点以外の展開数はそれぞれ４・３。

依頼43では同じ地図を使い、新しい見積もり S=0、A=10、B=0、C=10、G=0 と前の見積もりを比較する。実際の残り最短費用より過大なのは A と C。新しい見積もりでは S→B→G の費用10で終了する一方、前の見積もりは最短の費用６を発見する。これは過大な見積もりが最短路を保証しないことを示す一例であり、過大なら常に失敗するとは主張しない。

同じ依頼の追加試験では S=0、A=4、B=0、C=0、G=0 とする。各地点の残り最短費用以下だが、A→C の費用２に対して h(A)=４、h(C)=０なので整合しない。S→B→C と調べた後、A から C への費用４が見つかる。C を再展開しない実装は費用７で終了し、改善時に候補へ戻す実装は C を再展開し費用６を得る。既存の途中記録を移行し、再展開直後の復元を確認。有限の正費用グラフによる反例であり、任意のグラフや終了条件に関する証明ではない。参考：[Berkeley、許容性と整合性](https://inst.eecs.berkeley.edu/~cs188/fa23/assets/notes/cs188-fa23-note03.pdf)。

依頼43では S=0、A=4、B=0、C=2、G=0 の同じ見積もりを用い、h のみで候補を選ぶ貪欲探索と g+h を用いる A* も比較する。前者は S→B→G の費用10、後者は S→A→C→G の費用６。見積もりが各地点で許容的かつ全ての辺で整合的なこと、結果を独立した経路列挙と照合した。固定グラフの例で、貪欲探索が常に失敗することを示さない。参考：[Berkeley、探索の優先順位](https://inst.eecs.berkeley.edu/~cs188/su23/assets/notes/cs188-su23-note02.pdf)。

依頼44は冒険者が東西を選んだ後、守護者が冒険者の報酬を最小にする扉を選ぶ２手の固定例。第一試練は東 [2,8]・西 [4,5] で保証される値が２・４、第二は東 [3,7]・西 [1,9] で３・１。各組合せをテストし、最小値を取った後に最大値を選ぶ。枝刈り、一般のゲーム木、評価関数や実言語による実装は扱わない。

依頼44の追加試練では、東が10個または０個、西は必ず４個。当たり確率が1/2なら東の期待値は５、1/5なら２で、西の期待値４と比較する。東の最悪値０と西の４を比べる場合は確率にかかわらず西を選ぶ。期待値は１回の結果を保証せず、ここでは宝石数をそのまま価値として比較する。２段の固定例で、複数段の偶然・対戦の混在、確率の推定や一般の探索は扱わない。[Berkeley の期待値による探索](https://inst.eecs.berkeley.edu/~cs188/textbook/games/expectimax.html)を参照。

依頼44の地平効果の例では、１手先の非終局に対する仮評価が東８・西５、守護者の応手まで読むと東の終局値は０・９、西は４・６となる。１手で打ち切ると東、２手で終局まで読むと最小値０・４を比較して西を選ぶ。仮評価は最終得点ではない。２手の固定木で、枝刈りとの組合せや一般の評価関数の設計は扱わない。参考：[Berkeley、深さ制限と評価関数](https://inst.eecs.berkeley.edu/~cs188/textbook/games/minimax.html)。

依頼45では石を１個か２個取り、最後に取った側が勝つゲームを守護者と対戦する。守護者は各手について終局までミニマックスで勝敗を調べ、冒険者の勝利を避ける手を選ぶ。初期状態６では先手は勝てず、７と８では先手が勝つ戦略を持つ。０〜８個の全状態を３の倍数による独立した戦略則と照合し、全プレイヤー手順を列挙する。枝刈りや深さ制限は使わない。

同じ依頼では７個からモンテカルロ木探索も試す。未試行の子を優先し、試行済みの子は各手番の勝率に √(2 ln N / n) を加えた値で選択、１ノードを展開して残りを１・２個から一様に選ぶ模擬対戦で終局まで進め、根から展開先まで結果を集計する。勝率は先手の勝ちを記録し、守護者の手番では１から引いた値を使う。初期乱数列は固定し、選んだ手の履歴から途中記録を再現する。全32試行で合法手・手番・勝敗・訪問数・勝ち数の不変条件、双方の手番の選択と再現を確認した。固定方策と有限回の試行であり、必勝や一般の探索性能は保証しない。参考：[Kocsis・Szepesvári、UCT](https://sites.ualberta.ca/~szepesva/papers/ecml06.pdf)。

さらに石０個を「手番の人の負け」として、各状態から相手に負けを渡せる手を順に記録し、０〜８個の勝敗・勝てる手の表を作る。全行を独立した終局までのミニマックスと照合した。これは定めたルールと範囲の終局からの解析の例であり、実際の定跡集や大規模な終盤表の再現ではない。参考：[AAAI、終局からの解析](https://cdn.aaai.org/ocs/123/123-2430-1-PB.pdf)。

依頼49ではＡ・Ｂ・Ｃ・Ｄの４塔を赤・青・緑で塗る。接続は AB、AC、BC、AD、CD、Ｄは赤のみ。各配置後、未配置の塔から隣接済みの色を除く前方検査を行い、候補が空になったら戻る。独立した条件判定で全81配置を列挙し、解が２通りであることを確認する。固定順序・小規模モデルであり、一般の制約伝播や性能は扱わない。

依頼85の状態生成試験は、入口へ戻る地図で「部屋と鍵」を状態として幅優先探索する。状態の展開時にのみ通行規則から後続状態と辺を作る。発見順は S0・A0・K1・S1・A1・G1、最短状態列は S0→K1→S1→A1→G1。０・１は鍵の有無で、同じ入口でも S0 と S1 は異なる。移動費用が１で同じ組の初回到達が最短なので、長い再訪は残り時間が増えず省く。独立した幅優先探索と照合し、誤順・履歴復元を検査した。この試験は固定された通行規則を扱う。参考：[Berkeley、状態と遷移](https://inst.eecs.berkeley.edu/~cs188/assets/exam/cs188-sp23-midterm-solutions.pdf)。

同じ依頼の別の試験は S→A→G の計画中に A–G の橋が閉じる。A で変化を正確に観測し、古い橋へ進めないことを確かめて A→B→G の回り道を選ぶ。閉鎖は一度だけで残りの道は変化しない。履歴の再生と不正移動を検証した。一般の動的探索や最適性、実機の安全性は評価しない。動的な障害物を含む経路計画の参考：[AAAI の研究](https://ojs.aaai.org/index.php/AAAI/article/view/26453)。

依頼372の追加試験は中央を (0,0) とし、第一の地形の値を 8−2(x−y)²+x+y、第二を 8+x²−y² とする。第一は中央８、東・北７、西・南５、北東10で、４方向の固定１歩では改善がなくても斜めでは高い。第二は東西９、南北７、北東８で、中央は方向によって高低が異なる鞍点。第一の中央は４方向の格子上で改善がないだけで、連続地形の局所最大ではない。５候補の値と途中記録を検証した。固定の地形・歩幅で、一般の探索や収束を保証しない。参考：[CMU の非凸最適化](https://www.cs.cmu.edu/~mgormley/courses/10425/slides/lecture25-nonconvex.pdf)。

同じ依頼では、配置とは別に有向の各道 X→Y を選び、X の色ごとに Y の異なる色が存在するか調べる。A→D と C→D で赤が除かれた後、A と C は青・緑、B は赤・青・緑、D は赤となり、全ての道がアーク整合する。候補の直積は27から12に減るが、これは隣接条件を考えない組合せ数であり、探索回数や解の個数ではない。ただし B が青だと A と C はともに緑になり、互いに隣接するため全体の解にならない。全81配置を独立に列挙して確認した。局所的な整合性が全体の解を保証するわけではない。固定した二項不等制約の模型で、一般の制約伝播や性能は扱わない。参考：[Berkeley、制約充足とアーク整合性](https://inst.eecs.berkeley.edu/~cs188/fa25/assets/lectures/cs188-fa25-lec05.pdf)。

依頼97は東 [3,5]、西 [2,9] の２手の木。東を先に調べた後、西の２を先に発見すれば、残りの扉を見ずに東を選べる。西の９を先に調べた場合、残り次第で西が勝つこともあり、直ちには枝刈りできない。ゲーム木全体の任意の探索や実装は未対応。

依頼369は各部屋が左右に分かれる深さ３の木で、唯一の目標は RRL。幅優先は待機リストの先頭を、反復深化は末尾を選び、後者は上限０から３まで繰り返す。目標判定も１回に含むと探索回数は14・25、待機リストの最大数は８・４。前者はキュー、後者は明示的なスタックの数であり、実際の総メモリ量ではない。一定の辺費用、有限の木に限定し、一般のグラフの重複状態や漸近的な計算量は扱わない。[参考：UBC の探索手法](https://www.cs.ubc.ca/~poole/aibook/3e/html/ArtInt3e.Ch3.S5.html)

同じ依頼の IDA* は依頼42の正費用・非巡回グラフを道筋の木として探索し、見積もり S=３、A=２、B=４、C=１、G=０を使う。深さ優先で g+h が上限を超えた道を切り、全候補が尽きたら最小超過値で再開する。上限は３→４→５→６、得られる道は S→A→C→G で費用６。全経路の独立列挙で最短費用と見積もりの許容性を確認し、各反復の次の上限を超過値から検査した。循環検出、一般のメモリ量、SMA*・RBFS は扱わない。参考：[Korf、反復深化と IDA*](https://cse.sc.edu/~mgv/csce580f12/gradPres/korf_IDAStar_1985.pdf)。

依頼370の木は S→A・B、A→C・D、B→E・F、C→X、E→G。G が唯一の目標で、各深さの候補から見積もりの小さい順に幅の数だけ残す。幅１は A→C→X を残して失敗し、幅２は B と E を残して G を発見する。木全体の目標経路と選択をテストで確認した。見積もりは正確な距離を保証せず、幅２でも一般に完全性や最適性を保証しない。同点・循環・実言語での実装は扱わない。[参考：IJCAI のビーム探索](https://ijcai.org/proceedings/2005/50)

依頼371では S→A→C→M→F→T を含む等費用の有向グラフを使う。単方向・双方向とも深さごとに全地点を展開し、双方向では出発側と目的側を交互に広げ、目的側は入辺を逆にたどる。M で出会い、５辺の経路をつなぐ。この例の展開地点数は単方向13、双方向10。全単純経路を別に列挙し最短長５と経路を確認した。一般の重み付きグラフや常に高速になることは保証しない。[参考：双方向幅優先探索の研究](https://arxiv.org/abs/2410.22186)

依頼372は A(3)–B(6)–C(8)、A(3)–D(2)–E(10) の無向地形で、隣のうち最も高い地点が現在より高ければ移る。A からは C で停止し、D からの再出発は E に到達する。全地点の隣を列挙し局所最大が C・E、全体最大が E であることを確認した。再出発地点は指定された固定例であり、平坦地、ランダムな再出発、一般の最適性保証は扱わない。[参考：Berkeley の局所探索](https://inst.eecs.berkeley.edu/~cs188/textbook/csp/local-search.html)

同じ依頼の追加試験では、C から各回で許される隣の最大値を選び、下りも許す。禁止なしは C→B→C→B→C と往復する。直前の地点への復帰を次の１回だけ禁じると C→B→A→D→E と進む。４回の固定例で、禁則の例外、より長い記憶、同点、一般の最適性は扱わない。参考：[Glover、タブー探索](https://pubsonline.informs.org/doi/10.1287/ijoc.1.3.190)。

依頼373は同じ地形で、下りの受理確率を exp((移動先の値−現在の値)/温度)、上りを１とする。抽選値0.30では C→B の受理確率は温度１で約0.135、温度４で約0.607。温度４・４・２・１、固定された提案と抽選値では C→B→A→D→E と進む。乱数の実行や温度スケジュールの設計、一般の最適性保証は扱わない。[参考：Carnegie Mellon の焼きなまし](https://www.cs.cmu.edu/~15281-s23/coursenotes/localsearch/index.html)

依頼374は４ビットの１の数を適応度とし、前世代 1111・1100・0011・0000 から、抽選で選ばれた親 1100・0011 を一箇所交叉する。２文字後で交叉すると 1111・0000 となり、１つ目の子の左端を反転すると 0111。残り２枠を 0000 とし、最後の枠を前世代の最良 1111 に置き換える場合と比較すると、次世代の最大適応度は３・４。交叉位置３通りと各反転をテストした。選択や変異の確率、長期的な多様性、一般の最適性は未検証。[参考：Berkeley の遺伝的アルゴリズム](https://inst.eecs.berkeley.edu/~cs188/textbook/csp/local-search.html)

依頼374の別の比較では、同じ４ビットの適応度について、親 1100・0011 と交叉の２子を評価する。２文字後の交叉では４回の評価に 1111 が含まれる。0000 から 1111 まで順に評価する全列挙では16回かかる。元の世代とは別の固定初期集団であり、親・順序や問題に依存する一例で、一般的な優劣は示さない。勾配法は選択肢として説明するのみで、モデル学習や実行は扱わない。参考：[Berkeley、遺伝的アルゴリズム](https://inst.eecs.berkeley.edu/~cs188/archive/sp24/assets/notes/cs188-sp24-note04.pdf)。

依頼138は負の費用がある固定グラフで、最小候補を確定して目的地で終了する方式と、全辺を繰り返し緩和する方式を比較する。後者はこの例で費用３を得る。一般のグラフ、負の循環や実装は未対応。[詳細](al-foundational.md)


## タブー探索の例外（依頼372）

過去の最良値８に対し、一時禁止の移動先が10・８・７の３状況を用意する。例外なしと、最良値を厳密に上回る場合に禁止を解除する方式を比べる。解除できなければ、許される値６の候補へ移る。禁止は移動の特徴に付いていると仮定し、この模型では最良値の更新は10だけで、同値８は更新ではない。他の例外基準や長期記憶は扱わず、最適解の保証もしない。[Glover と Laguna の解説](https://leeds-faculty.colorado.edu/glover/224%20-%20Tabu%20Search%20Chapter_Glover_Laguna%20in%20Reeves.pdf) の aspiration criteria を参照。

依頼369の候補袋の追加試験では、同じ迷宮の幅優先（調査14・候補最大８）と反復深化（調査25・候補最大４）について、袋の上限４・８・３件を満たす中で調査回数が少ない方法を選ぶ。候補以外の記録や実際の総メモリ量、候補の破棄や異なる探索順は扱わない。
