依頼504は初期の晴れ確率 1/2、晴れ→晴れ 0.8・霧→晴れ 0.3、光の確率は晴れで 0.8・霧で 0.2 の模型。日ごとに遷移を予測し、観測の尤度を掛けて正規化する。２日後の晴れの事後確率は光光 1516/1667、光暗 379/983、暗光 392/529、暗暗 49/323。初期状態と２日間の全経路を別途列挙し検証。固定確率・条件付き独立などの仮定に依存し、実データ、学習、平滑化や一般の HMM を評価しない。[CMU の隠れマルコフモデル教材](https://www.cs.cmu.edu/~15281-f25/coursenotes/hmm_pf/index.html)を参照。

依頼504では各日の観測に対して、晴れ・霧それぞれでその観測が生じる確率を選ぶ。誤った尤度では更新せず、光の確率または暗い確率がその補数であることを示す。遷移と正規化の数値自体は模型が計算する。

依頼562では連鎖 X→Y→Z、共通原因 X←Y→Z、共通結果 X→Y←Z と Y→D の単一道を比較し、観測なし・Y の観測・D の観測を７条件で扱う。分布が図に従って分解される前提で、d 分離は条件付き独立を保証する。道が開いても特定の数値で独立になる場合はある。７条件を独立した二値結合分布の例で照合したが、複数経路・任意の観測集合・一般の判定アルゴリズムや因果推論は扱わない。参考：[Berkeley、d-separation](https://inst.eecs.berkeley.edu/~cs188/textbook/bayes-nets/d-separation.html)。

依頼563は互いに独立な二値 X・Z が各確率 1/2 で、Y=X OR Z の模型。等確率の４行を条件に合わせて選び、P(X)=1/2、P(X|Y)=2/3、P(X|Y,Z)=1/2、P(X|Y,¬Z)=1 を比較する。全４条件の各256通りの行選択と分数、保存を検証した。確率と鐘の規則は仮定であり、実データ・不確実な観測・一般的因果推論は扱わない。参考：[Berkeley、共通結果と条件付き独立](https://inst.eecs.berkeley.edu/~cs188/textbook/bayes-nets/d-separation.html)。

依頼564は A→B→C と A→D の二値ネットワークで D=1 を固定し、A・B の両消去順を比較する。A の事前確率は1/2、B=1 の条件付き確率は A=0 で0.2・A=1 で0.8、C=1 は B=0 で0.25・B=1 で0.75、D=1 は A=0 で0.2・A=1 で0.8。消去対象を含む因子を掛けて変数の値を合算し、C の重み 0.205・0.295 を正規化して 0.59 を得る。最大の積の表は A 先行で４行、B 先行で８行。独立した全事象列挙で結果と両順序を照合。一般のネットワーク・最適順序・他手法との性能比較は未対応。参考：[Berkeley、変数消去](https://inst.eecs.berkeley.edu/~cs188/textbook/bayes-nets/elimination.html)。

依頼564では別の２値 X・Y の同時分布の重みを (0,0)=1、(0,1)=3、(1,0)=3、(1,1)=1 とし、X・Y を条件付き確率で交互に更新する。固定くじ 10・60・80・20・70・40 の３巡で標本は (1,0)・(0,1)・(0,1)。X=1 の割合は1/3で、正確な周辺確率1/2と異なる。各条件付き確率を重みから独立に計算して検証。少数の固定標本は収束・十分な混合・近似精度を保証せず、観測の固定や一般のネットワークは扱わない。参考：[Berkeley のギブスサンプリング講義](https://inst.eecs.berkeley.edu/~cs188/archive/su25/assets/lectures/cs188-su25-lec28.pdf)。

依頼562の追加試験では、P→X・X→C・Z→C・P→G の X の毛布 P,C,Z と、X→A・X→B・W→B・B→D の X の毛布 A,B,W を選ぶ。親、子と子の他の親を含み、親の他の子や子の子はそれだけでは含まれない。図に従う分解と正確率の条件のもと、毛布で条件付けた X は、X 自身と毛布を除く変数から独立となる。２図の選択肢の全部分集合を検証。一般の図の判定や現実の因果関係は評価しない。[Berkeley の説明](https://inst.eecs.berkeley.edu/~cs188/textbook/bayes-nets/structure.html)を参照。

依頼564は別の無向グラフ X―Y―Z に対し、各辺の両端が同じなら重み３、異なれば１とする。８状態の重みは９・３・１・３・３・１・３・９で合計32。各状態の重みを32で割る確率モデルであり、全消灯は9/32。Y の各値について X と Z の条件付き分布の行列式が０になることを別途検査した。一般の無向グラフや確率の学習・推論は未評価。参考：[CMU の確率グラフィカルモデル講義](https://www.cs.cmu.edu/afs/cs.cmu.edu/academic/class/15780-s16/www/slides/prob_models.pdf)。

依頼81は別の関係模型で、人が山を訪れる関係を固定し、各山の雨確率1/2、雨なら濡れる確率0.8・雨でなければ0.2という共通規則を２人に適用する。天気を固定すれば２人の濡れは独立、別の山の天気も独立と仮定する。同じ山ではアオが濡れたときアカが濡れる確率0.68、濡れないとき0.32。別の山では両方0.5。全天候・観測を列挙して100件分の表を照合した。関係自体は既知で、一般の関係確率モデルやパラメータの学習は扱わない。参考：[Getoor らの関係確率モデル](https://www.jmlr.org/papers/volume3/getoor02a/getoor02a.pdf)。
