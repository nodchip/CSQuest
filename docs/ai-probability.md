# AI-Probability の対応

原典: CS2023 p.77。依頼81は雨 R、濡れた石 W、鐘 B の同時分布を100回分の架空記録として表示し、観測条件に合う行と求める行を選択する。R → W、R → B の小さなベイズネットワークの例として、P(R | W) = 16/24、P(R | W,B) = 12/14、P(B | R,W) = 12/16 を比較する。R の各値で W と B が条件付き独立になるよう構成した。実測や一般的な予測精度を主張しない。

例示学習成果 1 は依頼81の固定例のみ。2 は条件付き独立の数値比較のみで計算効率は未対応。3 はベイズネットワークの例示のみ。4–8 のうち時間的推論は依頼504の２日間の固定例。推論計算量・近似、一般の表現の設計と実装は未対応。9 の意思決定は依頼98の固定例のみ。実言語での記述や自由な説明は評価しない。

依頼504は初期の晴れ確率 1/2、晴れ→晴れ 0.8・霧→晴れ 0.3、光の確率は晴れで 0.8・霧で 0.2 の模型。日ごとに遷移を予測し、観測の尤度を掛けて正規化する。２日後の晴れの事後確率は光光 1516/1667、光暗 379/983、暗光 392/529、暗暗 49/323。初期状態と２日間の全経路を別途列挙し検証。固定確率・条件付き独立などの仮定に依存し、実データ、学習、平滑化や一般の HMM を評価しない。[CMU の隠れマルコフモデル教材](https://www.cs.cmu.edu/~15281-f25/coursenotes/hmm_pf/index.html)を参照。

依頼504では各日の観測に対して、晴れ・霧それぞれでその観測が生じる確率を選ぶ。誤った尤度では更新せず、光の確率または暗い確率がその補数であることを示す。遷移と正規化の数値自体は模型が計算する。
