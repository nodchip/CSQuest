# 分母照合：SPD-Robot

[CS2023 印字 pp.304–305](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=304) と[候補台帳](coverage-spd-robot.md)を 2026-11-11 に照合した。原典の区分を明示するため、台帳に KA Core の区分列を追加し、候補 ID の区分は「未記載」から変わる。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

すべて KA Core。トピック 1〜6 はロボットのプラットフォームと機器、センサー・組込み計算・動作器、言語とライブラリ、ソフトウェア構成、制約と設計、物理系・模擬系との接続。7a〜7e は順運動学、逆運動学、動力学、ナビゲーション・経路計画、把持・操作。原典の親 7 のロボットアルゴリズムという文脈を子に保持して親子を重複計上しない。8 は安全性と相互作用。台帳トピック 12 行。

成果 1〜6 は所与のロボットでのアプリ設計・実装、Arduino ロボットの組立てと迷路走行、ロボット用言語と汎用開発の比較、設計と物理・模擬系の接続の理由、ROS の構成と接続の設計、プラットフォーム上の制約。6 行をトピックと別に追跡する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の SPD-Robot 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実機の組立て・実言語の実装・自由な設計は固定模型だけで直接評価しない。
