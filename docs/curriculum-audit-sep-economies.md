# 分母照合：SEP-Economies

[CS2023 最終報告書 印字 p.283](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=283) の SEP-Economies と[候補台帳](coverage-sep-economies.md)を 2026-11-10 に照合した。これは原典項目の範囲と区分の照合であり、教材の完成・正確性、操作と保存、独立レビューを証明しない。

## トピック

すべて KA Core の 5 件：1 は規制の有無、独占、ネットワーク効果、自由市場、知識・注意の経済などの経済モデル。2 は計画的陳腐化、サブスクリプション、フリーミアム、ライセンス、オープンソース、フリーソフト、広告付きソフトなどの価格設定と提供戦略。3 は計算資源へのアクセス差、および熟練労働の需給が製品の品質に与える影響。4 は自動化・AI が雇用市場、開発者、利用者に与える影響。5 は注意の経済などに関する倫理的懸念であり、原典は説明を受けた同意、データ収集、利用規約の冗長で難しい法律文を例示する。

番号 1〜5 は独立し、原典に番号付き子項目はない。括弧内の例を別の原典番号とは数えず、列挙例だけで各項目の全範囲が尽くされるともみなさない。

## 例示学習成果

すべて KA Core の 5 件：1 は経済モデルの社会的影響をまとめる、2 は競合する提供戦略の違いと共通点を説明する、3 はデジタル格差の例を議論する、4 は自動化と AI の社会への影響を理解する、5 は注意とデータに依存するコンピューティング経済の倫理的影響を理解する。

トピック 5 件と成果 5 件は別々に追跡する。番号・区分は候補台帳と一致し、親子の重複はない。

## 現行の冒険との区別

台帳中の番号付き依頼は旧教材の記録で、この原典照合だけでは現行の冒険からの到達・操作を確認したことにならない。現行の冒険に関する SEP-Economies の項目別評価は、この記録時点では未作成である。未作成は教材不存在の証明ではない。実際の社会調査、経済モデルの一般的な分析、自由な説明や議論は固定例だけで直接評価したとは扱わず、代替体験と残る範囲を別途確認する。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・経済的文脈と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
