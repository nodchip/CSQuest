# 庭の知らせと全称・存在

[CS2023 MSF-Discrete（印字187〜188ページ）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の CS Core 6 と学習成果 6b に関連する有限模型。三つの灯りについて全称と存在の真偽、反例と証人、全称・存在の否定を調べる。二人と二つの道具では「各人に使える道具がある」と「二人に共通の道具がある」を比較し、各人の証人、使える道具がない人、各道具を使えない人を示す。二つの基礎依頼で応用が開く。

対象は３個の灯り、または２人と２道具に固定される。有限例は一般の同値性の証明ではなく、空の領域、自由な述語式の作成や変形、一般の推論規則と証明は扱わない。表現や学習成果全体は部分対応である。

実装担当とは別の coverage_next が原典、有限例の真偽、否定、量化の順序、証拠の十分性、説明、誤答、開放と保存をコード上で確認した。独立担当は実ブラウザーを操作していない。`tests/endgame-quantifiers.test.js` は独立した期待値で正誤と不十分な証拠を確かめる。`scripts/endgame-quantifiers.playwright.js` は物語と４地域の達成状態を用意した別のブラウザー記録から、誤答、途中保存、再挑戦、段階の開放と達成を操作する。実際のスクリーンリーダー音声は未確認。
