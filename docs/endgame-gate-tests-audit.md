- [ISTQB CTFL syllabus 4.0.1](https://www.istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf) の境界値分析と分岐試験を参照。教材は少数の人工的な入力と変更を扱い、境界値分析全体を実施したとはしない。
- 仕様と元の門は人数１〜５が通る。変更Ｂは２〜５、変更Ｃは１〜６。候補は０・１・２・５・６で、最大３つを選ぶ。最初の依頼は両結果を通しながら少なくとも１変更を見逃す組合せを確認する。０と２は元の単一判定の両結果を通るが両変更の差を検出しない。１はＢの差、６はＣの差を検出し、１と６を合わせれば両結果と両変更を検出する。
- 表示するのは元の単一判定の結果であり、短絡評価される条件ごとの網羅や、実プログラム全体の分岐網羅ではない。有限例の結果は他の欠陥がない証明ではなく、実コードの作成・試験ツールの操作・自由な試験設計や一般のカバレッジ達成は未評価。
