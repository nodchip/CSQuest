# 原典との範囲照合：AR-Security

[CS2023 印字 pp.107–108（PDF 107〜108ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-ar-security.md)を2026-11-05に照合した。トピック１〜６と成果１〜５は KA Core。安全なハードウェアの原則、メモリ保護、信頼された実行環境の親項目１・４・５を追加した。台帳はトピック16行、成果５行で、親子の重複は集計時に検討する。

範囲と区分の照合であり、教材の正確性や成果の達成を証明しない。固定模型は実機の安全性・隔離・攻撃耐性を直接評価しない。
