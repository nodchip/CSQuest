## 例示学習成果

| 番号 | 区分 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | CS Core | 図から記憶技術と相対的な費用・性能を特定 | 部分 | 489 で架空の２階層を比較。SRAM・DRAM などの実技術と実数値は未評価。 |
| 2 | CS Core | メモリ遅延の実行時間への影響を計測 | 部分 | 103 は模型の固定値を集計。実機測定は未評価。 |
| 3 | CS Core | 仮想記憶管理の機能を列挙 | 部分 | 40 の固定変換。管理機能の一般的な列挙は未評価。 |
| 4 | CS Core | 複数構成・命令とデータの参照混合で平均アクセス時間を計算 | 部分 | 103 は単一キャッシュの４例。複数構成一般と混合参照は未評価。 |

依頼795では各４棚の直接対応と２ウェイ・組内 LRU を、２つの８参照列で比較する。前者はヒット０対６、後者は５対４。２ウェイで組数が減ることで干渉する組合せも変わる固定例であり、全ての参照列・方針・実機で性能が決まることを示さない。独立した LRU 模型と４種類の巻物・長さ５の全1,024列×２方式を照合し、各方式の途中復元も検査した。参考：[Cornell: キャッシュ](https://www.cs.cornell.edu/courses/cs3410/2026sp/notes/caches.html)。
