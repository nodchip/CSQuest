# MSF-Calculus：差商と瞬間の速さ（部分対応）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.192–194、MSF-Calculus 2a の導関数と極限に関連する固定例。現行観測所の勾配降下は与えられた傾きを使う。旧依頼473 `derivative-limit.js` は同じ位置・前後の差商を既に扱うため、その計算を再利用し重複を新しい範囲として二重計上しない。

位置 s(t)＝t²、基準 t＝２ で s＝４。h≠０ の平均速度は ((2+h)²−４)/h＝４＋h。h＝１・0.5・0.1・−0.5・−0.1 の値は５・4.5・4.1・3.5・3.9。h を０に近づけると差商は４に近づき、この点の導関数は４。０をそのまま分母に代入しない。数例が近いだけで一般の極限を証明しないが、この固定式では代数的に４＋h と示す。

参考：[OpenStax Calculus Volume 1, Derivative as a Function](https://openstax.org/books/calculus-volume-1/pages/3-2-the-derivative-as-a-function)。１つの関数・点・幅のみで、任意の導関数・証明・実測データや自由な説明は評価しない。MSF 全体の完成を示さない。
