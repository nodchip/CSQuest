# SEP-Ethical-Analysis の対応状況

出典: [CS2023, SEP-Ethical-Analysis](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 274–276。原典を要約した作業用一覧。依頼63は架空の村に限定した固定例で、特定の案を一般的に正しいと判定しない。

## トピック

| 番号 | 分類 | 要約 | 現状 |

| 1 | CS Core | 議論における誤謬や誤った表現を避ける | 未着手 |
| 2 | CS Core | 倫理理論と意思決定 | 依頼63で複数の視点と案を比較。理論の体系的な適用は未対応 |
| 3 | CS Core | 文化が技術の理解・設計・利用に果たす役割 | 地域の状況を考慮する必要に触れるのみ。文化の比較は未対応 |
| 4 | CS Core | コンピューティング倫理と法・社会規範の関係 | 未着手 |

| 9 | KA Core | 結果、義務、権利、公正、ケアなど複数の倫理枠組み | 未着手 |

## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | CS Core | 文化的背景が意思決定に与える影響を説明 | 未着手 |
| 2 | CS Core | 倫理的議論における例と類推の利用を表現 | 未着手 |
| 3 | CS Core | 議論の基本的な誤謬を分析・回避 | 未着手 |
| 4 | CS Core | 議論の前提と結論を特定 | 未着手 |
| 5 | CS Core | 倫理と文化・価値・法の関係を評価 | 未着手 |
| 6 | CS Core | 倫理的根拠に基づく決定を正当化 | 固定の選択肢の影響を比較するのみ。自由な根拠の提示は未対応 |
| 7 | KA Core | 関係者の立場を文化的背景とともに区別 | 架空の４人の声を読む例。文化的背景と実際の関係者の立場は未対応 |
| 8 | KA Core | 技術的決定における倫理的課題の先送りを分析 | 未着手 |
| 9 | KA Core | 倫理枠組みの長所と短所を議論 | 未着手 |
| 10 | KA Core | 複数の倫理的枠組みでジレンマを分析 | 依頼63は固定の影響を比較するのみ。複数の理論を適用する分析は未対応 |

依頼63では公開・端末・受付の３案について、提示された条件と４人の声から利点と負担を確認する。最終的な３案の選択はすべて受け入れ、唯一の倫理的正解としない。実際の関係者、地域、法律、実施後の影響を評価するものではない。
