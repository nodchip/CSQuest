# SPD-SEP/Game：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.309–312。[既存調査](spd-sep.md)と照合。すべて Non-core。「未照合」は未実装の証拠ではない。固定例は実際の調査・設計・自由な説明能力を直接評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1a | Non-core | 創作の知的財産権の所有、生成 AI など | 未照合 | 対応例を要照合。 |
| 1b | Non-core | 利用許諾、例外、ライセンスと権利の執行 | 部分 | 依頼399で販売用の架空素材に CC BY・BY-NC の条件を比較。例外や執行は未対応 |
| 2a | Non-core | ゲーム UI の要件、使いやすさと評価 | 未照合 | 対応例を要照合。 |
| 2b | Non-core | 障害の種類、ゲーム UI のアクセシビリティと評価 | 部分 | 依頼117の字幕と操作の代替、806の色以外の形・読み上げ名・キーボード操作の固定模型。障害全般や実利用者との評価は未対応 |
| 3a | Non-core | プレイ時の上半身のけがと緩和 | 未照合 | 対応例を要照合。 |
| 3b | Non-core | イベント・製造における火災、電気などのリスク評価 | 未照合 | 対応例を要照合。 |
| 3c | Non-core | 遊ぶ動機、ゲーム心理と精神的健康 | 部分 | 依頼398で休憩時の進捗と通知の選択を比較。実際の心理や健康は評価しない |
| 4a | Non-core | 機器の材料・製造・使用・再利用と持続可能性 | 未照合 | 対応例を要照合。 |
| 4b | Non-core | 調達網での強制労働、労働条件、認証と支援 | 未照合 | 対応例を要照合。 |
| 5a | Non-core | 表象、包摂、ステレオタイプとメディアリテラシー | 未照合 | 対応例を要照合。 |
| 5b | Non-core | 業界の平等、職業経験、社会的流動性 | 未照合 | 対応例を要照合。 |

## 例示学習成果
