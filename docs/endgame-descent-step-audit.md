# AI-ML：誤差の谷を進む（部分対応）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.71–75、AI-ML 10b の勾配降下に関連する固定例。現行観測所の教師あり分類は固定した候補を選ぶが、勾配で値を更新しない。旧依頼116 `gradient.js` は同じ二次関数と学習率をすでに扱うため、その計算を再利用し、重複を新しい範囲として二重計上しない。

損失 L(w)＝(w−２)²、勾配２(w−２)、初期値０。学習率0.25では更新 w←w−0.25×勾配で０→１→1.5、損失４→１→0.25。学習率１では０→４→０、損失４→４→４。局所的に勾配と逆向きへ進んでも、大きな歩幅で谷底を越える場合がある。２回だけの例で、0.25 が常に最良・一般の収束を保証するとはしない。

参考：[Google の勾配降下入門](https://developers.google.com/machine-learning/crash-course/linear-regression/gradient-descent)。固定の１変数・２歩の模型であり、一般のモデルやデータ、パラメータ選択、実コード・自由な説明や実学習の性能は評価しない。
