# DM-Processing：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.118–119。[既存の調査](dm-processing.md)と実装・テストを照合した。状態は[追跡方法](coverage-status.md)に従う。原典の親項目 2・3・4・6・8 は子項目を個別に記し、集計で重複させない。すべて KA Core。模型の操作は実際の DBMS や一般の性能を直接評価しない。
