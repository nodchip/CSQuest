# SEP-Communication：コミュニケーションの項目別対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.279–280。[既存調査](sep-communication.md)と依頼・検査を照合。状態は[追跡方法](coverage-status.md)に従い、「未照合」は未実装の証拠ではない。「部分」は関連する固定例を示し、項目全体の修得を意味しない。実際の社会調査・法的判断・自由な説明や文章作成は固定例だけでは直接評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | CS Core | 口頭、文章、電子的なチーム・集団内の連絡 | 部分 | 依頼295で架空の報告の札を選ぶ固定例。実際の連絡は未対応 |
| 2 | CS Core | ソース、文書、チュートリアル、参照・API 文書等 | 未照合 | 対応例を要照合。 |
| 3 | CS Core | 顧客、管理者、一般の人など異なる相手への伝達 | 部分 | 依頼295で旅人と修理係の必要を聞き、報告を選ぶ固定例。他の相手・状況は未対応 |
| 4 | CS Core | ツールを含むチーム協働と対立解決 | 未照合 | 対応例を要照合。 |
| 5 | CS Core | 対象者に向けたアクセシビリティと包摂 | 未照合 | 対応例を要照合。 |
| 6 | CS Core | 自然言語の違いを含む文化的配慮 | 未照合 | 対応例を要照合。 |
| 7 | KA Core | 伝達手段や選択に関わる要因のトレードオフ | 未照合 | 対応例を要照合。 |
| 8 | KA Core | 倫理やアクセシビリティ等の懸念を伝え、問題を解く・提案する | 未照合 | 対応例を要照合。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 代替と限界 |
|---|---|---|---|---|
| 1 | CS Core | 簡潔・正確な技術文書と形式、図表、参照の重要性 | 部分 | 依頼295で事実・範囲と未確認事項の札を選ぶ固定例。実際の文書構成は未対応 |
| 2 | CS Core | 技術文書の正確性、簡潔さ、明確さと対象者への配慮を分析 | 部分 | 依頼295で不確かな断定・不要な個人情報を除き相手に必要な情報を選ぶ固定例。自由な分析は未対応 |
| 3 | CS Core | 対象者に配慮したアクセシブルな正式発表 | 未照合 | 対応例を要照合。 |
| 4 | CS Core | 多様な意見と参加を尊重する交流の計画 | 未照合 | 対応例を要照合。 |
| 5 | CS Core | 効果的な伝達の性質の特定と説明 | 部分 | 依頼295で２人の必要を聞き、限定された情報を選ぶ固定例。一般的な説明は未対応 |
| 6 | CS Core | チーム内の効果的な伝達と対立解決 | 未照合 | 対応例を要照合。 |
| 7 | CS Core | 多様で異文化のチームの成果に影響する方法 | 未照合 | 対応例を要照合。 |
| 8 | KA Core | 多様な遠隔チームで働く際の自身の強みと弱みの評価 | 未照合 | 対応例を要照合。 |
| 9 | KA Core | 繊細な倫理的懸念を伝える適切な方法の選択 | 未照合 | 対応例を要照合。 |

各依頼の前提・出典と検証、実際の状況に一般化できない範囲は[既存調査](sep-communication.md)を参照する。
