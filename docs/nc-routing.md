# NC-Routing の対応状況

出典: [CS2023 NC-Routing](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p. 199。原典を要約した作業用一覧。依頼48は一つの宛先と固定ネットワークのモデルであり、実際のネットワーク全体を再現しない。

## トピック

| 番号 | 分類 | 内容と現状 |
|---:|---|---|
| 1 | KA Core | 経路制御の方式と階層、ドメイン内外、集中・分散、送信元経路、仮想回線、品質 | 依頼48で固定した次の塔の設定のみ。経路の自動決定、階層や品質は未対応 |
| 2 | KA Core | 転送表と照合方法 | 依頼48で次の塔を設定し、依頼61で８ビットの架空宛先と最長接頭辞を照合。実 IP 転送表の設定は未対応 |
| 3 | KA Core | IP と規模拡張、NAT、CIDR、BGP、IP の版 | 依頼61は可変長接頭辞の固定例。集約や NAT・BGP・IP の版の比較は未対応 |

## 例示学習成果

| 番号 | 分類 | 内容と現状 |
|---:|---|---|
| 1 | KA Core | 経路制御の方式と階層を説明 | 依頼48の固定経路のみ。一般の方式と自由記述は未対応 |
| 2 | KA Core | IP 網でのパケット転送を説明 | 依頼48の次の塔と回数制限、依頼61の最長接頭辞を操作。IP ヘッダー・実網の転送・自由記述は未対応 |
| 3 | KA Core | インターネットの規模拡張への対応を説明 | 未着手 |

依頼48では S–A、S–B、A–B、A–G の費用が１、B–G が４。各塔の城 G への転送先を設定し、S・A・B の３地点からの手紙を１ホップずつ進める。巡回を含め最大５ホップで停止する簡略モデル。S→A、A→G、B→A の設定では費用はそれぞれ２・１・２。全18設定を独立した単純経路の列挙と照合し、各出発地点からの最小費用を検証する。転送表の更新で全試行をリセットする。

依頼61は８ビットの架空宛先に対し、長さ０・１・３・４の固定接頭辞の一致と最長の送り先を選ぶ。全256宛先を独立した整数範囲による判定と照合。実際の IP アドレス、経路学習、同じ長さの候補の優先順位は操作しない。
