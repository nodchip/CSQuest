# 水門の型の依頼

CS2023 FPL-Types（印字ページ136–138）を参照。数と真偽の札、足し算と門への入力、名前付きの水位・合図の組を操作する。数0と真偽のいいえは別の値とし、数札は例であって数の全範囲とはしていない。札は写しを配置し、同じ札を複数の欄に使える。

基礎の異なる２依頼の達成後に、両方の分岐を実行前に調べる方式と、選んだ分岐を実行時に調べる方式の固定例が開く。直す前後や条件を変え、条件と結果を保存・比較できる。依頼内で規則を説明する。

原典と模型、画面を別担当が独立レビューし、結果の条件を保持し最後の結果を達成表示に残すよう修正、再確認した。`tests/endgame-types.test.js` は型不一致、値違い、全８条件と完了履歴を検証し、`scripts/endgame-types.playwright.js` は到達、誤答、復元、異なる２件での開放、達成を複数幅で検証する。

固定模型での部分的な導入にとどまり、実言語の型規則や型システム全体、自由な実装やデバッグ、形式的な安全性の証明を扱っていない。実行前検査がすべての誤りを防ぐとは主張しない。
