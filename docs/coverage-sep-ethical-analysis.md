# SEP-Ethical-Analysis：倫理分析の方法の項目別対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.274–276。[既存調査](sep-ethical-analysis.md)と依頼・検査を照合。状態は[追跡方法](coverage-status.md)に従い、「未照合」は未実装の証拠ではない。「部分」は関連する固定例を示し、項目全体の修得を意味しない。実際の社会調査・法的判断・自由な説明や文章作成は固定例だけでは直接評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | CS Core | 議論における誤謬や誤った表現を避ける | 部分 | 依頼499で後件肯定・前件否定と妥当な推論を反例で比較。非形式的な誤謬や実際の議論は未対応 |
| 2 | CS Core | 倫理理論と意思決定 | 部分 | 依頼63で関係者の声、500で限定した結果・同意・配分の物差しを比較。理論の体系的な適用は未対応 |
| 3 | CS Core | 文化が技術の理解・設計・利用に果たす役割 | 部分 | 1200で架空の語りの慣習と公開・再利用の希望を比較。実共同体や多様な文化全般は未評価。 |
| 4 | CS Core | コンピューティング倫理と法・社会規範の関係 | 未照合 | 対応例を要照合。 |
| 5 | KA Core | 専門的なチェックリスト | 未照合 | 対応例を要照合。 |
| 6 | KA Core | 評価ルーブリック | 未照合 | 対応例を要照合。 |
| 7 | KA Core | 関係者の分析 | 部分 | 依頼63で４人の架空の声と各案の影響を比較。実際の関係者の調査は未対応 |
| 8 | KA Core | 立場性の理論 | 未照合 | 対応例を要照合。 |
| 9 | KA Core | 結果、義務、権利、公正、ケアなど複数の倫理枠組み | 部分 | 依頼500で支援人数、同意の条件、少ない方への配分を限定的に比較。各理論全体やケアの分析は未対応 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 代替と限界 |
|---|---|---|---|---|
| 1 | CS Core | 文化的背景が意思決定に与える影響を説明 | 部分 | 1200で架空の語りに関する異なる希望を聞き、用途と公開範囲を選ぶ。実際の共同体や自由な説明は未評価。 |
| 2 | CS Core | 倫理的議論における例と類推の利用を表現 | 未照合 | 対応例を要照合。 |
| 3 | CS Core | 議論の基本的な誤謬を分析・回避 | 部分 | 依頼499で２形式の反例を操作。一般の誤謬や自由な分析は未対応 |
| 4 | CS Core | 議論の前提と結論を特定 | 部分 | 依頼499で明示された前提・結論の真偽を比較。自由な文章からの特定は未対応 |
| 5 | CS Core | 倫理と文化・価値・法の関係を評価 | 未照合 | 対応例を要照合。 |
| 6 | CS Core | 倫理的根拠に基づく決定を正当化 | 部分 | 依頼63は固定の選択肢の影響を比較するのみ。自由な根拠の提示は未対応 |
| 7 | KA Core | 関係者の立場を文化的背景とともに区別 | 部分 | 依頼63は架空の４人の声を読む例。文化的背景と実際の関係者の立場は未対応 |
| 8 | KA Core | 技術的決定における倫理的課題の先送りを分析 | 未照合 | 対応例を要照合。 |
| 9 | KA Core | 倫理枠組みの長所と短所を議論 | 部分 | 依頼500で各物差しが何を含み省くかを示す。実際の自由な議論は未対応 |
| 10 | KA Core | 複数の倫理的枠組みでジレンマを分析 | 部分 | 依頼500で架空の２案を３つの限定した物差しで比較。理論全体や実際のジレンマの分析は未対応 |

各依頼の前提・出典と検証、実際の状況に一般化できない範囲は[既存調査](sep-ethical-analysis.md)を参照する。

依頼1200は [UNESCO の無形文化遺産を守る倫理原則](https://ich.unesco.org/en/ethics-and-ich-00866) を参考に、架空の語りについて関係者の異なる希望、限定した閲覧、別用途での再相談を扱う。意見や同意の範囲は場面ごとの仮定で、特定の文化や共同体を代表せず、法的権利・実際の合意・自由な議論を評価しない。`tests/community-archive.test.js` は各場面の資料確認・選択・保存を検査する。
