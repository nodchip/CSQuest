# 分母照合：MSF-Discrete

[CS2023 最終報告書 印字 pp.187–188](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=187) と[候補台帳](coverage-msf-discrete.md)を 2026-11-11 に照合した。これは原典範囲の照合であり、教材の完成を示さない。

## トピック

原典の1〜8は、集合・関係・関数・濃度、再帰定義、証明、数え上げ、合同算術、論理、グラフ、漸近記法。KA Core は同じ項目をより深く多くの計算への応用と共に扱うため、台帳は `CS Core / KA Core` の8行として記録し、二重計上しない。

## 例示学習成果

CS Core の1a〜1e、2a〜2e、3a〜3f、4a〜4d、5a〜5b、6a〜6g、7a〜7dの33項目。集合操作と濃度、再帰・漸化式、証明、数え上げ、合同算術、論理、グラフについて、用語の説明だけでなく計算・モデル化・論証等が含まれる。親1〜7は見出しであり子と重複して数えない。トピック8に独立した例示成果8は列挙されていない。番号・区分は台帳と一致する。

## 現行の冒険と残る確認

旧台帳の依頼は旧教材の記録であり、この照合によって現行の冒険から到達できるとは判定しない。現行冒険の項目別評価には一部の固定例があるが、その部分対応を原典全体の完成とみなさない。教材の正確性、実際の到達、操作・保存、独立レビュー、および操作で直接評価できない能力は別途確認する。範囲ハッシュは候補 ID と台帳要約の変更検出であり、内容の正しさや教材完成の証明ではない。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
