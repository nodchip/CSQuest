# 原典との範囲照合：FPL-Translation

[CS2023 印字 pp.139–140](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の FPL-Translation と[項目別台帳](coverage-fpl-translation.md)を2026-11-06に照合した。PDF の取得が一時的にタイムアウトしたため、[ACM が公開する同報告書](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)の本文を参照した。

トピック１〜８は CS Core、９〜10は KA Core。例示学習成果１〜６は CS Core、７は KA Core。番号付きの子項目はなく、分母候補はトピック10件・成果７件。成果３は実在言語の構文を BNF 等で指定する内容であり、架空の固定図から選ぶ依頼788だけでは実在言語の文法や自由な記述を評価しない。成果６はネストした条件文または算術式で曖昧性と優先順位を示すが、現在の台帳は算術式の限定例である。

トピック９に該当するメソッド表の固定模型として、既存の依頼1204を台帳に加えた。クロージャの依頼774とともに実装や一般の ABI の全体を評価するものではない。これは原典との範囲・区分の照合であり、教材の正確性、学習成果の達成、単位全体の完成を証明しない。

同日、依頼788に C の `if` 文の限定された形を規則札で選び試す教材を追加した。C 全体や文法の自由な記述は引き続き未評価。
