水晶の題材は、既知の３例から固定の２特徴の距離が最小の１例を選び、既知の記録と別に取っておいた３件で予測を比較するもの。結果は小さな架空データの例に限られ、現実の鑑定や一般化性能を評価しない。

依頼376は高さ・光が (160,0)、(180,1) の手本と高さ168の新規例を使う。光１のとき、差の合計は元の尺度で９・12、手本の高さ範囲20で割った尺度では1.4・0.6。光が欠測のときは手本の平均0.5で補い、尺度変換後は0.9・1.1。変換の基準は手本から得て新規例にも適用し、補完値は観測された真値と区別する。架空の２例であり、実データ・他の補完方法や実際の精度は扱わない。[正規化](https://developers.google.com/machine-learning/crash-course/numerical-data/normalization)、[欠損値](https://developers.google.com/machine-learning/crash-course/overfitting/data-characteristics)。

依頼377の３組は重複しない各４件の架空記録。用意された境界３・４の予測一致数は、訓練３・４、検証４・３、テスト４・３。検証で境界３を選んでから別のテストを開く。候補は自動学習せず、検証やテストの繰り返し利用による適合と、小標本では実際の精度が保証されない点を説明する。[参考：Google のデータ分割](https://developers.google.com/machine-learning/crash-course/overfitting/dividing-datasets)

依頼378は２つの二値特徴の XOR を対象とし、各特徴の重みと境界を −２〜２ から選ぶ。元の２特徴のみの125設定を列挙すると最大３/４一致。積の特徴を加え、各重み１・１・−２、境界１で４/４一致する。元の特徴について、(0,0) を負、(1,0)・(0,1) を正とする条件から (1,1) も正になるため、任意の実数重みでも単一直線では分離できない。手動設定の固定例であり、学習アルゴリズムや一般化性能は扱わない。[参考：Carnegie Mellon の XOR と線形分離](https://www.cs.cmu.edu/~tom/10601_fall2012/recitations/Recitation_2Oct2012_PG.pdf)

依頼379は入口で報酬１の終了か報酬０で奥へ進み、奥では報酬４で終了する決定的環境。初期値０、学習率１、割引率0.5の Q 学習で、初回の扉は０、宝の取得で奥は４、次の扉の更新で入口の扉は２となる。プレイヤーが行動を選ぶ固定例で、確率的遷移や一般の収束は扱わない。[参考：Berkeley の Q 学習](https://inst.eecs.berkeley.edu/~cs188/textbook/rl/mfl.html)

依頼380はラベルのない点 [1,2,8,9] を２群に分ける。初期中心 [1,2] では [1,19/3]、[1.5,8.5]、[1.5,8.5] と３回更新し、初期中心 [1,9] では２回で同じ中心に落ち着く。各点を近い中心に割り当て、各群の平均を取り直す。同距離・空群は発生しない固定例で、一般のデータ、群数の選択や結果の評価は扱わない。[参考：Google の k-means](https://developers.google.com/machine-learning/clustering/kmeans/overview)

依頼70では、記号を記憶し未知には訓練の多数派を返す方法と、用意された温かさの規則を比べる。前者は訓練６/６・未使用２/４、後者は５/６・４/４。いずれも固定された架空の小標本であり、単純な方法の一般的な優位性や実際の汎化性能を示さない。ルールは訓練アルゴリズムで自動獲得していない。

依頼118は各10軒の東西の村の架空の修理予測を使用。方式１は真陽性率６/８・３/４、偽陽性率１/２・３/６、選択後の適合率６/７・３/６。方式２は真陽性率６/８・３/４、偽陽性率２/２・１/６、適合率６/８・３/４。必要性の確認結果を全軒で正しいと仮定し、分子・分母と分数の等しさを操作する。指標の一致だけで公平と断定せず、確認結果の偏り、影響や当事者の意見の必要性を明記。実データ、因果関係、実際の判断の公平性は評価しない。参考: [Hardt らの分類と機会に関する研究](https://papers.neurips.cc/paper_files/paper/2016/hash/6a9659feb1216f14f7384ba499518b38-Abstract.html)。

依頼496は妨害３件・普通３件に対する３人の固定判定を比較する。各人はいずれも正答４／６、見逃し１、誤警報１。誤りが別々の組の多数決は６／６、同じ２件に重なる組は４／６。全行の票と集計を検証した。これは学習済みと仮定した６件の模型で、学習手法、一般の性能や防御の安全性を評価しない。[scikit-learn の多数決](https://scikit-learn.org/stable/modules/ensemble.html)を参照。

依頼497は同じ点灯確率で独立に観測する模型に Beta(1,1)・Beta(4,4) の事前分布を使い、点灯数・消灯数を各パラメータに加える。点灯３・消灯１の事後平均は４／６・７／12、点灯１・消灯３では２／６・５／12。２分布と８回までの全二値列、平均と観測割合の比較を検証した。事前分布と独立性は仮定で、事後平均は分布全体や確率の確定ではない。[Carnegie Mellon の解説](https://www.stat.cmu.edu/~brian/ting/hw02/hw2sol.pdf)を参照。

依頼501は６頂点の鎖で両端を赤１・青−１または赤１に固定し、中間４頂点を隣の直前値の平均で同時更新する。中央の辺の有無と右端の手本の２×２条件を４回操作する。両端が異なる場合の４回後は、道ありで [1, 0.5625, 0.25, −0.25, −0.5625, −1]、道なしで [1, 0.75, 0.75, −0.75, −0.75, −1]。４条件の手計算結果と保存を検証した。値は正解や確率と断定せず、似た点を結ぶ仮定、手本の誤り、４回後の未収束と実データの限界を明示する。[Xiaojin Zhu の博士論文](https://pages.cs.wisc.edu/~jerryzhu/ssl/pub/thesis.pdf)の反復ラベル伝播を参照。

依頼549は Fisher の Iris 原データから Versicolor・Virginica の各50行を抽出し、花弁の長さ・幅を 0.1 cm 単位の整数で使う。各種の元順の１、６、11、…、46行をテスト10件とし、残り40件を比較に用いる。６候補の比較用一致数は長さ4.8・5.0・5.2 cm以上で74・72・65、幅1.6・1.7・1.8 cm以上で74・75・75（各80件）。幅1.7・1.8のテスト一致はそれぞれ19/20。原データとの全行照合と混同行列を検査した。公開済みの資料を規則的に分割した固定例で、実運用での未知データの一般化や自動学習は証明しない。[出典・利用条件](sources-and-assets.md)。
