# 分母照合：SEP-Privacy

[CS2023 印字 pp.278–279](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=278) と[候補台帳](coverage-sep-privacy.md)を 2026-11-11 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core トピック 1〜4 は広範な収集の影響、匿名性・仮名性・身元、技術による保護、市民的自由・権利・文化差。KA Core 5〜10 はプライバシーの哲学的・法的概念、法域の法的基盤、実務分野の法制、人を対象とする研究と法を超える原則、表現の自由と制限、投稿・モデレーション・責任。10 行に番号付き子はない。原典は個人・組織・専門職・統治の各面と、文化・法域ごとの違いを文脈に含める。

CS Core 成果 1〜5 は取引・蓄積データの脅威対策、監視における収集、匿名性と仮名性、差分プライバシーと E2E 暗号化等、文化による違い。KA Core 6〜8 は適切な法域における保護の哲学的基礎、法令と法を超える原則の批評、適切な表現の自由のための戦略。成果 8 行を別に追跡する。法域と事情の異なる問題を単一の法的判断に一般化しない。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行の案内所には収集・仮名性・閲覧範囲に関する一部評価があるが、実社会の匿名性・法令適合・自由な議論の達成を意味しない。各現行行の到達・正確性・操作・保存・独立レビューは別途確認する。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
