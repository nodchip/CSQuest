# MSF-Statistics の対応状況

出典: [CS2023 MSF-Statistics](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 190–191。原典を要約した作業用一覧。依頼47は７件の架空データの固定例であり、一般の統計的推論や自由な計算能力を評価しない。

| 1 | CS Core | 母集団、標本、代表値、分散 | 依頼47で７件の平均・中央値の比較。母集団からの標本抽出、分散は未対応 |
| 2 | CS Core | 一変量データの点推定、信頼区間 | 未着手 |
| 3 | KA Core | 多変量データの推定、相関、回帰 | 未着手 |
| 4 | KA Core | 次元削減、平滑化 | 未着手 |
| 5 | KA Core | 統計モデルとアルゴリズム | 依頼18で既知と未使用の架空データの一致数を比較。一般のモデルや過学習の検証は未対応 |
| 6 | KA Core | 仮説検定 | 未着手。原典にはこのトピックに対応する独立した例示学習成果の列挙がないため、トピックとして追跡する |
