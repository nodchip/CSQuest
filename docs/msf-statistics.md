依頼47では [1,2,3,4,5,6,7] と [1,2,3,4,5,6,28] を短い順に並べ、平均４・７と中央値４・４を比較する。後者の値28は架空の記録であり、誤記や異常値だと断定しない。少数のデータから将来の分布を推定するものではない。

依頼113は10枚の整数札を [0,3)、[3,6)、[6,9) に分類し、等幅のヒストグラムを作る。広がった記録は度数４・２・４、集まった記録は０・10・０で、どちらも合計40・平均４。区間境界と全札の分類を検証した。区間幅による影響は説明のみで操作できず、一般的な標本分布の推定は未対応。

依頼114は依頼113の広がった記録 [1,1,2,2,4,4,6,6,7,7] と最後の７を30に替えた記録を小さい順に表示する。上下各５枚の中央値を四分位数とする方法では両方とも Q1=2、Q3=6、IQR=4、内側の境界は −4 と12。30は境界外の候補だが誤記や除外すべき値とは限らない。四分位数の定義は複数ある。境界と数え上げの例は [NIST の箱ひげ図の説明](https://www.itl.nist.gov/div898/handbook/eda/section3/boxplot.htm) を参照。

依頼115は４点 (0,1)、(1,2)、(2,3)、(3,4) と、最後を (3,9) に替えた架空の記録に直線を当てる。傾き 0〜2.5 を0.5刻み、切片 0〜2 を0.5刻みで選び、縦の残差の二乗和を比較する。最小はそれぞれ傾き１・切片１で０、傾き2.5・切片０で7.5。全候補を数え上げ、独立した通常の最小二乗の式と照合した。大きな値の誤記・因果関係・未知データへの精度は断定しない。

依頼431は独立かつ同じ点灯確率の４回の二値観測を仮定し、順序付きの「点灯３・消灯１」と「点灯２・消灯２」の尤度を確率０・1/4・1/2・3/4・１で比較する。尤度の分子はそれぞれ [0,3,16,27,0] と [0,9,16,9,0]（分母256）。[Penn State のベルヌーイ試行と尤度の教材](https://online.stat.psu.edu/stat504/Lesson01)を参照。候補が真である確率を表すものではなく、独立性・確率一定の仮定や少標本の不確実性に注意する。一般の推定や信頼区間は扱わない。

依頼432は固定された３観測と３本の直線に対し、独立で平均０・既知の分散１の正規誤差を仮定して二乗誤差の合計と尤度の比 exp(−SSE/2) を比較する。[MIT の線形回帰の講義資料](https://ocw.mit.edu/courses/18-655-mathematical-statistics-spring-2016/b36cbb44af02cddb9dc42d92b767c462_MIT18_655S16_LecNote19.pdf)を参照。３候補の比較であり、一般的な導出や自由な計算は扱わない。
