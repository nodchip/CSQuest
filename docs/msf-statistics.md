# MSF-Statistics の対応状況

出典: [CS2023 MSF-Statistics](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 190–191。原典を要約した作業用一覧。依頼47は７件の架空データの固定例であり、一般の統計的推論や自由な計算能力を評価しない。

依頼47では [1,2,3,4,5,6,7] と [1,2,3,4,5,6,28] を短い順に並べ、平均４・７と中央値４・４を比較する。後者の値28は架空の記録であり、誤記や異常値だと断定しない。少数のデータから将来の分布を推定するものではない。

依頼718は９日の架空記録 [2,2,2,8,2,2,2,2,2] について、３〜５日目を中心とする１・３・５日の平均を比べる。４日目の結果は８・４・3.2。窓が端を越える場合は計算せず、中心付きの窓は未来の値も使う。急変の原因をノイズと断定せず、実データの平滑化や予測性能は評価しない。[NIST の中心付き移動平均](https://www.itl.nist.gov/div898/handbook/pmc/section4/pmc422.htm)を参照。

依頼113は10枚の整数札を [0,3)、[3,6)、[6,9) に分類し、等幅のヒストグラムを作る。広がった記録は度数４・２・４、集まった記録は０・10・０で、どちらも合計40・平均４。区間境界と全札の分類を検証した。区間幅による影響は説明のみで操作できず、一般的な標本分布の推定は未対応。

依頼114は依頼113の広がった記録 [1,1,2,2,4,4,6,6,7,7] と最後の７を30に替えた記録を小さい順に表示する。上下各５枚の中央値を四分位数とする方法では両方とも Q1=2、Q3=6、IQR=4、内側の境界は −4 と12。30は境界外の候補だが誤記や除外すべき値とは限らない。四分位数の定義は複数ある。境界と数え上げの例は [NIST の箱ひげ図の説明](https://www.itl.nist.gov/div898/handbook/eda/section3/boxplot.htm) を参照。

依頼115は４点 (0,1)、(1,2)、(2,3)、(3,4) と、最後を (3,9) に替えた架空の記録に直線を当てる。傾き 0〜2.5 を0.5刻み、切片 0〜2 を0.5刻みで選び、縦の残差の二乗和を比較する。最小はそれぞれ傾き１・切片１で０、傾き2.5・切片０で7.5。全候補を数え上げ、独立した通常の最小二乗の式と照合した。大きな値の誤記・因果関係・未知データへの精度は断定しない。

依頼431は独立かつ同じ点灯確率の４回の二値観測を仮定し、順序付きの「点灯３・消灯１」と「点灯２・消灯２」の尤度を確率０・1/4・1/2・3/4・１で比較する。尤度の分子はそれぞれ [0,3,16,27,0] と [0,9,16,9,0]（分母256）。[Penn State のベルヌーイ試行と尤度の教材](https://online.stat.psu.edu/stat504/Lesson01)を参照。候補が真である確率を表すものではなく、独立性・確率一定の仮定や少標本の不確実性に注意する。一般の推定や信頼区間は扱わない。

依頼432は固定された３観測と３本の直線に対し、独立で平均０・既知の分散１の正規誤差を仮定して二乗誤差の合計と尤度の比 exp(−SSE/2) を比較する。[MIT の線形回帰の講義資料](https://ocw.mit.edu/courses/18-655-mathematical-statistics-spring-2016/b36cbb44af02cddb9dc42d92b767c462_MIT18_655S16_LecNote19.pdf)を参照。３候補の比較であり、一般的な導出や自由な計算は扱わない。

依頼433は母平均からの差が −1.5・−0.5・0.5・1.5 の４値を等確率でとる位置模型で、独立に２回抽出し標本平均の両側に0.5または１の幅を取る。順序付き16通りのうち母平均を含む区間は10通りと14通りで、包含率は62.5％と87.5％。母平均4.5の例で各組を調べ、区間作成法の包含率と観測後の特定の区間を区別する。[NIST の信頼区間の説明](https://www.itl.nist.gov/div898/handbook/prc/section1/prc14.htm)を参照。一般の母集団や95％区間の公式は扱わない。

依頼434は母標準偏差２が既知の正規母集団からの独立標本を仮定し、標本平均10・12、標本数１・４・16について平均 ± 1.96×２/√n の約95％区間を比較する。片側の幅は3.92・1.96・0.98で、指定の幅以下に必要な最少本数を３候補から選ぶ。[NIST の公式と条件](https://www.itl.nist.gov/div898/handbook/prc/section1/prc14.htm)を参照。母標準偏差が未知の場合や、任意の値の自由な計算は扱わない。

依頼435では観測２・２、各予測 θ、独立な正規誤差の分散１、平均０の正規事前分布を仮定し、２(２−θ)²＋λθ² の候補を比較する。事前分布を使わない λ=0 の最尤推定は２、事前分散1/2・1/6に対応する λ=2・6 の最大事後推定は１・0.5。平方完成により実数全体でも最小値は４/(２＋λ)。[Cornell の回帰と正則化の教材](https://www.cs.cornell.edu/courses/cs4780/2022sp/notes/LectureNotes12.html)を参照。一般の多変量模型、事前分布の選択、事後分布全体や予測精度は扱わない。

依頼436は８回の独立な二値観測について、帰無仮説 p=1/2 と両側対立仮説 p≠1/2、事前に決めた有意水準５％を用いる。点灯８回の場合は０・８回の２/256、７回の場合は０・１・７・８回の18/256が p 値で、それぞれ棄却・棄却しない。帰無仮説下の実際の棄却確率は２/256で５％以下。[NIST の p 値の説明](https://www.itl.nist.gov/div898/handbook/prc/section1/prc131.htm)を参照。自由な標本数や仮説、検出力、複数検定は扱わない。
