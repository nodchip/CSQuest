# SPD-Game のゲームデザイン教材の個別評価

[原典の範囲照合](curriculum-audit-spd-game.md)を踏まえ、2026-11-05 に [SPD-Game 台帳](coverage-spd-game.md)の 5a・5b を依頼117の画面、実装とテストに照らして評価した。両方とも **部分** とする。

- **5a ゲームデザインの語彙・経験モデル**：盾を毎回補充するか２回に制限するかを選び、盾と回避を３回操作する。その後、本人の感じ方と、ルールが選択に影響することを振り返る。画面では MDA のメカニクス・ダイナミクス・エステティクスを説明し、感じ方に正誤を設けない。MDA 全体や別の経験モデル、実際の感情の測定は扱わない。
- **5b 利用者中心の設計・反復**：架空の２人と、変更前後の字幕・操作設定を比較する。表示と操作の２つの改善を独立に切り替え、設定と人物の組合せを再び試せる。ただし、人物・反応は決められた模型で、実在の利用者への聞き取りや観察ではない。要求の収集、試遊、変更、再試験を含む開発過程全体の習得を保証しない。

`tests/game-design-rules.test.js` は両ルールにおける３回分の全行動列、盾２回・回避１回のすべての順序、振り返りと保存の復元を検査する。`tests/game-playtest.test.js` は２人と２つの設定の全８条件、記録の復元と従来記録の読み込みを検査する。画面上の操作や字幕課題完了後の保存は `src/app.js` と `src/game-captions.js` の実装、および[進捗記録](progress.md)のローカル・公開版の確認結果を参照する。

これらは元の字幕課題の達成条件には含まれない。依頼117の達成だけで追加課題を完了したことにはならず、いずれの固定例も実ゲームの品質や全利用者の体験、規格適合を保証しない。
