# 分母照合：SEC-Governance

[CS2023 印字 p.263](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=263) と[候補台帳](coverage-sec-governance.md)を 2026-11-11 に照合した。原典の区分を明示するため、台帳に KA Core の区分列を追加し、候補 ID の区分は「未記載」から変わる。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

すべて KA Core。トピック 1〜6 は重要資産の脅威からの保護、組織目標・リスク評価とガバナンス、機密性・完全性・可用性・説明責任・真正性・信頼性の管理、組織・課題・システム別の方針、基盤のリスク特定と軽減、データ収集・バックアップ・保持・クラウド・漏えい通知の方針。番号付き子はなく 6 行。

成果 1〜7 は重要資産の保護、ガバナンス・管理・対策の区別、技術対策の説明と実装、プログラム・DB の漏えいリスク評価、方針に合うバックアップ戦略の設計・実装、法的要件に基づく漏えい通知方針の議論と実施、クラウド委託のリスクと利点。7 行をトピックと別に追跡する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の SEC-Governance 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実組織での設計・実装・法的判断は固定模型だけで直接評価しない。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係、区分を補った39行と既存評価 ID への影響、候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
