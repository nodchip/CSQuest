# SF-Performance：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.294–295。[追跡方法](coverage-status.md)の「部分」は限定例、「未照合」は対応や十分性をまだ判定していないことを示す。原典のトピック１は子項目を個別に記し親と重複計上しない。この単位に Non-core は列挙されていない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1a | CS Core | 光速と計算機の時間 | 部分 | 依頼25で真空中の光の片道３距離と 1 GHz の周期、0.3 m での 2 GHz との比較を操作。配線・材料や実機の応答時間は未評価。 |
| 1b | CS Core | メモリ・ディスク・ネットワークの遅延 | 部分 | 依頼25は架空の近い棚と遠い書庫の固定時間。実機やネットワークの遅延は未評価。 |
| 2 | CS Core | キャッシュと時間的・空間的局所性 | 部分 | 依頼25・103で固定された参照列と棚を比較。実機や一般のアクセス列は未評価。 |
| 3 | CS Core | 複数システムにおけるキャッシュと一貫性 | 部分 | 依頼104の共有値と無効化は固定模型。実プロトコルや各システムでの一貫性は未評価。 |
| 4 | CS Core | プロセッサの記憶階層の導入 | 部分 | 依頼489で速い棚と遠い書庫の２階層・容量・費用を比較。実際の複数階層やプロセッサ内部は未評価。 |
| 5 | KA Core | 平均メモリアクセス時間の式 | 部分 | 依頼103で棚を調べる時間＋ミス率×追加時間を３構成に適用。複数階層や実測は未評価。 |
| 6 | KA Core | 仮想化と隔離の理由 | 部分 | 依頼135で共有カーネルと別ゲストの互換性を比較。保護と予測可能な性能の理由は未評価。 |
| 7 | KA Core | 仮想メモリによる間接参照 | 部分 | 依頼40・385で仮想頁から物理枠への対応を操作。一般のページング機構は未評価。 |
| 8 | KA Core | 仮想メモリと VM の実装方法 | 部分 | 依頼40・135は頁表と環境の固定模型。一般の VM・仮想メモリの実装や実機は未評価。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | CS Core | メモリ・ディスク・ネットワークの遅延の内訳を説明 | 未照合 | 対応する比較と検証を確認できていない。 |
| 2 | CS Core | 局所性と性能の関係を説明 | 部分 | 依頼25・103の時間・空間局所性の固定例。自由な説明は評価しない。 |
| 3 | CS Core | 平均アクセス時間を計算し容量・ヒット率・時間の兼ね合いを説明 | 部分 | 依頼103の平均式・３構成と489の容量・費用・時間の固定例。実測や自由な説明は未評価。 |
| 4 | KA Core | 実行環境の隔離・保護の重要性を説明 | 部分 | 依頼385で別枠と共有枠を比較。一般の VM の保護や自由な説明は未評価。 |
| 5 | KA Core | 間接参照による専用資源の見かけを説明 | 部分 | 依頼385の同じ仮想頁から異なる物理枠への固定対応。専用機械全体の見かけや自由な説明は未評価。 |
| 6 | KA Core | 別 VM の２アプリの性能分離を評価 | 未照合 | 依頼135は互換性を扱い、性能分離の評価は確認できていない。 |

検証は `tests/cache.test.js`、`tests/cache-blocks.test.js`、`tests/coherence.test.js`、`tests/memory-budget.test.js`、`tests/address.test.js`、`tests/process-pages.test.js`、`tests/virtual-machines.test.js` を参照。各模型の仮定と限界は [記録](sf-performance.md)、[OS-Memory](os-memory.md)、[OS-Virtualization](os-virtualization.md) を参照。
