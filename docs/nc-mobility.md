# NC-Mobility：移動と通信

出典：[CS2023 NC-Mobility](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.201。以下は原典の要約と限定的な対応であり、固定模型の達成は実ネットワークの設計や自由な説明能力を保証しない。

| トピック | 区分 | 内容と対応状況 |
|---:|---|---|
| 1 | KA Core | セルラー通信の原理、登録など。未対応 |
| 2 | KA Core | 無線 LAN、主に 802.11 の原理。依頼317で探索と接続先の切り替えの固定模型。実際の無線手順やセキュリティは未対応 |
| 3 | KA Core | 端末間通信。依頼316で直接会える端末同士の受け渡しを操作。実際の端末発見・接続や IoT 通信は未対応 |
| 4 | KA Core | 複数区間の無線、アドホック、機会的・遅延耐性ネットワーク。依頼316で切断中の保存と再接続時の中継の固定例。一般的な経路選択や実プロトコルは未対応 |

| 例示学習成果 | 区分 | 対応状況 |
|---:|---|---|
| 1 | KA Core | セルラー通信と登録の説明。未対応 |
| 2 | KA Core | 802.11 による移動利用者の支援。依頼317で２つの接続先と範囲外での再接続の固定模型。一般の説明や実プロトコルは未対応 |
| 3 | KA Core | 端末間・複数区間通信の実用例。依頼316は不連続な接続での手紙の受け渡しの架空例。実際の利用事例の一般的な説明は未対応 |
| 4 | KA Core | アドホック等の移動ネットワークの説明。依頼316は接続が途切れる３者の模型。一般的な方式の説明は未対応 |

依頼316は３人の伝令、既知の接触予定、手紙１通、各時間に１回の受け渡しか待機という固定模型。中継者が接続のない時間に手紙を保持し、次の接触時に渡す。これは保存・運搬・転送の考え方の例で、配送保証、実際の複製、期限、認証や無線の詳細は扱わない。参考：[RFC 9171: Bundle Protocol Version 7](https://www.rfc-editor.org/rfc/rfc9171.html)。

依頼317は同じネットワーク名の２接続先を持つ架空の無線 LAN で、探索・簡略化した接続前確認・接続・送信と、範囲外へ移動後の再接続を操作する。確認は暗号認証ではなく、実際のセキュリティ手順や通信継続条件は未対応。参考：[Cisco: 802.11 WLAN and Roaming](https://www.cisco.com/c/en/us/support/docs/wireless-mobility/wireless-lan-wlan/116493-technote-technology-00.html)。
