# 親子の精霊と巻物：教材監査

[CS2023 OS-Process 印字210頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=210) のプロセス生成・実行内容の置換え・終了の固定例。旧 `src/process-fork.js` の依頼386を再利用し、現在の鍛冶街へ接続する。現行のコピーオンライトは頁の共有と書込み時の複製、同期の依頼は別の模型を扱う。

親の私有メモ「月」は fork 後に子が「星」に変えても親は「月」。共有メモリ領域は扱わない。fork 前に開いた内容 ABC のファイルについて、親子の別々の記述子は同じ開いたファイル記述を指し、読取り位置を共有する。子が２バイトで AB を読み、続く親の２バイト読取りは残り C の１バイト。exec が成功すると同じ子の実行内容を置き換え、元の呼出しへ戻らない。模型の非待機確認では実行中の子は終了結果なし、子の終了後に再確認して結果を回収する。

指定された固定手順・１親１子のモデルであり、実 OS の呼出し、fork/exec の失敗、スレッド、共有メモリ、exec 時の記述子の設定、シグナル、別の wait の選択肢、任意の順序・実装や一般の状態を評価しない。[fork(2)](https://man7.org/linux/man-pages/man2/fork.2.html)、[execve(2)](https://man7.org/linux/man-pages/man2/execve.2.html)、[waitpid(2)](https://man7.org/linux/man-pages/man2/waitpid.2.html) を参照。

## 独立レビューと動作確認

実装担当と別の担当が私有メモの独立、共有された open file description の位置、exec と終了確認、保存・開放・焦点を確認。ローカルで集いと４地域の達成状態を用意した記録から、幅 213・390・1200 px で誤操作、キーボード、途中保存・再開と達成を確認した。冒険開始からの通し到達は含まない。
