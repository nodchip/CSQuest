固定量８単位を１・２・４・８人に均等に分け、準備４または８時間を加算する。通信、同期、待ち、競合、エネルギーや問題規模の変化は再現しない。

依頼437では、準備４刻、人数に等しい追加費用、１人１刻１個の並列作業という模型で、１・２・４・８人を比較する。仕事量16固定では21・14・12・14刻、一人16個固定では21・22・24・28刻。固定量の効率は21/(人数×時間)、一人あたり固定の効率は21/時間であり、いずれも１人での時間を基準とする。[NERSC の強・弱スケーリングの説明](https://docs.nersc.gov/performance/parallelism/#strong-scaling)を参照。架空の費用による比較で、実システムの測定、通信の内訳、エネルギーや任意の規模は扱わない。

依頼438は鍵を持つＡと待つＢを初期状態とし、Ａの返却・再申込み・割込み取得で初期状態へ戻る循環を作る。循環の無限反復では同時取得を防ぐ安全性を保ってもＢは待ち続ける。先着順ではＢを追い越せないが、鍵が返され空きの際に先頭へ渡される進行も仮定する。[Lamport の安全性と活性の説明](https://lamport.azurewebsites.net/tla/tutorial/session9.html)を参照。一般の時相論理式、任意の人数や実装の飢餓検証は扱わない。

依頼439は５種類の状態から３状態を選び、３番目から１・２・３番目のいずれかへ戻る無限記録を作る。G ¬(Ａ入室∧Ｂ入室) と G(Ｂ待機→F Ｂ入室) を判定し、先行する入室が後の待機を満たさないことや、待機がない場合の含意が真になることを比較する。[Lamport の時相論理の説明](https://lamport.azurewebsites.net/pubs/pnueli.pdf)を参照。全375通りを有限展開で照合した。記録は任意の例であり、特定の実装で実行可能な遷移か、全実行で式が成立するかは検証しない。

依頼440は初期値０の１変数への書込みＷ＝１と読取りＯ＝０・Ｎ＝１について、完了済み３操作の全６順序を比較する。Ｗが１〜４刻、Ｏが２〜３刻、Ｎが５〜６刻の記録はＯ→Ｗ→Ｎで説明できる。一方Ｗが１〜２刻、Ｏが３〜４刻、Ｎが５〜６刻の記録では実時間と読取り値を両立する順序がない。[Herlihy と Wing の原論文](https://www.cs.cornell.edu/andru/cs711/2002fa/reading/linearizability.pdf)を参照。固定した完了済み履歴の比較で、未完了操作や任意の履歴、実装全体の正しさは扱わない。

依頼440の自由な比較では、書込み時間帯を３種類、２回の読取り値を各０・１から選べる。12記録のそれぞれに６通りの順序を表示し、開始と完了が同じ時刻に接する操作は前後が確定しないものとする。全72候補を、操作区間中の実行時点を別途列挙して照合した。３操作以外や任意時刻、未完了操作は未対応。
