# 分母照合：SEP-Professional-Ethics

[CS2023 印字 pp.276–277](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=276) と[候補台帳](coverage-sep-professional-ethics.md)を 2026-11-11 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core トピック 1〜7 は共同体の価値と法律、専門職の性質、継続学習と自己評価、資格・倫理綱領・行動規範、説明責任・責任・法的責任と安全性・脆弱性開示、人と技術の関係の諸理論、法や規範に反する可能性の認識と報告。原典 5 は技術的に作れることだけでなく、作るべきかを含む。6 の例には道具としての見方、技術システムの社会学、障害者の正義、中立性、プラグマティズム、脱植民地モデルがある。KA Core 8〜15 は公共政策、結果の認識、倫理的異議・内部告発、地域文化、ハラスメントと差別、資格、人間工学、市場投入と品質基準。番号付き子はなく 15 行。

CS Core 成果 1〜6 は倫理問題の特定と対応、安全性等を確保する責任と根拠、継続学習、専門職規範の長所・短所、世界的問題と専門家・政府の役割。KA Core 7〜14 は公共政策への貢献、不適切な行動の結果、内部告発、文化、ハラスメントと支援先、資格、人間工学と健康、市場投入と品質基準。成果 14 行を別に追跡する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の SEP-Professional-Ethics の項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実際の専門職判断、法的評価と自由な議論は固定模型だけで直接評価しない。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
