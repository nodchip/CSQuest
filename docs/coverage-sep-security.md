# SEP-Security：セキュリティ方針・法・犯罪の項目別対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.284–285。[既存調査](sep-security.md)と依頼・検査を照合。状態は[追跡方法](coverage-status.md)に従い、「未照合」は未実装の証拠ではない。「部分」は関連する固定例を示し、項目全体の修得を意味しない。実際の社会調査・法的判断・自由な説明や文章作成は固定例だけでは直接評価しない。

| 2 | CS Core | コンピュータ犯罪に適用される法律の課題 | 未照合 | 対応例を要照合。 |

各依頼の前提・出典と検証、実際の状況に一般化できない範囲は[既存調査](sep-security.md)を参照する。

依頼985は NIST の [virus](https://csrc.nist.gov/glossary/term/virus)、[worm](https://csrc.nist.gov/glossary/term/worm)、[Trojan horse](https://csrc.nist.gov/glossary/term/trojan_horse) の定義を参考に、感染した札の実行、隣の塔への固定的な拡散、便利に見える道具の隠れた動作を比較する。道を区切る例と実行しない例は、それぞれこの模型に限る。現実の分類の重なり、実際の感染条件、検知、被害回復や実例の調査は評価しない。`tests/malware-paths.test.js` で各場面の遷移、１刻１辺の拡散、道の切断、保存と達成を検査する。

依頼986は [英国会計検査院（NAO）の2017年報告](https://www.nao.org.uk/reports/investigation-wannacry-cyber%20attack-and-the-nhs/) と[報告書本文](https://www.nao.org.uk/wp-content/uploads/2017/10/Investigation-WannaCry-cyber-attack-and-the-NHS.pdf) を要約する。報告書本文では少なくとも80トラストに影響、紹介ページでは81と数が異なること、当初感染とされた37のうち３が後に感染ではなく業務への影響と再分類されたこと、5月12〜18日に6,912件の取消しを確認、約19,494件は推計という区別と、NHS Digital の患者情報に関する見解、地域レベルの訓練不足を扱う。2017年時点の報告であり、全被害、原因、現在の体制や法的救済を確定しない。`tests/wannacry-evidence.test.js` で各問いの記録と結論、保存・達成を検査する。

報告書本文の表紙には2018年4月の日付があり、当初の分類の修正が本文に記される。紹介ページと本文で80・81と異なる理由は両資料からは断定しない。依頼986の旧版では81とだけ示していたが、現行版は両方を明示して本文を問う。旧クリアは保持し、旧版での達成は修正後の記述を確認した証拠ではない。

依頼987では [NIST SP 800-63B-4](https://pages.nist.gov/800-63-4/sp800-63b.html) の一要素パスワード、漏えい候補との照合、管理道具・貼り付け、漏えい時の変更と、[英国 ICO の職員監視の案内](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/employment/monitoring-workers/data-protection-and-monitoring-workers/) の必要性、データ最小化、透明性を参照する。城の固定例であり、全ての認証要件、適法性、実運用や自由な方針作成を評価しない。英国の指針を全法域に一般化しない。`tests/security-policy.test.js` で選択・確認・保存と達成を検査する。

依頼988は、架空の７日間の調査要件と５件の出来事に対し、アカウント・時刻・成否・私的伝言と保存期間を選ぶ。10分以内の同一アカウントへの３回の失敗を検出するための項目と、模型における不要な収集・保存を比較する。[英国 ICO の職員監視の案内](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/employment/monitoring-workers/data-protection-and-monitoring-workers/?search=example) の目的限定・データ最小化・保存期間を参考とするが、７日はこの依頼の仮定であって法定期間ではない。実ログ、通知や法的根拠の判断、アクセス権、誤検知・回避、自由な設計は評価しない。`tests/log-policy.test.js` で項目と期間の全48組合せ、復元・達成を検査する。
