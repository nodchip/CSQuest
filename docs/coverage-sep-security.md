# SEP-Security：セキュリティ方針・法・犯罪の項目別対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.284–285。[既存調査](sep-security.md)と依頼・検査を照合。状態は[追跡方法](coverage-status.md)に従い、「未照合」は未実装の証拠ではない。「部分」は関連する固定例を示し、項目全体の修得を意味しない。実際の社会調査・法的判断・自由な説明や文章作成は固定例だけでは直接評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | CS Core | コンピュータ犯罪、法的救済、被害者・社会への影響 | 未照合 | 依頼362の窓口停止は原因不明で、犯罪と断定できない。犯罪や法的救済の教材を要照合。 |
| 2 | CS Core | ソーシャルエンジニアリング、詐欺、なりすましと回復 | 部分 | 依頼365で合言葉を求める偽の伝令と正規の連絡を別経路で確認。実際の被害回復は未対応 |
| 3 | CS Core | サイバーテロ、犯罪目的の侵入、ハクティビズム | 未照合 | 対応例を要照合。 |
| 4 | CS Core | マルウェア、ウイルス、ワーム | 部分 | 985で感染した札の実行、自力で広がる模型、偽装された道具を比較。実例の調査、実機の検知や回復は未評価。 |
| 5 | CS Core | 重要インフラへの攻撃 | 未照合 | 対応例を要照合。 |
| 6 | CS Core | 人・方針・秘密保持などの非技術的基礎 | 部分 | 依頼365で一度きりの合言葉を伝えず、既知の窓口に確認する固定例。組織方針や秘密保持の体系は未対応 |
| 7 | KA Core | 犯罪に関する現行・提案法の利点と課題 | 未照合 | 対応例を要照合。 |
| 8 | KA Core | 方針と変更・遵守の課題 | 未照合 | 対応例を要照合。 |
| 9 | KA Core | ライフサイクル全体の安全への責任 | 部分 | 依頼360で不具合を報告・検査する固定例。ライフサイクル全体は未対応 |
| 10 | KA Core | 国際法・地域法と交差 | 未照合 | 対応例を要照合。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 代替と限界 |
|---|---|---|---|---|
| 1 | CS Core | 社会的影響のあるコンピュータ犯罪や社会工学の実例 | 部分 | 依頼365は架空のなりすまし。実例の調査は未対応 |
| 2 | CS Core | コンピュータ犯罪に適用される法律の課題 | 未照合 | 対応例を要照合。 |
| 3 | CS Core | 各種攻撃の動機と影響 | 未照合 | 依頼362の停止は原因不明であり、攻撃の動機や影響の例としては扱えない。 |
| 4 | CS Core | アクセスの悪用や侵害の倫理・法律 | 未照合 | 対応例を要照合。 |
| 5 | CS Core | 安全における専門職の役割・トレードオフ | 部分 | 依頼360で報告と検査を扱う固定例。一般の議論は未対応 |
| 6 | KA Core | 個人・組織・政府による防止や軽減策の調査 | 部分 | 依頼365で既知の窓口に別経路で確認。組織・政府の対策や体系的な調査は未対応 |
| 7 | KA Core | パスワード・従業員監視を含む組織方針の設計 | 未照合 | 対応例を要照合。 |
| 8 | KA Core | 地域を越える法令の影響 | 未照合 | 対応例を要照合。 |

各依頼の前提・出典と検証、実際の状況に一般化できない範囲は[既存調査](sep-security.md)を参照する。

依頼985は NIST の [virus](https://csrc.nist.gov/glossary/term/virus)、[worm](https://csrc.nist.gov/glossary/term/worm)、[Trojan horse](https://csrc.nist.gov/glossary/term/trojan_horse) の定義を参考に、感染した札の実行、隣の塔への固定的な拡散、便利に見える道具の隠れた動作を比較する。道を区切る例と実行しない例は、それぞれこの模型に限る。現実の分類の重なり、実際の感染条件、検知、被害回復や実例の調査は評価しない。`tests/malware-paths.test.js` で各場面の遷移、１刻１辺の拡散、道の切断、保存と達成を検査する。
