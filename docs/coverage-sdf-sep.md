# SDF-SEP：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.233。[既存調査](sdf-society.md)と照合。すべて CS Core。固定のゲーム内操作は実際の法的判断や専門職の実践能力を証明しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | CS Core | プログラムの知的財産権 | 部分 | 269で架空の利用条件を比較。権利の帰属や法域ごとの扱いは未評価。 |
| 2 | CS Core | 剽窃と学術的誠実性 | 部分 | 270で出典と貢献の表示を選択。引用判断全般は未評価。 |
| 3 | CS Core | 開発したコードに関する責任・法的責任 | 部分 | 360で架空の不具合の報告と検査。一般の法的責任は未評価。 |
| 4 | CS Core | プログラマーの職業倫理 | 部分 | 360で不確実性・報告・協力を扱う。職業倫理全般は未評価。 |
