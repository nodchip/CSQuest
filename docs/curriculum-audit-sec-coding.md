# 分母照合：SEC-Coding

[CS2023 印字 pp.259–260](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=259) と[候補台帳](coverage-sec-coding.md)を 2026-11-11 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core トピック 1〜7 は一般的な弱点、SQL 等への注入、XSS、入力検証とサニタイズ、型安全、領域外書込み・スタック・整数桁あふれ、競合に起因する安全上の問題。KA Core 8〜17 は非干渉と非推論可能性、情報フロー攻撃の防止、防御のための攻撃的手法、AI を使うマルウェア検知、ランサムウェアの作成・予防・軽減、外部部品の安全な利用、マルウェアの種類・作成・逆解析・防御、試験・検証・妥当性確認による保証、静的・動的解析、安全なコンパイラとコード生成。番号付き子はなく 17 行。列挙の一例だけを項目全体の達成とはみなさない。

CS Core 成果 1〜8 は弱点と回避、入力検証、言語選択、型安全言語への書換え、領域外書込みと競合の評価・防止、SQL 注入と XSS の評価・防止。KA Core 9〜16 はマルウェアの説明、入力処理を検査するプログラム、外部コードのリスク、脆弱性修正の更新、情報フローの防止、解析ツール、マルウェアの検出・除去、ランサムウェアの予防。成果 16 行をトピックと別に追跡する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の SEC-Coding 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実コードの評価・書換え、実際の攻撃・防御・解析と一般の安全性は固定模型だけで直接評価しない。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
