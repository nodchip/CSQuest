トピックはすべて Non-core で 1〜9：モバイルアプリのプライバシー、包摂とアクセシビリティ、モバイルアプリでの AI の倫理、持続可能な開発とホスティング、スパム・押し付けがましい通知、いじめ・嫌がらせ、前向きなコミュニティ、収益化・広告、ゲーミフィケーションの倫理。番号付き子はない。原典は Web の見出しの下で 1・3 を mobile apps と記すため、推測で Web に書き換えない。

例示成果はすべて Non-core の 1〜5：モバイル計算による通信と情報流通への影響、日常作業を支援するモバイルアプリの設計、普及による仕事と生活の両立、健康管理と医療への影響、国連の持続可能性目標に向けた教育・支援。原典は成果 1〜5 も mobile / mobile apps と記す。台帳の 9 トピックと 5 成果は番号・区分に一致し、親子の重複はない。見出しとの対象の違いは原典上の記述として保持し、誤植と断定しない。

番号付き依頼は旧教材の記録であり、現行冒険への到達を意味しない。現行冒険の SPD-SEP/Web の項目別評価は記録時点で未作成。未作成は教材不存在の証明ではない。実際のアプリ設計、社会調査、自由な説明と一般化は固定例だけで評価しない。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
