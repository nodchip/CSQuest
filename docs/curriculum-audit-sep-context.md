# 分母照合：SEP-Context

[CS2023 印字 pp.273–274](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=273) と[候補台帳](coverage-sep-context.md)を 2026-11-10 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core トピック 1〜4 はネットワーク・AI 等の社会的影響、個人の幸福と身体・感情・経済上の安全、市民生活での AI・生体認証・自動判断と人の主体性・監督、多様性とアクセシビリティ不足による影響と公平性改善。KA Core 5〜8 はインターネット・データ・AI の成長と支配、デジタル格差と声を届けにくい人々への責任、アクセシビリティと関連要件、状況に応じた計算。原典の導入は計算と社会の相互作用を重視する。番号付き子はなく、トピック 8 行は番号・区分に一致する。

CS Core 成果 1〜5 は個人・集団の交流を媒介する技術、設計に埋め込まれた価値、設計・実装の社会的文脈、実証データによる有効性の分析、異なるアイデンティティ・文化・共同体への影響。KA Core 6〜11 は市民と政府間の通信、民主主義における計算機依存、歴史的に周縁化された人々の代表性不足、状況に応じた計算の影響、社会ごとのアクセスの影響、インターネットへのアクセスを人権として捉える理由。成果 11 行はトピックと別に数える。

台帳の番号付き依頼は旧教材で、現行冒険への到達を示さない。現行冒険の SEP-Context 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実社会の調査・文化的解釈・自由な議論は固定模型だけで評価しない。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
