# SE-Formal: 形式手法

出典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.251。すべて Non-core。依頼242は小さな有限模型の探索で、一般の仕様記述、プログラムの検証や自由記述能力を評価しません。

| 2 小規模な設計・プログラムへの形式仕様と解析の適用 | 依頼242で与えられた有限模型を探索。仕様の作成や実際のプログラムの解析は未評価 |
| 3 形式仕様言語の利点と欠点 | 未対応 |

依頼242は精霊Ａ・Ｂが各自「外、確認後、部屋の中、退出済み」を順に一度だけ進む有限模型。相手が部屋にいる間は外から確認後へ進めない。「別々」では確認後に再確認せず入室でき、Ａ確認・Ｂ確認・Ａ入室・Ｂ入室が同時入室の反例となる。「一つにする」では入室時にも相手がいないことを原子的に確認するため、到達可能状態に同時入室はない。探索は安全性のみを扱い、実装の正しさ、無限の動き、公平性や進行性は証明しない。
