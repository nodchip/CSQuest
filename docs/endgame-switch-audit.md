# SPD-Embedded：スイッチの信号（部分対応）

CS2023 原典印字 305–306 頁の SPD-Embedded（組込みプラットフォーム）の 3e「ハードウェア・センサー等とのやりとり」と 9「センサーとアクチュエーター」の入力に関係する導入として、鍛冶街の３つの固定例を追加した。教材は機械式スイッチの揺れを離散的な０／１の標本で表す。既存の鍛冶街の CPU・装置完了通知はこの信号を扱わない。旧 `sensor-hysteresis.js`（依頼 220）の値に対する二つの閾値の模型とも異なる。旧教材の存在を現行達成には数えない。

参考： [CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf)、[Arduino の Debounce 例](https://docs.arduino.cc/built-in-examples/digital/Debounce/)、[TI のスイッチのチャタリング解説](https://www.ti.com/video/5840441551001)。模型は各読み取りが同じ間隔という固定前提で、初期状態は解放（０）。読み取り値が反転すると連続数を１から数え直し、Ｎ回目で確定する。押下と解放の両方をこの方法で確定し、確定状態の０→１のみ押下を数える。押し続けている間は数えず、０に確定すると再度数えられる。

短い押下を３回条件で見逃すことと、１回の物理押下中に０が２回続く揺れを２回条件が別の押下と数えることを比較する。物理的な操作と標本はこの固定例の前提であり、実機の電気的挙動や標本との位相、最適な待ち時間、実装コードの作成、実機・安全性、一般の組込み開発能力は検証していない。SPD 全体は未完成。

`forge-switch-raw` と `forge-switch-filter` の２件を終えると `forge-switch-compare` が開く。鍛冶街の依頼分類から選び、地図の全達成判定にも含まれる。

実装担当とは別の `review_candidate` が原典、[TI の接点の解説](https://www.ti.com/lit/an/slva091/slva091.pdf)、固定例の押下・解放の連続数、再武装、短押しと長い揺れの結果、説明、分類と保存をコード上で確認した。０回となる場面で不正な履歴操作を受け入れる問題を指摘し、修正とテスト追加後に再確認した。実装コードの作成能力や実機の安全性を確認したものではない。レビュー担当自身はブラウザを操作していない。

`tests/endgame-switch.test.js` は信号の反転、確定、解放、再武装、固定例の比較、誤答と不正な履歴を確認する。`tests/forge-station-quest-groups.test.js` は分類と開放を確認する。`scripts/endgame-switch.playwright.js` は集いと４地域などの達成を用意した検証用記録から、213・390・1200 px 幅で分類からの到達、キーボードによる依頼と回答、誤答の案内、途中復元、段階開放、３依頼の達成と達成後の再開を確認した。新規開始からこの依頼群までの通し操作、実際のスクリーンリーダー音声、利用者による面白さの評価は未確認。
