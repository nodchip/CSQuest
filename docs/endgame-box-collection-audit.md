# つながる箱の回収：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字138〜139頁 FPL-Systems 6d の到達可能性に基づく自動回収に関連する固定例。旧依頼201 `src/garbage-collection.js` と202 `src/reference-counting.js` の箱・参照を現行の工房に接続した。
- [Cornell の GC 解説](https://www.cs.cornell.edu/courses/cs3410/2026sp/notes/rust.html) は根からたどって印を付け、印のない領域を回収する mark-sweep の概要を説明する。根は箱と別の外部参照であり、矢印の向きにのみたどる。
- 枝分かれは根→Ａ、Ａ→Ｂ・Ｃ、Ｂ→Ｄで到達 {A,B,C,D}、Ｅを回収。循環例は根→Ａ、Ａ→Ｂ、Ｃ→Ｄ、Ｄ→Ｃ、Ｅ→Ｂで到達 {A,B}、{C,D,E} を回収。Ｅから到達可能なＢへの矢印は、逆向きにＥを到達可能にはしない。
- 比較例は根→Ａ→Ｂ→Ｃ→Ｂ。根を外し単純参照カウントでＡを回収すると、ＢとＣは互いへの参照１本ずつで残る。その後、根のない残存箱を到達確認で調べ、Ｂ・Ｃを回収する。循環検出を併用する参照カウント方式もある。
- 根の切断・箱の回収による参照の変化は扱い、各段階では他からの参照変更がない固定模型である。実際の GC の全方式・並行変更・停止時間・実コードや一般の正しさを評価しない。旧教材・本教材の存在を原典全体の完成とはしない。

2026-11-11、実装担当と別の `signed_review` が原典と [Cornell の GC 資料](https://www.cs.cornell.edu/courses/cs6120/2025fa/blog/gc/) に照らし、固定グラフの到達・回収と単純参照カウントの循環、画面・保存・開放を独立レビューした。比較例の根切断・回収による参照変化と外部変更なしの前提が矛盾しないよう文言を修正し、再レビューした。親担当が準備済み記録から幅 213・390・1200 px の工房の分類に到達し、誤答、キーボード、途中保存・再開、開放条件、達成後の保存をブラウザ確認した。新規開始からの通し操作、スクリーンリーダー音声、利用者による面白さは未確認。
