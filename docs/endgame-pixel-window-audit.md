# GIT-Image：灯り絵の窓と重み

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.163–164、GIT-Image 3a・3b の画像フィルタ。旧依頼725 `src/image-kernel.js` の一点の乱れ・３つの対称窓を現行庭園に再利用し、旧教材と独立した範囲として重複計上しない。現行の画像拡縮や色灯りとは、近傍に重みを掛けて中央の画素値を変える操作が異なる。

中央８、周囲８画素は４。平均窓は合計40を９で割り40/9、中心重み４の窓は合計80を16で割り５、中央５・上下左右−1の鮮鋭化窓は24。24は切詰め前の数値で、この例では中央の乱れも強調される。３窓は180°反転しても同じため、中央の畳み込みと相互相関の値が一致するが、非対称窓では一般に異なり得る。[Cornell の２次元フィルタ資料](https://www.cs.cornell.edu/courses/cs465/2005fa/lectures/05samp-recon/05samp-recon.pdf) を参照。

固定の３×３中央窓と３種類の重みのみ。画像端の境界、丸め、値のクリップ、実画像、任意の核、一般的な画像改善や実装を評価しない。GIT-Image 全体の完成を示さない。

2026-11-11、実装担当と別の `signed_review` が原典と [OpenCV の線形フィルタ資料](https://docs.opencv.org/4.x/d4/d86/group__imgproc__filter.html) に照らし、対称核の固定値・相互相関との関係・画面・保存・開放を独立レビューした。中央の画素値を統計上の中央値と混同しうる表現を修正し、再レビューした。親担当が修正後に準備済み記録から幅 213・390・1200 px の庭園の分類に到達し、誤答、キーボード、途中保存・再開、開放条件、達成後の保存をブラウザ確認した。新規開始からの通し操作、スクリーンリーダー音声、利用者による面白さは未確認。
