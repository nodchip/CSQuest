# AR-Memory の対応状況

原典: [CS2023 AR-Memory](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.104–105。固定の模型による操作であり、実機の計測や自由な説明は直接評価しない。

| 番号 | 区分 | 内容と現状 |
|---|---|---|
| 1 | CS Core | メモリ階層と時間的・空間的局所性。依頼25と103で容量の小さい棚の時間的・空間的局所性。実機の階層は未対応 |
| 2–3 | CS Core | 主記憶の構成・操作と永続記憶。未対応 |
| 4 | CS Core | 遅延、サイクル時間、帯域幅、インタリーブ。依頼103は架空の固定遅延のみ。他は未対応 |
| 5 | CS Core | キャッシュの対応付け、ブロック、置換・書込み方針、先読み。依頼25・103で完全連想の固定例、ブロックと LRU。依頼104で書込み時の無効化の固定例。直接・セット連想、書戻しと先読みは未対応 |
| 6 | CS Core | 複数プロセッサのキャッシュ一貫性。依頼104で単一の札の更新と無効化の固定例。実プロトコルや同時実行は未対応 |
| 7 | CS Core | 仮想メモリのハードウェア支援。依頼40で固定のページ変換。実機の支援機構は未対応 |
| 8–9 | CS Core | 故障処理・信頼性、誤り符号、圧縮、整合性。未対応 |
| 10 | KA Core | メモリ内処理。未対応 |

| 例示学習成果 | 区分 | 内容と現状 |
|---|---|---|
| 1 | CS Core | メモリ技術の種類と費用・性能。未対応 |
| 2 | CS Core | 遅延の実行時間への影響を計測。依頼103は架空の時間の集計。実機測定は未対応 |
| 3 | CS Core | 仮想メモリ管理の機能。依頼40は固定の変換例のみ |
| 4 | CS Core | キャッシュとメモリ構成に応じた平均アクセス時間。依頼103は単一キャッシュの４固定例の平均。一般の構成と命令・データ混合は未対応 |

依頼103は合計容量４頁・完全連想・LRU の読出し専用模型。棚の確認が１、ミスの追加時間が５で、読み方２種類とブロック１頁・２頁を比較する。８回の合計時間は順次で28・18、１頁おきで28・48。ミス率と追加時間からの平均はそれぞれ 3.5・2.25・3.5・6。ブロックの転送時間を大きさにかかわらず同一とし、実ハードウェアの実測を意味しない。各アクセスは独立した LRU の参照計算と照合した。

依頼104では共有値０を A・B が読み、A が１を書き、B が再読する。書込みは共有値と A の写しを更新する。通知しない場合、B は古い０を読み、無効化の場合は共有値の１を読み直す。操作は順に完了し、単一アドレスだけを扱う。具体的なコヒーレンスプロトコル、通信中の競合と異なるアドレス間のメモリ順序は未対応。
