# 原典との範囲照合：GIT-Image

[CS2023 印字 pp.163–164](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)を照合した。全トピックと例示学習成果は KA Core。原典の親１〜５を台帳に追加し、親子24トピック行・成果５行とした。親と子は重複するため、行数を独立項目数や完成率としない。

各行は固定画像・少数の候補による部分対応であり、232の格子の辺と重心以外の輪郭推定、カラーの一般的なヒストグラム、ウェーブレット、一般の画像や実際の符号化などは未評価。成果に含まれる実際のプログラム作成能力は画面上の操作では評価しない。一般の画像処理や実利用者の学習成果については別途検証が必要。

この範囲照合は個々の教材の正確性や全教材の完成を証明しない。
