## トピック

原典は CS Core に 1〜6 を挙げ、KA Core では同じトピックをより多い時間で深く扱い、計算関連の応用を増やせると述べている。そのため台帳では各トピックを `CS Core / KA Core` として 1 行で追跡し、両区分で重複して数えない。

1 は標本空間・事象・確率・条件付き確率・ベイズ則、2 は離散確率変数と分布、3 は連続確率変数と分布、4 は期待値・分散・大数の法則・中心極限定理、5 は条件付き分布と条件付き期待値、6 は計算への応用と確率・統計の違い。各番号は独立したトピックであり、各項目内の列挙を別の原典番号とは数えない。

原典の例示成果は CS Core の 1a〜1d、2a〜2c、3a〜3b、4a〜4c、5a〜5c、6a〜6b の 17 件。番号 1〜6 の親はそれぞれ基本概念、離散、連続、期待値等、条件付き分布等、応用という分類の見出しであり、子項目と重複して数えない。KA Core に別個の成果は列挙されていない。

子項目は順に、確率過程の文章から標本空間・結果の確率・事象への対応、事象の確率、事象の独立、条件付き確率とベイズ則、確率変数と指示変数、変数の独立、代表的離散分布、代表的連続分布、累積分布からの確率、期待値と分散の定義と計算、大数の法則と中心極限定理の計算上の意義、同時・周辺・条件付き分布の区別、周辺・条件付き分布と条件付き期待値の計算、確率モデルによる実際の状況・応用の記述、確率的過程の計算問題への適用を含む。原典の計算には離散・連続の両方を含む成果があり、固定した有限例だけを全範囲とみなさない。
