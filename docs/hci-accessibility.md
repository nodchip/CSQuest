# HCI-Accessibility の対応状況

出典: [CS2023 HCI-Accessibility](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 177–178。原典を要約した作業用一覧。部分的な教材の達成は、包括的な実践能力や規格への適合を示さない。

## トピック

| 番号 | 分類 | 要約 | 状況 |
|---:|---|---|---|
| 1 | CS Core | 社会・法的な支援と義務、アクセシブルな設計の広い利益 | 未着手 |
| 2 | CS Core | WCAG 等のアクセシビリティ標準 | 依頼394で対象の大きさと間隔、575で窓のフォーカス順序・可視性と名前を扱い WCAG の手がかりを提示。規格全体と適合判定は未対応 |
| 3 | CS Core | アクセシビリティと包括的な開発を支援する技術 | 依頼22の読み上げ・キーボード・色以外の表示と依頼117の字幕の固定例。他の技術と実装は未対応 |
| 4 | CS Core | 包括的設計の枠組み、違いの認識 | 依頼22・575：異なる利用条件と操作経路の固定例。設計枠組み全体は未対応 |
| 5 | CS Core | ユニバーサルデザイン | 依頼575で同じ改善が多様な条件で役立つ可能性を考える。原則全体と参加型の設計は未対応 |
| 6 | KA Core | 障害の永続・一時・状況的側面、国際的観点と態度 | 依頼575で一時的なけがやポインターを使えない状況に触れる。国際的観点や態度は未対応 |
| 7 | KA Core | UX 調査と包括的開発の実践 | 依頼793で架空の利用者と試作品を評価。実際の調査・開発は未評価 |
| 8 | KA Core | 読み上げへの対応などの支援技術 | 依頼22：操作に名前が伝わる必要を扱う固定モデル。実際の読み上げ製品の検証は未対応 |
| 9 | KA Core | 参加型設計などの包括的プロセスと広い影響 | 依頼793で早期参加と反復の固定例。実際の協働や広い影響の検証は未評価 |
| 10 | Non-core | 思い込みの問い直しと障害学 | 未着手 |
| 11 | Non-core | 包摂の投資対効果 | 未着手 |
| 12 | Non-core | 利用者に配慮した包括的設計 | 未着手 |
| 13 | Non-core | 包摂などを扱う HCI の批判的アプローチ | 未着手 |

## 例示学習成果

| 番号 | 分類 | 要約 | 状況と限界 |
|---:|---|---|---|
| 1 | CS Core | 異なる障害に伴う課題と対応する支援技術を特定 | 依頼22：色以外の情報、キーボード、読み上げの三例。障害・支援技術全般は未対応 |
| 2 | CS Core | 適切な包括的設計のアプローチを識別 | 依頼793で参加と反復を選択。他のアプローチの比較は未評価 |
| 3 | CS Core | ソフトウェアのアクセシビリティ指針を理解 | 依頼575でキーボード・フォーカス・操作名に関する指針の手がかりを提示。規格全体や適合判定は未対応 |
| 4 | CS Core | 関係法令・規制を認識 | 未着手 |
| 5 | KA Core | 包括的枠組みを適用し、視覚・音声・タッチ UI をアクセシブルに設計 | 依頼117で音の内容と位置を文字で示す固定模型。一般の設計・実利用者による検証は未対応 |
| 6 | KA Core | 関係法令・規制を理解 | 未着手 |
| 7 | KA Core | 多様な人々との交流における適切・不適切な技能を理解 | 未着手 |
| 8 | KA Core | ウェブ・モバイルアプリを現行標準に照らして分析 | 未着手 |
| 9 | Non-core | 障害・人種・性別への偏りが技術設計に与えた影響の例と教訓 | 未着手 |
| 10 | Non-core | 利用者ニーズを把握する UX 調査を構想 | 依頼793で参加の時期を選択。調査計画の作成・実施は未評価 |

依頼22の結果は三つの固定条件を評価する教材用モデルである。実在する利用者の体験や支援技術の代用ではなく、利用者参加、実環境での検証、規格・法令の評価も行っていない。

依頼575は、閉じた後も開くボタンが残る確認窓について、窓内のフォーカス、可視性、キーボードによる閉じ方と戻り先、閉じる操作の名前を模型で確認する。[W3C のフォーカス順序](https://www.w3.org/WAI/WCAG22/Understanding/focus-order)、[可視性](https://www.w3.org/WAI/WCAG21/Understanding/focus-visible.html)、[ボタン](https://www.w3.org/WAI/ARIA/apg/patterns/button/)を参照。例外的な戻り先やスクリーンリーダー・利用者による実機検証、規格全体は扱わない。

依頼793は架空の旅人との早期参加、試作品の反復、標準と利用者による評価の組み合わせを扱う。実際の当事者参加や規格適合を証明しない。詳しい照合は[項目別台帳](coverage-hci-accessibility.md)を参照。
