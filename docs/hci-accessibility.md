# HCI-Accessibility の対応状況

出典: [CS2023 HCI-Accessibility](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 177–178。原典を要約した作業用一覧。部分的な教材の達成は、包括的な実践能力や規格への適合を示さない。

## トピック

| 番号 | 分類 | 要約 | 状況 |
|---:|---|---|---|
| 1 | CS Core | 社会・法的な支援と義務、アクセシブルな設計の広い利益 | 未着手 |
| 2 | CS Core | WCAG 等のアクセシビリティ標準 | 未着手 |
| 3 | CS Core | アクセシビリティと包括的な開発を支援する技術 | 依頼22：読み上げ、キーボード、色以外の表示に関わる固定例。他の技術と実装は未対応 |
| 4 | CS Core | 包括的設計の枠組み、違いの認識 | 依頼22：三つの異なる利用条件の固定例。設計枠組み全体は未対応 |
| 5 | CS Core | ユニバーサルデザイン | 未着手 |
| 6 | KA Core | 障害の永続・一時・状況的側面、国際的観点と態度 | 未着手 |
| 7 | KA Core | UX 調査と包括的開発の実践 | 未着手 |
| 8 | KA Core | 読み上げへの対応などの支援技術 | 依頼22：操作に名前が伝わる必要を扱う固定モデル。実際の読み上げ製品の検証は未対応 |
| 9 | KA Core | 参加型設計などの包括的プロセスと広い影響 | 未着手 |
| 10 | Non-core | 思い込みの問い直しと障害学 | 未着手 |
| 11 | Non-core | 包摂の投資対効果 | 未着手 |
| 12 | Non-core | 利用者に配慮した包括的設計 | 未着手 |
| 13 | Non-core | 包摂などを扱う HCI の批判的アプローチ | 未着手 |

## 例示学習成果

| 番号 | 分類 | 要約 | 状況と限界 |
|---:|---|---|---|
| 1 | CS Core | 異なる障害に伴う課題と対応する支援技術を特定 | 依頼22：色以外の情報、キーボード、読み上げの三例。障害・支援技術全般は未対応 |
| 2 | CS Core | 適切な包括的設計のアプローチを識別 | 未着手 |
| 3 | CS Core | ソフトウェアのアクセシビリティ指針を理解 | 未着手。依頼22は規格適合の評価ではない |
| 4 | CS Core | 関係法令・規制を認識 | 未着手 |
| 5 | KA Core | 包括的枠組みを適用し、視覚・音声・タッチ UI をアクセシブルに設計 | 未着手。依頼22の固定選択は実設計の検証ではない |
| 6 | KA Core | 関係法令・規制を理解 | 未着手 |
| 7 | KA Core | 多様な人々との交流における適切・不適切な技能を理解 | 未着手 |
| 8 | KA Core | ウェブ・モバイルアプリを現行標準に照らして分析 | 未着手 |
| 9 | Non-core | 障害・人種・性別への偏りが技術設計に与えた影響の例と教訓 | 未着手 |
| 10 | Non-core | 利用者ニーズを把握する UX 調査を構想 | 未着手 |

依頼22の結果は三つの固定条件を評価する教材用モデルである。実在する利用者の体験や支援技術の代用ではなく、利用者参加、実環境での検証、規格・法令の評価も行っていない。
