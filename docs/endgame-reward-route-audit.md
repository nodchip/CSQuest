# AI-ML：報酬と行動の価値（部分対応）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.71–75、AI-ML 1b・14 の強化学習に関連する入口。現行観測所は教師あり分類・固定ルールの案内人形を扱う。旧依頼379 `reinforcement.js` は２状態の Q 学習を既に扱い、本教材も同じ計算を再利用するため、新しい範囲として二重計上しない。

値は全て０から開始。入口の短い道は報酬１で終点、入口→部屋は報酬０、部屋→終点は報酬４。終点に将来価値はなく、試行後は入口に戻る。学習率１、割引率0.5、次状態で選べる行動は部屋では１つ。部屋の行動を試すと４、その後で入口→部屋を試すと０＋0.5×４＝２。短い道の値は１。最初に入口→部屋を試した時点では部屋の値も０なので０のまま。模型内の報酬を最大化するだけで現実の目的や道の良さを一般化しない。

参考：[Sutton and Barto: Reinforcement Learning, Chapter 6](http://incompleteideas.net/book/the-book-2nd.html)。固定の決定的な２場所・３行動・更新率１・割引率0.5の例であり、方策・探索の設計、確率的環境、一般の収束・実装や実性能は評価しない。

実装担当とは別の `review_candidate` が原典・Bellman backup、固定例の報酬と更新値、各画面の前提、誤答・不正履歴、分類と開放、旧記録の既定値を確認した。旧教材を含む関連11テストも成功した。一般の強化学習・実装を検証したものではなく、レビュー担当自身はブラウザを操作していない。

`scripts/endgame-reward-route.playwright.js` は集いと４地域の達成状態を用意した検証用記録から、213・390・1200 px 幅で分類経由の到達、キーボード操作、誤答案内、途中保存・再開、段階開放と達成後の再開を確認した。新規開始からこの依頼への通し操作、実際のスクリーンリーダー音声や利用者による面白さの評価は未確認。

公開確認：`2224718` の Pages run 42865979467 が成功し、2026-11-11 に公開サイトで同 Playwright スクリプトを隔離したブラウザの 213・390・1200 px 幅で実行、分類からの操作、途中保存・再開と達成を確認した。検証用に進捗を用意した記録からの操作であり、新規開始からの通し確認や利用者評価ではない。
