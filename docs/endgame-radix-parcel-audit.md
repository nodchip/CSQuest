# 桁で品札を分ける：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字89頁の AL-Foundational 14b（基数整列）の入口。旧依頼167 `src/radix-sort.js` の２桁・５札模型を現行の街に接続した。現行の挿入・選択・併合・分割整列とは別の桁による仕分けを扱う。
- [Cornell: Radix sort](https://www.cs.cornell.edu/courses/JavaAndDS/files/sort7Radix.pdf) は最下位桁から各桁を安定に並べる方式を説明する。模型では現在の列の先頭から同じ桁の箱へ入れ、各箱の中は投入順を保ち、箱０から順に集める。
- 例１は A21,B11,C12,D22,E11。一の位の後は A21,B11,E11,C12,D22、十の位の後は B11,E11,C12,A21,D22。元の等しい番号11のＢ・Ｅは順序を保つ。例２は A32,B13,C21,D23,E12 から E12,B13,C21,D23,A32 となる。
- ０〜３の箱のみを使う２桁の固定例であり、負数や他の桁・任意長、実装、一般的な正当性・安定性の証明、実時間やメモリの測定は扱わない。旧教材や本教材の存在を原典全体の完成とはしない。
