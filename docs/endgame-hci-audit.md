# 案内所の HCI 依頼の範囲

CS2023 HCI-Accessibility および HCI-Evaluation（報告書の印字ページ 177–181）を参照。案内の模型でキーボード操作、フォーカス表示、名前を比較する。評価の場面では、形成的・総括的評価を実施時期ではなく目的と結果の使い方で区別する。旅人の観察は架空の固定例。

いずれも部分的な導入であり、実際の支援技術の動作確認、利用者調査、規格適合、すべての利用者の必要条件を確認したものではない。評価手法の選定や調査設計も全範囲ではない。

独立レビューで評価を時期だけで分類しないよう修正し、正解位置を変えた。模型の操作を強制しないため、達成時には操作済みと断定しない。読み上げ名の表示は実際の読み上げではないことも明記した。

検証：単体テストと `scripts/endgame-hci.playwright.js`。後者は誤答と再選択、Enter による模型の操作、名前、保存からの再開、達成表示を複数画面幅で確認する。実機のスクリーンリーダーによる確認は未実施。
