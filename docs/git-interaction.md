# GIT-Interaction: 対話操作

出典：[CS2023 印字 pp.162–163](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf)。操作の固定例は、アプリやプログラムを自作する能力を評価しない。

| 分類・トピック | 対応と不足 |
|---|---|
| KA Core 1a–b マウス・タッチ、キーボードのイベント | 依頼351で方向ボタンの click と矢印キーの keydown を受けて同じ位置を更新。click はキーボードなどでも発生する。タッチ機器の実機検証、個別の低水準イベントや一般的な実装は未対応 |
| KA Core 1c–f 音声、センサー、メッセージ、ネットワークイベント | 依頼92で架空のイベントの送信・処理、依頼219でセンサー模型。実際の音声・ネットワーク入力や汎用的な処理は未対応 |
| KA Core 2 ウィンドウ、アイコン、メニュー、ポインティングデバイス | 依頼351で操作ボタンと画面表示の固定例。ウィンドウ・メニューなどの設計と比較は未対応 |
| KA Core 3 アクセシビリティ | 依頼22・117・350で異なる利用条件や字幕、依頼351で複数の操作方法。実際の支援技術や多様な利用者による評価は未対応 |
| Non-core 4 ジェスチャー | 未対応 |
| Non-core 5 触覚インターフェース | 未対応 |
| Non-core 6 マルチモーダル | 依頼351は二つの入力を操作する固定例。複数モダリティの統合設計は未対応 |
| Non-core 7 頭部装着インターフェース | 未対応 |
| Non-core 8 自然言語インターフェース | 未対応 |

| 例示学習成果 | 対応と不足 |
|---|---|
| KA Core 1 マウス・キーボードに反応する単純なゲームの作成 | 依頼351で固定ゲームを操作。ゲームの自作は未評価 |
| KA Core 2 タッチに反応するモバイルアプリの作成 | 依頼351のボタンはタッチでも操作可能な設計。実機検証とアプリの自作は未対応 |
| KA Core 3 複数のイベントを扱うアプリの設計・作成 | 依頼92・351の固定例のみ。設計・作成は未評価 |
| Non-core 4 機種間のタッチ操作の一貫性の評価 | 未対応 |
| Non-core 5 触覚フィードバックを備えたアプリの設計・作成 | 未対応 |
| Non-core 6 ジェスチャーで制御するプログラムの作成 | 未対応 |

依頼351では、方向ボタンの device-independent な click と矢印キーの keydown が移動処理を呼び、盤面の位置を更新する。イベントの概要は [MDN UI Events](https://developer.mozilla.org/en-US/docs/Web/API/UI_Events)、click の入力方法は [MDN click](https://developer.mozilla.org/en-US/docs/Web/API/Element/click_event) を参照。
