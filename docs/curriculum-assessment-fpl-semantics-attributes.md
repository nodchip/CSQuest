# 項目別評価：FPL-Semantics の属性文法

2026-11-05 に [CS2023 印字 pp. 141–142](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の FPL-Semantics トピック８と例示学習成果３を、依頼315の実装と検証結果に照らした。原典は属性文法などの宣言的仕様とその応用、属性文法を用いた意味解析の説明を挙げる。どちらも**部分対応**とする。

## 教材と正答

依頼315の合成属性では `2 + 3` と `2 + 真` を調べる。数の葉は数、真の葉は真偽値であり、親は両方が数の場合のみ数、それ以外は型エラーとする。子を確かめる前に親を記録できない。型エラーはこの教材の診断結果であり、通常の値の型とは区別する。

継承属性の例では、式 `x + 2` の親から x の節へ名前と型の環境を渡す。x が数なら足し算全体は数、真偽値なら型エラー、未登録なら名前の解決に失敗し式全体もエラーとなる。親から子への環境と、子から親へ得られる値を区別する例は [Cornell の属性文法の講義](https://www.cs.cornell.edu/courses/cs412/2008sp/lectures/lec14.pdf) の環境を渡す構成と照合した。
