# 市場の品札を並べる手順

[CS2023 AL-Foundational、印字89ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=89) と SDF-Algorithms、印字232ページに関連する固定例。３枚の品札で挿入ソートと選択ソートを一手ずつ進め、２組ずつ並べる。両方の依頼の達成後、同じ値の札の順序と、並び済みの入力で札の値を比較した回数を比べる。比較回数は値同士の比較のみで、交換回数や実際の実行時間ではない。

選択ソートは同値なら先の最小候補を維持する固定規則で、先頭との交換により同じ値の相対順が変わる例を扱う。挿入ソートは直前が厳密に大きい場合だけ交換する。３枚の少数例であり、空・１枚・任意長、一般の漸近解析、空間量、正しさの証明、実言語による実装や自由な説明は未対応。対象項目は部分対応である。

実装担当と別の coverage_candidates が原典・手順・比較回数・安定性・進行と保存を確認し、正式名称、入力と比較回数の説明、達成表示の要点を指摘した。修正後に再確認した。独立担当自身のブラウザ操作は行っていない。`tests/endgame-sorting.test.js` は比較順・誤操作・同値の順序・比較回数を検証する。`scripts/endgame-sorting.playwright.js` は集いと４地域の達成状態を用意した記録から、対象依頼の操作・誤答・取り消し・途中復元・再挑戦・開放と達成を確認する。実スクリーンリーダー音声は未検証。
