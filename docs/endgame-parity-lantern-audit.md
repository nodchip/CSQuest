# 偶数パリティの灯り：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字296頁の SF-Reliability 3b（冗長符号化）への入口。旧依頼106のハミング符号と107の CRC に対し、現行の塔に１つの偶数パリティによる検出とその限界を追加する。
- [Cornell の parity 解説](https://www.cs.cornell.edu/courses/cs4410/2014fa/slides/disksraid-09.pdf) は全ビットの偶奇による１ビット変化の検出と、１つのパリティでは位置を特定できないことを説明する。
- データ111に確認灯１を加えると1111で点灯数４。検査例の送信列1010は点灯数２。データ灯または確認灯のいずれか１灯を反転すれば奇数となり変化を検出し、異なる２灯を反転すれば偶数で見逃す。４箇所の１灯と６組の２灯を単体テストで検証する。
- 誤りのない偶数列を送る仮定の固定例。偶数だから無誤りとは限らず、単一の確認灯だけで位置特定や訂正はできない。一般の符号設計、３つ以上の変化、実際の通信路・確率・セキュリティ、実コードの記述や自由な説明は未評価。旧教材を含め原典全体の完成は主張しない。
