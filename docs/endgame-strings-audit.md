# 文庫の届け札と文字列

[CS2023 SDF-Data-Structures、印字231〜232ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=231) の文字列と文字列処理に関連する固定例。区切りで分けるときの空欄、最初の１件・すべての置換と該当なし、分割・各項目の半角空白除去・空欄除去の順序を操作して確かめる。

特定の文字と区切り、半角空白に限定した模型であり、任意の文字列、Unicode の数え方、ロケール、正規表現や実際の言語でプログラムを書く能力は扱わない。原典のプログラム作成に関する学習成果も部分対応にとどまる。

実装担当と別の coverage_next が原典、各例の結果、説明、操作、達成条件、履歴と開放条件を確認した。独立担当によるブラウザ操作は行っていない。`tests/endgame-strings.test.js` は空欄・置換範囲・該当なし・操作順と取り消しを検証する。`scripts/endgame-strings.playwright.js` は集いと４地域の達成状態を用意した記録から、誤操作、保存・再開、再挑戦、応用の開放と達成を確認する。実スクリーンリーダー音声は未検証。
