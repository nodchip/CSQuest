# 分母照合：SEC-Foundations

[CS2023 最終報告書 印字 pp.257–258](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=257) と[候補台帳](coverage-sec-foundations.md)を 2026-11-11 に照合した。これは原典範囲の照合であり、教材の完成を示さない。

## トピック

CS Core 1〜7 は機密性・完全性・可用性とリスク、認証・認可、脅威等、DoS、設計原則、安全性と他の性質のトレードオフ、AIによる攻防。KA Core 8〜16 はアクセス制御の方式、安全対策、信頼性、Web等への適用、組込み、使いやすさ、AIの信頼や運用リスク、ハードウェアを含む。各番号の中の列挙は例であり別の番号として数えない。16行の番号と区分は台帳と一致する。

## 例示学習成果

CS Core 1〜2 は攻撃可能性の評価と脅威に対する保護の設計・開発。KA Core 3〜8 はプライバシー被害の回避、安全性とプライバシーを組み込んだ開発、アクセス制御方式の比較、機械学習による攻撃と防御、ソフトウェアへ影響するハードウェアの脆弱性。8件はトピックと別に記録し、同じ番号だから対応すると見なさない。

## 現行の冒険と残る確認

旧台帳の依頼は旧教材の記録であり、この照合によって現行の冒険から到達できるとは判定しない。現行冒険の項目別評価には一部の固定例があるが、その部分対応を原典全体の完成とみなさない。教材の正確性、実際の到達、操作・保存、独立レビュー、および操作で直接評価できない能力は別途確認する。範囲ハッシュは候補 ID と台帳要約の変更検出であり、内容の正しさや教材完成の証明ではない。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
