# GIT-Animation の対応状況

出典: [CS2023, Graphics and Interactive Techniques, GIT-Animation](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 160–161。原典を要約した作業用一覧。固定模型の達成は単位全体の習得を示さない。

## トピック

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | KA Core | タイミング、緩急、予備動作などのアニメーションの原則 | 依頼182で一定速度と始点・終点の緩急の固定例。他の原則や人物モデルは未対応 |
| 2 | KA Core | ２・３次元、モーションキャプチャ、ストップモーションなどの種類 | 依頼635で動きの収録と欠測の架空例を操作。他の種類の比較は未対応 |
| 3 | KA Core | キーフレームと線形・球面線形・スプライン補間 | 依頼182で１次元位置と時間の緩急、633で平面の回転の角度境界、634で等間隔 Catmull–Rom の位置と直線を比較。３次元の回転や一般のスプライン補間は未対応 |
| 4 | KA Core | 順運動学と逆運動学 | 依頼183・184で平面の２関節の先端位置、複数の姿勢と到達範囲の固定模型。一般の角度・３次元・逆運動学の解法は未対応 |
| 5 | KA Core | スキニング、リギング、ブレンド形状など | 依頼185で２変換の重みを選び４点を線形ブレンドする平面の固定例。３次元、重み付けの制作や他の手法は未対応 |
| 6 | KA Core | モーションキャプチャの収録・合成と倫理、アクセシビリティ | 依頼635で遮蔽と補間の模型、利用条件の確認を扱う。実収録・合成・アクセシビリティは未対応 |

## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | KA Core | モデルとリグを使いアニメーションの原則を視覚的に説明 | 依頼182で点の移動の緩急を比較。モデル・リグや各原則の自由な説明は未対応 |
| 2 | KA Core | 順運動学で各部の位置・向きを計算 | 依頼183で長さ２と１の腕について、90°刻みの角度から関節・先端位置と向きを確認。任意の角度や３次元は未対応 |
| 3 | KA Core | 逆運動学で各部の向きを計算 | 依頼183・184で目標に合う角度を操作し、同じ目標に届く２姿勢と長さによる到達不能を扱う固定例。一般の解法と体系的な扱いは未対応 |
| 4 | KA Core | 回転表現のトレードオフを比較 | 未着手 |
| 5 | KA Core | スプライン補間のプログラムを作成 | 依頼182で３次の時間変換、634で等間隔 Catmull–Rom の固定例を操作。一般のスプラインやプログラム作成は評価しない |
| 6 | KA Core | 既存ソフトで形状・リグ・アニメーションを制作 | 未着手 |

依頼182では位置０から８へ４刻で進む。一定の割合は時刻１・２・３で２・４・６、緩急の割合 `3t²−2t³` は 1.25・４・6.75。再生は曲線の細かい標本間を線形に結ぶ近似で、回転や制作能力を評価しない。

依頼183は長さ２・１の平面の腕を90°刻みで動かし、２本目の向きを根元と相対関節の角度の和として求める。全16通りの位置を三角関数による独立計算と照合。一般の角度、３次元や逆運動学の解法は扱わない。

依頼184では長さ１・１の腕が (1, 1) に届く姿勢として (0°, 90°) と (90°, 270°) を選ぶ。90°刻みの全16組を列挙して２解を確認し、(3, 0) は腕の長さの合計２を超えるため任意の角度でも届かないことを扱う。

依頼185では x 座標０・１・３・４の点を、恒等変換と (2, 0) を中心とする90°回転の結果の重み付き平均で動かす。４点の重みの全256通りを検証し、目標に一致する組は (0, 0.25, 0.75, 1) のみ。平面の固定例で、３次元メッシュや実際の制作は評価しない。

依頼633は平面角度350°→10°と０°→180°を、数値差そのままの補間と最短回転で比較。前者の４分の１・半分・４分の３は数値差で265°・180°・95°、最短で355°・０°・５°。後者は両方向とも180°で、模型では数値差が反時計回り、最短が同点規則で時計回りを選ぶ。３次元姿勢、クォータニオンや球面線形補間は扱わない。[Godot: lerp_angle](https://docs.godotengine.org/en/4.1/classes/class_%40globalscope.html#class-globalscope-method-lerp-angle)。

依頼634は等間隔の４札 (０,０,１,１) と (０,１,１,０) の中央区間を直線と Catmull–Rom で比較。前者の４分の１・半分・４分の３は直線が0.25・0.5・0.75、曲線が0.203125・0.5・0.796875。後者は直線が常に１、曲線が1.09375・1.125・1.09375。曲線の値を中心差分による接線を使う Hermite 基底と101点で照合した。グラフは40区間の折れ線近似で、一般の３次元・非等間隔・プログラム制作は扱わない。[Three.js: Interpolations](https://threejs.org/docs/pages/module-Interpolations.html)。

依頼635は５刻の観測 (０,１,欠測,１,０) を共通に持つ２つの架空の収録を使う。中央を直線補間すると１だが、模型で設定した隠れた値はそれぞれ２・０で差の大きさはいずれも１。隠れた真値を後から明かすのは教育用の設定であり、実収録で利用できるとは限らない。収録の別用途への公開条件が不明な場合に演者へ確認する選択も扱う。１点の高さの模型で、実測・３次元復元・法的判断やアクセシビリティは評価しない。[Chalmers: Missing Marker Problem](https://research.chalmers.se/en/publication/100724)。
