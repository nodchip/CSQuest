# GIT-Animation の対応状況

出典: [CS2023, Graphics and Interactive Techniques, GIT-Animation](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 160–161。原典を要約した作業用一覧。固定模型の達成は単位全体の習得を示さない。

## トピック

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | KA Core | タイミング、緩急、予備動作などのアニメーションの原則 | 依頼182で一定速度と始点・終点の緩急の固定例。他の原則や人物モデルは未対応 |
| 2 | KA Core | ２・３次元、モーションキャプチャ、ストップモーションなどの種類 | 未着手 |
| 3 | KA Core | キーフレームと線形・球面線形・スプライン補間 | 依頼182で１次元の線形位置補間と３次式による時間の緩急。回転や一般のスプライン補間は未対応 |
| 4 | KA Core | 順運動学と逆運動学 | 依頼183・184で平面の２関節の先端位置、複数の姿勢と到達範囲の固定模型。一般の角度・３次元・逆運動学の解法は未対応 |
| 5 | KA Core | スキニング、リギング、ブレンド形状など | 依頼185で２変換の重みを選び４点を線形ブレンドする平面の固定例。３次元、重み付けの制作や他の手法は未対応 |
| 6 | KA Core | モーションキャプチャの収録・合成と倫理、アクセシビリティ | 未着手 |

## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | KA Core | モデルとリグを使いアニメーションの原則を視覚的に説明 | 依頼182で点の移動の緩急を比較。モデル・リグや各原則の自由な説明は未対応 |
| 2 | KA Core | 順運動学で各部の位置・向きを計算 | 依頼183で長さ２と１の腕について、90°刻みの角度から関節・先端位置と向きを確認。任意の角度や３次元は未対応 |
| 3 | KA Core | 逆運動学で各部の向きを計算 | 依頼183・184で目標に合う角度を操作し、同じ目標に届く２姿勢と長さによる到達不能を扱う固定例。一般の解法と体系的な扱いは未対応 |
| 4 | KA Core | 回転表現のトレードオフを比較 | 未着手 |
| 5 | KA Core | スプライン補間のプログラムを作成 | 依頼182で３次の時間変換による固定の位置を選択。一般のスプラインやプログラム作成は評価しない |
| 6 | KA Core | 既存ソフトで形状・リグ・アニメーションを制作 | 未着手 |

依頼182では位置０から８へ４刻で進む。一定の割合は時刻１・２・３で２・４・６、緩急の割合 `3t²−2t³` は 1.25・４・6.75。再生は曲線の細かい標本間を線形に結ぶ近似で、回転や制作能力を評価しない。

依頼183は長さ２・１の平面の腕を90°刻みで動かし、２本目の向きを根元と相対関節の角度の和として求める。全16通りの位置を三角関数による独立計算と照合。一般の角度、３次元や逆運動学の解法は扱わない。

依頼184では長さ１・１の腕が (1, 1) に届く姿勢として (0°, 90°) と (90°, 270°) を選ぶ。90°刻みの全16組を列挙して２解を確認し、(3, 0) は腕の長さの合計２を超えるため任意の角度でも届かないことを扱う。

依頼185では x 座標０・１・３・４の点を、恒等変換と (2, 0) を中心とする90°回転の結果の重み付き平均で動かす。４点の重みの全256通りを検証し、目標に一致する組は (0, 0.25, 0.75, 1) のみ。平面の固定例で、３次元メッシュや実際の制作は評価しない。
