# 巻物の字句を分ける：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字141頁 FPL-Syntax の字句解析・トークンに関連する固定例。旧依頼313 `src/lexer-scroll.js` の規則を現行の工房に接続した。構文解析・実行の正しさまでは判断しない。
- [Cornell の字句解析講義](https://www.cs.cornell.edu/courses/cs412/2004sp/lectures/lec04.pdf) は最長一致と、同じ最長文字列に複数規則が一致するときの優先順位を説明する。本模型では小文字英字の最長列を読み、全体が `if` なら予約語、それ以外は名前とする。数字の最長列、単独の `=`、空白の読み飛ばしも固定する。
- `ifx=12` は名前 `ifx`、等号、数 `12`。`if x=12` は予約語 `if`、名前 `x`、等号、数 `12`。実際の言語の予約語全体、Unicode・他の記号・構文・意味・実装は扱わず、固定例の達成を原典全体の完成としない。
- 未確定の同じ巻物・同じ選択欄だけの操作履歴を圧縮し、確定済みの印と別巻物の選択は保持する。単体テストは100回の交互選び直しと途中復元、正しい確定を検証する。
