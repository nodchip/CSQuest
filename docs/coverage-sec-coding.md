82の固定結果は SQLite と照合済みで、パラメータ化は一般の入力検証・認可の代替ではない。578の算術は架空の８ビット模型である。各依頼の参照・検証は [既存調査](sec-coding.md)と [分析の台帳](coverage-fpl-analysis.md)を参照。

依頼971は [Cornell の情報フローと非干渉](https://www.cs.cornell.edu/courses/cs5430/2012sp/MCinfo01.iflow_lecture_1.html)を参考に、３方式で同じ公開入力に対する秘密の変更を比べる。`tests/noninterference-lab.test.js` は有限の全32比較・反例・保存と達成を検査。決定的で必ず終了する固定模型の数値出力のみで、時間・終了・他の出力や一般の非干渉は未評価。

依頼972は [Cornell の時間を含む情報フロー](https://www.cs.cornell.edu/andru/papers/now-info-flow/now-info-flow.pdf)を参考に、同じ公開値でも秘密によって模型の刻みが変わる方式と、一定の方式を比較する。`tests/timing-flow.test.js` は２方式・２観測・公開２値と秘密の順序付き全組を検査。雑音、並行実行、実測や実システムでの安全性は未評価。

依頼973は [Clarkson・Schneider の非干渉](https://www.cs.cornell.edu/fbs/publications/Hyperproperties.JCS.pdf)を参考に、秘密によって自己遷移を繰り返す門と両方終了する門で、終了後の値と終了の有無を比較する。`tests/termination-flow.test.js` は有限状態の手順・比較・保存を検査。自己遷移は模型の規則として与えられ、有限回の観察だけで一般の停止を判定しない。

依頼1013は C11 の配列・ポインター、Java の通常の配列・強い参照、安全な Rust の配列・借用について、範囲外、解放・所有者破棄、同期のない同時書込みを固定例で比較する。[Rust の借用](https://doc.rust-lang.org/stable/book/ch04-02-references-and-borrowing.html)、[Java の配列](https://docs.oracle.com/javase/specs/jls/se21/html/jls-10.html)、[C のメモリーモデル](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1479.htm) を参照。Rust の添字は実行時の値で通常の添字演算、２可変借用は両方を使用する設定。Java の参照は強い参照で native 操作を含まない。例は実コードの作成・書換えを評価せず、言語の全機能、FFI、任意の安全性を保証しない。`tests/language-safety.test.js` で９条件、回答と復元を検査する。

C の範囲外・寿命・データ競合の根拠は [C11 委員会草案 N1570](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf) §6.2.4・6.5.6・5.1.2.4、Java の競合は [JLS §17](https://docs.oracle.com/javase/specs/jls/se21/html/jls-17.html)。Rust 1.99.1 で借用後の drop が E0505、同時に使う可変借用が E0499 で拒否され、実行時に決めた範囲外添字がパニックすることを確認した。Java の実環境での実行は行っていない。

依頼985・986の前提と公的資料は [SEP-Security の対応記録](coverage-sep-security.md)を参照。985の経路遮断は固定模型で、実際のマルウェア分析や全ての拡散防止を示さない。986の報告は予防・対応の一部に触れるが、ランサムウェア作成や実際の復旧は扱わない。

依頼1075は [GitHub の依存グラフ](https://docs.github.com/en/code-security/concepts/supply-chain-security/dependency-graph-data)と [OWASP の CI/CD セキュリティ](https://cheatsheetseries.owasp.org/cheatsheets/CI_CD_Security_Cheat_Sheet.html)を参考に、架空の４候補の直接・間接依存、注意情報、照合値と互換性試験を比較する。期待値は信頼できる経路から取得済みという仮定で、記号は実ハッシュではない。`tests/supply-review.test.js` は判断と記録を検査し、実パッケージの取得・解析・安全性を保証しない。

依頼1134は [Rust のスライス取得](https://doc.rust-lang.org/std/primitive.slice.html#method.get)と[回復可能な失敗](https://doc.rust-lang.org/book/ch09-02-recoverable-errors-with-result.html)を参考に、長さ３の棚でポインターによる無検査の読取り、安全な取得後の無条件の取出し、失敗の報告を比較する。`tests/safer-reader.test.js` は３方式×５番号、予想、９比較と保存を検査。Rust 1.99.1 で０〜２が各値、３・４が取得失敗となり、失敗の無条件取出しがパニックすることを別途確認した。C の範囲外を実行せず未定義動作として扱う。負の入力、他の脆弱性、実際のコードの書換えや一般の正しさは評価しない。

依頼1135は1134の読取り模型を使い、取得方法と失敗の扱いを組み立てて４つの注文列を段階的に試す。範囲外を０にすると報告の仕様を満たさず、無検査の範囲外の後は追跡を打ち切る。`tests/reader-migration.test.js` は６構成、正常時の値、失敗と後続処理、保存を検査する。手順変更後は試験結果を取り消す。実プログラムの書換え、負の番号、任意の入力や他の安全性は評価しない。

依頼1135には、０〜４の番号を最大４件まで並べる任意の試験を追加した。空列を含む781列×６構成について、処理された番号列と仕様の通過判定を独立した期待値と比較した。任意試験は完成条件に含まず、旧版の途中記録も復元できる。負の番号や５以上の番号、４件を超える列、実プログラムは評価しない。

依頼1136は [OWASP の XSS 対策](https://cheatsheetseries.owasp.org/cheatsheets/Cross_Site_Scripting_Prevention_Cheat_Sheet.html)と [MDN の URL 解析](https://developer.mozilla.org/en-US/docs/Web/API/URL/URL)を参考に、HTML 属性向け文字処理のみの受付と、解析後に HTTPS と固定オリジンを照合する受付を比較する。相対、紛らわしい名前、スクリプト形式、改行入り、壊れた形式など８例×２方式を `tests/link-gate.test.js` で検査。リンクを作成・実行せず、リダイレクト、認可、同一オリジン内の危険な宛先、他の XSS 文脈や実アプリの安全性は評価しない。

依頼1137は [OWASP の未検証の転送](https://cheatsheetseries.owasp.org/cheatsheets/Unvalidated_Redirects_and_Forwards_Cheat_Sheet.html)と [MDN の HTTP 転送](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Redirections)を参考に、1136の URL 解析を再利用する。最初だけの照合と転送のたびの照合で、８種類の固定経路を操作。相対指定は直前の URL に対して解決し、外部への未確認の進行は実行せず可能性を示すところで停止する。`tests/redirect-route.test.js` は16条件、連続した相対指定、外部・循環・不正と保存を検査する。実際の HTTP、認可、同一オリジン内の危険な操作やネットワークの安全性は評価しない。
