# SF-Security・SF-Design・SF-SEP の対応状況

出典：[CS2023 Systems Fundamentals](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 297–298。原典を要約した作業用一覧。既存の固定例は、システム全体の安全性、自由な説明、実システムの設計能力を保証しない。

## SF-Security のトピック

| 番号 | 区分 | 内容と現状 |
|---:|---|---|
| 1 | CS Core | ウイルス、サービス妨害、盗聴などの問題。依頼180で媒体・起動部品・受付の固定した攻撃経路。原典の例や一般的な攻撃は未対応 |
| 2a | CS Core | 暗号による対策。依頼58・128・261〜263で鍵再利用、署名、鍵交換、認証の固定例。安全な実用暗号は未対応 |
| 2b | CS Core | セキュリティアーキテクチャ。依頼180・258で層別の対策と構成証明の固定例。実際の設計・実装は未対応 |
| 3a | KA Core | 侵入検知、ファイアウォール。未着手 |
| 3b | KA Core | ウイルス対策。未着手 |
