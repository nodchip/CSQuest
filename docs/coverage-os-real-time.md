# OS-Real-time：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.214–215。[追跡方法](coverage-status.md)に従い、６トピックと４例示学習成果を個別に記録する。模型の攻略は実機での設計・安全性や自由な説明を直接評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | KA Core | プロセス・仕事のスケジューリング | 部分 | 133で同時到着する２仕事の実行順、134で鍵待ちと優先度継承。一般的な到着・方針や実 OS は未評価。 |
| 2 | KA Core | 期限とリアルタイムの問題 | 部分 | 133で完了時刻と期限を比較、420で周期基準と超過の固定例。実際の保証や一般の時間制約は未評価。 |
| 3 | KA Core | 低遅延、ソフト・ハードリアルタイム | 部分 | 133で期限超過を許せるかの違いに触れる。低遅延との体系的比較や実例は未評価。 |
| 4 | Non-core | リアルタイム環境でのメモリ・ディスク管理要件 | 未照合 | 時間制約と記憶管理を組み合わせた対応は未確認。 |
| 5 | Non-core | 故障、リスクと復旧 | 部分 | 395で検知不能時の停止判断、752で装置停止後の再試行を別々に比較。期限付き復旧と実機は未評価。 |
| 6 | Non-core | 安全性を含む特有の配慮 | 部分 | 395で検知から停止までの距離と遮蔽時の判断を操作。実機の危険分析や安全保証は未評価。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | KA Core | リアルタイムシステムの特徴を説明 | 部分 | 133で結果を期限内に出す順序を比較。体系的な説明や自由記述は未評価。 |
| 2 | KA Core | 遅延の原因と性質を説明 | 部分 | 134で鍵待ち、420で仕事時間と周期のずれを比較。原因全体、実測や自由記述は未評価。 |
| 3 | KA Core | リスクを含む特有の配慮と対策を説明 | 部分 | 395で遮蔽時に止まるかを選ぶ固定例。一般のリスク分析や自由記述は未評価。 |
| 4 | Non-core | 特定のリアルタイム OS の機能・仕組みを説明 | 未照合 | 特定 OS の機構を説明する教材は未確認。 |

依頼133・134の期限と優先度の固定例は [OS-Real-time](os-real-time.md) を参照。依頼420は３刻周期と３仕事の長さを固定し、終了後の相対待機と基準時刻への待機、最初の仕事が周期を超える場合を比較する。依頼395の停止距離・遮蔽時の仮定は [SPD-Robot](spd-robot.md) を参照。関連検査は `tests/deadlines.test.js`、`tests/inversion.test.js`、`tests/periodic-timing.test.js`、`tests/robot-safety.test.js`。実測や一般的な期限保証ではない。
