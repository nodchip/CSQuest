# 中継塔の知らせ灯とイベント

[CS2023 FPL-Event-Driven、印字134ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=134) のイベント駆動に関連する模型。水辺と港の知らせに処理を登録し、未登録を含めて試す。別の依頼で押すイベントにより灯りの状態を反転し、応用では２通りの到着順を待ち箱から１件ずつ処理する。FIFO はこの模型の約束であり、現実のすべてのシステムの保証ではない。

固定された種類と状態の例であり、実言語でのハンドラーの実装、イベント配送の一般的な保証、無状態との比較、実装方式の比較と自由な説明は扱わない。関連項目は部分対応である。

実装担当とは別の coverage_next が原典、登録・状態・配送の動作、説明、保存と開放を確認した。独立担当自身のブラウザ操作は行っていない。`tests/endgame-events.test.js` は未登録、状態反転、処理順と誤操作を検証し、`scripts/endgame-events.playwright.js` は集いと４地域の達成状態を用意した記録から、誤操作、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
