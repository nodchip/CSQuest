# 原典との範囲照合：FPL-Types

[CS2023 印字 pp.136–138](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の FPL-Types と[項目別台帳](coverage-fpl-types.md)を2026-11-06に照合した。PDF の取得が一時的にタイムアウトしたため、[ACM が公開する同報告書](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)の本文を参照した。

トピック１〜６は CS Core、７・８は KA Core、９〜16は Non-core。子を含む台帳の分母候補は37行、例示学習成果は各区分６件ずつの18行。１の２つの子は原典の段下げされた項目を１a・１bとして記録した。１・６・８・11の親はそれぞれの概念を含むため保持するが、子との重複候補がある。原典の６c と６f は同じ多相性の比較を繰り返すため、そのまま独立した２項目と数えない。

成果２は特定の静的型付き言語、５は特定言語で不受理でも実行経路に誤りがない例を求めるため、要約を明確にした。依頼1041は Rust のコンパイル不受理と Python の実行経路を示すが、Rust の不受理プログラム自体を実行できた証拠ではない。８b・８e と成果８・13は未照合を維持する。６g の用語の解釈も未確定で、固定模型から原典の唯一の意味を断定しない。

これは項目の範囲と区分の照合であり、教材全体の完成、個別の正しさ、自由なプログラム開発や説明能力を証明しない。
