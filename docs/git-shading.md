# GIT-Shading の対応状況

出典: [CS2023, Graphics and Interactive Techniques, GIT-Shading](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 159–160。原典を要約した作業用一覧。固定模型の達成は知識単位全体の習得を示さない。

## トピック

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | KA Core | レンダリング方程式の近似、パストレーシングなど | 未着手 |
| 2 | KA Core | 時間、レンズ位置、光の波長と描画 | 未着手 |
| 3 | KA Core | シャドウマッピング | 依頼187で３本の平行光について最小深度を記録し、地面の深さと比較する固定模型。２次元深度画像、投影、精度誤差やバイアスは未対応 |
| 4 | KA Core | 遮蔽による描画対象の削減 | 未着手 |
| 5 | KA Core | BSDF とマイクロファセット | 未着手 |

## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | KA Core | 描画アルゴリズムがレンダリング方程式の解を推定する方法を説明 | 未着手 |
| 2 | KA Core | 描画アルゴリズムの完全性・一致性・不偏性を議論 | 未着手 |
| 3 | KA Core | 簡単なシェーディングの帯域・計算量を分析 | 未着手 |
| 4 | KA Core | 描画 API でトゥーン調などのシェーディングを実装 | 依頼186で明暗の段階化を選択操作。描画 API の実装能力は評価しない |
| 5 | KA Core | 芸術的技法を描画に実現する方法を示す | 依頼186で明暗の段階化を操作。一般的な技法の設計・自由記述は未対応 |
| 6 | KA Core | 画像から使われた描画技法を見分ける方法を説明 | 依頼186で滑らかな明暗と３段階の結果を比較。実画像の分析や自由記述は未対応 |
| 7 | KA Core | 画素単位の描画プログラムを作成 | 未着手 |
| 8 | KA Core | BRDF・反射・屈折を用いるレイトレーサを作成 | 未着手 |

依頼186では固定された単位法線と灯り方向の内積を０以上に制限し、0.25 と 0.75 を境に３段階へ分ける。簡略化した拡散光であり、影・輪郭線・実際の描画 API やプログラミング能力は評価しない。

依頼187は２地図の各３本の道で、光から最も近い深さと地面の深さ５を比較する。記録より地面が奥なら影、等しい場合は明るいとする。平行光と離散的な道を仮定し、実際の深度画像、精度誤差や半影は扱わない。
