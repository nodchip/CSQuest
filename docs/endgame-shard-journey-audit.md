# 谷の二つの棚：照合記録

[CS2023 印字120–122頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の DM-NoSQL 4 と DM-Distributed 1a は分割・分散保存を扱う。[MongoDB の分割方式](https://www.mongodb.com/docs/manual/sharding/)は範囲分割やハッシュ分割を説明する。旧依頼191の `src/shard-routing.js` の固定例を現行冒険で再利用し、新規の範囲達成を主張しない。奇偶方式は単純な固定規則で、製品のハッシュ方式を再現しない。

鍵 K1–K4 の奇偶配置は左 K1・K3、右 K2・K4。範囲配置は左 K1・K2、右 K3・K4。K3 はそれぞれ左・右、K1〜K2 は左右２棚・左１棚が必要。指定鍵だけを過不足なく探し、棚への問合せ数のみ比較する。実際の実装、性能、分布・負荷、故障、複製、再配置、一般的な問い合わせ設計は未評価。
