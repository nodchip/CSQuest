# 文庫の案内帳と版管理

[CS2023 SE-Tools、印字241〜242ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=241) の構成管理、変更の統合、リリース管理に関連する固定模型。保存された２つの版と書きかけを区別し、共通の元からの別欄の変更と、同じ欄の異なる変更を統合する。さらに公開する版自身について、道名が空でないという一つの試験を行う。

版を見る操作は書きかけの復元や上書きではない。別欄を合わせられても内容の正しさは保証されず、同一欄でも同じ内容への変更が必ず競合するとは限らない。一つの試験の合格は他の誤りがない保証ではない。[Git の status](https://git-scm.com/docs/git-status) と [merge](https://git-scm.com/docs/git-merge) も参照したが、この模型は実 Git の index・merge・rebase や分散同期を再現していない。実際のチーム作業、自由な説明、再現可能なビルドや一般のテストは未評価であり、関連項目は部分対応である。

実装担当と別の coverage_next が原典、版と書きかけ、統合と競合、公開版ごとの試験、誤答と保存・開放をコード上で確認した。独立担当自身のブラウザー操作は行っていない。`tests/endgame-versioning.test.js` は両方の取込順、競合の再選択、版ごとの試験を検証し、`scripts/endgame-versioning.playwright.js` は集いと４地域の達成状態を用意した記録から誤答、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
