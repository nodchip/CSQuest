# 観測所の花札と教師あり分類

[CS2023 AI-ML、印字71〜72・74〜75ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=71) の教師あり分類と訓練・評価の分離に関連する固定模型。しきい値２・３・４をラベル付き訓練札で試し、誤りが最小の候補を選ぶ。同率の候補はすべて受理する。別の依頼では評価札に予測を出した後に正解を開き、応用では訓練・候補選択用の検証・最終評価の札を分ける。

評価札の正解色と誤り数は予測前の画面には含めないが、公開されたクライアント側の教材であり秘密情報ではない。固定例は再挑戦で既知になり得るため、繰り返し使った札を独立した初見の評価としない。模型には同じ数でも異なる正解の札がある。有限の候補探索と少数の札から一般化性能や公平性を保証せず、実データの分割・前処理、複数手法の設計・実装は未評価である。データ漏洩や分割の注意について [scikit-learn の公式解説](https://scikit-learn.org/stable/common_pitfalls.html) と [交差検証の解説](https://scikit-learn.org/stable/modules/cross_validation.html) を参照した。関連項目は部分対応である。

実装担当と別の coverage_next が原典、同率と誤分類数、評価前の画面、データ分離、誤答と保存・開放をコード上で確認した。訓練例と最終評価例の重複を指摘され、評価例を変更して再確認を受けた。独立担当自身のブラウザー操作は行っていない。`tests/endgame-supervised.test.js` は同率、誤分類、評価前の操作制限、最終例の重複を検証し、`scripts/endgame-supervised.playwright.js` は集いと４地域の達成状態を用意した記録から誤答、途中保存、評価前の非表示、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
