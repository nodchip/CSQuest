# 原典との範囲照合：HCI-SEP

[CS2023 印字 pp.181–182](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)を照合した。トピック１〜５は CS Core、６・７は KA Core、８は Non-core。トピック8行、例示学習成果5行。成果番号２は原典でも CS Core と KA Core にそれぞれ存在するため区分を併記する。

成果２（KA Core）は最近の実例の批判的検討と改善の提案を含むが、依頼1107に FTC の2023年の申立てと影響・見直しの固定選択を追加した。自由な議論・独自の実例調査、実際の利用者参加、実機や社会的な影響の評価は未評価。この範囲照合は教材の正確性や学習効果、全教材の完成を証明しない。
