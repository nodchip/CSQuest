# 分母照合：SE-Design

[CS2023 印字 pp.243–244](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=243) と[候補台帳](coverage-se-design.md)を 2026-11-11 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core は 1a〜1d（抽象・関心の分離・情報隠蔽・結合と凝集）、2a-i〜2a-iv・2b・2c（設計パラダイム、標準アーキテクチャ、部品の境界と依存）、3・4（大規模と小規模、正しさとは別の品質・コードスメル）。KA Core は 5a〜5e（API の一貫性・組合せ・契約・拡張性・エラー報告）、6・7（データと時間の不変条件・構造と振る舞いのモデル）、8a・8b（データ構造・保存システム）、9a（要件追跡）。原典 5a・5c・5e のさらに細かい i 等の説明は、それぞれ台帳の該当する子に含む。Non-core は 10・11（設計図と品質測定）、12a〜12c（最小権限・安全側の初期値・心理的受容性）、13（品質間のトレードオフ）。原典の親 1・2・2a・5・8・9・12 は子に共通する設計の文脈を保持し、親と子を単純に重複計上しない。トピック台帳 28 行。

CS Core 成果 1〜4 は標準アーキテクチャの特定、設計原則を用いた設計、関心の分離・情報隠蔽による修正、依存の特定。KA Core 5〜9 は API と契約の設計・記録、一貫性等の評価、新機能の追加、データ構造の設計、満たす要件の特定。Non-core 10〜12 はクラス図への変換、安全設計の原則に沿う修正、複数品質による設計比較。成果 12 行を別に追跡する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の SE-Design 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実際の設計・開発・自由な仕様記述や利用者との検証は固定模型だけで直接評価しない。
