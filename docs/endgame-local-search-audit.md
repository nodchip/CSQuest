# 観測所の局所探索

[CS2023 AI-Search（印字68〜69ページ）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の CS Core 1・3b・3c に関連する有限模型。場所の評価値を小さくするため、隣を調べて最小の候補へ進み、未訪問の候補がないと止める。別の地形、出発地点、同値移動の許可を試し、探索後に全体の値と道を表示する。値は道の費用ではなく、同値移動でも訪問済み地点は除外する。

候補がなくなったことは、この規則での停止を意味し、一般の局所最小の証明ではない。固定された少数のグラフは、任意の探索、一般の最適性、A*、計算量、実装の習得を評価しない。関連項目は部分対応である。

実装担当と別の coverage_next が原典、各地形の移動と停止、値の意味、同値と訪問済み、全体図、誤答、保存・開放をコード上で独立確認した。独立担当自身は実ブラウザーを操作していない。`tests/endgame-local-search.test.js` は誤った移動、行き詰まり、開始点と同値移動を検証する。`scripts/endgame-local-search.playwright.js` は物語と４地域の達成状態を用意した別ブラウザー記録から誤答、途中保存、再挑戦、開放と達成を確認する。実際のスクリーンリーダー音声は未確認。
