# PDC-Programs：並列・分散プログラム

出典: [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.219–220。ゲーム内の操作は並列プログラムの作成・実行能力を直接評価しない。

| トピック | 区分 | 内容と現状 |
|---|---|---|
| 1a–d | CS Core | 作用の粒度、順序、独立性、必要な順序の保証と不要な順序の緩和。依頼15・16・90・130で共有更新、排他、バリア、独立な小計と集約の固定例。一般的な依存関係の分析は未対応 |
| 2a–d | CS Core | 実行場所、少数の装置による並列動作の模倣、場所・主体の識別、通信。依頼129・130で２主体の通信と分担の模型。実装・仮想化や一般の場所は未対応 |
| 3a–e | CS Core | 活動の開始、手続き・反応・依存に基づく起動、粒度とオーバーヘッド。依頼90・130で先行処理の完了後に集約する固定例。実行環境や起動費用は未対応 |
| 4a–d | CS Core | 非決定性、一貫性、障害耐性、設計上の兼ね合い。依頼15で実行順序による結果の固定例。他の事項や一般の分析は未対応 |
| 5a–f | KA Core | 命令・データ並列、SIMD、複数コア、クラスタ・クラウド、ネットワーク、量子等の方式。依頼162で SIMD・MIMD の固定例。他の方式と一般的な比較は未対応 |

| 例示学習成果 | 区分 | 内容と現状 |
|---|---|---|
| 1 | CS Core | 数値式の並列化を有向非巡回グラフで表す。依頼130で２つの小計を集約する固定例。グラフの作成と一般の式は未対応 |
| 2 | CS Core | 一貫性・障害耐性と逐次実行の関係を説明。未対応 |
| 3–5 | KA Core | イベントを数える関数、filter/map/reduce の各方式、クライアントごとの活動を作るサービスの実装。依頼130で固定した箱の分担と合計の模型。実プログラム、filter・map の一般化、サービス実装は未対応 |

依頼130では４箱の個数 [2,1,3,2] を２人に重複なく割り当てる。２箱ずつと３箱・１箱のどちらでも各小計を足すと８。最大値だけを取る操作は全体の合計を失う。実時間、通信、障害、実際の同時実行は扱わず、箱数が同じでも所要時間が等しいとは限らない。
