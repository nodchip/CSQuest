# 分母照合：GIT-SEP

[CS2023 最終報告書 印字 pp.165–166](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=165) の GIT-SEP と[候補台帳](coverage-git-sep.md)を 2026-11-10 に照合した。これは原典項目の範囲と区分の照合であり、教材の完成・正確性、操作と保存、独立レビューを証明しない。

## トピック

すべて KA Core。1a・1b は没入型・対話型・物理計算における運動、視覚、聴覚に制約のある人のアクセシビリティ。2a〜2d は私的データの取得、没入体験から目をそらしにくいこと、本人と周囲の危険、顔認識の倫理的問題。2e-i・2e-ii は不正確なデータと正確なデータの両方で生じうる誤解を招く可視化。原典は前者の例に誇張・穴埋め・平滑化・データ整理、後者の例にエイリアシングで逆回転または停止したように見える扇風機の羽を挙げる。2f は健康など個人情報のプライバシー、2g-i・2g-ii は画像処理におけるバイアスの例として、ディープフェイクおよび肌色・髪型などによる誤認識。3a・3b は生成 AI の学習に使う画像と生成画像それぞれの知的財産、4 は分野の現在と過去の貢献者。

原典の 1・2・3 は子項目をまとめる見出し、2e・2g はそれぞれ二つの子項目をまとめる見出しとして扱い、親と子を重複して数えない。見出しが示す没入・対話・物理計算、グラフィクスでの倫理とプライバシー、知的財産法という共通の文脈をそれぞれ子の解釈に含める。トピックは 14 件。

## 例示学習成果

すべて KA Core の 3 件：1 は位置タグに内在するセキュリティ問題の議論、2 は顔認識の倫理的問題と倫理的な利用が可能か・可能ならどのように利用するかの説明、3 は透かし画像をニューラルネットワークの学習に使う場合の著作権問題の議論。トピックと成果は別々に追跡する。

## 現行の冒険との区別

台帳中の番号付き依頼は旧教材の記録で、この原典照合だけでは現行の冒険からの到達・操作を確認したことにならない。現行の冒険に関する GIT-SEP の項目別評価は、この記録時点では未作成である。未作成は教材不存在の証明ではない。実環境での安全性、倫理や法域ごとの判断、自由な議論を固定例で直接評価したとは扱わない。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係を確認し、2g の親見出しである画像処理のバイアスという文脈の不足を指摘した。追記後に再確認した。これは原典範囲のレビューであり、教材やブラウザ操作の確認ではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
