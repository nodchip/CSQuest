# 薬草の選び方と標本の偏り：教材監査

[CS2023 MSF-Statistics 印字190–191頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=191) の成果３にある標本抽出と偏りの固定例。旧 `src/light-estimator.js` は５光点の一様・中央固定抽出の分布を扱うが旧画面の教材であり、今回の現行冒険は非復元の２本の６組を明示して操作し、１標本の偶然のずれと手順全体の平均の違いを比べる。

４本 A,B,C,D の長さは２・２・６・６、全体の平均は４。手前 A,B だけを選ぶ決定的な手順は平均２。全４本から異なる２本を非復元で取り順番を区別しない６組を同確率に選ぶと、それぞれの標本平均は２・４・４・４・４・６、手順の反復平均は４。個々の標本が母平均と一致するとは限らず、１標本の一致やずれだけでは手順全体の無偏性を判定できない。

固定の完全な４本と既知の値による例であり、実調査の標本抽出、非回答、選択確率が不明な集団、一般の十分性、推定誤差、自由な説明や証明を評価しない。無作為抽出がどの調査でも代表性を保証するとは主張しない。成果３全体の完成を意味しない。
