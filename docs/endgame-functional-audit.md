# 水辺の数札と関数型の操作

[CS2023 FPL-Functional、印字131〜132ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=131) の関数型の基礎に関連する有限例。元の列を変えずに各要素を変換し、０を初期値として数を集約する。応用では選択・変換・合計を並べ替え、結果の違いを試す。空の列は初期値０になる。

固定した道具と列を操作する模型であり、任意の関数の定義・受け渡しを実言語で記述する能力、一般的な副作用・参照同一性や再帰の性質は評価しない。関連項目は部分対応である。

実装担当と別の coverage_next が原典、変換、集約の初期値、操作順、保存と開放を確認した。独立担当によるブラウザ操作は行っていない。`tests/endgame-functional.test.js` は変換、空と負数の集約、順序と取り消しを検証し、`scripts/endgame-functional.playwright.js` は集いと４地域の達成状態を用意した記録から、誤操作、保存・再開、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
