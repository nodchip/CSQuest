# 三つの塔の PageRank：照合記録

[CS2023 印字191–192頁 MSF-Linear](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 8f は PageRank と固有ベクトルを扱う。[Page らの原論文](https://storm.cis.fordham.edu/~gweiss/selected-papers/classic-pagerank-paper.pdf)を参照。旧依頼301 `src/pagerank.js` を現行冒険へ再利用し、新たな範囲達成を主張しない。

星・月・太陽を初期 1/3 とし、各回 3/5 が各塔の１本の道に沿い、2/5 は三塔へ均等に移る。東は星→月、月→太陽、太陽→月、西は星→月、月→星、太陽→月。１回後に月が最多、２回後は東で (10,31,34)/75、西で (34,31,10)/75。各固定点は東 (16,55,49)/120、西 (49,55,16)/120 で、変換 T により不変、T v=v の固有値１。有限２回の値を固定点と混同しない。固定模型であり一般の導出・任意グラフ・大規模な実装、収束の証明やリンクのない塔は未評価。

## 独立レビューと動作確認

実装担当と別の担当が東西の２回の分布、固定点、有限反復との区別と保存・開放・焦点を確認。ローカルで集いと４地域の達成状態を用意した記録から、幅 213・390・1200 px で誤操作、キーボード、途中保存・再開と達成を確認した。冒険開始からの通し到達は含まない。

公開確認：GitHub Pages の d4775ed（Actions 42978926842 成功）で、集いと４地域の達成状態を用意した記録から、幅 213・390・1200 px のブラウザ検証スクリプトが成功。新規開始からの通し到達はこの確認に含めない。
