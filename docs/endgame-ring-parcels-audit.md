# 輪につながる荷物棚：教材監査

[CS2023 AL-Foundational 印字88–90頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=88) のキューの固定例。現行 `src/endgame-queue.js` は到着と送信順、旧 `src/deque-missions.js` は両端キューを扱う。今回の依頼は固定容量の配列内の位置、折返し、満杯の拒否を直接操作する。

初期状態は３枠が空、先頭位置０・個数０。書込み位置は (先頭＋個数) mod ３、取り出しは先頭から行う。Ａ・Ｂ・Ｃを追加後は満杯・先頭０・書込み０・個数３。Ａを取り出してＤを追加すると物理枠はＤ・Ｂ・Ｃ、先頭１、書込み１、個数３で、FIFO の取出し順はＢ・Ｃ・Ｄ。満杯時にＤを追加しようとしても状態は変化せず、取り出し後の追加は成功する。空と満杯で位置が一致するため、この模型では個数で区別する。

操作順と容量を固定し、空の取出し・任意の操作列・サイズ拡張・並行アクセス・一般の費用は評価しない。参照する [Princeton の環状配列キュー](https://algs4.cs.princeton.edu/13stacks/ResizingArrayQueue.java.html) は満杯時に拡張するが、本模型は拡張せず拒否する別の仕様である。原典全体の完成を意味しない。

2026-11-11、実装担当と別の `signed_review` が原典と [Open Data Structures の ArrayQueue](https://opendatastructures.org/ods-java/2_3_ArrayQueue_Array_Based_.html) に照らし、固定列の折返し・FIFO・個数による空と満杯の区別、画面・保存・開放を独立レビューした。親担当の初回ブラウザ確認で焦点が操作前の状態を参照する問題を発見し、更新後の履歴から選ぶ修正を３幅で再確認、独立再レビューも受けた。準備済み記録から幅 213・390・1200 px の駅の分類に到達し、誤答、キーボード、途中保存・再開、開放条件、達成後の保存をブラウザ確認した。新規開始からの通し操作、スクリーンリーダー音声、利用者による面白さは未確認。
