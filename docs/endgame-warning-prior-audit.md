# MSF-Probability：警報と故障の事前割合

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.188–189、MSF-Probability 1d の条件付き確率・ベイズ則。旧依頼683 `src/base-rate.js` の２つの固定度数表を現行観測所に再利用するため、旧教材と独立の範囲として重複計上しない。現行の雲と雨の条件付き割合は、同じ警報性能で事前割合だけを変える例ではない。

各村は1000件の固定模型。故障時に警報が出る割合は90%、正常時にも警報が出る割合は10%で同じ。故障10件の村は警報ありの故障９・正常99、警報後の故障割合9/108。故障500件の村は警報ありの故障450・正常50、警報後の故障割合450/500。警報後の割合を求める分母は故障全体ではなく警報全体。[MIT の条件付き確率とベイズ則の教材](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/mit18_05_s22_class03-prep.pdf) を参照。

与えられた固定度数の比較であり、実際の故障率や装置性能の推定、個別事象の確実性、一般のベイズ計算や自由な説明・実装は評価しない。MSF-Probability 全体の完成を示さない。
