# 分母照合：SEP-History

[CS2023 最終報告書 印字 pp.282–283](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=282) の SEP-History と[候補台帳](coverage-sep-history.md)を 2026-11-10 に照合した。これは原典項目の範囲と区分の照合であり、教材の完成・正確性、操作と保存、独立レビューを証明しない。

## トピック

CS Core 1・2 はハードウェア・ソフトウェア・人と組織の歴史、および異なる社会的文脈を含む現在と将来における歴史の役割。KA Core 3〜8 はそれぞれデジタル以前、初期の現代計算機、PC、インターネット、モバイルとクラウド、AI の時代。原典は例として、デジタル以前のアナログ計算や機械、初期の計算機と暗号解読、PC とムーアの法則、ブラウザーや標準と分散計算、スマートフォン・SaaS・安全性とプライバシー、推薦・生成 AI などを挙げる。

1〜8 は独立した番号であり、各時代の括弧内の具体例は別の子番号ではない。原典の導入は社会と計算の相互作用、過去の成功や被害、過小評価されてきた人々への注目も説明している。これらを背景として保持し、例の列挙を時代全体の達成と同一視しない。

## 例示学習成果

CS Core 1・2：複数の文化的視点から歴史と現在・将来の関係を理解し、現在の見方が歴史で形づくられることと別の視点の存在を議論する。原典は AI が仕事を代替する／補助する見方やムーアの法則への見方を例示する。KA Core 3〜6：形成的・重大な傾向を特定、先駆者や組織の貢献を特定、重要な出来事の歴史的文脈を議論、画期的発展の前後で日常生活を比較する。原典の例にはトランジスタ、初期 OS、インターネット、Web やスマートフォンなどがある。

トピック 8 件と成果 6 件は別々に追跡する。番号・区分は候補台帳と一致する。

## 現行の冒険との区別

台帳中の番号付き依頼は旧教材の記録で、この原典照合だけでは現行の冒険からの到達・操作を確認したことにならない。現行の冒険に関する SEP-History の項目別評価は、この記録時点では未作成である。未作成は教材不存在の証明ではない。自由な議論や複数の文化的視点の理解、広い時代の分析は固定例の操作だけでは直接評価できず、代替体験と残る範囲を別途確認する。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・歴史的背景と候補台帳を照合した。これは原典範囲のレビューであり、人物の歴史的正確性や教材、ブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
