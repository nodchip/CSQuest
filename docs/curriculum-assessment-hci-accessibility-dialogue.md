# HCI-Accessibility：対話教材の項目別評価

2026-11-06に [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の KA Core 学習成果６・７と依頼1114を照合した。どちらも「部分」であり、ゲームクリアで法律の一般的理解や実際の交流技能を証明しない。

成果６について、依頼は日本の合理的配慮に関する2024年の制度変更と、本人との対話・負担を考慮する固定例を提示する。[内閣府の案内](https://www.cao.go.jp/press/new_wave/20240520.html)を照合した。他の国・分野の制度や、具体的状況の適法性は評価しない。

成果７について、鍵盤操作と文字情報を希望する２人の架空の旅人について、希望を聞き、対応を選び、試して反応を確認する。選択を誤っても再挑戦でき、選択した方法だけが唯一の配慮だとはしない。実際の当事者との交流、多様な経験、自由な会話や実機の使用は評価しない。

`tests/accessibility-dialogue.test.js` の２テストで順序違い、各候補、２場面、振り返りと記録のコピーを検査。公開版390pxの独立ブラウザで順序違いと２場面の達成、一般化の限界の表示を確認した。これは学習効果や WCAG 適合の実証ではない。
