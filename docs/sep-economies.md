# SEP-Economies: コンピューティングの経済

出典：[CS2023 印字 p.283](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf)。すべて KA Core。架空の伝令網の模型は、現実の市場の支配力や競争の結果を証明しない。

| トピック | 対応と不足 |
|---|---|
| 1 経済モデル、独占、ネットワーク効果、知識・注意の経済 | 依頼364で四人の伝令網の接続と相互運用を比較。市場支配、規制、知識や注意の経済は未対応 |
| 2 価格と提供方式：サブスクリプション、フリーミアム、ライセンス等 | 依頼269で架空のソフトウェア利用条件を比較。価格戦略の比較は未対応 |
| 3 計算資源へのアクセス差、熟練労働の需給と品質 | 依頼358で利用条件の異なる四人の申請経路を比較。労働需給と品質は未対応 |
| 4 自動化・AI と雇用、開発者、利用者への影響 | 未対応 |
| 5 注意やデータに依存する経済の倫理、同意・収集・利用規約 | 依頼194・352で架空の収集範囲を比較。注意の経済や利用規約の分析は未対応 |

| 例示学習成果 | 対応と不足 |
|---|---|
| 1 経済モデルの社会的影響をまとめる | 依頼364で四人の連絡可能性を比較。社会的影響全般は未評価 |
| 2 サブスクリプション等の提供戦略の違いと共通点 | 未対応 |
| 3 デジタル格差の事例を議論 | 依頼358で架空の利用条件を比較。実例の議論は未対応 |
| 4 自動化・AI の社会への影響 | 未対応 |
| 5 注意とデータに依存する経済の倫理的影響 | 未対応 |

依頼364では、異なる二つの網に各２人がいる場合、相互運用なしの連絡可能な組は２、ありの場合は６。全員が同じ網にいる場合も６。相互運用は人々が同じ網に移らずに連絡できる可能性を示すが、実市場における競争、費用や安全性を再現しない。[OECD の分析](https://one.oecd.org/document/DAF/COMP%282022%295/en/pdf) はネットワーク効果に対する相互運用性と移行費用の関係を検討している。
