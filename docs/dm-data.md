# DM-Data：データの役割とライフサイクル

出典: [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.115。原典のトピックは CS Core の１項目。

| トピック | 区分 | 内容と現状 |
|---|---|---|
| 1 | CS Core | 作成、処理、確認・報告、保管・検索、廃棄。依頼122では架空の２村の件数を記録・合計・報告し、保管した報告の読み出しと、必要性と保存義務がなくなった前提での削除を操作する。実データの安全な保管・削除や法令の適用は未対応 |

| 例示学習成果 | 区分 | 内容と現状 |
|---|---|---|
| 1 | CS Core | ライフサイクルの５段階の識別。依頼122で固定例の各段階を操作。一般の事例の分析や自由な説明は直接評価しない |

依頼122では北村２件と南村３件を記録し、合計５件を報告する。期間中の保管と読み出しの後、保管の必要性と法的な保存義務がない仮定の下で村別記録と報告を削除する。実際のライフサイクルは繰り返しや再利用を含み得る。
