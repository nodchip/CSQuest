# SDF-Data-Structures の対応

出典: CS2023 p.231。依頼79では同じ８つの追加・取出し操作を、待ち行列とスタックで試す。途中で追加が入り、取り出し順はそれぞれ A・B・C・D、C・D・B・A。幅優先探索の依頼08と深さ優先探索の依頼21で扱った構造にもつながる。実際のプログラム記述は直接練習・評価しない。

| CS Core トピック | 内容と状態 |
|---:|---|
| 1 | リスト、スタック、待ち行列、集合、辞書などの抽象データ型と操作。依頼79でスタックと待ち行列の追加・取出し、依頼46で有限集合の操作の固定例。依頼174で辞書の登録・取得・削除も操作。他の操作や型は未対応 |
| 2 | 適切なデータ構造の選択と利用。依頼79で順序要件、依頼527で先頭追加と末尾参照の操作数、２つの仕事の組合せを比較。一般の選択は未対応 |
| 3 | データ構造の選択による性能への影響。依頼527で固定条件の操作数を比較。実測時間・記憶量と一般の分析は未対応 |
| 4 | 文字列と文字列処理。依頼522で符号位置単位の固定文字列を走査し、重ならない一致を置換。一般の文字列処理は未対応 |

例示学習成果はすべて CS Core。1 の実言語で各データ型を使うプログラムの作成は直接評価せず、２種類の操作を固定例で体験するのみ。2・3 は依頼79・527の固定条件で比較。4 は依頼522で固定文字列の置換を操作するが、実言語の文字列処理プログラムの開発は未対応。

依頼527の追加比較では、独立した４冊の仕事を使い、各数えた操作を同じ１点と仮定する。先頭追加３回・末尾参照１回では配列16点・鎖10点、先頭追加１回・末尾参照３回では配列８点・鎖14点。各仕事を４冊の状態に準備し直す費用は含めず、点数は実時間ではない。実際の領域確保、キャッシュ、操作ごとの費用差や一般の負荷は未評価。
