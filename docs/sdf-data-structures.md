# SDF-Data-Structures の対応

出典: CS2023 p.231。依頼79では同じ８つの追加・取出し操作を、待ち行列とスタックで試す。途中で追加が入り、取り出し順はそれぞれ A・B・C・D、C・D・B・A。幅優先探索の依頼08と深さ優先探索の依頼21で扱った構造にもつながる。実際のプログラム記述は直接練習・評価しない。

| CS Core トピック | 内容と状態 |
|---:|---|
| 1 | リスト、スタック、待ち行列、集合、辞書などの抽象データ型と操作。依頼79でスタックと待ち行列の追加・取出し、依頼46で有限集合の操作の固定例。依頼174で辞書の登録・取得・削除も操作。他の操作や型は未対応 |
| 2 | 適切なデータ構造の選択と利用。依頼79で２種類の順序要件への選択のみ |
| 3 | データ構造の選択による性能への影響。未対応 |
| 4 | 文字列と文字列処理。依頼522で符号位置単位の固定文字列を走査し、重ならない一致を置換。一般の文字列処理は未対応 |

例示学習成果はすべて CS Core。1 の実言語で各データ型を使うプログラムの作成は直接評価せず、２種類の操作を固定例で体験するのみ。2 は順序要件の固定例のみ。3 の性能への影響と 4 は依頼522で固定文字列の置換を操作するが、実言語の文字列処理プログラムの開発は未対応。
