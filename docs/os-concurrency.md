## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | CS Core | OS における並行処理の利点と欠点 | 依頼53で仕事の待機中に別の仕事を進め、15で更新喪失の固定例。OS 全体での利点・欠点の評価は未対応 |
| 2 | CS Core | アーキテクチャ上の実行と競合状態との関係 | 依頼15で読み・更新・書込みの順序を操作。実際の命令・メモリ階層との関係は未対応 |
| 3 | CS Core | マルチプロセッサの並行処理の問題 | 依頼104で単一値のキャッシュ無効化の固定模型。一般的なマルチプロセッサの問題は未対応 |
| 4 | KA Core | OS の並行処理機構と各機構の利点 | 排他や待機の個別模型のみ。機構の体系的比較は未対応 |
| 5 | KA Core | OS の同期技法と原子操作 | 依頼16の鍵による排他の固定模型。原子命令やセマフォの実装は未対応 |
| 6 | KA Core | コードから競合と適切な解決策を分析 | 操作の並びを比較する固定模型のみ。実コードの分析や記述は評価しない |

依頼177は毎刻１通届き、１刻に１仕事を処理する模型。固定優先度では継続到着を仮定して修理が選ばれないことを考え、優先度上昇では時刻２の同値時に修理を選ぶ。一般のワークロードに対する飢餓の不在は証明しない。
