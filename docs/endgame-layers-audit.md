# 中継塔の荷札と通信の層

[CS2023 NC-Fundamentals、印字198〜199ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=198) の階層とカプセル化に関する簡略模型。内側の最終届け先と外側の次の区間の行き先を別の札にし、中継先で外側の札を付け替えながら２通りの道をたどる。内容や内側の届け先は模型内で維持する。札で包むことは暗号化ではないと画面に示す。

固定の道と札の模型であり、IP ヘッダーの各フィールド、TTL の変化、NAT、トンネル、実際のリンク層や一般のネットワーク設計・実装は扱わない。関連項目は部分対応である。

実装担当とは別の coverage_next が原典、各区間の札、誤操作の修正、説明、保存と開放条件を確認した。独立担当によるブラウザ操作は行っていない。`tests/endgame-layers.test.js` は札の順序・付け替え・経路と誤操作を検証し、`scripts/endgame-layers.playwright.js` は集いと４地域の達成状態を用意した記録から、誤操作、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
