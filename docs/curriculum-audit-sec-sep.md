# 分母照合：SEC-SEP

[CS2023 最終報告書 印字 pp.258–259](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=258) の SEC-SEP と[候補台帳](coverage-sec-sep.md)を 2026-11-10 に照合した。これは原典項目の範囲と区分の照合であり、教材の完成・正確性、操作と保存、独立レビューを証明しない。

## トピック

CS Core 1〜4：プライバシーの原則と実践、セキュリティやプライバシーの破綻の社会的影響、両者に関わる法律と規制の適用可能性、安全なシステムの設計・プライバシー維持に関する職業倫理と倫理的ハッキング。

KA Core 5〜8：設計段階からのセキュリティ、設計段階からのプライバシーとプライバシー工学、悪意ある AI・機械学習の主体による安全性・プライバシーへの影響、IoT やその他の新技術が社会の安全性とプライバシーに与える影響。原典は 7 の例にディープフェイクの識別を挙げる。

トピック 1〜8 はそれぞれ独立した番号であり、括弧内の具体例は別の子番号ではない。番号・区分は台帳と一致する。

## 例示学習成果

CS Core 1〜3：所与のシステムのセキュリティ破綻の影響を計算する、セキュリティ関連法に適合するシステムを構築する、プライバシー規制を適用してプライバシーを守るシステムを設計する。KA Core 4・5：適用される法令に適合しないシステムの法的影響を評価する、利用者のプライバシーへの害を避けるよう設計されたシステムを構築する。

トピック 8 件と成果 5 件は別々に追跡する。現実の法域・適用要件は状況によって異なり、原典項目の照合は特定の法的判断を与えるものではない。

## 現行の冒険との区別

台帳中の番号付き依頼は旧教材の記録で、この原典照合だけでは現行の冒険からの到達・操作を確認したことにならない。現行の冒険に関する SEC-SEP の項目別評価は、この記録時点では未作成である。未作成は教材不存在の証明ではない。実際の法令適合の判断、システムの設計・構築、自由な説明を固定例だけで直接評価したとは扱わず、代替体験と残る範囲を別途確認する。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・文脈と候補台帳を確認した。これは原典範囲のレビューであり、法的・教材の正確性や現行のブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
