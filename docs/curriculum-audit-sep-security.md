# 分母照合：SEP-Security

[CS2023 印字 pp.284–285](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=284) と[候補台帳](coverage-sep-security.md)を 2026-11-11 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core トピック 1〜6 はコンピュータ犯罪と法的救済・被害、ソーシャルエンジニアリング・詐欺・なりすましと回復、サイバーテロ・犯罪目的の侵入・ハクティビズム、マルウェア・ウイルス・ワーム、重要インフラへの攻撃、人・方針・秘密保持等の非技術的基礎。KA Core 7〜10 は現行・提案法の利点と課題、方針の変更と遵守、ライフサイクル全体の責任、国際法と地域法の交差。番号付き子はなく 10 行。

CS Core 成果 1〜5 は社会的影響のある犯罪・社会工学の例、犯罪に関する法律の課題、攻撃の動機と影響、不正アクセスや侵害の倫理・法律、専門職の役割とトレードオフ。KA Core 6〜8 は個人・組織・政府の防止や軽減策の調査、パスワードと従業員監視を含む組織方針の設計、地域を越えた法令の影響。成果 8 行はトピックと別に追跡する。原典には法域差と越境の影響があり、特定法の一般化はしない。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の SEP-Security 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実際の法的判断・方針設計・社会調査と自由な議論は固定模型だけで直接評価しない。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
