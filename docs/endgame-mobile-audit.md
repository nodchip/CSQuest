# 旅の観測帳の依頼

CS2023 SPD-Common（印字302–303ページ）と SPD-Mobile（304ページ）の固定模型。端末→受付→記録庫への要求と逆向きの返事を操作し、保存・読み取り・保存前から記録庫へ到達できない場合を比べる。すべての Web が同じ構造とはしない。

別の依頼は圏外の端末内保存、受付へ到達後の返事喪失、同じ番号での再送を扱う。受付内部は学習用に見せるが、返事を受けていない端末は結果を知らない。受付が同番号を重複排除し再送の返事は届く固定条件で、同じ値の別番号は別の観測とする。実ネットワーク一般に配送や重複排除を保証しない。

両依頼後の応用は二つの保存順で古い版の更新を拒否し、下書きを残し、読み直して自分の変更を加え直す。版比較と書込みが一体という模型上の仮定であり、同じ項目への相反する変更は人の判断が必要。CS2023 PDC-Coordination 4f と [RFC 9110 13.1.1](https://www.rfc-editor.org/rfc/rfc9110.html#section-13.1.1) の条件付き更新にも関連するが、数値版を ETag 一般と同一視しない。

独立レビューで結果と前提、達成表示を確認。版を実際に比較する関数と、内容が同じでも古い版を拒否する境界テストを追加し再確認した。`tests/endgame-mobile.test.js` と `scripts/endgame-mobile.playwright.js` は誤答・途中保存・失敗・異なる２件による開放と達成を検証する。実 API・認証・実機・一般の原子性・プライバシー・永続化を保証せず、実スクリーンリーダー音声は未検証。
