# NC-Security：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.200–201。[既存の調査](nc-security.md)と依頼を照合した。状態は[追跡方法](coverage-status.md)を参照。3 は子項目で追う。

## トピック

| 番号 | 区分 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | KA Core | 脅威、脆弱性、対策の導入 | 部分 | 180・279 は攻撃経路や通信制御の固定例。一般の脅威モデルは未評価。 |
| 2 | KA Core | ネットワーク固有の脅威・攻撃 | 部分 | 261〜263 で差し替え、改変、再送の模型。DoS、経路攻撃等と実環境は未評価。 |
| 3a | KA Core | 暗号による対策 | 部分 | 261・262 の鍵交換と認証の固定例。TLS と実暗号は未評価。 |
| 3b | KA Core | 安全なネットワークの構成 | 部分 | 274 の VLAN 転送分離。VPN、DNS、経路、ゼロトラスト等の方式と実環境は未評価。 |
| 3c | KA Core | 監視、侵入検知、ファイアウォール等 | 部分 | 279・280 の接続記録と検知しきい値。DoS 対策や実設定は未評価。 |
