依頼238では倉庫Ａ・Ｂのどちらかが動けば受付可能。共通配電盤が故障すると両方が止まる一方、別経路にはその共通盤がない。どちらの構成も、双方を止める洪水には耐えない。個々の故障確率、故障の独立性、実際の設備のリスクは所与でも算出済みでもない。

依頼239では固定期間の100件中98件以上の成功を目標とし、失敗２件を上限として５組の結果を追跡する。各組の失敗数は操作ごとに固定され、事前に示された架空の値であり、実際に予測できるとの主張ではない。期限・対象・成功の定義や業務上の影響を考えずに数値だけで運用上の安全性を判断できない。参照：[Google SRE Workbook のエラーバジェット方針の例](https://sre.google/workbook/error-budget-policy/)。

依頼240は三つの水位計の値を比べ、二つ以上が一致すればその値、すべて異なれば保留とする。実際の値３に対し、(3,3,2) は正しく３、(2,2,3) と (2,2,2) は誤って２を返し、(1,2,3) は保留する。実際の値は答え合わせとして与えられ、誤りの独立性や投票器自体の正しさは保証されない。参考：[NASA Technical Reports Server の多数決を用いた冗長構成](https://ntrs.nasa.gov/api/citations/19770006159/downloads/19770006159.pdf)。
