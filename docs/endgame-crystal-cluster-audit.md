# AI-ML：水晶を近さで分ける（部分対応）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.71–75、AI-ML 1c の教師なしクラスタリングに関連する入口。現行観測所の教師あり依頼は正解ラベル付きの札を扱う。旧依頼380 `clustering.js` は１次元２群の k-means を既に扱うため、その計算を再利用し重複を新しい範囲として二重計上しない。

水晶は１・２・８・９、各点を最も近い中心へ割り当て、同距離ならＡにする。各中心を割り当てた点の平均に更新し、変わらなくなったら止める。初期 (1,9) は (1.5,8.5)→(1.5,8.5) の２回、初期 (1,2) は (1,19/3)→(1.5,8.5)→(1.5,8.5) の３回。両例では空群が生じない。初期値で過程が変わるが、この例だけから一般に同じ結果になるとは言えない。名前のない点に距離の規則を適用する例であり、得られた群が真の種類を示す保証はない。

参考：[scikit-learn の k-means](https://scikit-learn.org/stable/modules/clustering.html#k-means)。固定した４点・２群・１次元の模型で、任意の点・空群への一般的な対応・多次元・一般の最適性や実コードは評価しない。

実装担当とは別の `review_candidate` が原典・scikit-learn、固定例の割当・平均・更新回数、各画面の前提、誤答・履歴、分類と開放、旧記録の既定値を確認した。関連11テストも成功した。一般の教師なし学習・実データを検証したものではなく、レビュー担当自身はブラウザを操作していない。

`scripts/endgame-crystal-cluster.playwright.js` は集いと４地域の達成状態を用意した検証用記録から、213・390・1200 px 幅で分類経由の到達、キーボード操作、誤答案内、途中保存・再開、段階開放と達成後の再開を確認した。新規開始からこの依頼への通し操作、実際のスクリーンリーダー音声や利用者による面白さの評価は未確認。
