# 庭園の関係と関数

[CS2023 MSF-Discrete、印字187〜188ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=187) の関係と関数に関連する例。花と届け先の関係、花から世話役への関数、それに続く道具棚への関数の合成を、それぞれ２通りの有限例で操作する。１入力に０・複数の出力がある関係や、異なる入力が同じ出力を持つ関数も扱う。

指定された対応を組み立てる具体例であり、一般の関係演算、無限集合、関数の諸性質、集合の濃度、自由な説明や証明を評価するものではない。CS2023 の関連項目は部分対応である。

実装担当と別の coverage_next が原典、対応、操作、説明、進行と保存を確認し、達成後のボタンと別の場面の不足を指摘した。２場面への拡張と表示修正を再確認した。独立担当によるブラウザ操作は行っていない。`tests/endgame-relations.test.js` は誤答、修正と有限例の正答を検証し、`scripts/endgame-relations.playwright.js` は達成状態を用意した記録から、操作、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
