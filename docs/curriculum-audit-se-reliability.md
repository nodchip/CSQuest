# 分母照合：SE-Reliability

[CS2023 最終報告書 印字 pp.250–251](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=250) の SE-Reliability と[候補台帳](coverage-se-reliability.md)を 2026-11-10 に照合した。これは原典項目の範囲と区分の照合であり、教材の完成・正確性、操作と保存、独立レビューを証明しない。

## トピック

KA Core 1〜6：故障確率・平均故障間隔と欠陥、用途別の信頼性要件、欠陥の混入を減らし試験・レビュー等で除去すること、ソフトウェアとシステムの信頼性・故障時の振る舞い、欠陥の混入と除去のサイクル、エラーバジェット方式と無誤りを目指す方式の比較と各方式が適する分野。

Non-core 7・8・8a・9〜11：信頼性モデル、障害許容技法とモデル、文脈による障害許容の違い、レビュー・試験・実用的なモデル検査等、依存・独立する故障領域の特定と信頼性への影響、テレメトリー・監視・警報・ダッシュボード・リリース判定指標などの測定に基づく分析。原典 8a は、飛行に重大な影響を与えるシステムの停止は強く避ける一方、不正なデータを書き込む前にデータ処理を停止することは有益になりうる、と例示する。

原典 8 の親文には「障害許容技法とモデル」という 8a の文脈例に還元できない固有範囲がある。このため台帳の `8-本体` と `8a` を別々に追跡する。ただし両者は同じ親項目の関連する範囲であり、原典の独立した番号の数として単純に加算しない。他の項目には番号付きの子がない。台帳行としてトピック 12 件、うち 8-本体・8a の関係を明示する。

## 例示学習成果

KA Core 1〜3：システムに必要な信頼性の決め方、非常に高い信頼性を達成する難しさ、ソフトウェアライフサイクルの各段階で欠陥を抑える方法。Non-core 4〜7：複数の方法を用いた信頼性推定、指定された信頼性に達する構成の方法、冗長化による障害許容、単一障害点の特定。

成果 7 件はトピックと別に追跡する。番号・区分は候補台帳と一致する。

## 現行の冒険との区別

台帳中の番号付き依頼は旧教材の記録で、この原典照合だけでは現行の冒険からの到達・操作を確認したことにならない。現行の冒険に関する SE-Reliability の項目別評価は、この記録時点では未作成である。未作成は教材不存在の証明ではない。現実のシステムの設計・実装、信頼性の実測や自由な説明は固定例だけで直接評価したとは扱わず、代替体験と残る範囲を別途確認する。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
