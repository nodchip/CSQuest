# 分母照合：SEC-Forensics

[CS2023 印字 pp.262–263](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=262) と[候補台帳](coverage-sec-forensics.md)を 2026-11-11 に照合した。原典の区分を明示するため台帳に KA Core 列を追加し、候補 ID の区分は「未記載」から変わる。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

すべて KA Core。トピック 1〜7 はデジタル調査の原則と方法、調査を支えるシステム設計、OS・ファイル・アプリ・Web・ネットワーク・モバイル・DB 等の調査、調査への妨害と防止、インシデント対応、証拠規則と法域差、証拠の保護・管理・保管の連鎖・報告・専門家証言。番号付き子はなく 7 行。

成果 1〜12 は調査の説明と支援ソフトの設計・実装、押収データの法的要件、取得から廃棄までの保管の連鎖、法令に従う抽出、専門家証言の責任、イメージからの検索・回復、履歴からの再構成、ネットワーク通信の取得・分析、モバイル調査の課題、ツールによる侵害調査、調査妨害の特定・軽減。12 行をトピックと別に追跡する。法域や具体的事情の異なる判断を一般化しない。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の SEC-Forensics 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実データの調査、実装、証拠手続や法的判断は固定模型だけで直接評価しない。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係、区分を補った73行と既存評価 ID への影響、候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
