# SEP-Sustainability・AR-SEP の対応

原典: CS2023 pp.109、281–282。依頼91は架空の負荷点を使い、修理案（最初20、年12）と新調案（最初80、年４）を１・５・10年、使用中のみと最初の負荷を含む２範囲で比較する。両案は同じ仕事をし、選んだ期間は故障しないと仮定する。５年の全体は80対100、10年は140対120。実測や一般的な機器の排出量ではない。廃棄、材料、寿命、電力の由来、費用、利用者への影響などは未計上として明示する。

## SEP-Sustainability トピック

| 分類・番号 | 内容と状態 |
|---|---|
| CS Core 1 | 実装判断の環境・社会・文化への影響。依頼91は架空の負荷点と集計範囲の例。社会・文化や経済への具体的な評価は未対応 |
| CS Core 2 | 機器・ソフトウェア・廃棄の地域・世界への影響。製造と利用の架空比較、廃棄などの追加情報の必要性に言及。具体的な実測・地域や供給網の評価は未対応 |
| CS Core 3 | 依頼858で ENERGY STAR の待機時間の一部を参考に架空の設定を比較。製品認証や基準全体は未評価 |
| KA Core 4–6 | 複雑な技術のシステム的影響、遍在的な計算、社会システムとの相互依存。未対応 |

例示学習成果 CS Core 2 は架空モデルにおける集計範囲・期間の比較のみ。CS Core 1・3・4 と KA Core 5–8 は未対応。実際のプロジェクトの環境影響を算定する能力や、自由な説明を直接評価しない。

## AR-SEP

Non-core トピック1と例示学習成果1のうち、依頼91は修理・製造と使用中の負荷を簡略比較する。依頼844では４個・８個の仕事を４台以下の装置に割り当て、稼働台数と仮定した設備電力を比較する。１台の容量は４個、１時間の IT 電力量は稼働１台あたり100 Whと仕事１個あたり25 Whの合計、設備全体は IT の1.5倍とする。これは仮定に基づく模型であり、実際の PUE は同じ期間の設備全体と IT 機器のエネルギーの比で、通常は年間の測定値を用いる。[米国エネルギー省の指針](https://www.energy.gov/sites/default/files/2024-07/best-practice-guide-data-center-design.pdf)を参照。仮想化のオーバーヘッド、冷却の負荷変動、冗長性、製造、水、排出量や実測は含めない。依頼858は設計基準の一部を参考に待機時の設定を比較する。プロセッサごとの実測、電子廃棄物の具体的評価、基準全体や経済的実現可能性は未対応。

依頼802は架空の利用回数と製造を含む範囲を変えて総負荷を比較する。利用増加は仮定であり、効率化による増加を実証しない。[項目別台帳](coverage-sep-sustainability.md)を参照。

依頼858は [ENERGY STAR のコンピューター基準](https://www.energystar.gov/products/computers)に記載された画面15分・本体30分以内の無操作時の設定を参考にする。架空の本体30 W・画面10 W・スリープ２ W、瞬時復帰と操作自体の消費０を仮定し、60分連続と20分後に操作してさらに40分の２条件を比較。両方眠らない場合はいずれも40 Wh、画面15分・本体30分では18.5 Whと約30.333 Wh。表示は小数第３位まで。設定は基準の一部にすぎず、実際の製品種別ごとの要件、消費電力、電源効率や認証を評価するものではない。復帰待ち、実測、製造・廃棄、排出量も扱わない。
