# 工房から旅立つ体験版：学習内容の根拠

2026-11-06 確認。一次資料は ACM・IEEE-CS・AAAI の [Computer Science Curricula 2023 最終報告書（ACM 公開 HTML）](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)。ユーザー指定の IEEE-CS 版 PDF は取得がタイムアウトしたため、ACM 公開版を参照した。SDF-Fundamentals は命令の実行による状態遷移・制御の流れ、条件・反復、実行の追跡、試験とデバッグを挙げ、SDF-Practices はテストケース設計とテストの限界を挙げる。HTML の章名は SDF-Fundamentals / SDF-Practices で検索できる。

| 依頼 | 操作と確認した説明 | CS2023 との関係と範囲 |
| --- | --- | --- |
| 工房の灯り | 前進のお願いを順番に並べ、実行結果を見直す | SDF-Fundamentals の制御の流れ・状態遷移の入門例。プログラミング言語全般や変数は扱わない。 |
| 森の薬草 | 前進と向きの変更の順序を組み合わせる | 同じく制御の流れ。右を向く操作自体は進まず、壁や地図の外には進めない。 |
| 木立の道しるべ | 前に壁があるときだけ向きを変える | SDF-Fundamentals の条件付き実行の限定例。壁がない場合は向きを変えない。 |
| 水路の灯り | １枚で前進を２回実行する操作を使う | SDF-Fundamentals の反復の入門例。回数は２回固定であり、一般的なループ構文や終了条件を網羅しない。 |
| 水辺の道 | 同じ並びを２つの地図で実行し、両方の到達を確かめる | 条件付き実行と SDF-Practices のテストケースの導入。２例で成功しても、あらゆる状況で正しい証明にはならない。 |

各説明を `src/engine.js` の命令・壁・到達判定、および `src/workshop-journey-data.js` の説明と照合した。`tests/workshop-journey.test.js` は新しい３依頼の正解・失敗と水辺の片方だけ成功する例を確認する。これは CS2023 の学習成果全体の達成、実際のプログラミング言語での作成能力、教材の大学水準の深さを証明しない。ユーザー方針により本体験版ではコード・数式・文章を入力する演習を設けない。
