# NC-Fundamentals：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.198。[既存の調査](nc-fundamentals.md)と依頼を照合した。状態は[追跡方法](coverage-status.md)を参照。

## トピック

| 番号 | 区分 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | CS Core | 現代の計算におけるネットワークの重要性と課題 | 部分 | 10・62 は消失や再送の例。社会的課題や重要性全般は未評価。 |
| 2 | CS Core | インターネットの組織 | 部分 | 517 で接続事業者、相互接続、中継と複製を操作。実事業者と一般の構造は未評価。 |
| 3 | CS Core | 回線交換とパケット交換 | 部分 | 272・516 で蓄積転送と共有・予約を比較。実回線の確立や一般の遅延は未評価。 |
| 4 | CS Core | アプリケーションから物理までの層と役割 | 部分 | 78 は２区間の封を操作。各層のプロトコルや役割全般は未評価。 |
| 5 | CS Core | カプセル化と砂時計型等の階層原則 | 部分 | 78 の封と 558 の共通 IP 層。一般の階層設計と実装は未評価。 |
| 6 | CS Core | ルータ・スイッチ・ハブ・アクセスポイント・ホスト | 部分 | 556 はハブ・スイッチ・ルータの固定転送。アクセスポイントと実機の詳細は未評価。 |
| 7 | CS Core | 待ち行列と遅延・輻輳・サービス水準 | 部分 | 271 は固定容量の到着と損失。実ネットワークやサービス水準全般は未評価。 |
