# 原典との範囲照合：HCI-Accessibility

[CS2023 印字 pp.177–178](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の HCI-Accessibility を [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)と照合した。トピック１〜５は CS Core、６〜９は KA Core、10〜13は Non-core。欠けていた親９行と成果９の親１行を追加し、親子28トピック行・12成果行とした。親子は重複するため、行数は独立項目数や完成率ではない。

原典１bはアクセシブルな設計の広い利益を挙げるが、特定の変更がすべての人に必ず利益をもたらすと判断しない。国際的観点・態度・障害学、歴史的偏りの具体例と教訓などは未照合を維持する。実際の交流技能は評価していない。成果７は原典の不自然な英文を踏まえ、多様な人との適切な交流技能として追跡し、固定例から実際の技能を証明しない。

成果６は依頼1114の日本の合理的配慮と対話の固定例を部分対応に加えた。根拠である [内閣府の2024年の案内](https://www.cao.go.jp/press/new_wave/20240520.html)と表示内容を照合した。他の国・分野の制度、個々の事情への法的適用や実際の交流は評価しない。これは原典の範囲と区分の照合であり、全教材の完成・実利用者による検証・学習効果を証明しない。

依頼1114の２場面を成果７の部分対応にも記録した。本人の希望を聞き選択と反応を確認する固定の代替体験であり、実際の人との交流や多様な経験への一般化を評価したものではない。
