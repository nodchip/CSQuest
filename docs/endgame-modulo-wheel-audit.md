# MSF-Discrete：５つの灯りと合同（部分対応）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.187–188、MSF-Discrete 5a の合同算術に関連する固定例。現行の文庫のハッシュは非負の余りを扱う。旧依頼405 `modular-wheels.js` は法５・７の非負の足し算と掛け算を既に扱うため関連と重複を記録し、範囲を二重計上しない。今回は負の数を含む５の輪の位置と足し算を扱う。

輪は０〜４の５位置。進む歩数を整数 n とし、n＝５q＋r、０≦r＜５となる代表 r を使う。８＝５×１＋３、−２＝５×(−１)＋３なのでどちらも位置３。さらに４進むとそれぞれ合計12と２で、どちらも位置２。負の数を含むこの定義と、言語によって異なる剰余演算子の符号を混同しない。[MIT の合同算術](https://ocw.mit.edu/courses/6-1200j-mathematics-for-computer-science-spring-2024/mit6_1200j_s24_lec09.pdf)を参考にする。

法５と固定された数・加算のみの模型。一般の法、掛け算・割り算、合同の一般的証明、任意のプログラム・自由な説明は評価しない。
