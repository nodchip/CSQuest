# 集いの後：谷の発送札

原典：[CS2023 最終報告書](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印刷ページ118 の DM-Querying。準備済みの荷物の選択、届け先番号による二つの表の結合、地名による選択、札番号の射影を、三つの有限の例で操作します。該当する札がない例も含みます。

この依頼は問い合わせの考え方の一部を練習するもので、実際の SQL 作成・実行や、和・共通・差・除算、入れ子の問い合わせなどの学習成果を満たすものではありません。ゲーム上の「結合」は、この依頼に示した番号の一致を用いる内部結合の例です。

物語の一区切りと南の四地域それぞれ二件の後に谷から到達できます。三つの結果 A・E・該当なし、番号の一致と学習範囲は別担当が独立レビューしました。390・1,200 px のブラウザで誤った選択・結合、途中保存と復帰、三場面の達成を、進行済みの検証用記録で確認しました。プレイヤー本人の楽しさの評価や公開後の確認は含みません。
