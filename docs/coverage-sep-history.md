# SEP-History：計算の歴史の項目別対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.282–283。[既存調査](sep-history.md)と依頼・検査を照合。状態は[追跡方法](coverage-status.md)に従い、「未照合」は未実装の証拠ではない。「部分」は関連する固定例を示し、項目全体の修得を意味しない。実際の社会調査・法的判断・自由な説明や文章作成は固定例だけでは直接評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | CS Core | ハードウェア・ソフトウェア・人や組織の歴史 | 部分 | 依頼363で解析機関の注記、ENIAC を準備した女性たち、CERN での Web 提案を時系列で扱う。歴史全体は未対応 |
| 2 | CS Core | 現在・異なる社会的文脈・将来における歴史の役割 | 部分 | 依頼363で人々の仕事と組織の目的に触れる。複数の社会的文脈と現在・将来への影響の比較は未対応 |
| 3 | KA Core | デジタル以前 | 部分 | 依頼363で1843年の解析機関の注記を紹介。他の古代・機械式・理論史は未対応 |
| 4 | KA Core | 初期の現代計算機 | 部分 | 依頼363で1945年の ENIAC の仕事を紹介。他の機械・組織・文脈は未対応 |
| 5 | KA Core | PC の時代 | 未照合 | 対応例を要照合。 |
| 6 | KA Core | インターネットの時代 | 部分 | 依頼363で1989年の Web 提案を紹介。ネットワーク、標準、ブラウザーなどの発展は未対応 |
| 7 | KA Core | モバイル・クラウドの時代 | 未照合 | 対応例を要照合。 |
| 8 | KA Core | AI の時代 | 部分 | 依頼363で1955・1980・2012・2017年の４つの文献を扱う。多様な研究系統や社会的文脈を含む時代全体は未対応 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 代替と限界 |
|---|---|---|---|---|
| 1 | CS Core | 歴史と現在・将来を複数の文化的視点から理解 | 部分 | 依頼363は三つの出来事と人々の役割のみ。複数文化・現在と将来への関係は未対応 |
| 2 | CS Core | 現在の見方が歴史から形作られることや異なる視点を議論 | 部分 | 依頼1305で ENIAC の設計とプログラミングに焦点を当てた資料を比べ、物語に含める貢献を選ぶ固定例。複数文化や自由な議論は未評価 |
| 3 | KA Core | 歴史上の形成的・重大な傾向を特定 | 部分 | 依頼363で三時点を並べる固定例。傾向の一般的な分析は未対応 |
| 4 | KA Core | 先駆者・組織の貢献を特定 | 部分 | 依頼363でラブレス、ENIAC に関わる女性たち、CERN の Web 提案、498でジョンソン、ハミルトン、チューリングの資料を紹介。他の貢献者は未対応 |
| 5 | KA Core | 重要な出来事の歴史的文脈を議論 | 部分 | 依頼363で研究者間の情報共有という Web の目的に触れる。広い文脈の議論は未対応 |
| 6 | KA Core | 大きな発展の前後の日常生活の比較 | 部分 | 依頼1306で紙の目録とリンクによる研究記録の探索を架空の模型で比較。日常生活全体や地域による違いは未対応 |

各依頼の前提・出典と検証、実際の状況に一般化できない範囲は[既存調査](sep-history.md)を参照する。
