# 分母照合：SE-Teamwork

[CS2023 印字 pp.240–241](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=240) と[候補台帳](coverage-se-teamwork.md)を 2026-11-10 に照合した。原典との範囲照合であり教材の完成・内容・操作・独立レビューの検証ではない。

CS Core トピックは 1・2、3a〜3c、4-本体・4a・4b、5・6：公式・非公式の効果的な伝達、対立と解決、ペア作業・群作業、コードレビュー、版管理を通じた協働、チームの役割と責任、協働の利点とリスク、仕事の分担・見積り・会議・予定、多様性と包摂。原典の 3 は協働プログラミングの見出しとして子を追跡する。4 は役割と責任という子の利点・リスクだけでは尽くせない固有範囲を含むため 4-本体 として保持し、4a・4b と別記する。ただし親子を独立した原典番号として単純合算しない。KA Core 7a〜7c・8 は、管理者と非技術チーム・顧客・利用者との連携と、対面・分散・ハイブリッド・仮想チームのリスク、緩和と回復である。7 は子をまとめる見出し。台帳のトピック 14 行について番号・区分を照合した。

CS Core 成果 1〜8 は、チームでの伝達、対立の原因・危険・利益、対立解決と問題解決、協働開発、役割・責任の提案と分担、会議の議題、プロジェクトを通して健全なチーム文化を築き、チーム形成と運営の計画を作成・実行すること、多様性と包摂の重要性と利点の促進。原典の成果 2 は人を侮辱せずに考えや提案について意見を異にする価値を強調する。KA Core 9・10 は技術・非技術の関係者との連携、および異なる勤務形態に伴うリスク・失敗箇所・緩和と回復を挙げること。成果 10 行をトピックと別に追跡する。

番号付き依頼は旧教材の記録であり、現行冒険への到達を意味しない。現行冒険の SE-Teamwork の項目別評価は記録時点で未作成。未作成は教材不存在の証明ではない。実際の協働・チーム運営・会議・自由な説明は固定例だけで評価しない。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
