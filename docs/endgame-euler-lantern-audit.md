# 育つ灯火とオイラー法：教材監査

[CS2023 MSF-Calculus 印字192–194頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=192) 成果7bの初期値問題へのオイラー法の固定例。旧 `src/euler-growth.js` の依頼475を再利用して観測所に接続する。現行の差商・積分の依頼はそれぞれ別の微積分の固定例を扱う。

初期値 y(0)=1、微分方程式 y′=y。前進オイラー法では各歩の初めの y を傾きとして y←y+h y。時刻０から１まで h=1 で１歩は２、h=0.5 で２歩は2.25、h=0.25 で４歩は2.44140625。厳密解 y=eᵗ の t=1 は e≈2.71828 であり、いずれも有限歩の近似。この例では４分割が最も厳密値に近いが、任意の方程式で刻み幅を小さくすれば常に単調改善する、または安定するとは主張しない。

固定された１変数の式と３刻みのみで、任意の微分方程式・長時間の安定性・数値丸め・誤差評価の証明・自由な実装は未評価。[オイラー法の更新式](https://math.libretexts.org/Bookshelves/Differential_Equations/Differential_Equations_%28Chasnov%29/03%3A_First-Order_ODEs/3.01%3A_The_Euler_Method) を参照。
