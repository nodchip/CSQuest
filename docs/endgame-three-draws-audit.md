# 三回の灯りと二項分布：教材監査

[CS2023 MSF-Probability 印字188–189頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=188) の離散分布と有限事象の固定例。旧教材の依頼651・653は分布の定義や二項分布の条件を扱い、現行の確率・警報の依頼は有限の事象や条件付き確率を扱う。今回、確率が偏った独立３回の順序付き結果と異なる重みを明示して事象ごとに足す。

各回は独立、赤１/４・青３/４で一定。赤の数０・１・２・３に応じ各並びの重みは分母64で27・９・３・１。８通りの重みは 27,9,9,3,9,3,3,1 で合計64。赤ちょうど１回は３×９＝27/64、２回は３×３＝９/64、少なくとも１回は残りの37/64。８つの並びは等確率ではない。

３回・固定確率の有限模型であり、任意の n,p、独立性の実証、実測、一般の二項分布・期待値や自由な計算は未評価。[Penn State の二項分布](https://online.stat.psu.edu/stat504/Lesson01) を参照。
