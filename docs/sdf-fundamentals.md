# SDF-Fundamentals の対応状況

出典: [CS2023, Software Development Fundamentals, SDF-Fundamentals](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 230–231。下記は原典を要約した作業用一覧。すべて CS Core。項目の一部をゲームで扱っても、原典の学習成果全体を達成したとはみなさない。

## トピック

| 番号 | トピックの要約 | 現状 |
|---:|---|---|
| 1 | 変数、基本型、式と評価 | 未着手 |
| 2 | 命令実行による状態遷移と制御の流れ | 試作：精霊の位置・向きの変化と実行記録。変数や一般的なプログラムの状態は未対応 |
| 3 | 代入、条件分岐、繰り返し、入出力 | 試作：壁による分岐と固定２回の繰り返し。代入、一般的な反復、入出力は未対応 |
| 4 | 関数などの部品化、引数、スコープ、抽象化、カプセル化 | 未着手 |
| 5 | ファイルや API による入出力 | 未着手 |
| 6 | 配列や連想コンテナなどの構造化データと使い分け | 未着手 |
| 7 | ライブラリとフレームワーク | 未着手 |
| 8 | 再帰 | 未着手 |
| 9 | 実行時エラーへの対処 | 未着手 |
| 10 | エラー、テスト、デバッグ | 試作：命令列を複数の道で試して結果を確認する。体系的なテスト設計・デバッグは未対応 |
| 11 | プログラムとモジュールの文書化 | 未着手 |
| 12 | セキュリティを考える姿勢 | 未着手 |

## 学習成果

| 番号 | 成果の要約 | 現状と限界 |

| 1 | 代入、式、入出力、条件、反復を使うプログラムの開発 | 条件と固定２回の反復をゲーム内操作で部分体験。実言語での設計・記述・テスト・デバッグは直接練習しない |
| 2 | 引数を伴う関数を使うプログラムの開発 | 未着手 |
| 3 | 構造化データを効果的に使うプログラムの開発 | 未着手 |
| 4 | ファイル入出力によるデータ永続化 | 未着手 |
| 5 | ライブラリやフレームワークを用いる開発 | 未着手 |
| 6 | API によるデータへのアクセス・更新 | 未着手 |
| 7 | クラスとインスタンスを使う開発 | 未着手 |
| 8 | 再帰と適切な利用の説明 | 未着手 |
| 9 | 再帰関数の開発 | 未着手 |

| 14 | 識別子・演算子・オペランドなどを用語で識別する | 未着手 |

「試作」は動作する初期の題材があるという意味であり、深さ、十分な問題数、学習効果、原典の成果との同等性を確認したものではない。
