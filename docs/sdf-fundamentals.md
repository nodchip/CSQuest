# SDF-Fundamentals の対応状況

出典: [CS2023, Software Development Fundamentals, SDF-Fundamentals](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 230–231。下記は原典を要約した作業用一覧。すべて CS Core。項目の一部をゲームで扱っても、原典の学習成果全体を達成したとはみなさない。

## トピック

| 番号 | トピックの要約 | 現状 |
|---:|---|---|
| 1 | 変数、基本型、式と評価 | 依頼197・198で箱への数値の代入と加算の固定模型。基本型や一般的な式の評価は未対応 |
| 2 | 命令実行による状態遷移と制御の流れ | 初期依頼の精霊の状態と、依頼198で反復中の位置・数の変化を追跡。一般的なプログラムの状態は未対応 |
| 3 | 代入、条件分岐、繰り返し、入出力 | 依頼197・198で数値の代入、条件と列の反復の固定模型。一般的なプログラムや入出力は未対応 |
| 4 | 関数などの部品化、引数、スコープ、抽象化、カプセル化 | 依頼199で数値の引数・戻り値と別々のローカルな箱、依頼52で値を覚える封印の固定模型。一般的な部品化や実言語は未対応 |
| 5 | ファイルや API による入出力 | 未着手 |
| 6 | 配列や連想コンテナなどの構造化データと使い分け | 依頼198で固定された数値の列を先頭から走査。一般の構造や使い分けは未対応 |
| 7 | ライブラリとフレームワーク | 未着手 |
| 8 | 再帰 | 試作：依頼33で並べ方を数える小さな問題の呼び出し、停止、戻りを操作。一般の再帰関数の開発は未対応 |
| 9 | 実行時エラーへの対処 | 未着手 |
| 10 | エラー、テスト、デバッグ | 試作：命令列を複数の道で試して結果を確認する。体系的なテスト設計・デバッグは未対応 |
| 11 | プログラムとモジュールの文書化 | 未着手 |
| 12 | セキュリティを考える姿勢 | 未着手 |

「試作」は動作する初期の題材があるという意味であり、深さ、十分な問題数、学習効果、原典の成果との同等性を確認したものではない。

依頼33は異なる３個と４個の並べ方を数える固定例。０個の１通りを基底とし、一つ少ない問題の答えに個数を掛けて戻る。実言語での記述、一般の停止性や正しさの証明は評価しない。
