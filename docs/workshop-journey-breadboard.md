# 工房から旅立つ冒険：操作の設計と実装単位

[選択した方針](workshop-journey-shaping.md) に対する提案。P1–P5 の基本部分は `workshop-preview.html` / `src/workshop-preview.js` に既存。森への出会いと薬草の依頼も存在するが、３件の選択と地域間移動は未実装。以下の N は既存関数名の主張ではなく、必要な処理を示す。

## Places

| ID | 場所 | プレイヤーができること |
| --- | --- | --- |
| P1 | タイトル・設定 | 始める、続きから、文字とコントラストの設定 |
| P2 | 導入 | 世界と工房、人物を知り、最初の依頼を受ける |
| P3 | 工房周辺 | 達成状況、少数の依頼・人物、条件成立後の旅立ちを見て選ぶ |
| P4 | 出会い | 人物と依頼の背景・目的を知り、受けるか戻る |
| P5 | 依頼 | 目標と必要情報を読み、操作・試行・修正・ヒントを見る |
| P6 | 達成ダイアログ | 達成を知り、記録を見直すか依頼の結果へ進む。背後の操作は不可 |
| P7 | 結果 | 人物の反応・CS の説明を読み、工房周辺または旅先へ戻る |
| P8 | 地域移動 | 移動先を明示して選び、移動または現在地に戻る |
| P9 | 旅先 | 風景・人物・世界の手がかりに出会い、依頼、帰路を選ぶ |

## 記録

| ID | 記録 | 内容・読み手 |
| --- | --- | --- |
| S1 | 体験版の冒険記録 | 現在地・場面、初回達成、依頼の途中操作、選択結果 → N1、N3–N7 |
| S2 | 体験版の表示設定 | 文字サイズ、コントラスト → N2 |
| S3 | 依頼と物語の定義 | 人物、説明、目標、条件、CS 対応、移動先 → N3、N5 |

既存本編の保存を消去しない。旧体験版の移行は任意。記録の破損・保存不能時は、既存記録を勝手に消さず、再開できない場合はその旨を示す。達成ダイアログから記録へ戻る際は操作位置を分かるようにする。

## 実装単位

| 単位 | 見せられる成果 | 主な接続 |
| --- | --- | --- |
| V1 | 導入と最初の依頼から工房周辺へ進み、依頼を選び、達成・再開できる | P1–P7、U1–U7、N1–N6、S1–S3 |
| V2 | 異なる３件以上から選べ、同じ依頼の再達成を数えず、２件達成後に旅立ちを選べる | P3–P8、U3–U8、N3–N6、S1、S3 |
| V3 | 旅先の出会いと依頼を終え、工房へ戻って残った依頼を遊べる | P3–P9、U3–U9、N3–N7、S1、S3 |
| V4 | 体験版全体を検証し、既存トップを保って別ページに公開、公開 URL で一連の旅を確認する | P1–P9、U1–U9、N1–N7、S1–S3 |

各単位は動作確認用であり、公開は V4 にまとめる。面白さの最終判断は実際のプレイヤーの感想を待つ。
