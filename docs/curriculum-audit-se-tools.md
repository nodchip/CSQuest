# 分母照合：SE-Tools

[CS2023 印字 pp.241–242](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=241) と[候補台帳](coverage-se-tools.md)を 2026-11-10 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core 1a〜1c は構成管理と再現可能なビルド、開発・リリース分岐とトランク、マージとリベース。KA Core 2・3 はリリース管理と静的・動的試験ツール、4a〜4c はビルドシステム、CI、依存関係管理、5〜7 は設計・意思疎通の道具、ツール統合、IDE のデバッグ・リファクタリング・検索・機械学習を用いた補助等。原典の 1・4 は共通の構成管理・プロセス自動化を表す親で、子に文脈を保持し親子を重複して数えない。11 台帳行の番号・区分を確認した。

CS Core 成果 1〜3 は集中型と分散型の構成管理の違い、リリース管理への版管理、チームでの構成項目と版管理ツールの利用。KA Core 4〜7 は静的・動的試験ツールの環境への統合、共有コードの状態を把握する CI、要件・設計・実装・ビルド・試験に用いるツールの選択、中規模製品の開発でのツール利用。7 行をトピックと別に追跡する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の項目別評価には文庫の版と統合の限定例があるが、実ツール・再現可能なビルド・実チームや自由な説明の評価を示さない。各現行項目の正確性・到達・操作・保存・独立レビューは別途確認する。

2026-11-10、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
