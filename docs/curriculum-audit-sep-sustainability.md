# 分母照合：SEP-Sustainability

[CS2023 印字 pp.281–282](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=281) と[候補台帳](coverage-sep-sustainability.md)を 2026-11-11 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core トピック 1〜3 は実装判断の環境・社会・文化への影響、計算機の製造・使用・廃棄による地域・世界の社会と環境への影響、持続可能な設計標準の指針。KA Core 4〜6 は複雑な技術のシステム的影響、日常に組み込まれた情報処理と持続可能性、利用者の技能・組織・政策等の社会システムとソフトウェアの相互依存。番号付き子はない。6 行を追跡する。

CS Core 成果 1〜4 は特定分野・企画で持続可能に行動する方法、導入の環境影響、利用と廃棄の世界的影響、現代の活動による影響。KA Core 5〜8 は設計選択の環境影響、新システムの社会・環境影響、持続可能な設計・導入の指針作成、計算の応用の環境面での評価。8 行をトピックと別に追跡する。原典は環境・公平性・経済の関係も文脈に含める。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の SEP-Sustainability 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実際の環境・社会の測定や自由な影響評価は固定模型だけで直接評価しない。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。 これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
