# 番号以上の最初の札：教材監査

[CS2023 AL-Foundational 印字88–90頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=88) の二分探索の固定例。旧依頼29と現行 `endgame-complexity.js` は整列済みの異なる番号の存在探索を扱う。今回は重複と不在時に、目標以上の最初の位置を探す。

列は [1,2,2,2,4,6]。半開区間 [lo,hi) を初め [0,6) とし、中央 floor((lo+hi)/2) が目標未満なら lo=中央+1、そうでなければ hi=中央。常に lo より前は目標未満、hi 以降は目標以上。２・３・７の答えは０始まりで１・４・６。６は末尾の挿入位置で、札の添字ではない。等値でも左側に最初の等値がある可能性がある。

固定列と３目標の操作であり、任意入力・未整列列・並行更新・一般の不変条件の証明・実行時間は未評価。位置を探す費用と挿入時に要素を移動する費用は別であり、挿入の高速性を主張しない。[Python bisect_left の公式仕様](https://docs.python.org/3/library/bisect.html) を参照。
