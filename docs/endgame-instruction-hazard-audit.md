# 命令の重なり：教材監査

- 対応：CS2023 AR-Organization の成果 1・3（報告書印字 106 ページ）に関する入口。旧教材 `src/instruction-pipeline.js` の固定模型を現行冒険で操作する。従来の鍛冶街の命令教材は順番の実行が中心で、読み取りの依存による待機と転送は扱っていない。
- 参考：CMU 講義資料 [Instruction Level Parallelism](https://www.cs.cmu.edu/~418/lectures/02_ilp.pdf) はデータ依存と結果の転送による待機の削減を扱う。
- 固定模型：取出し・解読・実行の３段。赤と青の初期値は０。命令１は赤に２、命令２は赤＋１を青に書く。解読の読取りは刻の始め、実行結果の書込みは刻の終わり。転送だけは同じ刻の命令１の結果２を次の命令２の実行へ直接渡す。
- 対策なしは４刻・青１、１刻待機は５刻・青３、転送は４刻・青３。これらは選んだ固定例の結果であり、実 CPU の構造や性能一般を表さない。
- 制限：構造・制御ハザード、複数の待機、実機のレジスタ・命令セット、一般のパイプライン設計、任意のコードの実行や説明は未評価。旧教材があることや本教材の完了をもって成果の全体を達成済みとはしない。

2026-11-11、実装担当と別の `signed_review` が原典と [Cornell のパイプライン講義](https://www.cs.cornell.edu/courses/cs3410/2018fa/schedule/slides/06-pipeline-bw.pdf) に照らし、固定規則・各方式の推移・画面・保存・開放を独立レビューした。初回レビューで段階表示が常に空となる不一致を発見し、各刻の段階を記録してテストした後に独立再レビューを受けた。親担当が修正後、準備済み記録から幅 213・390・1200 px の鍛冶街の分類に到達し、誤答、キーボード、途中保存・再開、開放条件、達成後の保存をブラウザ確認した。新規開始からの通し操作、スクリーンリーダー音声、利用者による面白さは未確認。
