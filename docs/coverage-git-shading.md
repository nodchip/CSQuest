# GIT-Shading：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.159–160。全トピックと成果は KA Core。[追跡方法](coverage-status.md)に従い、親と子を重複して完成率に数えない。固定模型は実際のレンダラーの制作・性能を評価しない。
