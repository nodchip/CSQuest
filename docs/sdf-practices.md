# SDF-Practices の対応状況

出典: [CS2023, Software Development Fundamentals, SDF-Practices](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p. 232。原典を要約した作業用一覧。ゲーム内の操作は実際の開発環境や文章作成の能力を評価しない。

## トピック

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | CS Core | テストケース設計を含む基本的なテスト | 依頼23で境界を含む試験の選択、198で４つの列を試す固定例。実際のモジュールのテスト作成は未対応 |
| 2 | CS Core | 汎用 IDE とデバッガの利用 | 依頼198で反復の状態を追う固定模型。実際の IDE とデバッガは未対応 |
| 3 | CS Core | 読みやすさを高めるプログラミングスタイル | 未着手 |
| 4 | CS Core | モジュールの機能を自然言語で仕様化 | 未着手 |
