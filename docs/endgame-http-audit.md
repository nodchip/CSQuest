# 塔の記録の要求と応答

[CS2023 NC-Applications（印字199ページ）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の CS Core 2・4 と学習成果 3 に関係する固定模型。依頼者と受付の要求・応答を、道、GET／HEAD、状態、ヘッダー、本文に分けて操作する。登録済みの２つの道には 200、未登録の道には 404 を返す。GET 404 に説明本文を付け、HEAD は本文を送らない。違う記録を返した架空の応答も、登録表と照らして調べ直す。

[RFC 9110 の GET・HEAD・状態コード](https://www.rfc-editor.org/rfc/rfc9110.html) に照らし、HEAD の一部のヘッダーは実際には省略されうること、404 は永久的な不存在の証明ではないことを説明する。実通信、動的な内容、認証、TLS、中継、リダイレクト、任意の HTTP サーバーや自由な説明は未評価であり、該当項目は部分対応である。

実装担当と別の coverage_next が原典、RFC、説明、要求と応答の判定、誤った結果からの修正、保存と開放をコード上で独立確認した。独立担当自身は実ブラウザーを操作していない。`tests/endgame-http.test.js` は応答、状態、本文と宛先の一致、比較、診断を検証する。`scripts/endgame-http.playwright.js` は物語と４地域の達成状態を用意した別ブラウザー記録から、誤答、途中保存、再挑戦、段階の開放、達成を確認する。実際のスクリーンリーダー音声は未確認。
