# OS-Faults：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.214–215。[追跡方法](coverage-status.md)に従い、９トピックと５例示学習成果を記録する。固定模型は実機の耐障害性・復旧を保証しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | KA Core | 信頼性と可用性 | 部分 | 108で同じ稼働割合の２記録と連続航海を比較。一般の指標・実システムは未評価。 |
| 2 | KA Core | 耐障害性へのソフト・ハード両面の手法、RAID | 部分 | 229でミラー・パリティの装置故障と復元。実装や故障の一般的なモデルは未評価。 |
| 3 | Non-core | 空間・時間の冗長性 | 部分 | 229で複製、10で消失後の再送を別々に体験。OS による体系的な比較は未評価。 |
| 4 | Non-core | 障害耐性の実現方法 | 部分 | 181の写し、736のジャーナル、752の装置再試行の固定例。一般の方式や OS 全体は未評価。 |
| 5 | Non-core | 誤り検出・訂正、RAM の検査 | 部分 | 106・107で符号による検出・訂正。実際の RAM の検査や制御は未評価。 |
| 6 | Non-core | ファイルシステムの整合性検査と復旧 | 部分 | 736・743で確定記録による復旧。一般の整合性検査や実装は未評価。 |
| 7 | Non-core | ジャーナリングとログ構造ファイルシステム | 部分 | 736で確定記録の再適用、737・738で有効記録の移動と復旧点を操作。実装や一般の復旧は未評価。 |
| 8 | Non-core | データベース・安全重視システムでの利用 | 部分 | 136で単一送金の復旧、395で遮蔽時の停止を別々に体験。安全重視システム全般での障害耐性は未評価。 |
| 9 | Non-core | OS の検出・復旧・再起動と OS 自身のサービスへの利用 | 部分 | 752で装置の期限切れ後の再試行、759で進捗監視と再起動開始。再起動後の復旧や OS 全体は未評価。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | KA Core | OS が信頼性・可用性・障害耐性を支援する方法を説明 | 部分 | 736・752で記録再適用と装置復旧の例。OS 全体や自由記述は未評価。 |
| 2 | KA Core | OS の障害耐性の幅広い実現方法を説明 | 部分 | 181・229・736・752で複製・復元・記録・再試行の固定例。体系的な説明は未評価。 |
| 3 | KA Core | 障害後に OS が動作を継続する方法を説明 | 部分 | 736で保存済み記録による復旧、752で装置の復旧または失敗報告。OS サービス継続全般は未評価。 |
| 4 | KA Core | 障害耐性と性能・柔軟性の兼ね合いを説明 | 未照合 | OS の障害耐性による性能・柔軟性を比較する教材は未確認。 |
| 5 | Non-core | OS の障害耐性の課題と機構を詳述 | 部分 | 736・752で特定の記録・再試行を操作。実 OS の詳細と自由記述は未評価。 |

依頼108・229・136の前提と検査は [SF-Reliability](coverage-sf-reliability.md)、依頼736–738・743は [OS-Advanced-Files](coverage-os-advanced-files.md)、依頼752は [OS-Devices](coverage-os-devices.md) を参照。各例のテストは限定された模型の状態・判定を検査し、実機の障害耐性や一般の方法の習得を証明しない。
