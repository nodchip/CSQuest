# DM-Relational の対応状況

出典: [CS2023, DM-Relational](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 117–118。原典を要約した作業用一覧。依頼67は一つの関係の固定例であり、一般の正規化や無損失性の証明ではない。

## トピック

| 番号 | 分類 | 要約 | 現状 |
|---:|---|---|---|
| 1 | CS Core | 実体・参照整合性、候補キー、スーパーキー | 依頼67の村番号と依頼101の組のキー・外部キーの固定例。制約やキーの体系的な検証は未対応 |
| 2 | CS Core | 関係データベースの設計 | 重複と分割を固定例で比較。一般的な設計は未対応 |
| 3 | KA Core | 概念スキーマから関係スキーマへの対応 | 依頼101で参加関係の固定例を比較。一般の変換は未対応 |
| 4 | KA Core | ファイルと保存構造を含む物理設計 | 未着手 |
| 5 | KA Core | 関数従属性の基礎 | 村番号に対し村名が一つという条件を使う例。理論は未対応 |
| 6 | KA Core | 分解、無損失結合、依存性保存、正規形、非正規化 | 依頼67で固定例の分解・結合と余分な行を比較。一般の証明、依存性保存、正規形や非正規化は未対応 |
| 7 | Non-core | 属性閉包と正準被覆 | 未着手 |
| 8 | Non-core | 多値・結合従属性、４NF・５NF、表現理論 | 未着手 |
