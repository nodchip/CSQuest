依頼269は１ファイルのソースを改変して配布する固定例で、MIT と GPL-3.0 の表示、変更の明示、改変作品全体の許諾を比較する。全条件やライセンスの組合せを評価しない。参考：[MIT 原文](https://spdx.org/licenses/MIT.html)、[GPL-3.0 原文](https://www.gnu.org/licenses/gpl-3.0.html) §§4–5。

依頼270は学術的な表示を扱う４つの架空の事例。引用と言換えの双方に出典が必要な場合、合意した共同執筆者の表示、既に出典を示した引用を比較する。出典表示のみで利用許諾が得られるわけではなく、共同執筆の基準や法的条件の一般的判断は扱わない。参考：[Harvard Guide to Using Sources](https://usingsources.fas.harvard.edu/what-constitutes-plagiarism-0)。
