# 分母照合：MSF-Statistics

[CS2023 最終報告書 印字 pp.190–191](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=190) と[候補台帳](coverage-msf-statistics.md)を 2026-11-11 に照合した。これは原典範囲の照合であり、教材の完成を示さない。

## トピック

CS Core 1〜2 は母集団・標本と記述統計、一変量の推定と信頼区間。KA Core 3〜6 は多変量の推定と相関・回帰、次元削減・平滑化、統計モデルとアルゴリズム、仮説検定。6行はそれぞれ原典の番号に対応する。

## 例示学習成果

CS Core 1a〜1d、2a〜2d、KA Core の独立した3、4a〜4f、5a〜5d、6a〜6eの計24項目。3は標本抽出・偏り・十分性および頻度主義とベイズの解釈。4は多変量の推定と回帰、5はPCAや回帰の幾何、6は次元削減・回帰・過学習と交差検証を含む。4〜6は子の見出しであり子と重複して数えない。

**成果番号とトピック番号は機械的に対応しない。** 成果3は標本抽出、成果4・5・6はそれぞれトピック3・4・5に概ね関連し、トピック6の仮説検定に独立した番号の成果は列挙されていない。番号・区分は台帳と一致する。

## 現行の冒険と残る確認

旧台帳の依頼は旧教材の記録であり、この照合によって現行の冒険から到達できるとは判定しない。現行冒険の項目別評価には一部の固定例があるが、その部分対応を原典全体の完成とみなさない。教材の正確性、実際の到達、操作・保存、独立レビュー、および操作で直接評価できない能力は別途確認する。範囲ハッシュは候補 ID と台帳要約の変更検出であり、内容の正しさや教材完成の証明ではない。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
