# 原典との範囲照合：HCI-Design

[CS2023 印字 pp.179–181](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)を照合した。トピック１〜３は CS Core、４〜７は KA Core、８〜12は Non-core。欠けていた親８行と成果２の親を追加し、親子41トピック行・12成果行とした。親子は重複するため行数を独立項目数や完成率としない。

創造性を支援する道具は未照合。空間音響８bは依頼933の左右ステレオ模型で部分対応とした。アーキテクチャの４aは依頼92の MVC 模型、成果４は同依頼の架空の作業点比較で部分対応とした。４bは依頼1030の対応状況と代替表示の模型で部分対応とした。ハードウェア設計６eは依頼1298の入力・制御・出力の固定模型で部分対応とした。コントローラ６cと触覚６dは依頼1298の操作器模型で部分対応とした。部分対応も固定例に限られる。原典の範囲・区分の照合であり、教材の正確性、自由な設計能力、実利用者による評価や全教材の完成を証明しない。
