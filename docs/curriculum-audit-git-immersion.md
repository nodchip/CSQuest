# 原典との範囲照合：GIT-Immersion

[CS2023 印字 pp.161–162](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)を照合した。全トピックと成果は KA Core であり、台帳の各行にも区分を追記した。原典の親４・５・６・11を追加し、親子・補助行を含む22トピック行・成果８行とした。従来の５-本体・６-本体はそれぞれ親の内容を独立に追跡する補助行であり、原典の独立した子番号ではない。親子や補助行が重複するため、行数を独立項目数や完成率としない。

没入とプレゼンスの違い、詳細度と三角形数の比較、現実の障害物への対応は依頼1179の固定例として部分対応。頭・体・手の追跡、分岐映像、応用や酔いなどは未照合。追跡方式や分散 VR の既存模型は実機や利用者の体験を評価しない。実アプリや医療向け仕様の作成、実利用者を交えたアクセシビリティ評価も未評価。

この範囲照合は教材の正確性、学習成果の達成、全教材の完成を証明しない。
