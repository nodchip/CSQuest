# 分母照合：SEP-Ethical-Analysis

[CS2023 印字 pp.274–276](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=274) と[候補台帳](coverage-sep-ethical-analysis.md)を 2026-11-10 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core 1〜4 は誤謬・誤った表現を避ける議論、倫理理論と意思決定、文化の役割、倫理と法・社会規範の関係。KA Core 5〜9 は専門的チェックリスト、評価ルーブリック、関係者分析、立場性の理論、複数の倫理枠組みとジレンマへの適用。原典の例には結果主義、義務・権利・正義、徳・フェミニズム、契約、ケアがある。原典の導入は、単一の倫理理論が全ての文脈に最適とは限らず、脱植民地・先住民・歴史的に周縁化された立場も可能な限り含める必要を述べる。トピック 9 行に番号付き子はない。

CS Core 成果 1〜6 は文化と意思決定、例と類推、誤謬の分析と回避、前提と結論、倫理と文化・価値・法、倫理的根拠による正当化。KA Core 7〜10 は文化的背景を含む関係者の立場、技術的決定における倫理的負債、従来の枠組みの長所・短所、複数の枠組みを用いたジレンマの分析。成果 10 行をトピックと別に追跡する。
