# 原典との範囲照合：SF-SEP

[CS2023 印字 pp.297–298（PDF 297〜298ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-sf-sep.md)を2026-11-05に照合した。トピック１〜３と例示学習成果１〜３はすべて KA Core。台帳の各行に区分を明記した。トピック３行、成果３行。

項目の範囲と区分の照合であり、教材の正確性や学習成果の達成を検証したものではない。知的財産権とコンピュータ犯罪は教材対応を未確認とし、ライセンスの固定例の範囲や自由な列挙は別途評価が必要。
