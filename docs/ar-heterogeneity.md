# AR-Heterogeneity: 異種アーキテクチャ

参照：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) p.107。依頼162は４つの仕事を同時に扱える模型で、SIMD の共有命令と MIMD の独立した命令を比べます。マスクされた仕事はその回に動かさず残せます。回数は模型内の操作回数で、実機の性能測定ではありません。

| 2 異種メモリ、共有と分散、揮発性、一貫性 | 依頼104で写しの無効化の模型。異種メモリ全体は未対応 |
