# AR-Heterogeneity: 異種アーキテクチャ

参照：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) p.107。依頼162は４つの仕事を同時に扱える模型で、SIMD の共有命令と MIMD の独立した命令を比べます。マスクされた仕事はその回に動かさず残せます。依頼163は専用機械への運搬・準備の固定費用を含めて、小さな仕事と大きな仕事を比べます。いずれも架空の模型で、実機の性能測定ではありません。

| KA Core トピック | 対応と不足 |
| --- | --- |
| 1 SIMD・MIMD と GPU・TPU・NPU 等 | 依頼162で SIMD・MIMD、872で SIMT 分岐の固定例。各実機の構成と一般の比較は未対応 |
| 2 異種メモリ、共有と分散、揮発性、一貫性 | 依頼104で写しの無効化の模型。異種メモリ全体は未対応 |
| 3 機械学習・ネットワーク・組込み・ニューロモーフィック・エッジ等の専用構成 | 依頼163は専用機械への運搬・準備費用の一般的な模型。各分野の専用構成は未対応 |
| 4 3D 集積・チップレット | 未対応 |
| 5 構成設計における機械学習 | 未対応 |

| KA Core 例示学習成果 | 対応と不足 |
| --- | --- |
| 1 並列構成図から SIMD と MIMD の違いを分析 | 依頼162で同じ・異なる命令の固定例を操作。一般の構成図の分析は未対応 |
| 2 マルチプロセッサ固有のメモリ管理と対策 | 依頼104は一貫性の一例。一般のメモリ管理は未対応 |
| 3 異なるメモリ接続と遅延・性能への影響 | 未対応 |
| 4 専用アクセラレータと汎用 CPU の使い分け | 依頼163で架空の固定費用と仕事量を比較。実機の性能、電力、転送の重なりや準備の再利用は未対応 |
| 5 ベクトルとスカラの設計の違い | 依頼162は複数のデータに命令を適用する例。実際の設計原理の比較は未対応 |
| 6 PIM の利点と欠点 | 未対応 |

依頼872は太陽４・月４の仕事を４人ずつの２組に配置する。各分岐は１命令、組ごとに異なる分岐を順に実行し、対象外の人は待つと仮定する。両組に２種類ずつ混ざると合計４回・待機８枠、種類ごとに分けると２回・待機０枠で、各仕事の結果は同じ。70通りの分岐配置を検査した。[NVIDIA の SIMT 説明](https://docs.nvidia.com/cuda/cuda-programming-guide/01-introduction/programming-model.html)は CUDA の32スレッドのワープと分岐を扱う。これは４レーンの固定模型で、実機の命令・独立スケジューリング、再編成やメモリの費用、実行時間は測定しない。
