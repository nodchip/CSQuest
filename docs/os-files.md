# OS-Files の対応

出典: CS2023 p.212。依頼77は Linux 系の単純化した通常ファイルを対象に、二つの名前が同じファイルを指す場合、片方の名前の削除、開いたまま最後の名前を削除した後の読取り、最後の参照を閉じる操作を扱う。根拠: Linux man-pages の [link(2)](https://man7.org/linux/man-pages/man2/link.2.html) と [unlink(2)](https://man7.org/linux/man-pages/man2/unlink.2.html)。特定ファイルシステムの全動作を再現するものではない。

## トピック

| 分類・番号 | 内容と状態 |
|---|---|
| KA Core 1 | ファイルのデータ、メタデータ、操作、アクセスモード。名前・内容・開く・読む・閉じる・リンクを部分的に体験。メタデータやモードは未対応 |
| KA Core 2 | マウント。未対応 |
| KA Core 3 | ファイルのアクセス制御。未対応 |
| KA Core 4 | ファイル共有。複数名が同じ実体を指す限定例。複数利用者は未対応 |
| KA Core 5 | ファイル割当て方式と連結割当て表。未対応 |
| KA Core 6 | ファイル割当て、ディレクトリ構造と識別。単一ディレクトリの２名が同じ実体を指す固定例。割当てや一般の識別方式は未対応 |
| KA Core 7 | 割当て・解放と性能、断片化・圧縮。未対応 |
| KA Core 8 | 空き領域の管理方式。未対応 |
| KA Core 9 | ディレクトリの実装と位置管理。名前と実体の関係の固定例のみ。実装は未対応 |

## 例示学習成果

KA Core 1–3（ファイルシステム設計の選択、組織方式の長短評価、実装知識に基づくソフトウェア構成の適用）は未対応。依頼77は操作の意味を体験する一例であり、実 OS の API を使う能力を評価しない。
