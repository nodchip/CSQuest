# 鍛冶街の灯りの計数器

[CS2023 AR-Representation、印字103ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=103) の整数表現を４ビットの模型で扱う。８・４・２・１の灯りで数を作り、同じ並びを符号なしと２の補数で読み分ける。基礎２件の達成後は同じ下４ビットの加算結果、５桁目への繰り上がり、２の補数の範囲外を区別する。

４ビットの固定例であり、他の幅、符号・絶対値方式、固定小数点や浮動小数点、自由な説明は未対応。該当項目は部分対応である。ゲーム内では５桁目を捨てる模型と符号なし０〜15、２の補数−８〜７の範囲を明示する。

実装担当と別の coverage_next が原典・算術・操作・保存・進行を確認し、依頼内の説明とキーボードのフォーカスを指摘した。修正後に再確認し、全256入力組の加算を別の符号ビット条件で照合した。独立担当自身によるブラウザ操作は行っていない。`tests/endgame-integers.test.js` は境界と繰り上がり・符号付きの範囲外を、`scripts/endgame-integers.playwright.js` は集いと４地域の達成状態を用意した記録からの操作、誤答、途中復元、解放と達成を確認する。実際のスクリーンリーダー音声は未検証。
