# MSF-Calculus の対応状況

原典: [CS2023 MSF-Calculus](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.192–194。すべて KA Core。固定例の操作は、一般の微積分の計算や自由な説明を評価しない。

| 2 | 一変数の導関数、計算法と応用。依頼473で二次関数の平均速度の極限から瞬間速度を求める固定例。一般の微分規則や証明は未対応 |

| 5 | テイラー級数。依頼476で指数関数を４次まで近似。一般の級数と誤差評価は未対応 |

| 8 | 常微分方程式、オイラー法と応用。依頼475で y′=y の初期値問題を３刻み幅で操作。一般の方程式と安定性は未対応 |
| 9 | 機械学習の勾配降下など CS への応用。依頼116で１データの誤差を最小化する固定例。一般の学習や多変数は未対応 |

依頼116では入力１に対する記録２の予測誤差を (w−2)² とし、導関数 2(w−2) の反対方向に学習率を掛けて進む。w=0 から学習率0.25では 1、1.5、1.75、1.875 に進み、学習率１では４と０を往復する。導関数を対称差分で照合し、両経路と誤操作をテストした。誤差の曲線はこの固定モデルであり、一般の学習率や実データへの保証ではない。

依頼473は位置 s(t)=t² の t=2 において h=1、0.5、0.1、−0.5、−0.1 の平均速度を操作し、差商 4+h の極限４を確認する。数値を独立に差商と照合した。一般の極限の存在証明、微分規則や実測値は扱わない。[OpenStax の導関数](https://openstax.org/books/calculus-volume-1/pages/3-1-defining-the-derivative)を参照。

依頼474は速度 v(t)=2t の０〜２秒を１・２・４分割し、左右端による長方形を積み重ねる。合計はそれぞれ 4−4/n と 4+4/n で、極限４は依頼473の位置 t² の変化と一致する。全６方式の各段階を検査した。一般の積分規則や負の速度の距離は扱わない。[OpenStax の微積分の基本定理](https://openstax.org/books/calculus-volume-1/pages/5-3-the-fundamental-theorem-of-calculus)を参照。

依頼475は初期値 y(0)=1、変化率 y′=y を前進オイラー法で１秒まで追う。１・２・４分割の近似は２、2.25、2.44140625で、厳密値 e≈2.71828 と比較する。各段階を閉形式 (1+1/n)^k と照合した。一般の微分方程式、収束証明や安定性解析は扱わない。[OpenStax のオイラー法](https://openstax.org/books/calculus-volume-2/pages/4-2-direction-fields-and-numerical-methods)を参照。

依頼476は e^t の０周りの項を４次まで重ね、t=1 と t=2 で厳密値との差を比較する。各項を独立に階乗から照合し、４次の和 65/24 と 7 を検査した。一般の関数・中心、収束範囲と剰余の証明は扱わない。[OpenStax のテイラー級数](https://openstax.org/books/calculus-volume-2/pages/6-3-taylor-and-maclaurin-series)を参照。

依頼477は f(x,y)=(x−1)²+(y−2)² を (3,3) から学習率0.25で３歩進む。各点の偏微分を対称差分と照合し、誤差は５、1.25、0.3125、0.078125。二次関数では幅0.5の対称差分が偏微分に一致する。一般には有限幅の差分は近似である。一般の関数・制約付き最適化は未対応。[OpenStax の勾配](https://openstax.org/books/calculus-volume-3/pages/4-6-directional-derivatives-and-the-gradient)を参照。

依頼478は固定半径２の円で角度０、π/２、π、３π/２、２πに対応する直交座標を選ぶ。x=2 cos θ、y=2 sin θ と５点を照合し、０と２πの位置が同じことを確認する。負の半径、一般の曲線や媒介変数の微分は未対応。[OpenStax の極座標](https://openstax.org/books/calculus-volume-3/pages/1-3-polar-coordinates)を参照。

依頼479は f(x,y)=(x−1)²+(y−2)² を x,y≥0、x+y=2 の下で最小化する。候補を比較し、制約のない最小点 (1,2) は使えないことを確認する。y=2−x の代入で f=2(x−0.5)²+0.5 となり、連続範囲の最小点は (0.5,1.5)。候補と平方完成を検査した。一般の制約付き問題は扱わない。[OpenStax の制約付き最適化](https://openstax.org/books/calculus-volume-3/pages/4-8-lagrange-multipliers)を参照。

依頼473の追加場面は時刻２で横２・縦３、両辺が１秒に１ずつ伸びる長方形。時間幅１と0.1に対して面積増分を右の帯・上の帯・角に分け、平均変化率６と5.1を比較する。幅を０に近づけると角の寄与が消え、瞬間の面積変化率は３＋２＝５。積の微分の固定例であり、一般の関数の証明や商の規則は未評価。[OpenStax の微分規則](https://openstax.org/books/calculus-volume-1/pages/3-3-differentiation-rules)を参照。
