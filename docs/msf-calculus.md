# MSF-Calculus の対応状況

原典: [CS2023 MSF-Calculus](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.192–194。すべて KA Core。固定例の操作は、一般の微積分の計算や自由な説明を評価しない。

| 番号 | 内容と現状 |
|---|---|
| 1 | 数列・級数・極限。依頼116で小さい学習率の数列が２へ近づく４歩の例。一般の極限や級数は未対応 |
| 2 | 一変数の導関数、計算法と応用。依頼473で二次関数の平均速度の極限から瞬間速度を求める固定例。一般の微分規則や証明は未対応 |
| 3 | 一変数の積分。依頼474で速度の長方形近似と基本定理の固定例。一般の積分規則は未対応 |
| 4–5 | 媒介変数・極座標、テイラー級数。未対応 |
| 6 | 多変数微積分、偏微分と勾配。未対応 |
| 7 | 凸性、極小値、勾配降下、制約付き最適化。依頼116で一変数二次関数と２つの学習率の固定例。一般の凸性や制約は未対応 |
| 8 | 常微分方程式、オイラー法と応用。依頼475で y′=y の初期値問題を３刻み幅で操作。一般の方程式と安定性は未対応 |
| 9 | 機械学習の勾配降下など CS への応用。依頼116で１データの誤差を最小化する固定例。一般の学習や多変数は未対応 |

| 例示学習成果 | 内容と現状 |

| 2a–e | 導関数の定義、関数としての微分、計算規則。依頼473で二次関数の２秒における差商の両側の極限を操作。一般の計算規則は未対応 |
| 3a–d | 積分の定義、規則、基本定理と応用。依頼474で速度の積分と位置変化の固定例。一般の計算規則や証明は未対応 |
| 4a–b | 媒介変数と極座標による曲線。未対応 |

| 7a–c | オイラー法による積分と微分方程式。依頼475で固定の初期値問題を近似。一般の解法や誤差解析は未対応 |

依頼116では入力１に対する記録２の予測誤差を (w−2)² とし、導関数 2(w−2) の反対方向に学習率を掛けて進む。w=0 から学習率0.25では 1、1.5、1.75、1.875 に進み、学習率１では４と０を往復する。導関数を対称差分で照合し、両経路と誤操作をテストした。誤差の曲線はこの固定モデルであり、一般の学習率や実データへの保証ではない。

依頼473は位置 s(t)=t² の t=2 において h=1、0.5、0.1、−0.5、−0.1 の平均速度を操作し、差商 4+h の極限４を確認する。数値を独立に差商と照合した。一般の極限の存在証明、微分規則や実測値は扱わない。[OpenStax の導関数](https://openstax.org/books/calculus-volume-1/pages/3-1-defining-the-derivative)を参照。

依頼474は速度 v(t)=2t の０〜２秒を１・２・４分割し、左右端による長方形を積み重ねる。合計はそれぞれ 4−4/n と 4+4/n で、極限４は依頼473の位置 t² の変化と一致する。全６方式の各段階を検査した。一般の積分規則や負の速度の距離は扱わない。[OpenStax の微積分の基本定理](https://openstax.org/books/calculus-volume-1/pages/5-3-the-fundamental-theorem-of-calculus)を参照。

依頼475は初期値 y(0)=1、変化率 y′=y を前進オイラー法で１秒まで追う。１・２・４分割の近似は２、2.25、2.44140625で、厳密値 e≈2.71828 と比較する。各段階を閉形式 (1+1/n)^k と照合した。一般の微分方程式、収束証明や安定性解析は扱わない。[OpenStax のオイラー法](https://openstax.org/books/calculus-volume-2/pages/4-2-direction-fields-and-numerical-methods)を参照。
