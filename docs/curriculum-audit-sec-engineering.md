# 分母照合：SEC-Engineering

[CS2023 印字 pp.261–262](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=261) と[候補台帳](coverage-sec-engineering.md)を 2026-11-11 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core トピック 1〜4 は誤り・事故・攻撃に耐えるシステム、プライバシー機能と制御、状況分析、時間・費用・リスク等のトレードオフ。KA Core 5〜11 は要件・保護・試験・評価を含む安全な設計、要求・対策・脅威・脆弱性の分析、通信・物理・社会・ソフトウェア・供給網等の攻撃面、認証悪用・盗聴・偽装・改変等の攻撃手法、製品の仕様と適応性に対する構成証明、サイバーフィジカル系の設計・開発、信頼の基点・署名・仮想化等の信頼できる計算環境。番号付き子はなく 11 行。

CS Core 成果 1〜3 は脅威モデルの作成、状況分析と安全な解決策、性能・リスク・費用の比較。KA Core 4〜7 は対策の設計と評価、脆弱性の特定・軽減、データ科学・AI 等の創発的な振る舞いの評価・予測。成果 7 行を別に追跡する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の SEC-Engineering 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実環境での脅威評価、設計・実装・検証や一般的な保証は固定模型だけで直接評価しない。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
