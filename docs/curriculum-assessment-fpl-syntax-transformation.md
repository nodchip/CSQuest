# 項目別評価：FPL-Syntax の文法変換

2026-11-05 に [CS2023 印字 p. 141](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の FPL-Syntax トピック６c と依頼1299の実装・試験を照合した。原典の項目は文法変換であり、判定は**部分対応**。この一項目の照合は、構文解析全体の完成を意味しない。

## 内容と範囲

依頼では `E → E + a | a` と `E → a R`、`R → + a R | 空` をそれぞれ操作し、３つの指定文字列を作って構文木を比較する。前者は `E → E + a` を k 回使ってから `E → a` とし、後者は `E → a R`、`R → + a R` を k 回、`R → 空` の順に使うと、いずれも `a` の後に `+ a` が k 回続く。両者の構文木は異なる。直接左再帰の除去に関する [Stanford の講義資料](https://web.stanford.edu/class/archive/cs/cs143/cs143.1156/handouts/parsing.pdf) と照合した。

追加の別例では `(8 − 3) − 2 = 3` と `8 − (3 − 2) = 7` を比較する。同じ文字列の受理と意味の保存は別に考える必要がある。これは上の `a` と `+` の文法をそのまま評価したものではない。追加比較は依頼の達成条件ではなく、クリアだけでは比較を行ったと判断できない。

## 検証と限界

`tests/left-recursion.test.js` で４文字列の導出、木の葉、操作制限、達成条件、旧形式と新形式の復元を確認した。`scripts/left-recursion-smoke.playwright.js` はローカル配信用ビルドの390・1280px幅で６導出と達成、達成後の追加比較の再開、誤答・正答、キーボード操作、別の依頼1265の操作を確認した。前回の公開版でも追加比較と途中復元を確認している。

指定の規則を適用する体験であり、任意の左再帰や間接左再帰の除去、一般の文法変換、意味保存の証明、解析器の実装や自由な説明は評価しない。有限の試験や表示上の操作だけで学習効果は証明できない。

依頼1299の追加実験では、入力 `a+a` に対して、もとの規則で常に再帰側を先に選ぶ単純な上からの解析と、変換後に先読みで規則を選ぶ解析を６手ずつ比較する。前者は入力を読まず `E` が処理待ちの先頭に残り、後者は入力を読み終えて受理する。各手順を `parserTrace` と `tests/left-recursion.test.js` で検査。固定した規則選択の例であり、左再帰に対応する他の解析方式を否定しない。追加実験は達成必須ではない。
