# 関所の名前検索：範囲と未完了

[CS2023 印字 259 ページ（PDF 259 ページ目）SEC-Coding](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の CS Core 2 は SQL インジェクションを含む。[SQLite の公式 API 解説](https://www.sqlite.org/cintro.html)は、準備した文に値を束縛する仕組みを説明する。[OWASP の解説](https://community.owasp.org/attacks/SQL_Injection)は、外部からの値を命令と混ぜることによる問題と対策を扱う。

旧 `injection.js` は現行冒険への到達を示さない。関所の既存依頼は本人確認・権限と複数入口、塔は暗号を扱い、今回の固定例はそれらと別に名前の等値検索を扱う。通常の名前、正当な引用符を含む名前、条件を変える文字列を、無加工の連結と値の束縛で比較する。引用符そのものを悪意と決めつけない。束縛した条件変更の文字列は、名簿中に同じ名前がないため該当なしとなる。

画面は固定例のシミュレーションであり、実際の DB 接続や自由入力は行わない。値用のパラメータは表名・列名など任意の構文を束縛するものではなく、本人確認・認可・アプリケーション全体の安全性を保証しない。一般の SQL・入力形式・他の注入・実コードの評価や修正、自由な説明は未評価であり、関連項目は部分対応である。

`gate-injection-concat` と `gate-injection-bound` の２件を終えると `gate-injection-choose` が開く。関所の依頼分類から選び、地図の全達成判定にも含まれる。

実装担当とは別の `review_candidate` が原典、上記資料と [SQLite の値の束縛](https://www.sqlite.org/c3ref/bind_blob.html)、画面の固定例と同じ検索文の一時 SQLite における結果、説明、分類と保存をコード上で確認した。実アプリ全体の安全性や実コードの評価・修正を確認したものではない。レビュー担当自身はブラウザを操作していない。

`tests/endgame-injection.test.js` は一時メモリ SQLite で画面と同じ等値検索の雛形・固定値を実行し、連結時の構文エラーと条件変更、束縛時の正当な引用符と空結果を独立照合する。SQL の行順は仮定せず集合として比較する。`tests/tower-gate-quest-groups.test.js` は分類と開放を確認する。`scripts/endgame-injection.playwright.js` は集いと４地域などの達成を用意した検証用記録から、213・390・1200 px 幅で分類からの到達、キーボードによる依頼と回答、誤答の案内、途中復元、段階開放、３依頼の達成と達成後の再開を確認した。新規開始からこの依頼群までの通し操作、実際のスクリーンリーダー音声、利用者による面白さの評価は未確認。
