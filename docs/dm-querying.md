# DM-Querying の対応状況

出典: [CS2023, Data Management, DM-Querying](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p. 118。原典を要約した作業用一覧。条件による行の絞り込みは問い合わせ全体の一部にすぎない。

## トピック

| 番号 | 分類 | 要約 | 現状 |
|---:|---|---|---|
| 1 | CS Core | SQL の問い合わせ作成、対話・プログラムからの実行 | 試作：複数条件を満たす行の選択と等しい値による内部結合・左外部結合の固定例をゲーム内操作で扱う。SQL を書く・実行する操作は行わない |
| 2 | KA Core | 関係代数 | 行の選択と内部結合の例のみ。関係代数全体は未対応 |
| 3 | KA Core | SQL によるデータ定義、整合性制約、更新 | 未着手 |
| 4 | Non-core | 関係論理 | 未着手 |
| 5 | Non-core | QBE と第４世代環境 | 未着手 |
| 6 | Non-core | 通常の言語からの非手続き問い合わせの呼び出し | 未着手 |
| 7 | Non-core | XPath、SPARQL などの問い合わせ言語 | 未着手 |
| 8 | Non-core | ストアドプロシージャ | 未着手 |

## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | CS Core | 選択・射影・結合・集合演算・除算を含む SQL の作成 | 条件による行の選択と内部・左外部結合の固定例のみ。SQL 記述や他の演算は未対応 |
| 2 | CS Core | 入れ子の問い合わせの相関の有無を判断 | 未着手 |
| 3 | CS Core | プログラムから取得結果を反復処理 | 未着手 |
| 4 | KA Core | 制約やトリガを含むスキーマの SQL 定義 | 未着手 |
| 5 | KA Core | 組を更新する SQL の作成 | 未着手 |

薬師の依頼は固定された台帳を対象に、条件をすべて満たす行の選択と、共通の番号による内部結合を扱う。実際の SQL やデータベースを利用する能力を直接練習・評価するものではない。

依頼124は左の薬草に月草・星花、右の棚に月草２行・火花１行を置く。内部結合は月草の２行、左外部結合はそれに星花の棚なし１行を加える。右側だけの火花は出力しない。SQL の記述、NULL を含む条件式、一般の結合は扱わない。
