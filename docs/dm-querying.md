## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | CS Core | 選択・射影・結合・集合演算・除算を含む SQL の作成 | 条件による行の選択、内部・左外部結合、和・共通部分・差集合と全称条件の固定例のみ。SQL 記述や一般の問い合わせは未対応 |
| 2 | CS Core | 入れ子の問い合わせの相関の有無を判断 | 依頼462で外側の村を参照する存在判定と参照しない存在判定を比較。一般の SQL の判断は未対応 |

薬師の依頼は固定された台帳を対象に、条件をすべて満たす行の選択と、共通の番号による内部結合を扱う。実際の SQL やデータベースを利用する能力を直接練習・評価するものではない。

依頼124は左の薬草に月草・星花、右の棚に月草２行・火花１行を置く。内部結合は月草の２行、左外部結合はそれに星花の棚なし１行を加える。右側だけの火花は出力しない。SQL の記述、NULL を含む条件式、一般の結合は扱わない。

依頼125は１列の名簿 [アオ, ベニ, ベニ] と [ベニ, クロ] を対象とする。重複を除いた和は各１行、UNION ALL に対応する操作は１・３・１行、重複を除いた共通部分はベニ１行、差はアオ１行。NULL や複数列、SQL 文の作成は扱わない。

依頼126は、別に与えられた４人の候補のうち必要な印をすべて持つ人を選ぶ。太陽・月を持つアオと、さらに星を持つクロが２条件を満たす。必要な印が空なら、印を持たない人を含む候補全員が条件を満たす。候補集合の設定が重要で、SQL の記述や一般の除算実装は未対応。

依頼462は森・川・山の村について、配達先 [森,森,山] または空の台帳を調べる。内側が外側の村を参照する存在判定では森・山、参照しない存在判定では全３村となり、空の場合はどちらも０行。重複した配達は村を重複させない。空・重複を含む３行以下の台帳を検査した。[PostgreSQL の EXISTS](https://www.postgresql.org/docs/current/functions-subquery.html)を参照。NULL、実行計画、実際の SQL 作成は扱わない。
