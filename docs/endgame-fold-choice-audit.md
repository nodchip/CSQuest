# 記録を入れ替えて予測を調べる：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字71〜75頁の AI-ML 13d・13d.i（交差検証と選択）に関連する固定例。旧依頼551 `src/iris-cross-validation.js` は実データを使う４分割であり、今回は現行の観測所で固定の架空成績を使う３分割の手順を操作する。
- [scikit-learn の交差検証](https://scikit-learn.org/stable/modules/cross_validation.html) と[情報漏洩の注意](https://scikit-learn.org/stable/common_pitfalls.html) は各回の学習・検証と、方法の選択に使わない別のテストを説明する。各回の学習で得る前処理はその回の学習部分から決める。
- 開発３組と別テスト１組は各３件。各回は別々に残る２組で学習し１組で検証する。学習組同士は回をまたいで重なる。固定の正解数はＡが２・３・１で６／９、Ｂが３・２・３で８／９。等サイズなので正解率の単純平均と合計正解数／９が一致する。Ｂを選び、開発９件で学習した模型の別テストは２／３と仮定する。
- 固定表は実際の学習や実データの評価ではない。分割方法や乱数・独立性・偏り、少数テストによる不確実性、実 API、自由な実装・実験計画、一般の汎化性能を評価せず、テスト結果を使う方法選択もしない。旧教材や本教材をもって原典全体の完成とはしない。
