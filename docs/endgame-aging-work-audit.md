# OS-Scheduling：待つ仕事の優先度

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.209–210、OS-Scheduling 5 の公平性と飢餓。旧依頼177 `src/starvation.js` の５刻の模型を現行の駅に再利用するため、旧教材と独立した範囲として重複計上しない。現行の先着・交代や優先度付きキューは、待機に応じた優先度の変化をこの例では扱わない。

開始時に修理１件と手紙０通。各刻の開始時に手紙１通が到着し、手紙１通または修理１件を処理する。手紙の優先度３、修理の初期値１、同順位は修理。上昇方式では各刻の選択後に修理が未完了なら１上がる。固定方式は手紙を５回選び、修理は５刻では未完了、残り０通。上昇方式は手紙・手紙・修理・手紙・手紙の順で３刻目に修理が完了し、手紙１通が残る。[Cornell のスケジューリング講義資料](https://www.cs.cornell.edu/courses/cs4410/2019sp/schedule/slides/Lecture13.pdf) は優先度と待機に応じた調整を紹介する。

５刻の固定到着・所要時間・同順位規則であり、無限に待ち続けることや一般の公平性を証明しない。実 OS の優先度・処理時間・測定や他の到着条件、一般のスケジューラ設計も評価しない。OS-Scheduling 全体の完成を示さない。
