# 原典との範囲照合：GIT-Physical

[CS2023 印字 pp.164–165](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)を照合した。全トピックと例示学習成果は KA Core。原典の親トピック１・２・２c・３と成果５を追加し、全行に区分を記した。親子14トピック行・成果12行で、親と子は重複するため、行数を独立項目数や完成率としない。

成果１の一部として依頼1298のボタン・制御部・灯りの固定模型を確認した。押すと点灯、離すと消灯するが、電源・配線は仮定であり、実回路の設計・製作を評価しない。成果４は依頼219の可変抵抗の３位置と読み取り・目標の固定例として部分対応。成果５は CAD での３次元形状の作成そのものが未評価のため未照合とした。CAM、物理的な試作、無線接続や実製作なども未照合。

この範囲照合は個々の教材の正確性や全教材の完成を証明しない。

成果５cに関連して、依頼807で仮定した段取りと１個あたりの費用・時間を積算する操作を追加した。実際の製作計画や CAD の作成は未評価のため、成果５全体は引き続き未照合とする。

成果５dについては、依頼807の仮想事例で費用・時間の予定と結果の差を比較する。実物の製作と検証は未評価である。
