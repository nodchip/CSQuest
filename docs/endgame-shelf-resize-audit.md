# 大きくした棚と再配置：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字88〜89頁 AL-Foundational 7a（ハッシュ表と衝突処理）に関連する固定例。現行の文庫の線形探索と削除の教材に加え、旧依頼1342 `src/hash-resize-workshop.js` の拡張・探索を現行冒険に接続した。
- [Oracle の HashMap 説明](https://docs.oracle.com/javase/8/docs/api/java/util/HashMap.html) は容量増加時に内部構造を再構築することを説明する。ここでは番号 mod 棚数と線形探索を使う独自の模型であり、Java HashMap の内部と同一ではない。
- 旧３棚は１番に１、２番に４。７棚に同じ番号のまま写し７を０番へ入れると [7,1,4,空,空,空,空] となる。４の探索は 4 mod 7 = 4 から始まり空で止まるため、２番に４が残っていても見逃す。７で再計算し入れ直すと [7,1,空,空,4,空,空] となり４番で見つかる。
- 空きで打ち切る規則は削除済み印がなく、新規則に従い正しく挿入した表を前提とする。単純な写しはその前提を壊す。満杯時の１周・削除済み印、他のハッシュ関数・一般のサイズ、拡張中の並行更新、実装・性能は評価しない。旧教材・本教材の存在を原典全体の完成とはしない。
