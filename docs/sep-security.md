# SEP-Security: セキュリティ方針・法・コンピュータ犯罪

出典：[CS2023 印字 pp.284–285](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf)。架空の伝令の固定例は、実際の詐欺の全件判別、被害回復、個別の法的判断を保証しない。

| CS Core 2 ソーシャルエンジニアリング、詐欺、なりすましと回復 | 依頼365で合言葉を求める偽の伝令と正規の連絡を別経路で確認。実際の被害回復は未対応 |

依頼365の偽の伝令は一度きりの合言葉を要求し、以前から知っている書庫窓口は送信を否定する。もう一通は窓口が予定を確認する。急ぎの表現だけで偽物と断定せず、伝令中の連絡先・添付を使わない設定で確かめる。[米 FTC の案内](https://consumer.ftc.gov/articles/how-recognize-avoid-phishing-scams) は、予期しない連絡について既知の連絡方法で確認することを勧めている。特定の窓口や対応があらゆる状況で安全という保証ではない。
