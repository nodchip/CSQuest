# 鍛冶街の灯り道具とオブジェクト

[CS2023 FPL-OOP、印字130〜131ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=130) のオブジェクトの状態・振る舞い・情報隠蔽に関連する模型。同じ設計の２つの道具が個別の残量を持ち、公開操作の充電・消費で変化する。０での消費、３での充電、直接変更は拒否され、もう一方の状態も変わらない。

固定の道具と契約を操作する例であり、実言語によるクラスやコンストラクタの定義、言語固有の可視性、継承、動的ディスパッチ、自由な設計は評価しない。関連項目は部分対応である。

実装担当と別の coverage_next が原典、状態、境界、表示、保存と開放を確認し、「Ｂはそのまま」の判定が途中変更を許す問題を指摘した。判定と理由の表示を修正後、再確認した。独立担当自身のブラウザ操作は行っていない。`tests/endgame-objects.test.js` は個別状態・拒否・途中変更後の復帰・再設定を検証し、`scripts/endgame-objects.playwright.js` は集いと４地域の達成状態を用意した記録から、誤操作、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
