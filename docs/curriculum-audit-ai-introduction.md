# 原典との範囲照合：AI-Introduction

[CS2023 印字 pp.67–68（PDF 67〜68ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-ai-introduction.md)を2026-11-05に照合した。トピック１〜６は CS Core、７〜９は KA Core、10〜11 は Non-core。知的な振る舞い・問題の特性・主体の性質の親項目３・４・５を追加した。成果１〜４に個別の区分は明記されていない。台帳はトピック27行、成果４行で、親子の重複は集計時に検討する。

これは範囲と区分の照合であり、教材の正確性・学習成果の達成や大学水準の深さを証明しない。特に実在の AI 応用とその経済・社会・倫理・安全上の影響について、台帳に不足が残る。
