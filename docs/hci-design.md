## 例示学習成果

| 番号 | 区分 | 内容 | 対応状況 |
|---|---|---|---|
| 1 | CS Core | 指定された対話方法に合わせた設計提案 | 依頼287で固定の表示・取り消しを選択。自由な提案は未対応 |
| 2 | CS Core | 利用者理解、試作、評価、次の反復への反映 | 依頼188・287で架空の困りごとと固定の反応を使う一例。実利用者の調査・評価は未対応 |
| 3 | CS Core | 制約・トレードオフが設計に及ぼす影響の説明 | 未対応 |
| 4 | KA Core | 目的に照らしたアーキテクチャ設計の評価 | 未対応 |
| 5 | KA Core | 分散環境での同期と利用体験の課題 | 未対応 |
| 6 | KA Core | 入力方法のプライバシーへの影響の比較 | 未対応 |
| 7 | KA Core | 視覚設計原則に基づく根拠の説明 | 未対応 |
| 8 | Non-core | VR・AR・MR におけるプライバシーの評価 | 未対応 |

依頼287は、決められた２場面を初期試作で観察し、受付状況と取り消しを追加して両方を再試行する固定模型。操作変更時には再評価の記録を消す。実利用者の行動や通信の正確性は保証しない。
