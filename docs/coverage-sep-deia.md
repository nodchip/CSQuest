# SEP-DEIA：多様性・公平・包摂・アクセシビリティの項目別対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.285–286。[既存調査](sep-deia.md)と依頼・検査を照合。状態は[追跡方法](coverage-status.md)に従い、「未照合」は未実装の証拠ではない。「部分」は関連する固定例を示し、項目全体の修得を意味しない。実際の社会調査・法的判断・自由な説明や文章作成は固定例だけでは直接評価しない。

各依頼の前提・出典と検証、実際の状況に一般化できない範囲は[既存調査](sep-deia.md)を参照する。

依頼1016は実 HTML の試作品をボタン・操作名・状態通知の３点で確認し、改善後にキーボードで実際に操作する。[W3C のキーボード](https://www.w3.org/WAI/WCAG22/Understanding/keyboard)、[名前・役割・値](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value)、[状態メッセージ](https://www.w3.org/WAI/WCAG22/Understanding/status-messages)を参照。検査は限定した試作品と３条件であり、実際の支援技術や利用者の評価、WCAG 全体の適合判定を意味しない。`tests/accessibility-audit.test.js` は３検査、改善による記録の無効化と復元を検査する。

依頼1016はタッチ等で Enter 操作を画面上から模擬して進める経路も持つ。模擬と実際のキーボード入力の記録・達成後の説明は区別し、前者を実際の入力確認と主張しない。旧途中記録は模擬なしとして復元し、改善を切り替えると両方の操作確認を無効化する。

依頼1017は [RFC 9454](https://www.rfc-editor.org/rfc/rfc9454.html) の OSPF 役割・旗の名称更新を参照し、旗の値を変える架空の誤りと区別する。RFC は仕様の動作を変更しない。[Google の技術文書指針](https://developers.google.com/style/inclusive-documentation)を参考に、既存の語や入力がある場合の移行を架空の受付で比較する。入力名は実際の OSPF コマンドではない。個別の受け止め方や実システムの互換性、移行の実施は評価しない。`tests/terminology-migration.test.js` で４旗条件、６入力条件、記録と達成を検査する。

依頼1193は [W3C の利用者参加](https://www.w3.org/WAI/planning/involving-users/) と [異なる時間の意見を含む決定方針](https://www.w3.org/WAI/about/groups/apawg/decision-policy/) を参考に、架空の３人の開発経験と本人の参加条件を明示し、単独、全員を招くだけ、参加方法を整える相談を比較する。３つの発見と参加条件は固定の仮定で、属性から能力を推測せず、実際の多様性・協働・成果を測定しない。`tests/inclusive-team-design.test.js` は32条件・履歴・達成を検査する。

依頼1199は [W3C の人名と入力欄](https://www.w3.org/International/questions/qa-personal-names) と [プライバシー原則](https://www.w3.org/TR/privacy-principles/) を参考に、架空の３人が明示した一つの名前、非 ASCII 文字、公開用の呼び名の希望と３種類の受付設定を比較する。各条件は本人が伝えた仮定で文化・外見から推測せず、一つの欄が全人名に十分とは限らない。`tests/name-access-workshop.test.js` は24設定・試行履歴・保存を検査。実利用者、実装、本人確認や法令適合は評価しない。

依頼1317は [NCES の参加率と構成の比較](https://nces.ed.gov/admindata/crdc/datastory/) と [計算教育研究の属性データに関する研究](https://par.nsf.gov/servlets/purl/10349246) を参考に、架空の100人、64人の申込者、44人の参加者について分母を変えて比べる。丘の地域は対象20％、参加者の４／44（約９％）。申込みは川60／80、丘４／20、申込者の参加は川40／60、丘４／４。交通の声は調査の候補であり原因を証明しない。`tests/education-representation.test.js` で比率、各選択と途中保存を検査。実際の機関・文化・集団や自由な調査を評価しない。
