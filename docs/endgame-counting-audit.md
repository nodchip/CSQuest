# 港の選び方と場合の数

[CS2023 MSF-Discrete（印字187〜188ページ）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の CS Core 4 と学習成果 4a〜4d に関連する有限例。旅支度から一つずつ選ぶ積、互いに重ならない交通手段から一つ選ぶ和、役割を区別する選び方と区別しない二人組を操作する。箱に印を配る場面では、箱より印が多ければ必ず重なる理由と、同数で重ならない反例を調べる。

一般の順列・組合せの公式、包除や数列による数え上げ、形式的証明や多様な現実の条件のモデル化は未評価である。固定された例を扱うため、関連項目は部分対応である。

実装担当と別の coverage_next が原典、数え上げと重複、鳩の巣の保証と反例、説明、達成、保存と開放をコード上で独立確認した。先頭ゼロを含む保存履歴での重複判定を修正し、独立担当が再確認した。独立担当自身は実ブラウザーを操作していない。`tests/endgame-counting.test.js` は独立の期待値と重複・反例を検証する。`scripts/endgame-counting.playwright.js` は物語と４地域の達成状態を用意した別ブラウザー記録から誤答、途中保存、再挑戦、開放と達成を確認する。実際のスクリーンリーダー音声は未確認。
