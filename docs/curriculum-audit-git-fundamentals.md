# 原典との範囲照合：GIT-Fundamentals

[CS2023 印字 pp.155–156](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の GIT-Fundamentals を [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)と照合した。トピック１〜９は CS Core、10・11 は KA Core。原典の階層を親と子で記録し、トピック34行、学習成果14行とした。親１・２・２d・３・４・４a・５は子と重複するため、行数を独立した学習項目数や完成率として扱わない。

従来の台帳には上記７つの親がなかったため、子を参照する形で追加した。親１の一般的な用途・リスク、親３の視覚系全体などは子の固定例で網羅したと判断しない。トピック10・11と成果14は未照合のまま。画面操作による固定例は実ライブラリでの自由な構築や実機接続の知識を証明しない。

原典は GIF を非可逆形式の例に含めるが、既存台帳に記載の通り可逆の圧縮と、表現可能な色数への制限や減色による損失を区別する。視覚の持続やちらつきの例も、人間の知覚全般を証明しない。これは原典の範囲と区分の照合であり、個別教材の正確性、利用者の学習成果、全教材の完成を意味しない。
