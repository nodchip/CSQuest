# 伝令と二つの時計：教材監査

[CS2023 SPD-Embedded 印字305–306頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=305) の時刻同期と、分散通信の遅延に関連する固定模型。旧 `src/clock-sync.js` の依頼503を再利用し、現行の中継塔へ接続する。現行の配送・時刻や通信遅延の依頼とは別に、往復からの時計のずれ推定を扱う。

時計の速度は同じでずれ一定、参照側の処理時間０、遅延非負。塔の送信97・受信101の中点は99。実際の塔の遅れ３で往路２・復路２なら参照の返答102、推定３。往路１・復路３なら返答101、推定２だが実際は３。返答101の同じ観測は、往路１・２・３／復路３・２・１で実際の遅れ３・２・１の各例にも対応する。この３例は全候補ではなく、非負なら往路０・４などもあり得る。

固定時計・遅延・即時返答による中央推定であり、NTP 全体、時刻合わせの実施、遅延測定、時計の周波数誤差・可変遅延・非ゼロ処理や一般の誤差保証は評価しない。[RFC 5905](https://www.rfc-editor.org/rfc/rfc5905.html#section-8) の時刻差と往復遅延を参照。

## 独立レビューと動作確認

実装担当と別の担当が中点推定、非対称時のずれ、同一観測の複数例、前提と保存・開放・焦点を確認。３例が全候補でないことも明示。ローカルで集いと４地域の達成状態を用意した記録から、幅 213・390・1200 px で誤答、キーボード、途中保存・再開と達成を確認。冒険開始からの通し到達は含まない。

公開確認：GitHub Pages の 767c30b（Actions 42975281394 成功）で、集いと４地域の達成状態を用意した記録から、幅 213・390・1200 px のブラウザ検証スクリプトが成功。新規開始からの通し到達はこの確認に含めない。
