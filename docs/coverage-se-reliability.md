# SE-Reliability：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.250–251。[既存調査](se-reliability.md)と依頼・検査を照合。状態は[追跡方法](coverage-status.md)に従う。「未照合」は未実装の証拠ではなく、「部分」は項目全体の完成を意味しない。原典の細目を分けた場合、親と子は数値上で重複計上しない。実際の開発・協働・自由な説明やコード記述の能力は固定例だけでは直接評価しない。
