# SE-Teamwork の対応状況

出典: [CS2023, SE-Teamwork](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 240–241。原典を要約した作業用一覧。ゲーム内の固定例は実際の人との協働を評価しない。

## トピック

| 番号 | 分類 | 要約 | 現状 |
|---:|---|---|---|
| 1 | CS Core | 公式・非公式の効果的な意思疎通 | 依頼59・650で関係者の事情を聞く固定例。実際の意思疎通は未対応 |
| 2 | CS Core | チーム内の対立の原因と解決 | 依頼650で安全・配送・通行の条件を聞いて案を比較。架空の固定条件であり、実際の対立解消は未評価 |
| 3 | CS Core | ペア作業、レビュー、版管理による協働 | 依頼59で版管理上の統合を例示。実際の協働やレビューは未対応 |
| 4 | CS Core | チームの役割、利点と複雑さ | 依頼650で安全確認・案内・小舟運航を分担。一般の役割や組織は未対応 |
| 5 | CS Core | 責任分担、見積り、会議と予定 | 依頼650で議題・時間帯・担当を選ぶ。一般の見積りや会議運営は未対応 |
| 6 | CS Core | 多様性と包摂の重要性 | 依頼650で通行者の事情と参加を確認。一人の経験を一般化しない注意を示す。実際の包摂は未評価 |
| 7 | KA Core | 技術・非技術の関係者との連携 | 依頼59で代表者の希望を確認する固定例のみ |
| 8 | KA Core | 対面・分散・混合チームのリスクと回復 | 未着手 |

## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | CS Core | 効果的なチーム内の意思疎通 | 依頼650で３人の事情を聞き案を確認する固定例。実際の対話は未評価 |
| 2 | CS Core | 対立の原因・危険・利益を説明 | 依頼650で異なる制約から見落としを発見する例。一般の説明は未対応 |
| 3 | CS Core | 対立解消と問題解決を進行 | 依頼650で聞取り・制約・案・担当を選ぶ固定例。実際の進行能力は未評価 |
| 4 | CS Core | 協働開発を効果的に行う | 依頼59は一人で固定例を操作するのみ |
| 5 | CS Core | 必要な役割と責任を提案・分担 | 依頼650で３つの担当を選択。一般の分担は未対応 |
| 6 | CS Core | 会議の議題を作成・遵守 | 依頼650で固定の４議題を並べる。自由な作成・実会議は未対応 |
| 7 | CS Core | プロジェクトを通じてチーム形成・運営 | 未着手 |
| 8 | CS Core | 多様性と包摂の利点を促進 | 依頼650で当事者の参加と単一の経験を一般化しない点を扱う。現実での促進は未評価 |
| 9 | KA Core | チーム外の関係者との連携を説明 | 固定された希望を読む例のみ。実際の連携や説明は未対応 |
| 10 | KA Core | 多様な勤務形態に伴うリスクと対策を列挙 | 未着手 |

依頼650では３人の事情を聞き、安全を確保する３時間の修理と薬の荷車・通行者の必要時刻、代替の小舟、３担当を選ぶ。４つの時間・代替案と64通りの役割を検査。利用者参加の利点と一人の経験を一般化しない注意は [W3C WAI](https://www.w3.org/WAI/planning/involving-users/) を参考にした。選択肢と同意は架空の固定例で、実際の対話、交渉、橋や小舟の安全・法令適合は評価しない。
