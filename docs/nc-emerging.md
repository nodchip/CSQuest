# NC-Emerging：新しいネットワークの話題

出典：[CS2023 NC-Emerging](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.201。原典の要約と限定的な対応であり、固定模型の達成は実際のネットワーク設計・運用や自由な説明能力を証明しない。

| トピック | 区分 | 内容と対応状況 |
|---:|---|---|
| 1 | KA Core | ミドルボックス：AI・意図に基づくネットワーク、フィルタ、深いパケット検査、負荷分散、NAT、CDN など。依頼279で通信フィルタ、280で侵入検知の固定模型。他の方式と一般的な配置・運用は未対応 |
| 2 | KA Core | ネットワーク仮想化、SDN、データセンターネットワーク。依頼319で制御側による規則設定と中継器による転送の固定模型。仮想化と実際の制御器・運用は未対応 |
| 3 | KA Core | 量子ネットワーク、テレポーテーション、安全性、量子インターネット。未対応 |
| 4 | KA Core | 衛星、ミリ波、可視光。未対応 |

| 例示学習成果 | 区分 | 対応状況 |
|---:|---|---|
| 1 | KA Core | ミドルボックスの進歩の価値を説明。依頼279・280は通信フィルタと侵入検知の固定模型。一般的な説明は未対応 |
| 2 | KA Core | SDN の重要性を説明。依頼319で集中した制御側による２中継器の規則設定と転送を比較。一般的な説明と実ネットワークの設計は未対応 |
| 3 | KA Core | 量子ネットワークの付加価値を説明。未対応 |

依頼319では１つの宛先、出発・A・B・村の４地点、既知のリンク状態と単一の指揮塔を仮定する。壊れた道で出発の次の塔を変更する例と、B の規則不足を補うか、通れる A へ切り替える例を操作する。転送は設定済みの規則で行う。実際の SDN には複数の制御器、異なる制御・転送方式、配布順や障害の問題があり、この模型はそれらや実装を保証しない。参考：[ONF: SDN Architecture](https://opennetworking.org/wp-content/uploads/2013/02/TR_SDN_ARCH_1.0_06062014.pdf)。
