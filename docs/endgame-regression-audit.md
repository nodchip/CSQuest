# AI-ML：回帰の誤差（部分対応）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.71–75、AI-ML 13b の回帰評価に関する固定例。現行の教師あり依頼は分類結果の誤りを調べる。旧依頼115は二乗誤差の固定例を扱い、一部が重複する。今回の例は平均絶対誤差と平均二乗誤差を同じ観測と予測で比較し、指標で候補の順位が変わることを扱う。

観測１・３・５、予測２のとき絶対誤差１・１・３、二乗誤差１・１・９、各平均は５／３と11／３。観測０・０・９で一定予測０と３を比較すると絶対誤差の合計９と12、二乗誤差の合計81と54。観測は３件なので各合計を３で割る。より小さい値を良しとするこの例では候補の順位が反転する。平均二乗誤差の単位は元の単位の二乗であり、大きい誤差を相対的に強く反映する。[scikit-learn の MAE](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.mean_absolute_error.html)、[MSE](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.mean_squared_error.html) の定義を参照。

この少数の決められた例だけでは実データの品質・モデルの訓練・分割・選択の妥当性、一般的な予測性能や評価指標選択、自由な実装・説明は検証できない。AI-ML 全体を完成とは扱わない。

実装担当とは別の `review_candidate` が原典と指標の定義、固定例の計算、画面の説明、誤答・不正履歴、分類と開放、旧記録の既定値をコード上で確認した。関連９テストも成功した。実データによる評価設計や実装能力を確認したものではなく、レビュー担当自身はブラウザを操作していない。

`scripts/endgame-regression.playwright.js` は集いと４地域の達成状態を用意した検証用記録から、213・390・1200 px 幅で分類経由の到達、キーボード操作、誤答案内、途中保存・再開、段階開放と達成後の再開を確認した。新規開始からこの依頼への通し操作、実際のスクリーンリーダー音声や利用者による面白さの評価は未確認。
