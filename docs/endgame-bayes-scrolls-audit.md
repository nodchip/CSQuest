# 伝言と多項ナイーブベイズ：教材監査

[CS2023 AI-ML 印字71–75頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=71) の単純な統計的教師あり分類の固定例。旧 `src/text-bayes.js` の依頼1144を再利用し、現行の文庫へ接続。現行の文書検索は検索結果の適合率・再現率、他の分類教材は別の特徴と模型を扱う。

火係の手本は「火火」「火薬」、薬係は「薬薬」「薬ない」で各２通、事前確率各１/２。語彙は火・薬・ないの３語。各係で語数４、各語に１を加え分母７とすると火係は4/7・2/7・1/7、薬係は1/7・4/7・2/7。語彙内で薬係に未出現の「火」も平滑化する。語彙外の語は扱わない。

事前確率と各語の条件付き確率の積を比較し、火火は火係16/98・薬係1/98、薬薬は4/98・16/98、火ないとない火は各4/98・2/98。いずれも未正規化の値で、事後確率として表示しない。語順を無視し係を条件に語の発生を独立とみなす模型であり、仮定は実データで保証されない。

固定の手本と語彙、加算１の平滑化・少数の２語伝言に限る。実データ・任意の手本、未知語、文脈、独立性の実証、事後確率の校正や実際の分類精度は未評価。[Stanford IR Book](https://nlp.stanford.edu/IR-book/html/htmledition/naive-bayes-text-classification-1.html) と [scikit-learn の説明](https://scikit-learn.org/stable/modules/naive_bayes.html) を参照。
