# AL-Foundational：集落をつなぐ最小全域木

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.88–90、AL-Foundational 13b の最小全域木。旧依頼910 `src/prim-tree.js` の２固定グラフを現行の山で再利用するため、独立した新規範囲として重複計上しない。現行の山の最短経路は出発地から目的地への経路を扱い、全地点をつなぐ道の総費用を最小にする目的とは異なる。

連結で無向の固定グラフについてＡから開始し、つながった集合と外側を結ぶ辺のうち最小費用を選ぶ。同額ならいずれも正しい。５地点は AC(2)、BC(1)、BD(5)、DE(2) の合計10。４地点は AB(1)、AC(1) の後、BD(3) または CD(3) で合計５。全域木の独立全列挙で前者は40候補中唯一の最小、後者は８候補中２種類の最小と確認した。[Princeton のプリム法資料](https://algs4.cs.princeton.edu/lectures/keynote/43MinimumSpanningTrees-2x2.pdf) は木の内外を結ぶ最小辺を選ぶ説明を示す。

２つの固定グラフであり、非連結の場合の森、一般の正しさの証明、任意の入力、優先度付きキューの実装や実際の費用を評価しない。AL-Foundational 全体の完成を示さない。

2026-11-11、実装担当と別の `review_candidate` が原典と [Princeton の資料](https://algs4.cs.princeton.edu/43mst/) に照らし、全域木の独立全列挙、画面・保存・開放条件を確認した。親担当が準備済み記録から幅 213・390・1200 px の現行山の分類に到達し、誤答、キーボード、途中保存・再開、開放条件、達成後の保存をブラウザ確認した。新規開始からの通し操作、スクリーンリーダー音声、利用者による面白さは未確認。
