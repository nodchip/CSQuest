# 原典との範囲照合：AR-Organization

[CS2023 印字 p.106（PDF 106ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-ar-organization.md)を2026-11-05に照合した。トピック１〜４と２の子 a・b、例示学習成果１〜５はすべて KA Core。制御装置の親項目２を追加した。台帳はトピック６行、成果５行で、親子の重複は集計時に検討する。

範囲と区分の照合であり、教材の正確性や成果の達成は別途評価する。固定された制御表やデータパスの操作はプロセッサ全体の自由な設計能力を証明しない。
