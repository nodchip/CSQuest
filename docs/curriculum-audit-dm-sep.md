# 分母照合：DM-SEP

[CS2023 印字 p.123](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の DM-SEP と[台帳](coverage-dm-sep.md)を2026-11-04に照合した。

トピック９件（1、2、2a、3〜8）と学習成果６件（1〜6）を追跡する。２はプライバシー全般、２aは設計段階での法令順守を扱う。２の分母範囲から２aを除くことで同じ範囲を重複して数えない。括弧内の例は各成果の範囲に含める。

トピック１〜５と成果１〜４は CS Core、トピック６〜８と成果５・６は KA Core。分母の照合は教材の完成、法令適合や実社会の影響評価を保証しない。
