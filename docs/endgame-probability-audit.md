# 観測所の確率の依頼

[CS2023 MSF-Probability、印字188–189ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=189) の有限模型。等確率の札から事象を選び、条件を変えたときの分母と割合を比べる。別の依頼は公平な札の復元抽出を２回行う４・９結果を赤の回数で分類し、分布と平均を比べる。両方の達成後、雲ありのとき雨と、雨のとき雲ありの割合を２種類の模型で比べる。天気の実際の確率を示すものではない。

条件に合う母集団は画面側で自動的に絞る。一般の標本空間、条件付き確率やベイズ則の導出、独立性、分散、連続分布、一般の期待値の計算、自由な説明は扱い切れておらず、対応は部分的である。

実装担当と別の candidate が原典・計算・判定・進行・保存を確認し、結果の条件表示と前提を指摘した。修正後に再確認した。独立担当による実ブラウザ操作はない。`tests/endgame-probability.test.js` は固定結果の独立した期待値、誤答と修正を検査する。`scripts/endgame-probability.playwright.js` は集いと４地域の進行済みの検証用記録から対象依頼に入り、誤答、途中復元、２件による解放と達成を確認する。実スクリーンリーダー音声は未検証。
