# FPL-Functional：構造化データと木の集約の教材評価

2026-11-06 に [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の CS Core トピック３・３a と依頼773を照合した。両方の判定は「部分」。

空の枝の答えは０、節では左右の枝の結果と節の値を組み合わせる。空の木、固定された３節の木の値の合計と節の数を、それぞれ枝から根へ集める。節の値を使う合計と、節ごとに１を加える個数の２種類を比較し、元の木は変えない。[Cornell の木の fold の説明](https://courses.cs.cornell.edu/cs3110/2021sp/textbook/hop/fold_trees.html)にある空と節を分ける構造と対応する。

`tests/tree-fold.test.js` の３テストは空の木と２集約、各80通りの依存関係を満たす処理順、不正な順序と答え、復元を検査する。公開版390px幅で３つの集約と振り返りを操作し達成を確認した。

木・値・集約は固定され、任意の木や利用者が定義した関数、一般のデータ型、実言語での開発や自由な説明は評価しない。この固定例だけで学習成果全体を達成したとはいえない。
