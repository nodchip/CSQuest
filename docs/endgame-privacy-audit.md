# 案内所：旅人の記録を守る依頼

[CS2023 SEP-Privacy、印字279ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=279) の収集、匿名性・仮名性、取引記録の保護を扱う固定例。薬草の受取帳で目的に応じた情報・閲覧者・保存期間を選び、番号と対応表、少人数の集計を他の情報と合わせた識別を考える。対応表があれば仮名の記録を本人に結びつけられる。集計は必ず匿名になるわけではなく、本人に結びつかない集計は明示した仮定である。

異なる２件の達成後に公開の相談が届き、受取帳の閲覧範囲、対応表との照合、少人数の集計の危険を検討する。同じ依頼の再挑戦は別件に数えない。３件とも模型上の選択であり、実社会の一般的な脅威分析や匿名性評価、実利用者の希望、実装、法令や文化差、自由な説明は扱い切れていない。対象項目は部分対応である。

実装担当とは別の next_domain が原典と各依頼を照合し、集計から識別できる前提と正解位置を指摘。村の住民だけの受取数と唯一の住民を知る人を明示し、選択肢の位置を変えて再確認した。独立担当によるブラウザ操作は行っていない。`tests/endgame-privacy.test.js` は誤答と選び直しを、`scripts/endgame-privacy.playwright.js` は到達・途中保存・達成・繰返しと２件達成による解放を検証する。実際のスクリーンリーダーの音声は未検証。
