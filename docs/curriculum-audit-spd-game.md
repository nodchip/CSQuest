# 完成率の分母の照合：SPD-Game

[CS2023 印字 pp.306–308（PDF 306〜308ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の SPD-Game と[項目別台帳](coverage-spd-game.md)を2026-11-05に照合した。すべて KA Core。

原典の１〜５は子項目を束ねる見出しとして扱い、各子項目を数える。括弧内の事例は、対象の理解を助ける例として親項目に含め、別の項目に数えない。4a の原典の表現「open game engines」から、例示されたすべてがオープンソースであるとは推定しない。

トピックの分母候補は20件（1a〜1e、2a〜2d、3a〜3d、4a〜4b、5a〜5e）、例示学習成果は15件（1〜15）。台帳に区分を追加し、2c と 4b の要約に範囲を補った。個々の教材の正確性、深さや達成判定をこの照合で検証したわけではない。例示成果にある実装、実機、自由な説明や性能評価は、代替体験の範囲と限界を別途確認する必要がある。

この記録は SPD-Game の原典と項目の範囲の照合であり、教材の完成や CS2023 全体の完成率を示さない。台帳の「部分」「未照合」はそれぞれ根拠と未検証範囲を見て再評価する。
