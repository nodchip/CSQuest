# 原典との範囲照合：GIT-Animation

[CS2023 印字 pp.160–161](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)を照合した。全トピックと成果は KA Core。原典の親２・３・５・６を追加し、親子23トピック行・成果６行とした。親は子と重複する行として保持する。原典の２b・２d はいずれもモーショングラフィックスであり、台帳にも両方を残す。行数を独立した項目数や完成率に使わない。

アニメーションの諸原則のうち既存の182で扱うのは緩急の固定例であり、他の原則は網羅していない。双対クォータニオンや３次元制作なども未評価。成果６は既存ソフトによる単純な有機的形状の構築・リグ付け・アニメーション制作であり、未照合のまま残す。画面上の固定模型は実際の制作や自由な説明の能力を証明しない。

この範囲照合は教材の正確性、学習成果の達成、全教材の完成を証明しない。
