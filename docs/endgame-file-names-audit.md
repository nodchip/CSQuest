# 名前と開いたファイル参照：教材監査

[CS2023 OS-Files 印字212頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=212) のファイル名・共有・操作の固定模型。旧 `src/files.js` の依頼77を再利用し現行の文庫へ接続する。現行の連結リストや台帳・復旧は異なる仕組みである。

通常ファイルの一つの実体に「太陽」と別名「月」があり、別名はコピーでない。「太陽」を削除後も「月」で同じ実体を参照できる。開いた参照がある状態で両方の名前を削除しても、開いた参照から読める。他の名前や開いた参照がない固定条件で最後の参照を閉じると領域は再利用可能になる。再利用可能は記憶媒体上の内容が物理的に完全消去された保証ではない。

固定手順・単一ファイル・通常ファイルの模型で、他のリンクやプロセス、権限、OS ごとの制約、シンボリックリンク、実際のファイル API、実媒体の消去を評価しない。[Linux link(2)](https://man7.org/linux/man-pages/man2/link.2.html)、[unlink(2)](https://man7.org/linux/man-pages/man2/unlink.2.html) を参照。

## 独立レビューと動作確認

実装担当と別の担当が名前と参照の寿命、再利用と物理消去の違い、保存・開放・焦点を確認。ローカルで集いと４地域の達成状態を用意した記録から、幅 213・390・1200 px で誤答、キーボード、途中保存・再開と達成を確認した。冒険開始からの通し到達は含まない。

公開確認：GitHub Pages の 837f9b0（Actions 42966980846 成功）で、集いと４地域の達成状態を用意した記録から、幅 213・390・1200 px のブラウザ検証スクリプトが成功。新規開始からの通し到達はこの確認に含めない。
