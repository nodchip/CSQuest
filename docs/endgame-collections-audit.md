# 森の文庫の札と番号帳

[CS2023 SDF-Data-Structures、印字231–232ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=231) の固定例。リストで同じ札を複数置き、位置の参照・削除と範囲外を試す。辞書では番号への登録・更新と、空の名前、未登録の番号、未登録の削除を区別する。この模型では未登録の削除で何も変化しない。

異なる基礎２依頼の後、仕事に合わせて順番待ち・辞書・集合を選び、投入と取出し、更新と照会、重複追加を操作する。集合の表示順は保証しない。これらは指定された少数の操作例であり、すべての ADT・操作、文字列処理、性能の一般的比較、実言語でのプログラム作成や自由な説明は未対応。該当項目は部分対応である。

実装担当と別の sdf_review が原典と模型を照合し、応用の実操作の不足、固定例の限界、挿入位置の説明を指摘した。修正後に結果と説明を再確認し、追加の単体テストも確認した。独立担当自身のブラウザ操作は行っていない。`tests/endgame-collections.test.js` は重複と位置の変化、空と未登録、キュー・辞書・集合の結果を検証する。`scripts/endgame-collections.playwright.js` は集いと４地域の達成状態を用意した検証用記録から、操作・誤答・途中復元・再挑戦・開放と達成を確認する。実際のスクリーンリーダー音声は未検証。
