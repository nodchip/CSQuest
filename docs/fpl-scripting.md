# FPL-Scripting: シェルスクリプト

参照：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) pp.133–134。依頼151では、行を選び、並べ、数える道具の出力を次に渡す模型を操作します。空の入力と読み込み失敗を区別します。依頼152では、２つの係の標準出力・標準エラー・終了状態、および Bash の pipefail の固定例を比較します。依頼153は新しい変数の子への引継ぎと起動後の変更を扱います。依頼154は限られた記号の正規表現を札で組み立てます。

実際のシェルのパイプはコマンドの出力を別のコマンドの入力につなぎます。依頼の模型は読み込み失敗で後続を実行しませんが、実際には後続コマンドが動く場合があります。標準出力・標準エラー・終了状態も別です。根拠：[Bash Reference Manual: Pipelines](https://www.gnu.org/software/bash/manual/html_node/Pipelines)。模型の「行の型」「数の型」も、シェルのバイト列を単純化しています。

| CS Core トピック | 対応と不足 |
| --- | --- |
| 1 エラー・例外処理 | 依頼151は読み込み失敗と空の入力を区別する模型。依頼152で終了状態の固定例を比較。実際の例外処理は未対応 |
| 2 パイプ | 依頼151で出力の受け渡しと順序を操作。依頼152で標準エラーと終了状態を比較。依頼152で標準出力と標準エラーの出口の変更順を比較。実際の並行実行、ファイルの書込みや部分出力は未対応 |
| 3 システムコマンドと OS との接点 | 未対応 |
| 4 環境変数 | 依頼153で新しい変数の export、子への引継ぎ、親子別の変更と一度の外部プログラム起動に限る値を操作。環境全体や実際のシェル構文は未評価。根拠：[Bash Reference Manual: Environment](https://www.gnu.org/software/bash/manual/html_node/Environment.html) |
| 5 ファイルの抽象と操作 | 読み込み成功・失敗の模型のみ。ファイル操作は未対応 |
| 6 配列・リスト等のデータ構造 | 行の列を扱う模型のみ。シェルのデータ構造は未対応 |
| 7 正規表現 | 依頼154で開始・終了、文字条件、繰り返しの固定例。一般的な表現やツール間の方言は未対応 |
| 8 プログラムとプロセス | 依頼153で子プログラム起動時の環境の固定例。プロセスの一般的な作成・管理は未対応 |
| 9 ワークフロー | 複数処理をつなぐ固定例のみ。実際のワークフローは未対応 |

| CS Core 例示学習成果 | 対応と不足 |
| --- | --- |
| 1 システムの仕事を自動化するスクリプトを作成・実行 | 依頼151は道具の順序を組み立てる代替体験。実際のシステム操作やスクリプト記述能力は評価しない |
| 2 スクリプトによるさまざまなテキスト処理 | 依頼151は固定の行の選択・整列・件数、154は文字パターンの選択を体験。実言語での多様なテキスト処理は未対応 |

依頼152の出口の模型は、通常の出口を巻物に変更する操作と、警告の出口をその時点の通常の出口に合わせる操作を比較する。変更を左から順に適用し、後の通常の出口の変更は既に複製した警告の出口に影響しない。[Bash Reference Manual: Redirections](https://www.gnu.org/s/bash/manual/html_node/Redirections.html) を参照。実際のファイルや権限、リダイレクト構文は操作しない。
