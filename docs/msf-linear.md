# MSF-Linear の対応状況

出典: [CS2023 MSF-Linear](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 191–192。原典を要約した作業用一覧。依頼50は２次元の固定例であり、一般の線形代数や自由記述・実言語での計算を評価しない。

| 番号 | 分類 | 内容と現状 |
|---:|---|---|
| 1 | CS Core | ベクトルの定義・演算・幾何・角度、行列と演算、行列方程式 | 依頼50で内積と向き、依頼86で２×２行列と矢印の積。一般の演算、角度の数値、行列方程式は未対応 |
| 2 | KA Core | 行列と行列方程式、幾何学的変換 | 依頼26で平行移動と回転、依頼86で２×２行列の回転・せん断・つぶれる変換。一般の方程式や変換は未対応 |
| 3 | KA Core | 連立方程式と行基本変形 | 未着手 |

## 例示学習成果

| 番号 | 分類 | 内容と現状 |
|---|---|---|
| 1a | CS Core | ベクトルの代数的・幾何学的表現、加算・スカラー倍・内積 | 依頼50で２次元の内積と図。一般の次元、加算とスカラー倍は未対応 |
| 1b | CS Core | ベクトルの性質を列挙 | 依頼50で内積の符号と方向の一例。一般の性質の説明は未対応 |
| 1c | CS Core | ベクトル間の角度を計算 | 依頼50で90度を境にした分類のみ。角度の数値計算は未対応 |
| 2a–2d | KA Core | 行列演算、連立方程式、積の可否、幾何変換 | 依頼86で２×２行列と矢印の積を見て選択。一般の演算や連立方程式は未対応 |
| 3a–3f | KA Core | 線形方程式のモデル化・行基本変形・ガウス消去 | 未着手 |
| 4a–4j | KA Core | 部分空間、基底、座標、次元、生成、線形独立 | 未着手 |
| 5a–5e | KA Core | グラム・シュミット、射影、直交補空間、最小二乗 | 依頼115で直線の二乗誤差を比較。一般の射影、正規方程式や証明は未対応 |
| 6a–6e | KA Core | 多項式の線形結合、直交性、ベルンシュタイン多項式とベジェ曲線 | 未着手 |
| 7a–7h | KA Core | 固有値・固有ベクトル、特性多項式、対角化 | 未着手 |
| 8a–8h | KA Core | PCA、次元削減、最小二乗、固有値問題、PageRank、SVD | 未着手 |

依頼50は基準ベクトル (2,1) と (1,0)、(1,−2)、(−2,−1) を比較し、内積はそれぞれ２、０、−５。零ベクトルは使わず、向きや角度が定まらないことを解説する。内積の計算と選択肢をテストする。

依頼86は−１・０・１を成分とする２×２行列を選び、２本の基底ベクトルの像を目標に合わせる。各列と基底の像、和の像、行列式を表示し、回転・せん断・異なる入力を同じ像へ写す変換を比較する。一般の基底や逆行列の計算・自由な証明は未対応。
