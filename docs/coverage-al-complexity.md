# AL-Complexity：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.91–93。[追跡方法](coverage-status.md)に従う。親見出しと子項目は重複集計せず、原典の番号を維持する。固定入力の結果は一般の計算量の証明や実環境の性能を意味しない。

依頼334の追加比較は、石４・８・16・32個で直接参照、半減、線形、二重の組合せ、部分集合、順列の各規則による回数を表示する。大きな階乗は整数演算で求める。`tests/work-growth.test.js` は32個を含む値と旧記録の復元を検査する。計算した回数であり、実測時間や一般の性能保証ではない。

依頼335の追加操作では正の整数 c・n₀ を各１・２・４・８から選び、すべての整数 n≥n₀ で 8n≤c n² が成り立つか調べる。c n₀≥８なら n≥n₀ と n>０ から上界が従い、そうでなければ n₀ が反例になる。`tests/asymptotic-bound.test.js` は16条件、反例、旧記録の復元を検査する。この固定された関数の例は、一般の O・Ω・Θ の証明全体を扱わない。
