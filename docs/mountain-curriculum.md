# 山の中継所：学習内容と出典

CS2023 の [Algorithmic Foundations](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm) は、グラフとグラフ探索、幅優先探索、最短経路を扱う。本地域では、有向の小さな例で、到達可能性、道の数と所要時間の違いに触れる。幅優先探索そのものを操作する演習や、ダイクストラ法の実行、一般的な正しさの証明は扱っていない。

一本道の数が最少の経路は中継所→尾根→集落で２本・10分、所要時間が最短の経路は中継所→森の道→小川→集落で３本・６分。見晴らし台は行き止まり。時間は例として設定した値。
