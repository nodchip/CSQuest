# GIT-Modeling：幾何モデリング

出典: [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.158–159。固定した曲線の操作は、一般の形状やモデリングツールを実装する能力を直接評価しない。

| トピック | 区分 | 内容と現状 |
|---|---|---|
| 1 | KA Core | ２次元の交差判定と近接判定。依頼94で一次元の移動と壁の衝突の固定例。一般の２次元判定は未対応 |
| 2a–e | KA Core | 曲面分割、メッシュ、パラメトリックな多項式曲線・曲面、陰的表現、空間分割。依頼142で２次ベジェ曲線の制御点と中間点の固定例。他の曲線・曲面と各手法は未対応 |
| 3a–d | KA Core | ボリューム・ボクセル・点、符号付き距離場、疎なボリューム、CSG。未対応 |
| 4a–b | KA Core | フラクタル、L システムなどの手続き表現。未対応 |
| 5–6 | KA Core | 多重解像度モデリング、走査・写真測量などからの復元。未対応 |

| 例示学習成果 | 区分 | 内容と現状 |
|---|---|---|
| 1 | KA Core | 陰的表現とパラメトリック表現の比較。依頼142で２次曲線の固定例。陰的表現と一般の比較は未対応 |
| 2–7 | KA Core | 曲面分割、陰的曲面・走査点からのメッシュ、手続き的地形、CSG、各方式の費用・品質の比較。未対応 |

依頼142では始点 (0,0)・終点 (4,0) を固定し、制御点を (2,h) とする。両端と制御点を結ぶ各線の中点は (1,h/2)・(3,h/2)、その中点は (2,h/2)。この点は２次ベジェ曲線のパラメータ 1/2 の位置である。高さ 0・2・4 に対する中間の高さは 0・1・2。一般のパラメータ、３次曲線や曲面は扱わない。
