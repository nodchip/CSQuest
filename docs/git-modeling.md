# GIT-Modeling：幾何モデリング

出典: [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.158–159。固定した曲線の操作は、一般の形状やモデリングツールを実装する能力を直接評価しない。

依頼142では始点 (0,0)・終点 (4,0) を固定し、制御点を (2,h) とする。両端と制御点を結ぶ各線の中点は (1,h/2)・(3,h/2)、その中点は (2,h/2)。この点は２次ベジェ曲線のパラメータ 1/2 の位置である。高さ 0・2・4 に対する中間の高さは 0・1・2。５つのパラメータの値でベルンシュタイン重みと曲線上の点を操作できる。任意のパラメータ、３次曲線や曲面は扱わない。

依頼722は x²+y²=４ の陰的な条件を５×５の整数格子に適用し、(２,０)・(０,２)・(−２,０)・(０,−２) を選ぶ。同じ半径２の円を x=２cos θ、y=２sin θ と表し、０°・90°・180°・270°の点と比較する。格子外や非整数の点を排除した円ではなく、格子上の４点は円の一部。一般の曲線・曲面や自由な式の構築は扱わない。参考：[MIT 多変数解析ノート](https://math.mit.edu/~poonen/notes02.pdf)。

依頼143は５×５画素上の重なる２つの３×３矩形について、和15画素、共通部分３画素、各方向の差６画素を選ぶ。有限の画素を使う２次元模型で、３次元 CSG の立体・境界・メッシュは扱わない。

依頼145は反時計回りの凸・凹の各五角形を耳切りで分割する。選択頂点が凸で、隣接する２頂点と作る三角形の内側・辺上に他の頂点がないとき切り出す。残る３頂点も含め３三角形とする。実行可能なすべての切り出し順を列挙し、各三角形の正の面積と面積合計を独立に照合。穴・３次元曲面・浮動小数点誤差や一般のメッシュは扱わない。


依頼723は半径２の円の25個の格子点について、d＝√(x²＋y²)−２ の符号で内側・境界・外側を分類し、陰的な式 f＝x²＋y²−４ と比較する。d の絶対値は円周までの最短距離で、中心では d＝−２、f＝−４。符号の約束が逆の定義もある。円の固定例で、一般形状の距離場・３次元・連続領域の操作は扱わない。[Cornell の level set 講義](https://www.cs.cornell.edu/courses/cs664/2005fa/Lectures/lecture24.pdf)。
