# 原典との範囲照合：SF-Performance

[CS2023 印字 pp.294–295（PDF 294〜295ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-sf-performance.md)を2026-11-05に照合した。トピック１〜４と１の子 a・b、成果１〜３は CS Core、トピック５〜８と成果４〜６は KA Core。遅延の親項目１を追加した。台帳はトピック10行、成果６行で、親子の重複は集計時に検討する。
