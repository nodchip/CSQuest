# AI-Introduction の対応状況

原典: [CS2023 AI-Introduction](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.67–68。固定した人形の規則を操作する例で、実際の AI 開発や自由な説明能力は直接評価しない。

「精霊と人工知能」の学びの道では、AI の例から探索、学習、確率や対戦に関連する33依頼を選べる。順番は目安で、他の道にも同じ依頼が含まれる。全トピックの達成を意味しない。

| 番号 | 区分 | 内容と現状 |
|---|---|---|

| 2 | CS Core | エージェントの定義と反射・熟慮などの例。依頼109で観測と記憶、688で反射・到達目標・期待費用に基づく３つの固定規則を比較。一般的な分類は未対応 |
| 3a–d | CS Core | 知的な行動、チューリングテストと限界、マルチモーダル、模倣、合理的・非合理的推論。依頼686で架空の模倣ゲームとその限界、中国語の部屋への異なる立場を比較。実際の試験や他の事項は未対応 |
| 4a–e | CS Core | 観測可能性、主体数、決定性、静的・動的、離散・連続。依頼109で部分観測、687で静かな遺跡と霧の橋の固定模型を操作して５特性を比較。一般的な分類や連続空間は未対応 |

| 例示学習成果 | 内容と現状 |
|---|---|
| 1 | チューリングテストと中国語の部屋。依頼686で固定された架空の対話と記号対応を操作し、会話の観察と理解をめぐるサールの主張・システムの応答を比較。自由な議論や実際の試験は未評価 |

| 3 | AI、機械学習、深層学習の区別。依頼375で探索・最近傍・多層ネットワークの固定例と包含関係を比較。一般の分類やモデルの学習は未対応 |
| 4 | 特定の問題の特性を列挙。依頼109・687で固定例の特性を選択。自由な列挙と一般的な判断は未対応 |

依頼109の入口では太陽か月の印が正確に観測でき、分かれ道ではその印が見えず景色は同じ。太陽なら左、月なら右が安全。記憶せず同一の決定的行動を選ぶ２方式はいずれも片方で失敗し、記憶して印ごとに左・右を選ぶ設定のみ両方で成功する。全設定を列挙して確認した。観測誤差、学習、確率的行動や他の主体は扱わない。

依頼368では各道の４つの結果が同確率で起きると仮定する。通常の荷物の近道は効用が 8、8、8、−4 で期待効用は5、安全な道は常に3。壊れやすい荷物では近道の最後の効用が −16 に変わり、期待効用は2となる。効用と確率の設定が与えられた例であり、現実の選好や確率の推定は扱わない。[参考：Berkeley の効用と合理的選択](https://inst.eecs.berkeley.edu/~cs188/textbook/vpis/utilities.html)

依頼375は固定地図の幅優先探索、２例の１近傍、２隠れ層の固定ネットワークを操作する。ネットワークは第２隠れ層の OR・AND を使い、４入力に対し XOR を出力する。学習済みと仮定した重みでの推論例であり、実際の訓練や一般化の確認ではない。各手法を最も具体的な分類に整理し、包含関係も示す。[参考：Google の機械学習用語](https://developers.google.com/machine-learning/glossary/fundamentals)

依頼685は依頼504の隠れた天候の予測・観測更新を冒険で用い、暗・光の観測後の晴れ確率 392/529 に基づいて２荷物の道を選ぶ。山道の費用を晴れで１、霧で丈夫な荷は９・壊れやすい荷は16、屋根道を４と仮定すると、山道の期待費用はそれぞれ 1625/529 と 2584/529。前者は山道、後者は屋根道が小さい。確率と費用は架空の固定条件で、実際の天気・運搬や単発の結果を保証しない。参考：[Berkeley、意思決定と期待効用](https://inst.eecs.berkeley.edu/~cs188/textbook/vpis/decision-networks.html)。

依頼686は、２つの幕に対する各３つの固定返答を確認し、推測後に架空の設定を明かす。記号の部屋では２つの対応規則を適用し、サールの形式操作と理解に関する主張、システム全体に理解を帰属させる反論を対比する。用意された返答は実際の人間や AI の対話記録ではなく、限られた対話で内面の理解や意識を判定しない。自由な議論や思考実験の一般的な評価は未対応。参考：[Turing、Computing Machinery and Intelligence](https://cbmm.mit.edu/sites/default/files/documents/turing.pdf)、[Searle、Minds, Brains, and Programs](https://cse.buffalo.edu/~rapaport/Papers/Papers.by.Others/Searle/searle80.html)。

依頼687は人形だけの完全観測・決定的・静的な遺跡と、人形に見えない番人が動き、同じ状態・行動から風の２結果が各1/2で生じる霧の橋を比較する。いずれも位置と時刻を離散化し、実験者が初期の番人位置と可能な風の結果を選ぶ。人形の観測には番人の位置を含めず、実験者の設定とは区別する。例は架空の限定模型で、一般の環境分類や実際の人間の行動を評価しない。参考：[Berkeley、エージェントと環境](https://inst.eecs.berkeley.edu/~cs188/fa22/assets/notes/cs188-fa22-note01.pdf)。

依頼688は、近道の印に反応する固定規則、通行可能な最短路を選ぶ目標、歩数と損失の期待費用を比べる方針を、開通・閉鎖・損傷リスクの３状況で比較する。危険な近道は歩数１と確率1/2の追加費用８で期待費用５、回り道は３。閉鎖時は近道に到着できない。別の反射規則や評価基準なら異なる結果になり得るため、これらの固定例から方式全般の優劣は主張しない。参考：[Berkeley、エージェント](https://inst.eecs.berkeley.edu/~cs188/textbook/search/agents.html)と[方策](https://inst.eecs.berkeley.edu/~cs188/textbook/mdp/solve.html)。
