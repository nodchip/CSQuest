# AI-Introduction の対応状況

原典: [CS2023 AI-Introduction](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.67–68。固定した人形の規則を操作する例で、実際の AI 開発や自由な説明能力は直接評価しない。

「精霊と人工知能」の学びの道では、AI の例から探索、学習、確率や対戦に関連する33依頼を選べる。順番は目安で、他の道にも同じ依頼が含まれる。全トピックの達成を意味しない。

依頼109の入口では太陽か月の印が正確に観測でき、分かれ道ではその印が見えず景色は同じ。太陽なら左、月なら右が安全。記憶せず同一の決定的行動を選ぶ２方式はいずれも片方で失敗し、記憶して印ごとに左・右を選ぶ設定のみ両方で成功する。全設定を列挙して確認した。観測誤差、学習、確率的行動や他の主体は扱わない。

依頼368では各道の４つの結果が同確率で起きると仮定する。通常の荷物の近道は効用が 8、8、8、−4 で期待効用は5、安全な道は常に3。壊れやすい荷物では近道の最後の効用が −16 に変わり、期待効用は2となる。効用と確率の設定が与えられた例であり、現実の選好や確率の推定は扱わない。[参考：Berkeley の効用と合理的選択](https://inst.eecs.berkeley.edu/~cs188/textbook/vpis/utilities.html)

依頼375は固定地図の幅優先探索、２例の１近傍、２隠れ層の固定ネットワークを操作する。ネットワークは第２隠れ層の OR・AND を使い、４入力に対し XOR を出力する。学習済みと仮定した重みでの推論例であり、実際の訓練や一般化の確認ではない。各手法を最も具体的な分類に整理し、包含関係も示す。[参考：Google の機械学習用語](https://developers.google.com/machine-learning/glossary/fundamentals)

依頼685は依頼504の隠れた天候の予測・観測更新を冒険で用い、暗・光の観測後の晴れ確率 392/529 に基づいて２荷物の道を選ぶ。山道の費用を晴れで１、霧で丈夫な荷は９・壊れやすい荷は16、屋根道を４と仮定すると、山道の期待費用はそれぞれ 1625/529 と 2584/529。前者は山道、後者は屋根道が小さい。確率と費用は架空の固定条件で、実際の天気・運搬や単発の結果を保証しない。参考：[Berkeley、意思決定と期待効用](https://inst.eecs.berkeley.edu/~cs188/textbook/vpis/decision-networks.html)。
