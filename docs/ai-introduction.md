# AI-Introduction の対応状況

原典: [CS2023 AI-Introduction](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.67–68。固定した人形の規則を操作する例で、実際の AI 開発や自由な説明能力は直接評価しない。

| 番号 | 区分 | 内容と現状 |
|---|---|---|
| 1 | CS Core | AI 問題と応用事例。依頼08・17・28などは探索、分類、移動の架空例。実在の応用事例は未対応 |
| 2 | CS Core | エージェントの定義と反射・熟慮などの例。依頼109で観測、記憶、規則による行動を操作。一般的な分類は未対応 |
| 3a–d | CS Core | 知的な行動、チューリングテストと限界、マルチモーダル、模倣、合理的・非合理的推論。未対応 |
| 4a–e | CS Core | 観測可能性、主体数、決定性、静的・動的、離散・連続。依頼109は単一主体・決定的・離散の部分観測の固定例。一般的な分類、動的環境や連続空間は未対応 |
| 5a–f | CS Core | 自律性の種類、反射・目標・効用、情報不足下の判断、知覚と環境、学習型・身体を持つ主体。依頼28・109で観測と動作、依頼98で不確実な判断の固定例。自律性や学習型主体の体系的な比較は未対応 |
| 6 | CS Core | AI 応用、成長と経済・社会・倫理への影響。未対応 |
| 7–9 | KA Core | 例での環境特性の判定、主体と応用・影響の追加の深さ。依頼109で部分観測の固定例のみ。一般の判定や影響は未対応 |
| 10–11 | Non-core | 哲学的問題、AI の歴史。未対応 |

| 例示学習成果 | 内容と現状 |
|---|---|
| 1 | チューリングテストと中国語の部屋。未対応 |
| 2 | 最適・合理的な推論と人間らしい推論の区別。未対応 |
| 3 | AI、機械学習、深層学習の区別。未対応 |
| 4 | 特定の問題の特性を列挙。依頼109の固定例で部分観測・決定性・主体数を扱う。自由な列挙と一般的な判断は未対応 |

依頼109の入口では太陽か月の印が正確に観測でき、分かれ道ではその印が見えず景色は同じ。太陽なら左、月なら右が安全。記憶せず同一の決定的行動を選ぶ２方式はいずれも片方で失敗し、記憶して印ごとに左・右を選ぶ設定のみ両方で成功する。全設定を列挙して確認した。観測誤差、学習、確率的行動や他の主体は扱わない。
