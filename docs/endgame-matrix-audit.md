# 庭園の行列と矢印

[CS2023 MSF-Linear、印字191ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=191) の行列とベクトルに関連する２次元の固定例。各行と列ベクトルの成分を掛けて足し、傾ける変換と原点まわりの反時計回り90度の回転を求める。応用では同じ入力に２種類の変換を逆順に作用させ、結果を比べる。図は横軸右・縦軸上を正とし、入力を破線、結果を実線で表す。

固定の２×２行列と整数の矢印に限定し、任意次元、行列同士の積の導出、連立方程式 Ax=b、一般の線形写像や証明は扱わない。関連項目は部分対応である。

実装担当と別の coverage_next が原典、成分計算、回転方向、変換順、保存と開放を確認し、細い画面での図の幅を指摘した。幅を調整後に再確認した。独立担当によるブラウザ操作は行っていない。`tests/endgame-matrix.test.js` は各変換と順序を検証し、`scripts/endgame-matrix.playwright.js` は集いと４地域の達成状態を用意した記録から、３種類の画面幅で図の枠内表示、キーボード操作、誤答、途中復元、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
