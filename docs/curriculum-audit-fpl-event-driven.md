# 完成率の分母の照合：FPL-Event-Driven

[CS2023 印字 pp.134–135（PDF 134〜135ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の FPL-Event-Driven と[項目別台帳](coverage-fpl-event-driven.md)を2026-11-05に照合した。

トピック１〜４は CS Core、５〜７は KA Core。５は反応型フレームワークの使用という見出しの下に、ハンドラー・リスナーの定義、送信元と引数のパラメータ化、外部とプログラム生成のイベントを列挙する。分母ではこれらを５a〜５cとして数え、親の５を重複計上しない。ただしフレームワーク全体の定義・利用という学習成果は、子項目の列挙とは別に成果３として追跡する。

トピックの分母候補は９件（１〜４、５a〜５c、６、７）。例示学習成果は４件（CS Core １・２、KA Core ３・４）。原典の４で挙げる利用先は GUI、モバイル端末、ロボット、サーバーであり、単なる端末一般という意味ではない。[台帳](coverage-fpl-event-driven.md)の要約を修正した。

これは原典との範囲・区分の照合であり、各教材の正確性の個別検証や、分野全体の完成を意味しない。実言語による実装や実フレームワークの定義・使用、自由な説明については、操作による代替と限界を別途評価する。
