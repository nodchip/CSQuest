# 案内所の掲示板の相談

[CS2023 SE-Requirements、印字242ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=242) の KA Core に関連する架空の固定例。発言を主な観点で分類し、２人の発言から立場・したいこと・理由を組み立てる。異なる基礎２件の達成後、情報の種類と閲覧者を質問し、架空の合意を６場面で試す。

発言は合意済みの仕様とは限らず、一つの発言が複数の観点に関わる場合もある。速度の数値にも測定条件の確認が必要。閲覧例は本人が正しく確認できる仮定であり、名前の表示だけを認証としない。実際の聞き取りや合意形成、自由な文書化、一般の完全性・実現可能性の検査は未対応で、対応は部分的である。

実装担当と別の curriculum_next が原典・例・判定・保存・開放を確認し、分類の多面性、測定条件、本人確認の前提、配置数と正答の区別を指摘。修正後に再確認した。独立担当自身によるブラウザ操作は行っていない。`tests/endgame-requirements.test.js` は誤分類の修正、本人の発言との対応、質問と合意後の閲覧を検証し、`scripts/endgame-requirements.playwright.js` は集いと４地域の達成状態を用意した記録から、対象依頼の操作・誤答・途中復元・再挑戦・開放と達成を確認する。実スクリーンリーダー音声は未検証。
