# 原典との範囲照合：GIT-Simulation

[CS2023 印字 p.161](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)を照合した。全トピックと例示学習成果は KA Core。原典にある親１・３・４・５を追加し、親子と補助行を含む20トピック行・成果３行とした。元の「１-応答」は親１の応答部分を追跡するための補助行で、原典の独立した子番号ではない。親子と補助行は重複するため、行数を独立した項目数や完成率としない。

子項目とその例に対する模型の限界は対応表に記載した。例えば、積分法では依頼209で一定加速度と位置依存のばねの固定例を扱うが、原典が例示するリープフロッグ法や一般の精度・安定性は未評価。空間占有による成長、３次元衝突や一般の流体も未評価。３つの成果はいずれも部分対応であり、煙ソルバーや粒子力学の実コードを書く能力は評価していない。

この照合は原典との範囲の確認であり、個々の教材の正確性や全教材の完成を証明しない。
