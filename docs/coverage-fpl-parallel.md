依頼944は [Illinois の Deterministic Parallel Java 仕様](https://dpj.cs.illinois.edu/DPJ/Download_files/DPJSpecification.html)の cobegin 終了時の合流を参考にした。競合例は逐次一貫で個別の読書きを原子的にした架空模型であり、DPJ が競合を許すという主張や実言語の競合時の意味を示すものではない。

依頼983は [Ongaro・Ousterhout: Raft](https://raft.github.io/raft.pdf) の同一任期の選挙安全性を参考に、３人の投票者、別の２候補と２票の多数派について、一人一候補と二重投票を比較する。候補と投票者は別、全員応答、票の記録が失われない同一選挙という簡略模型であり、Raft の実装ではない。任期の変更、ログの複製・確定、通信障害や進行保証は扱わない。`tests/election-overlap.test.js` は２票の選び方と風への依頼順を全列挙し、両方式の票数、途中記録を検査する。
