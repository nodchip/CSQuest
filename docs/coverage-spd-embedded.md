# SPD-Embedded：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.305–306。[既存調査](spd-embedded.md)と照合。子項目を記載した箇所は集計時に親と重複させない。すべて KA Core。固定例は実機の開発や安全性を直接評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1a | KA Core | リアルタイム、ソフトリアルタイム、非リアルタイム | 部分 | 依頼133で２仕事の期限を扱い、期限超過を許せるかの違いに触れる。用途別の体系的な比較は未対応 |
| 1b | KA Core | メモリや期限などの資源制約 | 部分 | 依頼133で期限、387で空き領域の割当を別々に操作。組込み機器全体の資源設計は未対応 |
| 2a | KA Core | GPU 技術のための API | 未照合 | 依頼162で SIMD・MIMD を比較する模型のみ。GPU API は未対応 |
| 2b | KA Core | FPGA のための API | 未照合 | 依頼６・37で論理回路の固定例。FPGA の開発環境や API は未対応 |
| 2c | KA Core | 異なるプラットフォームをまたぐシステム | 未照合 | 対応例を要照合。 |
| 3a | KA Core | マイクロコントローラー | 未照合 | 実機と構成は未対応 |
| 3b | KA Core | 割込みとフィードバック | 部分 | 依頼105で完了通知、219で光の測定と角度の操作を別々に体験。実際の割込みと閉ループ制御は未対応 |
| 3c | KA Core | 高水準言語の割込みハンドラー | 部分 | 依頼105で通知後の処理と復帰を操作。実言語での実装は未対応 |
| 3d | KA Core | ハード・ソフト割込みとトラップからの復帰 | 部分 | 依頼105で単一通知からの復帰のみ。種類と実装の区別は未対応 |
| 3e | KA Core | ハードウェア、アクチュエーター、センサーとのやりとり | 部分 | 依頼219で読み取り・目標送信・角度の変化を操作。実機・電気信号は未対応 |
| 3f | KA Core | エネルギー効率 | 部分 | 依頼161で固定の時間・電力からエネルギーを比較。組込み実機の測定や設計は未対応 |
| 3g | KA Core | 緩い時間制約のコードと同期 | 未照合 | 対応例を要照合。 |
| 3h | KA Core | ソフトウェアアダプター | 未照合 | 対応例を要照合。 |
| 4 | KA Core | 組込みプログラミング | 未照合 | 実際のプログラムの作成・デバッグは未対応 |
| 5a | KA Core | ハード・ソフトリアルタイムと適時性 | 部分 | 依頼133で期限を超える順序と間に合う順序を比較。一般の保証は未対応 |
| 5b | KA Core | 時刻の同期とスケジューリング | 部分 | 依頼133で２仕事の順序、420で相対待機と基準時刻に基づく周期・超過時の固定例を操作。時計の同期や一般のスケジューリングは未対応 |
| 5c | KA Core | 優先順位 | 部分 | 依頼134で固定した優先度逆転と優先度継承を操作。一般の優先度設計は未対応 |
| 5d | KA Core | 遅延 | 部分 | 依頼395で検知から停止までの距離を比較。処理遅延の内訳や実測は未対応 |
| 5e | KA Core | 実行時間の揺らぎ | 部分 | 依頼420で仕事時間の違いが開始間隔に与える影響と周期を超過した場合を操作。割込み、実測や一般的な解析は未対応 |
| 6 | KA Core | リアルタイム資源管理 | 部分 | 依頼133・134の固定されたスケジュールのみ。一般の資源管理は未対応 |
| 7a | KA Core | 変数とメモリ位置の対応 | 部分 | 依頼197で値を箱に写す模型のみ。実際のアドレスへの配置は未対応 |
| 7b | KA Core | 共有メモリ | 部分 | 依頼179で同一・別プロセスの共有状態を比較。組込み特有の共有と実装は未対応 |
| 7c | KA Core | 手動のメモリ管理 | 部分 | 依頼203で寿命の切れた参照を操作。実際の確保・解放と資源制約下の設計は未対応 |
| 7d | KA Core | ガーベジコレクション | 部分 | 依頼201で到達可能性に基づく回収の固定例。リアルタイム性への影響や実装は未対応 |
| 8 | KA Core | 安全への配慮と安全性分析 | 部分 | 依頼395で検知と停止距離を扱う。実機の危険分析や安全性保証は未対応 |
| 9 | KA Core | センサーとアクチュエーター | 部分 | 依頼219〜222で読み取り、角度、揺れ、量子化と標本化の固定模型。実装・実機は未対応 |
| 10 | KA Core | 分析と検証 | 部分 | 依頼133・395は与えられた条件での固定例。組込み装置の一般的な検証は未対応 |
| 11 | KA Core | アプリケーション設計 | 部分 | 依頼219の読み取りと駆動の模型のみ。実機のアプリケーション設計は未対応 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 代替と限界 |
|---|---|---|---|---|
| 1 | KA Core | 指定プラットフォーム向けの小さな組込みシステムの設計・実装 | 部分 | 依頼219で読み取りから駆動までの模型を操作。実機の設計・実装は直接練習・評価しない |
| 2 | KA Core | 組込みシステム固有の特徴の説明 | 部分 | 依頼133・219で期限と物理世界とのやりとりの一部を体験。特徴の体系的比較や自由な説明は未対応 |
| 3 | KA Core | センサー・アクチュエーターとの接続 | 部分 | 依頼219〜222で固定模型を操作。実機の接続は直接練習・評価しない |
| 4 | KA Core | 既存の組込みプラットフォームの問題のデバッグ | 未照合 | 対応例を要照合。 |
| 5 | KA Core | 組込みアーキテクチャの種類の識別 | 部分 | 依頼162・163で SIMD・MIMD と専用機械の模型を比較。組込みアーキテクチャ全般の識別は未対応 |
| 6 | KA Core | 要件に合うアーキテクチャの評価 | 部分 | 依頼163で固定費用と処理量を比べる模型。組込みの要件全般や実機評価は未対応 |
| 7 | KA Core | ハードウェアとやりとりし制御するソフトウェアの設計・開発 | 部分 | 依頼219の固定された読み取り・駆動操作のみ。実際のソフトウェアの設計・開発は直接練習・評価しない |
| 8 | KA Core | リアルタイムシステムの設計手法 | 部分 | 依頼133・134で期限と優先度継承、420で２種類の周期待機の固定例。一般の設計手法は未対応 |
| 9 | KA Core | リアルタイムスケジューリングとスケジュール可能性の評価 | 部分 | 依頼133で２仕事の３刻、757で周期４・６の仕事を12刻にわたり比較。一般の到着や実行時間での解析は未評価 |
| 10 | KA Core | 時間制約・性質の形式仕様と検証の評価 | 未照合 | 対応例を要照合。 |

関連する各模型の前提・検証は [既存調査](spd-embedded.md)、[リアルタイム OS](os-real-time.md) と [物理コンピューティング](git-physical.md)を参照。未照合は未実装の証拠ではない。
