`tests/unification.test.js`、`tests/horn-routes.test.js`、`tests/horn-search.test.js`、`tests/recursive-path.test.js`、`tests/horn-cut.test.js`、`tests/narrowing.test.js`、`tests/fib-tabling.test.js` は固定模型・操作を検査し、原典の全範囲や学習効果を保証しない。

依頼1171は [Cornell の事実・規則・問い合わせ](https://www.cs.cornell.edu/courses/cs4110/2025fa/lectures/slides34.pdf)を参考に、依頼147の道の事実を再利用し、全称含意の具体例と確定 Horn 節、逆向きの主張を比較。`tests/horn-meaning.test.js` は８真偽と道の２導出、保存・達成を検査する。一般の一階論理の変換や実言語は未評価。

依頼1235は [Carnegie Mellon の量化の講義](https://www.cs.cmu.edu/~iliano/courses/14S-CMU-CS317/dl/quantifiers.pdf)を参考に、２人の個体とその４つの部分集合を単項性質の候補とする有限模型。固定された青い灯りについて個体を量化する２問と、性質も量化する４問を比べる。`tests/predicate-quantifiers.test.js` は４候補の真偽、観察・回答・保存復元を検査。配信用画面で観察不足、誤答の理由・再開・達成、320・390・1280px幅とキーボードを確認。他の意味論、任意の構造や論理言語の実装・自由な証明は未評価。

依頼1236は [SWI-Prolog の append/3](https://www.swi-prolog.org/pldoc/man?predicate=append%2F3)を参考に、空列の基本規則と先頭を預けて戻す再帰を、２列の連結と未知の２列の分割に使う固定模型。分割は空を含む３解を順に探索し、最後に探索が尽きる。`tests/list-relation.test.js` は結果の順序、３解、操作順・復元を検査。配信用画面で誤操作・途中再開・両方向・達成、320・390・1280px幅とキーボードを確認。実際の Prolog 記述、任意の項の単一化、循環リスト、一般の停止や性能は評価しない。

依頼1237は [SWI-Prolog の有限領域制約](https://www.swi-prolog.org/man/clpfd.html)を参考に、X・Y の有限候補１〜４、合計５と X < Y を扱う固定模型。条件ごとに相手の候補に対応しない値を同時に除き、X の仮定、空領域からの後戻り、２解の記録を操作する。`tests/finite-constraint.test.js` は候補集合の組合せと各条件の対応、矛盾・復元・２解を検査。配信用画面で誤操作・矛盾・再開・２解・振り返り、320・390・1280px幅とキーボードを確認。条件ごとの局所的な絞り込みで一般の制約充足を保証せず、実際の CLP 言語、汎用ソルバー、高階・帰納論理プログラミングは評価しない。

依頼1238は [Carnegie Mellon の差分リスト](https://www.cs.cmu.edu/afs/cs/Web/People/fp/courses/lp/lectures/11-diff.pdf)を参考に、既に開いた末尾を持つ列の接続と、前の列を写してから接続する固定模型を０・２・４要素で比較する。開口を共有し、後ろの開口を閉じた結果を表示する。`tests/difference-list.test.js` は６条件の列・写す数・操作順・保存を検査。配信用画面で誤操作・再開・６条件・達成、320・390・1280px幅とキーボードを確認。閉じた列を開く費用、循環、実際の Prolog や実測性能は評価しない。

依頼1237は解の記録を保持したまま候補を初期値へ戻せるよう修正。２解を先に記録してから矛盾を試し、途中再開と達成ができることを画面と `tests/finite-constraint.test.js` で確認した。

依頼1239は [Oxford の帰納論理プログラミング研究](https://www.cs.ox.ac.uk/files/232/ox_working_papers2.pdf)を参考に、完全と仮定した５本の有向道、正負４手本と３候補を比較する。２本の道の規則と２組だけを記憶する規則はいずれも手本に一致し、候補選択後の別３例で A→F の予想が異なる。`tests/inductive-routes.test.js` は候補の手本一致、両選択、手本と試験の重複なし、保存・達成を検査。配信用画面で早期選択・誤答・未使用例の相違・再開・達成、320・390・1280px幅とキーボードを確認。固定例・候補の比較であり、試験を再利用できるため独立した性能推定や一般の自動規則発見を示さない。
