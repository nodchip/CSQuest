# MSF-Discrete の対応状況

出典: [CS2023 MSF-Discrete](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 187–188。原典を要約した作業用一覧。KA Core は CS Core と同じトピックをより深く扱う。依頼46は有限集合の固定例であり、自由な数学的証明を評価しない。

## トピック

| 番号 | 分類 | 内容と現状 |
|---:|---|---|
| 1 | CS Core / KA Core | 集合、関係、関数、濃度 | 依頼46で７人の和・共通部分・差・補集合と人数。一般の関係、関数、無限集合は未対応 |
| 2 | CS Core / KA Core | 再帰的な数学的定義 | 依頼33で並べ方の個数を小さい問題に帰着。一般の定義・漸化式は未対応 |
| 3 | CS Core / KA Core | 帰納法、背理法などの証明法 | 未着手 |
| 4 | CS Core / KA Core | 順列、組合せ、数え上げ、鳩の巣原理 | 依頼33で異なる物の並べ方、依頼46で包除の固定例。一般の数え上げと証明は未対応 |
| 5 | CS Core / KA Core | 合同算術 | 依頼19で３による余りの固定例。一般の計算は未対応 |
| 6 | CS Core / KA Core | 論理、真理値表、演算、推論規則、標準形、述語論理 | 依頼06で２入力の真理値表。一般の論理式・述語・証明は未対応 |
| 7 | CS Core / KA Core | グラフの基本 | 依頼08・21・32などで固定グラフを操作。一般の定義や構成は未対応 |
| 8 | CS Core / KA Core | オーダー記法 | 未着手 |
