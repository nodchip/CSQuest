# OS-SEP：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.215。[既存調査](os-society.md)と照合。すべて KA Core。原典の「例示概念」はトピックそのものと区別し、親・例を重複計上しない。実 OS の性質や法的判断は架空の模型だけでは評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | KA Core | OS におけるオープンソース | 部分 | 846で公開された修正の調査・適用とその限界を扱う架空例。実際の開発や修正は未評価。 |
| 1-例a | KA Core・例 | 公開カーネルの脆弱性の特定 | 部分 | 846で報告済みの架空の欠陥と修正を確認。実カーネルの欠陥を発見する能力は未評価。 |
| 1-例b | KA Core・例 | オープンソースのゲスト OS | 部分 | 846でゲストを別に検証・更新。実際の OS 操作は未評価。 |
| 1-例c | KA Core・例 | オープンソースのホスト OS | 部分 | 846でホストを別に検証・更新。実際の OS 操作は未評価。 |
| 1-例d | KA Core・例 | 更新の有償・無償と収益化 | 部分 | 857で無償更新・有償支援・専用版の架空条件を比較。実製品の価格や契約は未評価。 |
| 2 | KA Core | OS のサポート終了 | 部分 | 361で修正提供の終了と互換性・控え・移行を操作。実 OS の期限と移行は未評価。 |
| 例示-プライバシー | KA Core・例 | 独自仕様環境の送信・走査・広告・クラウド | 部分 | 361で架空の任意の利用状況送信を比較。他の項目と実 OS の送信は未評価。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 代替と限界 |
|---|---|---|---|---|
| 1 | KA Core | 公開カーネルのバグ発見と対処の長短 | 部分 | 846で公開による調査機会と、修正・適用が自動ではない点を比較。実際の発見・対応や自由な説明は未評価。 |
| 2 | KA Core | Linux の歴史とオープンソースの影響 | 部分 | 857で GNU 計画、Linux 0.01、GNU 条件への移行と公開による調査機会・限界を扱う。歴史全体や影響の一般的分析は未評価。 |
| 3 | KA Core | サポート終了後の OS 依存の問題 | 部分 | 361で修正提供の終了と互換性の固定例。一般の問題の列挙は未評価。 |
| 4 | KA Core | 課金方式とバグ発見・対処の違い | 部分 | 846・857で公開による調査機会と、無償更新・有償の応答契約を区別。実際の発見率、修正時間や契約全般は未評価。 |

361は架空の互換性・送信設定を扱い、実 OS の安全性を保証しない。詳細は[既存調査](os-society.md)を参照。
