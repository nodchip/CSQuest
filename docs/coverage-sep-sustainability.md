# SEP-Sustainability：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.281–282。[既存の調査](sep-sustainability.md)と依頼を照合。状態は[追跡方法](coverage-status.md)に従う。「未照合」は未実装を意味しない。架空の点数による計算は現実の環境・社会・経済への影響評価を証明しない。

## トピック

| 番号 | 区分 | 内容 | 状態 | 対応と限界 |
|---|---|---|---|---|
| 1 | CS Core | 実装判断の環境・社会・文化への影響 | 部分 | 91・802 は架空の負荷と集計範囲を比較。社会・文化・経済の影響は未評価。 |
| 2 | CS Core | 計算機の使用・製造・廃棄による地域・世界の影響 | 部分 | 91・802 は使用と製造の架空モデル。廃棄、供給網と実測は未評価。 |
| 3 | CS Core | 持続可能な設計標準の指針 | 未照合 | 標準と具体的な適用の照合が必要。 |
| 4 | KA Core | 複雑な技術のシステム的影響 | 部分 | 802 は利用回数を変えた架空の総負荷を比較。実際のシステム全体や因果関係は未評価。 |
| 5 | KA Core | 日常に組み込まれた情報処理と持続可能性 | 未照合 | 環境監視や交通等の具体的適用を確認する必要がある。 |
| 6 | KA Core | 社会システムとソフトウェアの相互依存 | 部分 | 802 は利用回数の仮定による違いを示す。利用者の技能、組織、政策や因果関係は未評価。 |

## 例示学習成果

| 番号 | 区分 | 内容 | 状態 | 対応と限界 |
|---|---|---|---|---|
| 1 | CS Core | 特定分野・企画で持続可能に行動する方法 | 未照合 | 実際の企画での行動は未評価。 |
| 2 | CS Core | 導入に伴う環境影響を評価 | 部分 | 91・802 の架空の集計範囲・期間。実際の環境影響や廃棄は未評価。 |
| 3 | CS Core | 計算機使用と廃棄の世界的影響 | 未照合 | 世界・地域の実例と廃棄の照合が必要。 |
| 4 | CS Core | 現代の活動による持続可能性への影響 | 未照合 | リモートワーク・データセンター等の具体的影響は未評価。 |
| 5 | KA Core | 分野別の設計選択と環境影響 | 未照合 | アルゴリズム・OS・通信等の設計との照合が必要。 |
| 6 | KA Core | 新システムの社会・環境影響を分析 | 部分 | 802 は架空の新装置の環境負荷指標を比較。社会的影響や実証分析は未評価。 |
| 7 | KA Core | 持続可能な設計・導入の指針を作成 | 未照合 | 実際の指針作成は未評価。 |
| 8 | KA Core | 情報技術の応用を環境面から評価 | 部分 | 802 は使用回数と製造を含む架空の点数を比較。実際の影響評価や他の環境課題は未評価。 |

依頼802は、５年の比較で旧装置の使用を年４回・１回６点、新装置を年４・８・12回・１回３点、追加の製造を12点と仮定する。使用時は旧120点に対し新60・120・180点、製造を含めると72・132・192点。利用増加は外から与えた仮定であり、効率化が利用増加を引き起こすと証明しない。負荷点は架空の共通指標で、廃棄・供給網・電源・社会的影響・便益は含まない。６条件を独立した期待値と照合した。参考：[European Environment Agency: デジタル化と環境への影響](https://www.eea.europa.eu/en/analysis/publications/navigating-europes-twin-transition-opportunities-and-challenges-of-digitalisation-in-the-green-transition)。
