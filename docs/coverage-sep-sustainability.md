# SEP-Sustainability：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.281–282。[既存の調査](sep-sustainability.md)と依頼を照合。状態は[追跡方法](coverage-status.md)に従う。「未照合」は未実装を意味しない。架空の点数による計算は現実の環境・社会・経済への影響評価を証明しない。

## トピック

| 番号 | 区分 | 内容 | 状態 | 対応と限界 |
|---|---|---|---|---|
| 1 | CS Core | 実装判断の環境・社会・文化への影響 | 部分 | 91・802 は架空の負荷と集計範囲を比較。社会・文化・経済の影響は未評価。 |
| 2 | CS Core | 計算機の使用・製造・廃棄による地域・世界の影響 | 部分 | 91・802 は使用と製造の架空モデル、860は世界の電子廃棄物推計。地域差、供給網と実測は未評価。 |
| 3 | CS Core | 持続可能な設計標準の指針 | 部分 | 858で ENERGY STAR の待機時間の一部を参考に架空の設定を比較。製品認証や基準全体は未評価。 |
| 4 | KA Core | 複雑な技術のシステム的影響 | 部分 | 802 は利用回数を変えた架空の総負荷を比較。実際のシステム全体や因果関係は未評価。 |
| 5 | KA Core | 日常に組み込まれた情報処理と持続可能性 | 部分 | 859で環境監視の観測間隔・欠測を架空模型で比較。実測、交通や社会的応用は未評価。 |
| 6 | KA Core | 社会システムとソフトウェアの相互依存 | 部分 | 802 は利用回数の仮定による違いを示す。利用者の技能、組織、政策や因果関係は未評価。 |

## 例示学習成果

| 番号 | 区分 | 内容 | 状態 | 対応と限界 |
|---|---|---|---|---|
| 1 | CS Core | 特定分野・企画で持続可能に行動する方法 | 部分 | 1301で工房の修理・新調を期間・予算・停止時間と架空の負荷点で比較し選択。実際の企画での行動は未評価。 |
| 2 | CS Core | 導入に伴う環境影響を評価 | 部分 | 91・802 の架空の集計範囲・期間。実際の環境影響や廃棄は未評価。 |
| 3 | CS Core | 計算機使用と廃棄の世界的影響 | 部分 | 860で電子廃棄物全体の世界推計と不適切な処理の健康リスクを扱う。機器別・地域別の実態や自由な説明は未評価。 |
| 4 | CS Core | 現代の活動による持続可能性への影響 | 部分 | 依頼1208で在宅勤務の移動・家庭・建物・通信の架空負荷を比較。実測や活動全般は未評価。 |
| 5 | KA Core | 分野別の設計選択と環境影響 | 未照合 | アルゴリズム・OS・通信等の設計との照合が必要。 |
| 6 | KA Core | 新システムの社会・環境影響を分析 | 部分 | 802 は架空の新装置の環境負荷指標を比較。社会的影響や実証分析は未評価。 |
| 7 | KA Core | 持続可能な設計・導入の指針を作成 | 未照合 | 実際の指針作成は未評価。 |
| 8 | KA Core | 情報技術の応用を環境面から評価 | 部分 | 802 は使用回数と製造の架空比較、859は環境監視の観測と消費の模型。実際の影響評価は未評価。 |

依頼802は、５年の比較で旧装置の使用を年４回・１回６点、新装置を年４・８・12回・１回３点、追加の製造を12点と仮定する。使用時は旧120点に対し新60・120・180点、製造を含めると72・132・192点。利用増加は外から与えた仮定であり、効率化が利用増加を引き起こすと証明しない。負荷点は架空の共通指標で、廃棄・供給網・電源・社会的影響・便益は含まない。６条件を独立した期待値と照合した。参考：[European Environment Agency: デジタル化と環境への影響](https://www.eea.europa.eu/en/analysis/publications/navigating-europes-twin-transition-opportunities-and-challenges-of-digitalisation-in-the-green-transition)。

依頼1208は [IEA の在宅勤務とエネルギーの解説](https://www.iea.org/commentaries/working-from-home-can-save-energy-and-reduce-emissions-but-how-much)を参考に、４人・１日について移動、建物、家庭、通信の架空の負荷点を比較する。８通りの前提を `tests/remote-impact.test.js` で検査。数値は実排出量ではなく、電源、非通勤移動、製造・廃棄、社会面や実際の環境影響は評価しない。

依頼1301は91の架空の修理・新調モデルを使い、３工房の利用期間・予算・停止時間の制約を満たす案から負荷点の小さい案を選ぶ。`tests/sustainability-project.test.js` は合計、制約、達成条件と復元を検査する。修理・新調の費用と停止時間も仮定であり、故障や廃棄、利用者・作業者への影響や実測は評価しない。参考：[米国 EPA：電子機器の環境面を考える](https://www.epa.gov/greenerproducts/identifying-greener-electronics)。
