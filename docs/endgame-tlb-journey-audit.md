# アドレス空間と TLB の控え：教材監査

[CS2023 OS-Memory 印字210–211頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=210) のアドレス空間と変換キャッシュを扱う固定例。旧 `src/tlb-switch.js` の依頼485は同じ３方式を旧画面で操作できる。現行の `endgame-pages.js` は固定の頁変換、`endgame-cow-pages.js` は共有・書込み時複製を扱い、空間切替時の TLB を直接は扱わない。今回は旧模型を再利用して現在の冒険へ接続する。

ＰとＱの仮想頁10はそれぞれ物理枠１・２。控えは初め空で、Ｐ読取→Ｑへ切替→Ｑ読取→Ｐへ切替→Ｐ読取。空間の識別なしに残す不正な模型は miss1・hit1・hit1 で、ＱがＰの枠を誤って使う。切替時消去は miss1・miss2・miss1。空間の印で照合する模型は miss1・miss2・hit1。控えがなければ現在の頁表から取得する。

固定例は容量十分、頁表不変、空間の印を再利用しない前提。印を付けても必ずヒットするわけではなく、実機の容量・置換、頁表更新時の無効化、印の再利用、他 CPU、権限、実際の性能は未評価。仮想頁の下位オフセットも省略する。[Wisconsin の TLB とコンテキスト切替](https://pages.cs.wisc.edu/~remzi/OSTEP/vm-tlbs.pdf) を参照。

2026-11-11、実装担当と別の `signed_review` が原典と [xv6 の頁表資料](https://pdos.csail.mit.edu/6.S081/2024/xv6/book-riscv-rev4.pdf) に照らし、固定３方式の変換・ヒット／ミスと頁表の前提、画面・保存・開放を独立レビューした。親担当が準備済み記録から幅 213・390・1200 px の駅の分類に到達し、誤答、キーボード、途中保存・再開、開放条件、達成後の保存をブラウザ確認した。新規開始からの通し操作、スクリーンリーダー音声、利用者による面白さは未確認。
