# SF-Overview：コンピュータシステムの概要

出典：[CS2023 SF-Overview](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 292–293。原典の項目を要約し、既存教材との接点と不足を整理する。すべて CS Core。固定模型は一般的な説明や実プログラムの作成能力を証明しない。

## トピック

| 番号 | 内容 | 現状と限界 |
|---:|---|---|
| 1 | ゲート、フリップフロップ、レジスタ、接続、データ経路、制御、メモリ | 依頼06・37で組合せ回路、73で架空命令の処理。順序回路や構成全体は未対応 |
| 2 | 論理回路、論理式、簡単化、積和形 | 依頼06でゲートを組み合わせる固定例。一般の簡単化や積和形は未対応 |
| 3 | プログラミングの抽象化、インターフェース、ライブラリ | 他分野の部品利用の例はあるが、ライブラリの利用と抽象化は未対応 |
| 4 | アプリと OS サービスの区別・連携、遠隔手続き呼出し | 依頼54で装置への要求の固定例。遠隔手続き呼出しは未対応 |
| 5 | パイプラインと処理段階の重なり | 依頼158で架空の３段階とデータ依存の固定例。一般の解析は未対応 |
| 6 | 問題規模と性能のスケーリング | 依頼66で固定の計算と比較。一般の規模・性能の関係は未対応 |
