# PDC-Programs：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.219–223。既存の調査と依頼・テストを照合。状態は[追跡方法](coverage-status.md)に従う。原典で子項目がある場合は子項目を数え、親を重複して数えない。KA Core の「１つ以上を選ぶ」構成も項目ごとに追跡する。固定模型は実プログラムの記述・実行能力を直接評価しない。

既存の調査：[pdc-programs.md](pdc-programs.md)。
