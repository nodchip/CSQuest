# IPv4 の MTU と断片：教材監査

[CS2023 NC-Routing 印字199–200頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=199) の IP パケット転送に関連する固定例。現行の転送表・送信窓・TCP 接続準備は経路や通信制御を扱い、この依頼は IPv4 のヘッダーと断片化を扱う。

オプションなしの IPv4、元データ2480バイト、ヘッダー20バイト、全長2500バイト、MTU 1000バイト、DF=0、元パケットは未分割。各断片のヘッダーも20バイト。非最終断片はデータ長を８の倍数とし、最大の976を２回、残り528とする。各全長996・996・548、元データ先頭からの８バイト単位オフセットは0・122・244、MF は1・1・0。分割は他にもあり得るがこの例は非最終断片を最大にする。

再分割、IP オプション、DF=1、欠落・順序・再送・再構成、ヘッダーチェックサム、経路 MTU 探索、IPv6、実通信や一般の実装を評価しない。[RFC 791 の IPv4](https://www.rfc-editor.org/rfc/rfc791.html) を参照。

## 独立レビューと動作確認

実装担当と別の担当が RFC 791 と断片長・全長・位置・MF および模型の前提を確認。ローカルで集いと４地域の達成状態を用意した記録から、幅 213・390・1200 px で誤答、キーボード、途中保存・再開と達成を確認した。冒険開始からの通し到達は含まない。
