# 原典との範囲照合：GIT-Rendering

[CS2023 印字 pp.157–158](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)を照合した。トピックと例示学習成果はすべて KA Core。原典の親１〜４と各行の区分を追加し、親子20トピック行と14成果行を記録した。親子は重複するため、行数を独立した項目数や完成率として扱わない。

既存の依頼は描画の各段階や光の固定模型、固定立方体の WebGL 描画、限られたミップマップと三線形補間の例を扱う。一般の光輸送・描画手法、一般の画像とフィルタ、自由な形状、透過、一般のカメラ姿勢などは未評価。ゲーム内操作で実際のプログラムやシェーダーを書く能力、自由な説明能力は証明しない。

この照合は原典の対象範囲と区分についての確認であり、各教材の正確性、学習効果や全教材の完成を証明しない。
