# 確認窓の操作位置：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字177〜178頁の HCI-Accessibility のキーボード操作・支援技術に関連する固定例。旧依頼575 `src/focus-dialog.js` の案内窓を参照し、現行の案内所で初期位置・窓内の両方向移動・閉じた後の戻り先を操作する。
- [W3C APG Modal Dialog Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) は窓内の Tab／Shift+Tab の循環、Escape、閉じた後の論理的な位置を説明する。初期位置は文脈によって異なり、呼出元が残る場合にも別の位置が自然な例外がある。
- 模型は短く危険な操作がない窓で、開いた後に「確認」へ位置を置き、確認→閉じる→確認→閉じると Tab・Tab・Shift+Tab を試す。Escape 後は、この例では元のボタンに戻る。元のボタンが消えた例では、操作位置を置ける更新後の見出しを代替先とする。
- 学習用の状態とボタンによる固定模型であり、実際のブラウザ・支援技術・WCAG 全体の適合や一般の窓設計を評価しない。旧教材や本教材の存在を原典全体の完成とはしない。
