# 項目別評価：AI-Search の非ヒューリスティック探索

2026-11-05 に [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.68–69、依頼08・369の実装・試験・公開版を照合した。対象はトピック４と例示学習成果２の２行。他の項目の完成を示さない。

## 原典と判定

トピック４はグラフ探索の時間・空間計算量、成果２は問題に合う非ヒューリスティック探索の選択・実装と計算量の特徴づけを求める。両方とも**部分対応**。依頼08は等長の双方向の道で、発見済み地点を再追加せず幅優先で調べ、最短の道の本数を求める。依頼369は深さ３の有限木で幅優先と反復深化を操作し、候補数上限に合う方式を選ぶ。実装や一般的な問題に対する方式選択・計算量の分析は直接評価しない。

## 内容・正答の確認

幅優先が FIFO、深さ優先が LIFO を使うこと、最短辺数と探索順の関係は [Poole・Mackworth の探索の説明](https://www.cs.ubc.ca/~poole/aibook/3e/html/ArtInt3e.Ch3.S5.html)と照合。依頼08の道は双方向・同一費用で、入口から調査隊まで３本の道があり、２本以下の道はない。発見時に記録した親から `S→B→E→G` を復元する。

依頼369の指定された木では、幅優先14回・候補最大８、反復深化25回・候補最大４で、目標はどちらも深さ３。候補４件では反復深化、８件では調査回数の少ない幅優先、３件ではどちらも入らない。これは表示された２手順をそのまま実行する場合であり、候補を捨てる別のアルゴリズムを否定しない。

深さ d の完全二分木で左から探索する追加の実験では、総数は 2^(d+1)−1。左端の最深葉まで幅優先は 2^d 回、深さ優先は d+1 回、右端まで両方とも全節を調べる。待機候補数はメモリ全体ではない。探索の調査回数は実行時間の実測でもなく、JavaScript 配列操作や描画を含む計算量をこの数だけから証明できない。深さ２〜６と左右端の限定例で、学習者が一般のグラフの漸近計算量を分析できるかは未評価。

追加の循環地図は S↔A↔B と孤立した G を持つ。発見時に印を付ける幅優先は S・A・B を１回ずつ調べて候補が尽き、印を使わない方法は８回の観察後も候補が残る。到達地点のどれも隣接地点を持つので、この規則では候補を１つ取り出すたびに少なくとも１つ加え、探索は終わらない。[Poole・Mackworth の循環と重複経路](https://www.cs.ubc.ca/~poole/aibook/3e/html/ArtInt3e.Ch3.S7.html)と照合。一般の幅優先については隣接リストと定数時間の発見判定・キュー操作を仮定した O(V+E) 時間と O(V) の追加空間を説明するが、任意のグラフの分析能力や実装の実測は評価しない。
