# 再帰と答えの記録：教材監査

[CS2023 AL-Strategies 印字90–91頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=90) の動的計画法・重複する部分問題を扱う固定例。旧 `src/fib-tabling.js` の依頼777を再利用し、現行工房へ接続。現行の再帰は札・箱、品札計画は別の動的計画法の模型を扱う。

F(0)=0、F(1)=1、F(n)=F(n−1)+F(n−2)。F(5)=5 を左側の問いから計算。記録なしは呼出し15・記録を使わず基底または分解に入る回数15、再利用０。記録ありは呼出し９・同回数６・再利用３。最初の F(5)、基底、記録に当たる問いも呼出しに含む。「計算」は基底または分解に入った回数で足し算回数や実時間ではない。記録は各依頼で空から始め、答えを返すとき保存する。

これは再帰にメモ化を加える方式であり、下から表を埋める方式とは別。固定入力と順序、有限の計数のみで、任意の再帰・一般の複雑度・記録の領域費用・実行時間や性能は評価しない。[MIT の動的計画法とメモ化](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/3eb48db83a86800455567bc7daa7c0f9_OQ5jsbhAv_M.pdf) を参照。
