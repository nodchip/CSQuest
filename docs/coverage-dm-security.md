# DM-Security：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.121。[追跡方法](coverage-status.md)に従う。未照合は未実装の証拠ではない。固定模型は実際の安全性や法令適合を保証しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | CS Core | 安全性とプライバシーの違い | 部分 | 194で収集・通信・閲覧を独立に操作。一般の文脈での説明は未評価。 |
| 2 | CS Core | インジェクション等への防御 | 部分 | 82で検索条件、180で権限の固定模型。実 DB と攻撃全般は未評価。 |
| 3 | CS Core | 個人を識別する情報と保護 | 部分 | 27・194で収集範囲や番号を扱う。実データの識別可能性評価は未対応。 |
| 4 | CS Core | データ保護の倫理 | 部分 | 27・63・194で架空の収集・関係者を比較。体系的な倫理分析は未評価。 |
| 5 | KA Core | 保存・通信・処理中の保護 | 部分 | 180で媒体、194で通信・閲覧の固定模型。処理中や実装の保護は未評価。 |
| 6 | KA Core | 監査とフォレンジック | 部分 | 195で記録項目と調査の手がかりを選び、別権限の控えと記録前の停止を比較。実際の証拠保全や調査は未評価。 |
| 7 | KA Core | データからの推論と攻撃防止 | 部分 | 196で重なる集計と人数制限を比較。一般の攻撃と防止の保証は未評価。 |
| 8 | KA Core | 関連する法令・規制 | 未照合 | 法域に応じた教材は未確認。 |
| 9 | Non-core | 完全性の危険因子と予防 | 未照合 | 関連する依頼を原典の範囲と照合していない。 |
| 10 | Non-core | ランサムウェア・データ損失等の防止 | 部分 | 181で消失・破損からの写しの復元を操作。ランサムウェアや実際の対策は未評価。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | CS Core | 安全性とプライバシーの目的の違いを説明 | 部分 | 194で不要な収集と通信・閲覧の保護を比較。自由な説明は未評価。 |
| 2 | CS Core | 異なる保護方法のリスクを特定・軽減 | 部分 | 194で３場面を比較。実装の脅威分析や一般的な軽減は未評価。 |
| 3 | CS Core | データの安全とプライバシーの法的・倫理的考慮 | 部分 | 27・63の架空の関係者と範囲を比較。法令や自由な説明は未評価。 |
| 4 | KA Core | リスクを考慮した DB 監査システムの開発 | 部分 | 195で記録項目と架空の要求を検討。実システムの開発・運用は未評価。 |
| 5 | KA Core | 未知のデータ集合を理解する探索 | 部分 | 111〜115で可視化・集計の固定例。未知の実データの探索は未評価。 |
