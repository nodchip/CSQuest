## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | CS Core | データ構造の性質・表現・操作と状態変化を説明 | 未着手 |
| 2 | CS Core | アルゴリズムの動作を段階的に説明 | 整列に向けた交換の体験のみ。一般のアルゴリズムや自由記述の説明は未対応 |
| 3 | CS Core | 代表的なアルゴリズムを適用 | 整列の隣接交換を試作。代表的な整列手順を系統的に適用する課題は未対応 |
| 4 | CS Core | 複数の解法を作り、要件に対して評価・選択 | 未着手 |
| 5 | CS Core | ハッシュ表の衝突の回避と解決の説明 | 未着手 |
| 6 | CS Core | 効率以外の選択要因の説明 | 未着手 |
| 7 | CS Core | ヒープの性質と優先度付きキューへの利用 | 未着手 |
| 8 | KA Core | KA Core の代表的手法と動作を説明 | 未着手 |
| 9 | Non-core | 量子計算とその応用への理解 | 未着手 |

この試作は、固定の４個の値を自由に隣接交換するもの。アルゴリズムの指示に従って整列することや、一般の入力に対する正しさ・計算量の習得は検証していない。
