整列の試作は、固定の４個の値を自由に隣接交換するもの。探索の試作は、固定の重みのないグラフで待ち行列の先頭を選び、到達経路を確認するもの。重み付き最短路の試作では、候補の最小値を選んで更新を確認する。一般の入力に対する正しさ・計算量や、これらの成果全体の習得は検証していない。

依頼713は残りを順に比較して最小を選び、先頭と交換する選択ソート。４個の列と、2A・2B・1C が 1C・2B・2A になる不安定な例を操作する。３種類の値からなる４要素の全81入力を独立した整列結果と比較し、比較６回を確認した。画面の例は固定され、任意の長さでの操作や一般の正しさの証明は扱わない。

依頼714は ABAB・AAAB の各接頭部分で、全体を除いた最長の共通の接頭辞・接尾辞の長さを選び、表を用いて ABABAB・AABAAAAB を探索する。発見後も重なりの長さに戻ることで、前者の１・３文字目の両方を見つける。２文字からなるパターン長１〜４と本文長１〜６の全組合せについて、結果を単純な部分文字列比較と照合した。固定例であり、任意の文字列を入力する機能、Unicode の扱いや一般の正しさ・計算量の証明は扱わない。参考：[Princeton University: Substring Search](https://algs4.cs.princeton.edu/53substring/)。

依頼714の不一致時は、現在一致している部分を表示し、残す長さを表から選ぶ。誤った長さでは進まず、正しい長さでは本文の位置を保って次の比較を行う。旧形式の途中記録は過去の戻る操作を同じ正しい長さの選択として読み込む。合図発見直後の戻りは自動処理する。

依頼19は整数の鍵を３で割った余りで棚を決め、同じ棚では挿入順に鍵を比較する固定例。連鎖法の一例であり、計算量の一般的な解析やハッシュ関数の選択は評価していない。

依頼21は固定グラフで隣接地点を名前順に選ぶ深さ優先探索。足あとのスタックと訪問済み集合を表示し、行き止まりから戻る。別の探索順や一般的な計算量は評価していない。

依頼29は昇順の８件から既存・不在の２番号を線形・二分探索し、比較回数を比べる固定例。探索の一般的な正しさの証明と計算量の導出は未対応。

依頼32は５村・８候補の双方向グラフ２例で、費用順に輪を作らない橋を建てるクラスカル法を操作する。各例の最小費用は全域木候補の独立した列挙で検証。重みが同じ場合や一般の正しさの証明は未対応。

依頼55は４個の値に印をつけた２例を下からマージし、同じ値を左から優先して安定な順序を保つ。各３種類の値を持つ４個の入力81通りで独立した安定順序と照合し、比較は最大５回と検証。一般的な長さの操作、正しさの証明、実装の作成は未対応。

依頼56は５仕事の非循環グラフで先行条件を満たす順番を選び、４仕事の別例で閉路による行き詰まりを確認する。５仕事の全120順序と各辺の条件を独立に照合し、７通りを正答として受け入れることを検証。任意のグラフの構築や一般の証明は未対応。

依頼57は２つの固定した挿入順で５つの鍵を二分探索木に格納し、５を探す経路と比較回数３・５を比べる。すべての子孫に対する大小関係と探索経路をテストで確認。重複、削除、不在の探索、平衡化、一般的な計算量の証明は未対応。

依頼138は S→A=2、S→B=5、B→A=−4、A→G=2 の一方向グラフ。目的地を確定する方式は費用４で終了するが、S→B→A→G の費用は３。全辺の反復緩和は各周の確認順にかかわらず費用３に収束し、更新のない周に終了する。負の循環や一般の正しさ・計算量は扱わない。

依頼345では５棚に鍵１・６・11を線形に配置し、６を削除後、未使用とした場合の誤った探索停止と削除印による継続を比較する。再挿入、満杯時、一般の性能は未対応。参考：[Cornell: Hashing](https://www.cs.cornell.edu/courses/cs2110/2026fa/lectures/lec20/)。

依頼346では依頼345の削除後の棚で、鍵11の重複確認と、新しい鍵16への最初の削除印の再利用を操作する。未使用の棚まで存在する固定例で、全棚を一周する場合や既存値の更新は未対応。参考：[Virginia Tech: Deletion](https://research.cs.vt.edu/AVresearch/hashing/deletion.php)。

依頼347では未使用の棚がない５棚を１・２・３・４・０の順に調べ、一周後に満杯と削除印の再利用を比較する。既存鍵がなく削除印が高々１つの固定例であり、一般的な実装や拡張は扱わない。参考：[OpenDSA: Hashing](https://opendsa-server.cs.vt.edu/ODSA/Books/CS3F25notes/html/Hashing.html)。

依頼348は３鍵の４種類の挿入順に対して AVL 木の単回転・二重回転を操作し、各節の高さの差と探索木の順序を確認する。一般の挿入・削除や計算量の証明は未対応。参考：[Cornell: Balanced binary trees](https://courses.cs.cornell.edu/cs2112/2021fa/lectures/avl/index.html)。

依頼559は先頭 A・B の列に C・X を順に加え、両端から届けるか取り消す固定例。X・A・B の順に届け C を取り消すことを目標に、追加と取出しの全1024通りを独立した配列模型と照合した。再挑戦と履歴の再生が可能。容量、空の列からの取出し、内部表現や計算量は扱わない。参考：[Oracle Deque](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Deque.html)。

依頼649はギルドから灯台への５地点・５本の重み付き道を選んで進む。灯り５の制限下では橋を経由する費用５の道が到達可能で、木立経由は費用６となる。橋の XOR 条件と伝令塔の再送を同じ冒険で利用する。到達可能状態を列挙して灯りと到着条件を検査。一般の最短路アルゴリズムの構築・証明は扱わない。

依頼794は葉・子一つ・子二つの固定例で二分探索木の削除を操作し、後継の右の子を残す。一般の削除や平衡化の証明は未評価。詳細は[項目別台帳](coverage-al-foundational.md)。
