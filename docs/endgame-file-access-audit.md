# 書庫の扉と本の権限：教材監査

[CS2023 OS-Files 印字212頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=212) のファイル操作とアクセス制御の固定例。旧 `src/file-permissions.js` の依頼740を再利用し、現行の文庫に接続する。現行の名前と参照の依頼は名前の削除後の実体を扱い、今回の依頼は操作を許可する条件を扱う。

既知の名前を用い、親ディレクトリ以外の上位経路は探索可能、対象者に適用される通常の許可ビットのみを扱う。名前から新しく開いて読むには親の探索とファイルの読取りが必要。名前を削除するには親の探索と親の書込みが必要で、ファイル自体の書込み許可とは別。親探索あり／本読取りありは読め、親探索なしでは読めない。親書込みなしでは削除できず、親探索・書込みありなら本の書込みがなくても名前を削除できる。

ACL・sticky bit・特権・読取り専用媒体・他の上位経路・開いた参照・実 OS の操作や一般の権限設定は評価しない。名前の削除はファイル内容の書込みや物理的消去と異なる。[path_resolution(7)](https://man7.org/linux/man-pages/man7/path_resolution.7.html)、[unlink(2)](https://man7.org/linux/man-pages/man2/unlink.2.html) を参照。
