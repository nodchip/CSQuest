# AI-NLP：巻物の検索と適合率・再現率

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.79–80、AI-NLP 8b の適合率と再現率。旧依頼119 `src/retrieval.js` の５巻物と２検索条件を現行文庫に再利用するため、旧教材と独立した範囲として重複計上しない。既存の現行冒険の検索は該当する巻物を探す操作であり、検索結果を適合率・再現率で比較するものではない。

薬師が必要と指定した巻物は調合法・保存法・傷を癒すの３件。題名に「月草の薬」を含む２件はともに必要なので適合率2/2、再現率2/3。題名に「月草」を含む５件はすべて返り、必要な３件を含むので適合率3/5、再現率3/3。結果と必要性はこの固定模型であらかじめ定める。[Stanford の情報検索教材](https://nlp.stanford.edu/IR-book/html/htmledition/evaluation-of-unranked-retrieval-sets-1.html) の定義に従い、適合率の分母は取得件数、再現率の分母は全適合件数とする。

題名の単純な部分文字列一致であり、実文書・未知の正解・順位付き検索・言語処理や一般的な検索評価を検証しない。検索結果０件や全適合件数０件での分母０の扱いも対象外。２指標だけで検索全体の品質や AI-NLP 全体が完成したとはしない。

2026-11-11、実装担当とは別の `review_candidate` が原典と [Google の適合率・再現率の説明](https://developers.google.com/machine-learning/crash-course/classification/accuracy-precision-recall) に照らして固定例と画面・保存・開放条件を独立レビューした。親担当が準備済み記録を用い、幅 213・390・1200 px の現行文庫の分類から到達し、誤答、キーボード操作、途中保存・再開、開放条件、達成後の保存をブラウザ確認した。新規開始からの通し操作、スクリーンリーダー音声、利用者による面白さは未確認。
