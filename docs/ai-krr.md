# AI-KRR の対応状況

原典: [CS2023 AI-KRR](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.70。自然言語での説明や実言語の実装はゲーム内操作では直接評価しない。

| 番号 | 区分 | 内容と現状 |
|---|---|---|
| 1a | CS Core | 自然言語から記号・論理への表現。依頼72で与えられた命題から推論、682で４つの文に対し量化と含意の札を選び反例を確認。自然言語からの一般的な変換は未対応 |
| 1b | CS Core | 学習した分散表現。依頼456で２語と２文脈の共起を二次元ベクトルに当てはめる固定模型。実際の学習済みモデルや一般の訓練は未対応 |
| 1c | CS Core | グラフィカルモデル。依頼81で３変数の有限分布。一般のモデル設計は未対応 |
| 2–3 | CS Core | 確率推論・ベイズの定理。依頼81・98で観測に条件づけた頻度、683で事前割合が異なる２村の観測後の割合とベイズ則を比較。一般の導出や推論は未対応 |
| 4 | KA Core | 確率変数・分布、公理、確率推論、ベイズ則の導出と応用。依頼81・98は有限の固定例。公理・導出や一般化は未対応 |
| 5–6 | KA Core | 独立と条件付き独立。依頼81の固定例。一般的な判定は未対応 |
| 7 | KA Core | マルコフ連鎖・モデル。依頼99で２状態・２時点の遷移と分布、依頼504で不確かな観測から隠れ状態を更新する固定例。一般の連鎖、定常分布や一般の HMM は未対応 |
| 8 | KA Core | 効用と意思決定。依頼98は固定した損失と条件付き頻度から二つの行動の期待損失を比較。一般の効用関数は未対応 |

| 例示学習成果 | 内容と現状 |
|---|---|
| 1 | 自然言語を記号・論理へ変換。依頼682は４文と６種類の候補から選ぶ固定例。一般の変換や自由記述は未対応 |
| 2 | 不確実性下の判断。依頼98で架空の観測別の故障割合と損失を比較。自由記述や一般的な状況は未対応 |
| 3–4 | ベイズ則による事後確率。依頼81・98・683は頻度表の固定例。683で同時確率と観測確率の比を表示するが、一般の導出と問題は未対応 |
| 5 | 確率の計算と独立性の検査。依頼81の固定された３変数分布のみ |

依頼98の100回の架空記録は、警報ありの故障８・正常18、警報なしの故障２・正常72。警報ありでの故障割合は 8/26、警報なしは 2/74。点検は１回２点、故障の放置は10点または５点と仮定する。警報ありの26回では点検52点、放置はそれぞれ80点・40点。警報なしの74回では点検148点、放置は20点・10点。同じ条件の回数で割れば一回あたりの期待損失を比較できる。記録が将来にも当てはまり、点検が必ず故障を解消するとの仮定に依存する。

依頼99は晴れと霧の２状態で、晴れから晴れへ 0.8、霧から晴れへ 0.5 の遷移を仮定する。初めが晴れなら翌日は (0.8, 0.2)、２日後は (0.74, 0.26)。初めが霧なら翌日は (0.5, 0.5)、２日後は (0.65, 0.35)。遷移は現在の状態だけに依存する仮定であり、実際の天気予報ではない。２通りの経路を独立に列挙した計算と画面操作を検証する。

依頼456は固定文脈ベクトル (1,1)・(1,−1) と語ベクトルの内積を、架空の共起回数 [3,1]・[1,3] に近づける。対象の差を文脈ベクトルの長さの二乗２で割って両座標を更新する、二乗誤差の単純な勾配更新。２つの文脈は直交するため各組を１度更新すれば損失０となり、語の値は [2,1]・[2,−1]。別の記録では樹も [2,−1] に変わる。４組の全24学習順を検査した。[Stanford の分散表現](https://web.stanford.edu/class/cs224u/2015/materials/distributedwordreps.html)を参照。固定の語・文脈と小さな教師信号の模型であり、一般の埋め込み手法、実際の言語モデルや意味・公平性の保証は扱わない。

依頼682は２人の対象と２つの性質を固定し、全称含意、その逆、全員が両方、存在、存在の否定、反例の存在を比較する。４文に対する６候補について、全16状態から真偽が異なる反例を探し、対象の性質を満たす人がいない場合の全称条件も検査する。候補と文章は固定されており、自然言語全般の曖昧性や任意の述語論理への翻訳は扱わない。参考：[Cornell、述語論理と量化](https://www.cs.cornell.edu/fbs/publications/GSprimus.pdf)。

依頼683は各1000個、故障時の警報率90%、正常時の誤警報率10%という架空の条件で、故障数10個と500個の村を比較する。警報ありで故障している割合はそれぞれ 9/108 と 450/500、警報なしでは 1/892 と 50/500。故障かつ観測の個数を1000で割った同時確率を、観測全体を1000で割った確率で割り、ベイズ則との関係を示す。分子と分母の集団を選ぶため、値が偶然同じ場合でも条件の向きを区別する。固定条件であり一般の推論や実際の検査性能を評価しない。参考：[MIT、条件付き確率とベイズ則](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/mit18_05_s22_lec03.pdf)。
