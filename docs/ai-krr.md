# AI-KRR の対応状況

原典: [CS2023 AI-KRR](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.70。自然言語での説明や実言語の実装はゲーム内操作では直接評価しない。

| 番号 | 区分 | 内容と現状 |
|---|---|---|
| 1a | CS Core | 自然言語から記号・論理への表現。依頼72で既に与えられた命題と含意から推論。自然言語からの一般的な変換は未対応 |
| 1b | CS Core | 学習した分散表現。未対応 |
| 1c | CS Core | グラフィカルモデル。依頼81で３変数の有限分布。一般のモデル設計は未対応 |
| 2–3 | CS Core | 確率推論・ベイズの定理。依頼81・98で観測に条件づけた頻度を操作。公式の導出や一般の推論は未対応 |
| 4 | KA Core | 確率変数・分布、公理、確率推論、ベイズ則の導出と応用。依頼81・98は有限の固定例。公理・導出や一般化は未対応 |
| 5–6 | KA Core | 独立と条件付き独立。依頼81の固定例。一般的な判定は未対応 |
| 7 | KA Core | マルコフ連鎖・モデル。未対応 |
| 8 | KA Core | 効用と意思決定。依頼98は固定した損失と条件付き頻度から二つの行動の期待損失を比較。一般の効用関数は未対応 |

| 例示学習成果 | 内容と現状 |
|---|---|
| 1 | 自然言語を記号・論理へ変換。依頼72は既に表現された命題のみ。一般の変換は未対応 |
| 2 | 不確実性下の判断。依頼98で架空の観測別の故障割合と損失を比較。自由記述や一般的な状況は未対応 |
| 3–4 | ベイズ則による事後確率。依頼81・98は頻度表の固定例。ベイズ則の導出と一般的な問題は未対応 |
| 5 | 確率の計算と独立性の検査。依頼81の固定された３変数分布のみ |

依頼98の100回の架空記録は、警報ありの故障８・正常18、警報なしの故障２・正常72。警報ありでの故障割合は 8/26、警報なしは 2/74。点検は１回２点、故障の放置は10点または５点と仮定する。警報ありの26回では点検52点、放置はそれぞれ80点・40点。警報なしの74回では点検148点、放置は20点・10点。同じ条件の回数で割れば一回あたりの期待損失を比較できる。記録が将来にも当てはまり、点検が必ず故障を解消するとの仮定に依存する。
