# SEP-Context：社会的文脈の項目別対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.273–274。[既存調査](sep-context.md)と依頼・検査を照合。状態は[追跡方法](coverage-status.md)に従い、「未照合」は未実装の証拠ではない。「部分」は関連する固定例を示し、項目全体の修得を意味しない。実際の社会調査・法的判断・自由な説明や文章作成は固定例だけでは直接評価しない。

各依頼の前提・出典と検証、実際の状況に一般化できない範囲は[既存調査](sep-context.md)を参照する。

依頼1107は [FTC の Rite Aid に関する2023年の申立て](https://www.ftc.gov/news-events/news/press-releases/2023/12/rite-aid-banned-using-ai-facial-recognition-after-ftc-says-retailer-deployed-technology-without) と [NIST の顔照合の誤りに関する研究](https://www.nist.gov/news-events/news/2019/12/nist-study-evaluates-effects-race-age-sex-face-recognition-software) を参考にする。架空の支援受付で警告だけの拒否と、独立した記録による別人・重複・不明の３結果、代替と再確認を比較。申請や３結果は実事件ではない。独立記録の結果は模型上の仮定であり、人の確認も誤り得る。実システムの公平性、安全性、法令適合や政策の是非は評価しない。`tests/alert-review.test.js` は操作順、３結果、再確認と保存を検査する。

依頼1138は [D’Amour らの研究](https://jmlr.org/papers/volume23/20-1335/20-1335.pdf) §5・表１・２を用い、２種類のモデル群と３画像集合のモデル対の不一致率を調べる。ResNet-50 の平均は元の ImageNet 16.0％、共通113種類の部分集合24.5％、ObjectNet 50.9％。不一致は正解率ではなく、各集合の画像も同一ではない。`tests/model-disagreement.test.js` で転記値、正解率との区別、６観察と保存を検査。実測の集計を読む代替体験であり、実際の利用者の調査、利用環境の安全性や公平性の評価、自由な分析は行わない。
