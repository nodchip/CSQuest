# 工房の札を数える仕掛け

[CS2023 AL-Models、印字93〜95ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=93) の正しさと不変条件に関連する固定の手順。赤の数を数える途中状態と空入力を確かめ、初期・維持・終了時の正しさ・終了性を説明する札を組み立てる。さらに停止条件を誤ると末尾の赤を数え損ねる反例を操作して比較する。

用意された手順と説明に限る練習である。任意の不変条件の発見や自由な証明、別のアルゴリズムの正しさは評価しておらず、関連項目は部分対応である。例の実行だけを一般的な証明とは扱わない。

実装担当と別の coverage_next が原典、初期・維持・終了・終了性、空入力、反例、保存と開放をコード上で確認した。範囲が保たれる理由と停止する理由の説明に関する指摘を反映し、再確認を受けた。独立担当自身のブラウザー操作は行っていない。`tests/endgame-invariant.test.js` は空入力と反例などを検証し、`scripts/endgame-invariant.playwright.js` は集いと４地域の達成状態を用意した記録から誤答、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
