# 完成率の分母の照合：FPL-Pragmatics

[CS2023 印字 pp.144–145（PDF 144〜145ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の FPL-Pragmatics と[項目別台帳](coverage-fpl-pragmatics.md)を2026-11-05に照合した。トピックと例示学習成果はいずれも Non-core。

原典３の本文は良い言語設計の評価基準で、子の直交性などはその一部であるため、全体を追跡する `3-本体` を追加した。依頼355の組合せと例外の比較は一部に限るため「部分」とする。原典は３bと６に制御・反復構成の定義を重複して挙げており、原典の両番号を残す。原典の区分を明確にするため全行に Non-core 列を追加した。

原典７と学習成果５について、依頼518で用意された道具の呼出しとファイルを開く固定模型、1184で別々に翻訳した処理間の受渡しの一致を確認したため「部分」とした。システムライブラリ全般の必要性や実機・実言語での呼出しは扱わない。

トピックの分母候補は10件（１・２、3-本体・３a〜３c、４〜７）、例示学習成果は５件。これは範囲と区分の照合であり、各教材の内容・正答の個別検証や分野全体の完成を意味しない。プログラム記述や自由な議論はゲーム操作で直接評価しない。

依頼518の追加模型は [Linux man-pages の open](https://man7.org/linux/man-pages/man2/open.2.html) と [close](https://man7.org/linux/man-pages/man2/close.2.html) を参照し、読取り用の要求で成功時の記述子、存在しない場合と権限不足の場合の失敗を固定条件で比較する。別の固定例で番号３を開いて読み、閉じた後の無効な読取りと、別の巻物に再利用された番号からの読取りを比べる。番号の割当ては固定された仮定で、複製・並行操作・実際のファイル操作や複数条件が重なる場合のエラー、全 API・環境の振る舞いは扱わない。
