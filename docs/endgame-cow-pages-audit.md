# 親子の頁とコピーオンライト：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字210〜211頁 OS-Memory 8 に関連する固定例。旧依頼486 `src/copy-on-write.js` の頁と物理枠の模型を現行の駅に接続した。既存の頁置換・空き領域教材とは書込み保護と共有枠の複製の扱いが異なる。
- [MIT xv6 Copy-on-Write Fork](https://pdos.csail.mit.edu/6.1810/2022/labs/cow.html) は元が書込み可能な私有頁を親子で共有・保護し、書込み障害時に複製する設計を説明する。ここでは意図的に書込みを共有する設定も別の比較対象として仮定する。
- 親は初期７の枠１を参照し、子の作成後は親子とも枠１を参照。共有書込みでは子の９が親にも見える。複製設定は障害時には両者７のままで、複製→子の頁表を枠２へ変更→書込み再開の後、親７・子９、物理枠２個になる。
- 二者が同じ枠を参照する固定例である。実 OS は参照が１つなどの条件で既存枠を再利用でき、すべての書込みで必ず複製すると一般化しない。複数頁、他の共有・保護設定、競合、実 API・実 OS・実時間や実装能力は評価しない。旧教材・本教材を原典全体の完成とはしない。
