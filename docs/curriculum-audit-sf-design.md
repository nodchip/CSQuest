# 原典との範囲照合：SF-Design

[CS2023 印字 p.297（PDF 297ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-sf-design.md)を2026-11-05に照合した。トピック１と成果１・２は CS Core、トピック２と成果３は KA Core。活性・安全性などと Apache・Spark・Linux は原典の例示で、対象をこれらだけに限定しない。台帳はトピック２行、成果３行。

範囲と区分の照合であり、教材の正確性や学習成果の達成は別途評価する。固定例による高水準設計と、一般の要件から自由に設計を提示する能力は区別する。
