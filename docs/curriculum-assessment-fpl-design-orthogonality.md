# FPL-Design：直交性の教材評価

評価日：2026-11-05。[CS2023 印字 pp.146–147](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の Non-core トピック１e・学習成果１と、依頼355を確認した。両項目の判定は「部分」。

依頼では架空の２規則について、数・数の列と保存・関数からの返却の８組合せを試す。片方は列の返却だけを認めず、もう片方は４組合せを認める。この限定された比較を通じ、構成要素を一貫して組み合わせられるか考える。実際の言語の型規則全体、他の設計原則、実在言語の総合評価は扱わない。

`tests/language-orthogonality.test.js` の２テストは８組合せの判定、全例と振り返りの達成条件、復元時の結果の整合を検査する。ローカル版の390px幅で８組合せと振り返りを操作し、達成を確認した。架空の例での比較は、実在言語を総合的に評価できる能力の証明ではない。
