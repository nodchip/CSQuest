# 完成率の分母の照合：SPD-Web

[CS2023 原典 p.303（PDF 303ページ目、印字番号303）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf)の SPD-Web と[項目別台帳](coverage-spd-web.md)を、2026-11-04 に照合した。原典上のページ位置は PDF の先頭を１ページ目として数えた303ページ目である。

## 分母の採用方針と結果

- 独立した内容を持つ番号を採り、単なる分類見出しは数えない。例は親の対象範囲として扱い、別項目に数えない。
- トピック２の本文はプラットフォーム・フレームワークを対象とし、子の２項目とは別の内容を持つため、台帳の `2-本体`、`2a`、`2b` を採用する。
- ７〜10は分類見出しとして重ねて数えず、原典の子項目を採用する。
- トピック19件（1、2-本体、2a、2b、3〜6、7a〜7c、8a〜8b、9a〜9d、10a〜10b）、例示学習成果６件（1〜6）。１〜５と全成果が KA Core、６〜10 の子項目は Non-core。
- 原典の 8b は data integrity と、それに続く利用可能性・削除に関する表現の組を持つ。台帳は原典の表記を追跡し、一般的な完全性・可用性・削除の概念を同一視しない。原典の要約だけで教科内容の正確さを証明しない。

これは **SPD-Web の分母候補についての原典照合**であり、分野全体・CS2023 全体の分母確定ではない。個々の判定・教材の十分性・正答や根拠は別途監査する。現在の台帳にはトピックが未照合13・部分６、学習成果が未照合５・部分１と記録され、完了はない。ただし、これらの状態を今回すべて独立に再検証したわけではないため、この単位についても完成率とはしない。
