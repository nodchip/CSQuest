# 完成率の分母の照合：FPL-Aspect

[CS2023 印字 p.136（PDF 136ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の FPL-Aspect と[項目別台帳](coverage-fpl-aspect.md)を2026-11-05に照合した。項目はすべて Non-core。原典のこの単位には例示学習成果の列挙はない。

原典３のアドバイスは before・after・around の子項目で追跡し、親を重複して数えない。原典４はポイントカット自体に加えて指定子を子項目に挙げる。指定子の例だけではポイントカットの意味を独立して追跡できないため、`4-本体` を加え、`4a` と別に数える。依頼323は操作の節目を選ぶ固定例を扱うため、本体は部分とした。実言語や一般的な定義は未評価である。

トピックの分母候補は９件（１・２、３a〜３c、4-本体・４a、５・６）、例示学習成果は０件。原典の区分を明確にするため全行に Non-core 列を追加した。

これは範囲と区分の照合であり、各教材の正確性の個別検証や、この分野の完成を意味しない。
