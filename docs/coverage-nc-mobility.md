# NC-Mobility：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.201。[既存の調査](nc-mobility.md)と依頼を照合した。状態は[追跡方法](coverage-status.md)を参照。

## トピック

| 番号 | 区分 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | KA Core | セルラー通信の原理 | 部分 | 318 は登録区域と呼び出しの固定模型。実登録手順や無線は未評価。 |
| 2 | KA Core | 無線 LAN、主に 802.11 の原理 | 部分 | 317 は探索と接続先の切替え。実無線手順やセキュリティは未評価。 |
| 3 | KA Core | 端末間通信 | 部分 | 316 は接触時の手紙の受渡し。実端末の発見・接続や IoT は未評価。 |
| 4 | KA Core | 複数区間無線、アドホック、機会的・遅延耐性通信 | 部分 | 316 は切断中の保持と接触時の中継。一般の経路選択と実プロトコルは未評価。 |
