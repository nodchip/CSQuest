# 原典との範囲照合：AI-Robotics

[CS2023 印字 pp.80–82（PDF 80〜82ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-ai-robotics.md)を2026-11-05に照合した。トピック１〜15と子項目は Non-core。概要、センサーと作動部、人との相互作用、社会・倫理の親項目１・２・14・15を追加した。成果１〜10には原典で個別の区分見出しがないため、区分を推測しない。台帳はトピック32行、成果10行で、親子の重複は集計時に検討する。

範囲と区分の照合であり、教材の正確性や成果の達成は別途評価する。原典はシミュレーションを認めるが、固定模型は実機の安全性や一般の実装能力を証明しない。
