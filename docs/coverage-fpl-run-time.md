## 例示学習成果

| 番号 | 区分 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | Non-core | 自動メモリ管理の利点と限界 | 部分 | 201・202で到達不能な循環の回収方式を比較。一般的な議論は未評価。 |
| 2 | Non-core | オブジェクトと活性化記録のメタデータの用途 | 部分 | 560で戻り先、785で呼出し枠の固定例。実オブジェクトの型情報や自由な説明は未評価。 |
| 3 | Non-core | 静的・スタック・ヒープ割当ての比較 | 部分 | 785で命令・大域・枠・ヒープを一体で操作。一般の割当て方針は未評価。 |
| 4 | Non-core | 復帰時に解放できないデータと回収の必要性 | 部分 | 785で枠の復帰後もヒープの宝石が残る。自動回収が必要な理由の一般的な議論は未評価。 |
| 5 | Non-core | JIT・動的再コンパイルの利点・欠点 | 部分 | 312で固定費用と回数を比較。実際の最適化や自由な議論は未評価。 |
| 6 | Non-core | 移動コードのサンドボックス | 部分 | 依頼1207で固定コードの実行と親文書へのアクセス制限を比較。外部コードの取得・安全性の保証は未評価。 |
| 7 | Non-core | 現代の言語実行時システムのサービス | 部分 | 201・202・312・785の個別模型。サービスの全体像や一般的な特定は未評価。 |

785 の操作と検査の限界は [FPL-Systems 台帳](coverage-fpl-systems.md)を参照。831は２種類のバイト順の模型であり、実際の相互運用を直接実装していない。

依頼1204は [Itanium C++ ABI の仮想呼出し例](https://itanium-cxx-abi.github.io/cxx-abi/abi-examples.html)を参考に、単一継承の２種類の実体と２つの動作について、実体の表と共通の番号をたどる固定模型。`tests/virtual-dispatch.test.js` は16選択の結果と保存を検査。実 ABI の配置、複数継承、最適化や実行時間は扱わない。

依頼1206は [Crafting Interpreters のメソッド表](https://craftinginterpreters.com/methods-and-initializers.html)と[ハッシュ表](https://craftinginterpreters.com/hash-tables.html)を参考に、同じハッシュ値から線形探索する名前３種を４マスで比較する固定模型。`tests/method-hash-lookup.test.js` は衝突、発見、欠落、誤順序と復元を検査する。削除・再配置・実言語処理系は未評価。

依頼1207は [HTML Standard の iframe sandbox](https://html.spec.whatwg.org/multipage/iframe-embed-object.html#attr-iframe-sandbox)を参考に、固定された同一サイトの srcdoc 内コードについて、不透明オリジンと同一オリジン許可時の親文書アクセスをブラウザで実測する。両者ともスクリプトを許し、後者は信頼済みの固定実験だけに限定。外部コードの読込みはしない。`tests/sandbox-origin-lab.test.js` は観測の記録を検査し、実際の制限はブラウザで検査する。全 API や環境全体の安全性は未評価。

依頼1211は [Princeton の静的リンクと呼出し枠](https://www.cs.princeton.edu/courses/archive/spring15/cos320/lectures/05-ActivationRecords-3x1.pdf)を参考に、直接と仲介経由の呼出しで、内側の引数と非局所変数の探索を比較する。呼出し元の鎖による名前探索は動的スコープの比較用模型。`tests/static-link-lab.test.js` は４経路、誤経路と復元を検査する。再帰・クロージャや実メモリ配置は未評価。

依頼382の追加例では、OS がプログラムと引数・環境を用意し、実行時の初期化後にアプリが値を使い終了を返す。２条件を扱う固定模型で、動的リンクや実装ごとの起動・終了処理の詳細は扱わない。参考：[GNU C Library の環境](https://sourceware.org/glibc/manual/latest/html_node/Environment-Variables.html)、[Linux execve](https://man7.org/linux/man-pages/man2/execve.2.html)。
