# 集いの入口 — Shaping

## 背景

> 「道と知らせをつなぐ集い」を始めるための操作に気付きにくいように感じました。

現在は12地域で各２件の依頼を達成した後にカエデの会話が現れ、地域画面の「これまでの出来事を見る」から「各地をつなぐ集い」を選ぶ。地域画面の直接入口は hidden になっている。実画面での見え方は未確認。

## 要件

| ID | 要件 | 状態 |
|---|---|---|
| R0 | 集いを始める操作に気付ける | 主目的 |
| R1 | 後で集いを始めたり、途中から再開したりできる | 採用 |
| R2 | 集いを始めるか、冒険を続けるかを選べる | 採用 |
| R3 | 既存の開始条件と保存済みの進行を保つ | 必須 |

## C：会話と地域画面に入口を設ける

利用者が会話と地域画面の両方に入口を設ける方向を了承。

| 部品 | 仕組み |
|---|---|
| C1 | カエデの会話に「仲間に相談する」と「あとで」を表示する |
| C2 | 集いが未完了の間、地域画面の「知らせ・出来事」に開始または途中再開のボタンを表示する |
| C3 | 両方の入口から既存の集い画面と保存済みの進行に接続する |
| C4 | 完了後は直接入口を隠し、既存の出来事履歴から振り返れる |

|---|---|---|---|---|---|---|
| N1 | P5 | 入口 | `storyGatheringSeen` と戻り先を保存し、既存の `storyClimaxHistory` を保持して集いを開く | 呼出 | → S1、→ P3 | — |
| N2 | P1 | 会話 | `storyGatheringSeen` を保存し元の地域または地図に戻る | 呼出 | → S1、→ P2 | — |

P1 の元画面が地図の場合は、あとでを選んだ後に地図へ戻る。途中の集いを再開するときは保存済みの手順を初期化しない。旧記録、未開始・途中・完了、会話後の再読込、キーボード操作と狭い画面を検証する。

## 実装と検証

会話と地域画面の入口を追加し、途中記録がある場合は「相談の続きを見る」と表示する。旧記録で会話済みフラグがなくても、集いの途中記録や開始済みフラグがあれば会話を繰り返さない。幅390px・1280pxの Edge で、会話からの開始、「あとで」、再読込、途中再開、旧記録、完了後の履歴を確認した。会話からの選択はキーボードでも確認した。
