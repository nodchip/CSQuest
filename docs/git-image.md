# GIT-Image：画像処理

出典: [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.163–164。固定された二値画像の操作は実画像の処理やプログラムの実装能力を直接評価しない。

| トピック | 区分 | 内容と現状 |
|---|---|---|
| 1a–d | KA Core | 連結成分、膨張、収縮、面積・周長・重心などの領域の性質。依頼139・140で十字近傍による膨張・収縮と連続操作の固定例。他は未対応 |
| 2a–b | KA Core | 色ヒストグラムと正規化によるコントラスト強調。未対応 |
| 3a–d | KA Core | 畳み込み、ぼかし、鮮鋭化、周波数フィルタ。依頼141で１方向３画素の高域フィルタの固定例。２次元の処理、周波数領域や他の項目は未対応 |
| 4a–c | KA Core | ノイズ・劣化、インペインティング、Wiener フィルタ。依頼139は孤立した画素に膨張・収縮を適用する例のみ。一般の復元は未対応 |
| 5a–e | KA Core | 画像符号化、冗長性、圧縮、変換、標本化定理、透かし。依頼110で一般的なハフマン符号の固定例。画像符号化や他の事項は未対応 |
| 6 | KA Core | 深層学習との関係。未対応 |

| 例示学習成果 | 区分 | 内容と現状 |
|---|---|---|
| 1 | KA Core | 二値画像の縁を平滑化する膨張・収縮のプログラム。依頼139・140で両操作と、孤立点の除去・小さい穴を埋める連続操作の固定例。一般の平滑化とプログラムの実装は未対応 |
| 2–5 | KA Core | 色相の操作、高域フィルタ、欠損部分の復元、周波数領域のフィルタ結果の評価。依頼141で３画素の高域フィルタの固定例。実画像とプログラムの実装、他の事項は未対応 |

依頼139は５×５の画像で中央の３×３を１とし、右下に孤立した１を置く。自画素と上下左右の十字近傍を使い、画像外は０とする。膨張は少なくとも１つが１なら１、収縮は５つすべてが１なら１。結果はそれぞれ22画素と中央１画素。形状や境界、操作順を変えた場合は扱わない。

依頼140は７×７の固定画像で、収縮→膨張により孤立した点を除く一方、３×３の角も失う例と、膨張→収縮で中央の穴を埋める例を比較する。境界は０、近傍は自画素と上下左右。実画像と一般的な復元は未対応。参考: [OpenCV のオープニング・クロージング](https://docs.opencv.org/4.13.0/d3/dbe/tutorial_opening_closing_hats.html)。

依頼141は横に並ぶ３画素に重み [−1, 2, −1] を掛けて足す。入力 [2,2,2]・[2,6,2]・[6,2,6] の出力はそれぞれ 0・8・−8。負値は中間結果であって表示可能な画素値とは限らない。１方向・３画素の模型で、２次元全体、境界や実画像の処理は扱わない。
