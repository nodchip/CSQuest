# GIT-Image：画像処理

出典: [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.163–164。固定された二値画像の操作は実画像の処理やプログラムの実装能力を直接評価しない。

依頼139は５×５の画像で中央の３×３を１とし、右下に孤立した１を置く。自画素と上下左右の十字近傍を使い、画像外は０とする。膨張は少なくとも１つが１なら１、収縮は５つすべてが１なら１。結果はそれぞれ22画素と中央１画素。形状や境界、操作順を変えた場合は扱わない。

依頼140は７×７の固定画像で、収縮→膨張により孤立した点を除く一方、３×３の角も失う例と、膨張→収縮で中央の穴を埋める例を比較する。境界は０、近傍は自画素と上下左右。実画像と一般的な復元は未対応。参考: [OpenCV のオープニング・クロージング](https://docs.opencv.org/4.13.0/d3/dbe/tutorial_opening_closing_hats.html)。

依頼141は横に並ぶ３画素に重み [−1, 2, −1] を掛けて足す。入力 [2,2,2]・[2,6,2]・[6,2,6] の出力はそれぞれ 0・8・−8。負値は中間結果であって表示可能な画素値とは限らない。１方向・３画素の模型で、２次元全体、境界や実画像の処理は扱わない。

依頼144は５つの点からなる５×５の二値画像を、上下左右の４近傍と斜めを含む８近傍で比較する。４近傍では２成分で出発点側が３画素、８近傍では５画素すべてが１成分。実画像の分割、ノイズや一般の認識は扱わない。

依頼724では４×４の灰色画像３枚の画素数ヒストグラムと、最小・最大を０・６へ写す線形伸張を比較する。一色では分母が０になるため、この教材では元の値を保つ。ノイズだけの画像も伸張で強調される。色チャンネル、実画像や任意の丸めは扱わない。[scikit-image の画像調整](https://scikit-image.org/docs/stable/user_guide/transforming_image_data.html)。項目別の最新状況は [対応台帳](coverage-git-image.md) を参照。

依頼725は５×５の２つの灰色画像に、３×３の平均、中心を重くしたガウス型の窓、元画像から４近傍の離散ラプラシアンを引く鮮鋭化を適用する。画像外は最近端の値を複製し、数値は小数第２位に丸めて表示、明るさの描画のみ０〜８に制限する。全て対称な窓なので畳み込みと相互相関の結果は同じ。非対称な核、他の端条件、実画像や一般の復元性能は未評価。[OpenCV の平滑化](https://docs.opencv.org/4.12.0/d4/d13/tutorial_py_filtering.html)、[離散ラプラシアン](https://docs.opencv.org/doc/doxygen/html/d4/d86/group__imgproc__filter.html)。

依頼726では４画素の紋章に色相の回転と彩度・明度の倍率を適用し、RGB 値が目標と一致するよう調整する。彩度０の灰色では色相に依存しない。RGB は８ビットに丸めて表示する。HSV の V は RGB の最大成分であり、知覚上の明るさを保証しない。実画像・色管理・異なる HSV 表現は未評価。[OpenCV の色空間](https://docs.opencv.org/4.12.0/df/d9d/tutorial_py_colorspaces.html)。

依頼727では５×５の画像２枚で、隣り合う２画素を欠損として指定する。欠損を０で初期化し、更新前の上下左右の平均で両画素を同時に更新する。既知の画素は固定。境界を含む一般のマスク、実画像、他の補完法、自由なプログラム作成は未評価。有限回では厳密解とは限らず、滑らかな補間は元の詳細を保証しない。[IPOL の画像補完](https://www.ipol.im/pub/art/2012/g-tvi/)。
