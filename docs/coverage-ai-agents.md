## 例示学習成果

| 番号 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|
| 1 | 標準的な構造の特徴と比較 | 部分 | 109・688で記憶と固定方針を比較。一般の構造は未評価。 |
| 2 | 応用と倫理的影響を説明 | 部分 | 689で人と人形の主導・確認を比較。実応用や自由な倫理分析は未評価。 |

| 5 | 確立した認知構造で主体を構築 | 部分 | 1331で BDI の簡略模型の状態と計画を操作。実アーキテクチャの設計・構築は未評価。 |

前提は [AI-Introduction](ai-introduction.md)、[AI-Planning](ai-planning.md)、[AI-ML](ai-ml.md) を参照。`tests/agent-memory.test.js`、`tests/agent-styles.test.js`、`tests/agent-initiative.test.js`、`tests/joint-crossing.test.js`、`tests/flock-rules.test.js`、`tests/auction-agents.test.js` は各模型を検査する。

依頼1330は [IEEE の部分観測下の情報交換](https://ieeexplore.ieee.org/abstract/document/11560930) と [協調主体の部分観測](https://arxiv.org/abs/2006.10822) を参考に、二体が別々の固定情報を観測・共有し、運び役が道を選ぶ。報告が正確で移動中に状況が変わらないと仮定する。実情報源や一般の自律的協調・学習は評価しない。`tests/agent-scout-relay.test.js` は報告の順序、両方の状況、保存を検査する。

依頼1331は [Rao・Georgeff の BDI エージェント](https://users.cs.utah.edu/~tch/notes/refs/Rao-Georgeff1995.pdf) と [意図の維持に関する論文](https://ijcai.org/proceedings/1995/92) を参考に、固定の配達例で信念・目的・意図を分け、状況変化後の観測と計画の見直しを操作する。これは規則を固定した簡略模型で、BDI 全体の形式意味論やプログラムの構築を評価しない。`tests/agent-bdi-courier.test.js` は信念の更新前後の行動と保存状態を検査する。

依頼1332は [独立学習の非定常性を扱う研究](https://www.jmlr.org/papers/volume21/20-081/20-081.pdf) と [協調学習の報酬](https://jmlr.org/papers/volume7/kok06a/kok06a.pdf) を参考に、二体が赤・青を選び、同じ色なら共有報酬１、違えば０となる固定ゲームを操作する。選択した行動の評価だけを旧評価と報酬の平均に更新する。旅人が行動を選び、長期報酬、自動探索、収束や一般的な学習性能は評価しない。`tests/agent-joint-learning.test.js` は報酬と独立評価の更新、保存を検査する。

依頼1333は [JMLR の探索と協調](https://www.jmlr.org/papers/volume9/bab08a/bab08a.pdf) と [独立学習における協調の失敗](https://www.jmlr.org/papers/v17/15-417.html) を参考に、1332と同じ評価更新を用い、異なる同点規則の貪欲な二体と、一方が初回だけ探索する二体を４回比較する。探索は固定した１回であり、確率的探索・長期報酬・一般の収束を評価しない。`tests/agent-coordination-learning.test.js` は２方式の選択と評価の軌跡、途中保存を検査する。

依頼1334は [W3C の情報の来歴](https://www.w3.org/TR/prov-overview/) と [BDI エージェント](https://users.cs.utah.edu/~tch/notes/refs/Rao-Georgeff1995.pdf) を参考に、道・状態・時刻・出所を表す固定報告の取得と更新を操作する。報告は正確で昼に道が変化したという模型の仮定であり、時刻だけで現実の報告の正しさを保証しない。一般の知識表現・信念更新理論や実情報源は評価しない。`tests/agent-report-ledger.test.js` は新旧の到着順と記録の保存を検査する。

依頼1335は [NIST の AI 評価と条件の記録](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/) を参考に、1334の固定報告に対する到着順上書きと観測時刻による更新を、順番どおり・逆順の２条件で比較する。実システムや誤観測・時刻ずれ・未観測の変化は評価せず、固定試験の結果を一般化しない。`tests/agent-ledger-evaluation.test.js` は４組合せの結果と保存を検査する。

依頼1336は [W3C の複数入力方式の要件](https://www.w3.org/TR/mmi-reqs/) と [ACL の身ぶりと言語の実験](https://aclanthology.org/2019.dnd-10.7/) を参考に、明示的な言葉と、この例では曖昧な身ぶりを受けた人形の確認を操作する。実音声・画像の認識や実利用者の評価ではなく、すべての身ぶりが曖昧という主張ではない。`tests/agent-communication.test.js` は会話の順序と途中保存を検査する。

依頼1337は [Winter Simulation Conference の供給網の主体](https://informs-sim.org/wsc00papers/242.PDF) と [協調主体による在庫管理](https://arxiv.org/abs/2304.08769) を参考に、固定需要と翌朝の補充を３日間追う。在庫係と運び役の簡略模型であり、実取引、需要や到着時刻の変動、費用、最適な方策は評価しない。`tests/agent-supply-chain.test.js` は在庫・補充・不足の軌跡と途中保存を検査する。

依頼1338は [AAMAS の感情を模した主体](https://ifaamas.org/Proceedings/aamas2015/aamas/p1947.pdf) と [ゲーム内主体の感情表現](https://arxiv.org/abs/2309.05076) を参考に、２つの出来事から架空の状態・表示を選ぶ固定規則を比較する。実際の感情や意識、人の気持ちの認識は評価しない。`tests/agent-affect-simulation.test.js` は４条件の状態・案内と保存を検査する。

依頼1339は [IJCAI の可能世界による信念](https://www.ijcai.org/Proceedings/03/Papers/160.pdf) と [BDI の可能世界模型](https://ijcai.org/proceedings/1995/92) を参考に、主体が可能と考える全世界で成り立つことと実際の状態を比較する。２世界・１命題の非空集合を使う固定模型で、一般の論理や信念更新は評価しない。`tests/agent-belief-worlds.test.js` は誤った信念と不確実性の例、保存を検査する。
