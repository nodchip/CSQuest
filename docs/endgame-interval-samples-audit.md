# 標本と区間の被覆：教材監査

CS2023 MSF-Statistics 2d（印字190–191頁）の信頼区間の入口として、水辺の村で固定の区間作成手続きを繰り返して比較する。旧 `src/confidence-interval.js` の計算を利用し、冒険中で標本を順に選んだ結果と全組合せを操作できるようにした。

母集団は 3、4、5、6 の４本で平均は既知の 4.5。毎回等確率で復元抽出し２回は独立なので、順序付き16組が同確率。区間は標本平均 ±0.5 で両端を含む。和が８・９・10の組が母平均を含み、それぞれ３・４・３組、被覆率は10/16＝62.5%。固定した区間と固定母平均の包含は決まっている一方、被覆率は標本を選ぶ前の手続きの割合である。

この例は95%信頼区間ではなく、任意の母集団や区間の構築、実際の無作為抽出、自由な説明・証明、実データでの妥当性を評価しない。原典の成果全体を完成としない。

参考：[NIST Engineering Statistics Handbook — Confidence Limits for the Mean](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm)。
