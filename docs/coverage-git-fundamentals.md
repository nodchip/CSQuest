# GIT-Fundamentals：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.155–156。[追跡方法](coverage-status.md)に従う。原典の項目を子項目まで分け、固定模型と実装・自由な説明を区別する。GIF は原典で非可逆形式の例に挙げられているが、圧縮そのものと色数の制限・減色による情報損失を区別して扱う必要がある。詳細な既存例は [記録](git-fundamentals.md) を参照。
