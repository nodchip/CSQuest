# 分母照合：FPL-OOP

[CS2023 印字 pp.130–131](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=130) と[候補台帳](coverage-fpl-oop.md)を 2026-11-11 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core は 1（命令型とオブジェクト指向）、2a・2b（状態と振る舞いへの分解・クラス階層）、3〜6（クラスの定義、継承・上書き、動的ディスパッチ、例外）、7a〜7c（非公開、署名のみのインターフェース、抽象基底クラス・トレイト・ミックスイン）、8・9（動的・静的な性質、合成と継承）、10a〜10c（サブタイプ多相、振る舞いによる置換、サブタイプと継承）。KA Core 11・12 はコレクション・反復子とメタプログラミング・リフレクション。原典の親 2・7・10 の設計・カプセル化・サブタイプの共通文脈を子に保持し、親子を重複計上しない。台帳トピック 17 行。

CS Core 成果 1〜10 は方式の違い、クラスの設計・実装・試験、再利用する階層、動的ディスパッチの制御、手続き・関数・オブジェクトの解法とデータ保護、継承と合成、継承とサブタイプ、カプセル化、複数言語での反復子・高階の集約操作。KA Core 成果 11 はコレクションと反復子による問題解決。原典では成果 10 は CS Core である。成果 11 行を別に追跡する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行の鍛冶街には個体・状態・公開操作の一部評価があるが、実言語での設計・実装、一般の階層や自由な説明の達成を意味しない。各行の到達・正確性・操作・保存・独立レビューは別途確認する。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
