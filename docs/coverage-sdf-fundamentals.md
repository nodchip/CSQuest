# SDF-Fundamentals：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.230–231。原典番号・区分を保ち、[既存の基礎記録](sdf-fundamentals.md)、該当する依頼の実装と個別テストを照合した。状態は[追跡方法](coverage-status.md)に従う。

原典の成果で「開発」は設計・記述・テスト・デバッグを含む。本作の方針では実際のコードや文章を入力する演習を設けないため、札や装置の操作を代替として記録し、実言語での開発や自由記述の能力を達成したとは扱わない。

この台帳は既存の例と不足を示す。教材の網羅、一般的な開発能力、大学水準の深さや学習効果の証明ではない。依頼ごとの前提と検証は[基礎記録](sdf-fundamentals.md)と[開発記録](progress.md)を参照。

依頼1125は [MDN の鍵付きの集まり](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Keyed_collections) と[鍵の有無](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map/has)を参考に、注文列を順に読み、薬草名を鍵とする在庫を確認・更新する。０個と未登録、重複注文、空の列を３場面で区別する。実際の言語でプログラムを書く能力、任意の注文や同時更新は評価しない。`tests/order-inventory.test.js` は在庫の消費・未登録・空列と途中記録を検査する。

依頼1126は1125の処理を再利用し、３種類の薬草それぞれについて未登録・０〜２個を選び、最大４件の注文を組み立てる。空の列、未登録、同じ薬草の在庫を使い切る場面をプレイヤーが作成する。`tests/order-inventory-lab.test.js` は長さ０〜３の注文と全在庫設定の2,560通りを独立した期待結果と照合し、途中記録も検査する。４件の全組合せ、一般の入力や実言語での開発能力を証明するものではない。

依頼1127は [MDN の制御の流れ](https://developer.mozilla.org/en-US/docs/Glossary/Control_flow)を参考に、在庫あり・０以下・未登録ごとの処理と次の注文への進み方を札で組み立て、1125の３入力を段階的に試す。誤った手順は負の在庫や同じ注文の繰り返しを示し、８回で観察を打ち切る。`tests/order-program.test.js` は16手順の組合せと期待値、打切り・復元を検査する。自由な手順構築、任意入力、実言語での開発は評価しない。
