# AR-Heterogeneity：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.107。[既存の調査](ar-heterogeneity.md)と依頼を照合した。状態は[追跡方法](coverage-status.md)を参照。2・3・5 は子項目で追う。

## トピック

| 番号 | 区分 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | KA Core | SIMD・MIMD と GPU・TPU・NPU 等 | 部分 | 162 で同一・独立命令、872で SIMT の分岐を模型化。各実機の構成は未評価。 |
| 2a | KA Core | 異種メモリ：共有と分散 | 部分 | 873で CPU・GPU の別々の記録と論理的に共有する記録、コピーと移動を比較。一般の分散メモリ構成は未評価。 |
| 2b | KA Core | 異種メモリ：揮発性と不揮発性 | 部分 | 455 で保存と電源断の模型。異種メモリ構成は未評価。 |
| 2c | KA Core | 異種メモリ：一貫性プロトコル | 部分 | 104 で写しの無効化。実プロトコルと異種構成は未評価。 |
| 3a | KA Core | 機械学習アクセラレータ | 部分 | 875で２×２の積和器に数を流し、２行と１行の行列積を比較。実 TPU の精度・命令・性能や他のアクセラレータは未評価。 |
| 3b | KA Core | ネットワーク内計算 | 部分 | 876で中継塔による４報告の集約と個別転送を比較。実スイッチの構成、損失・再送や性能は未評価。 |
| 3c | KA Core | 新しい応用向け組込みシステム | 部分 | 219の観測と駆動、877の川辺での判断と遠隔制御の固定模型。実機や多様な応用は未評価。 |
| 3d | KA Core | ニューロモーフィック計算 | 部分 | 878で離散時間の積分・減衰・閾値・発火後のリセットと入力時刻を操作。実回路、複数素子、学習や実機の性能は未評価。 |
| 3e | KA Core | エッジ計算装置 | 部分 | 877で観測点近くと遠方の判断を、通信の有無と仮定した期限で比較。実ネットワーク、装置負荷や安全性は未評価。 |
| 4 | KA Core | 3D 集積やチップレットの実装・統合 | 部分 | 879で一体・横並び・積層の組立てと架空の良品費用を比較し、検査・熱・接続を扱う。実装技術や実製品の費用・性能は未評価。 |
| 5a | KA Core | 構成設計のための AI による負荷分析 | 部分 | 880で計算量と転送量の比から分類器を訓練し、未学習の負荷で誤りを検査。実負荷の計測・分析は未評価。 |
| 5b | KA Core | 性能と電力効率のための構成最適化 | 部分 | 880で時間・消費量ごとに学習し２構成を予測。架空の２構成・有限候補であり、一般の設計空間探索や実機の効率は未評価。 |
