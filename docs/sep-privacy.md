# SEP-Privacy の対応状況

出典: [CS2023 SEP-Privacy](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 278–279。原典を要約した作業用一覧。依頼27の判定は架空の手順に基づく教材であり、実際の法令適合や情報の匿名性を保証しない。

## 例示学習成果

| 番号 | 分類 | 要約 | 状況と限界 |
|---:|---|---|---|

| 2 | CS Core | 広範な監視システムにおけるデータ収集の役割を説明 | 未着手 |

| 4 | CS Core | 差分プライバシーやエンドツーエンド暗号化等の影響を説明 | 依頼196で１回の二値回答の確率比と限界を比較。E2E 方式や自由な説明は未評価 |

依頼27の前提では、受取番号と薬草の種類で薬師が包みを作り、受付は番号と受取時間で照合して封をした包みを渡す。本人の名前や住所を使わず、掲示板にも個別注文を公開しない。受取番号は他の情報と結び付けられ得るため、匿名化を保証するものではない。他の手順、アクセス管理の実装、保存期間、本人の意思、法律や文化の違いは評価していない。

項目別の再照合は [coverage-sep-privacy.md](coverage-sep-privacy.md) を参照。

依頼196では二値回答に対し、４枚の等確率の札のうち３枚で本当の答え、１枚で反対の答えを公開する模型を比べる。いずれの公開結果についても、２通りの本当の答えにおける確率の比は最大３で、１回の応答は ε = ln 3 の局所差分プライバシーを満たす。独立に２回公開して両方「はい」になる確率は本当の答えが「はい」なら９/16、「いいえ」なら１/16 で、確率比の上限は９、ε は 2 ln 3 となる。８通りの札と２回の組を調べる教材であり、実際の乱数や個人の回答は使わない。実際の集計や公開制度の安全性は保証しない。参考：[NIST SP 800-226](https://csrc.nist.gov/pubs/sp/800/226/final)。

依頼27は、別の対応表で名前につながる番号と、個人に結び付かないと仮定した合計を比較する。現実には合計も他の情報から推測され得るため、匿名性を一般に保証しない。参考：[ICO の仮名化の説明](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/data-sharing/anonymisation/pseudonymisation/)。
