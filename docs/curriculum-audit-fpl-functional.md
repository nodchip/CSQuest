# 原典との範囲照合：FPL-Functional

[CS2023 印字 pp.131–133](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の FPL-Functional と[項目別台帳](coverage-fpl-functional.md)を2026-11-06に照合した。[ACM が公開する同報告書](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)の本文でも区分を確認した。

トピック１〜４は CS Core、５・６は KA Core、７〜10は Non-core。１・２・３・６には子項目がある。各親は子の列挙を導く本文の概念を含むため、台帳では親を保持し、子との重複候補を区別して扱う。分母候補は親子を含む22行であり、そのまま独立した22項目とみなさない。成果１〜４は CS Core、５〜９は KA Core、10〜13は Non-core の計13行。

成果１は変更可能な状態だけでなく、参照同一性を考慮しないアルゴリズムも含むため、台帳に未評価の範囲として追記した。成果５の SECD 機械、９の複数の実言語、11の ABC 機械、13の並行・逐次の比較は固定模型だけでは網羅されない。トピック５の関数型におけるメタプログラミングとリフレクションは対応を未確認のまま残す。

この記録は範囲と区分の照合であり、各教材の正確性、自由なプログラム開発・説明能力、知識単位全体の完成を証明しない。

同日、依頼590に有限の鎖の同一性と内容を比較する固定例を追加した。一般のアルゴリズム開発や実言語での実装は引き続き未評価。

同日、依頼779に式の形を調べ新しい式を作る固定例を追加し、トピック５の部分対応として記録した。実言語のマクロ・束縛や一般の反射機構は未評価。
