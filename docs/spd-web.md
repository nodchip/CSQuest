# SPD-Web の対応状況

出典: [CS2023, SPD-Web](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p. 303。原典を要約した作業用一覧。依頼62は実 Web アプリの作成や運用を評価しない。

## トピック

| 番号 | 分類 | 要約 | 現状 |
|---:|---|---|---|
| 1 | KA Core | Web プログラミング言語 | 未着手 |
| 2 | KA Core | Web プラットフォーム、サービス、API | 依頼62で POST による受付と再送の固定例。実 API やプラットフォーム開発は未対応 |
| 3 | KA Core | SaaS | 未着手 |
| 4 | KA Core | DOM やアクセシビリティなど Web 標準 | 未着手 |
| 5 | KA Core | セキュリティとプライバシー | 未着手 |
| 6 | Non-core | Web アプリの要求分析 | 未着手 |
| 7 | Non-core | クラウド、拡張性、費用 | 未着手 |
| 8 | Non-core | データの所在と完全性・削除 | 未着手 |
| 9 | Non-core | モノリス、マイクロサービス、REST、イベントなどの構成 | 未着手 |
| 10 | Non-core | 関係・NoSQL の保存方法 | 未着手 |

## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | KA Core | マイクロサービスによる Web アプリの設計と実装 | 未着手 |
| 2 | KA Core | ホスティング、サービス、拡張性の制約を説明 | 未着手 |
| 3 | KA Core | Web と一般のプログラミングを比較 | 未着手 |
| 4 | KA Core | SaaS と従来製品の違いを説明 | 未着手 |

識別番号による重複抑止は、対応するサーバーを仮定する。番号の一意性、保存期限、同時実行、異なる内容での再利用などは実装していない。
