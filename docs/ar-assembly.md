# AR-Assembly の対応状況

出典: [CS2023, AR-Assembly](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 103–104。原典を要約した作業用一覧。依頼73は記号を用いた架空機械であり、実機の命令セットやプログラムを書く能力を示さない。

## トピック

| 番号 | 分類 | 要約 | 現状 |
|---:|---|---|---|
| 1 | CS Core | フォン・ノイマン型の構成 | 依頼73で命令と数を同じ記憶に置く固定例。機能単位や実機の構成は未対応 |
| 2 | CS Core | 命令の取出し・解読・実行 | ５命令と２入力を段階的に操作。一般的な制御回路や実機は未対応 |
| 3 | CS Core | SIMD・MIMD と分類 | 未着手 |
| 4 | CS Core | 共有メモリ型マルチプロセッサ・マルチコア | 未着手 |
| 5 | KA Core | ISA、命令形式、アドレッシング、機械語・アセンブリ | LOAD・分岐・加算・書戻し・停止の架空例。実 ISA と言語での作成は未対応 |
| 6 | KA Core | サブルーチン呼出しと復帰 | 未着手 |
| 7 | KA Core | I/O と割込み | 未着手 |
| 8 | KA Core | ヒープ、静的領域、スタック、コード | 未着手 |

## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | CS Core | 組込み系の機能単位と記憶を議論 | 未着手 |
| 2 | CS Core | 命令の実行とスレッド・同期・SIMD を説明 | 取出し・解読・実行と条件分岐の固定例。並列拡張や自由な説明は未対応 |
| 3 | CS Core | パイプラインの並列性とハザードを評価 | 未着手 |
| 4 | KA Core | 命令の機械レベルと記号アセンブラの表現 | 記号の固定表示のみ。ビット表現やアセンブラは未対応 |
| 5 | KA Core | 高水準の構造をアセンブリ・機械語に対応づける | 未着手 |
| 6 | KA Core | 命令形式とアドレス数を比較 | 未着手 |
| 7 | KA Core | サブルーチンの呼出しを図から分析 | 未着手 |
| 8 | KA Core | 割込みと I/O を説明 | 未着手 |
| 9 | KA Core | 文字列・配列を処理するアセンブリプログラムを書く | 未着手。ゲーム内操作は実言語で書く能力を評価しない |

架空機関は番地６を読み、０なら番地４へ分岐し、そうでなければ番地７の２を足して番地６へ書く。命令取出し時に次の番地へ進める規則を採用し、入力０と３で状態を確認。記憶・命令・レジスタのビット表現、パイプライン、割込みは再現しない。
