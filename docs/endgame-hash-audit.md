# 文庫の番号棚とハッシュ表

[CS2023 AL-Foundational、印字88〜89ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=88) のハッシュ表と衝突処理に関連する固定例。０以上の番号を３で割った余りを棚番号とし、連鎖法と線形探査を操作する。異なる２件を達成後、削除済みの印を残す場合と空にする場合で、探索結果が異なることを確かめる。

３棚と指定された番号に限定した模型であり、任意の入力、負の番号、再ハッシュ、削除済み位置への再挿入、重複番号の更新、一般の計算量や自由な説明は扱わない。連鎖法の棚内照合は１操作で、各札の比較回数は測らない。教材の対応は部分的である。

実装担当とは別の coverage_candidates が原典、固定例の計算、文章、履歴と開放条件を確認し、探索の停止条件と、最後の不在結果の表示を指摘した。修正後に再確認した。独立担当によるブラウザ操作は行っていない。`tests/endgame-hash.test.js` は固定例と誤操作を検証し、`scripts/endgame-hash.playwright.js` は達成状態を用意した記録から、誤操作、途中保存、再挑戦、開放、達成結果を確認する。実スクリーンリーダー音声は未検証。
