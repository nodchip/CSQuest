# 四地域の画像制作記録

- `garden-nagi.png`: 組み込み imagegen。参照 `station-keeper.png` は絵柄のみ。若い男性の庭師、星形の花、緑と生成りの衣服、植物を世話する膝をついた姿、顔と全身が見える、羊皮紙風背景、文字なし。生成画像を目視確認。
- `observatory-sena.png`: 組み込み imagegen。参照 `station-keeper.png` は絵柄のみ。若い女性の観測者、藍色と生成りの衣服、片足を段にかけ望遠鏡で空を眺める、顔と全身、羊皮紙風背景、文字なし。生成画像を目視確認。
- `tailor-dario.png`: 組み込み imagegen。参照 `station-keeper.png` は絵柄のみ。中年男性の仕立て職人、椅子に座って布を縫う、顔と全身、羊皮紙風背景、文字なし。生成画像を目視確認。
- `guide-marta.png`: 組み込み imagegen。参照 `station-keeper.png` は絵柄のみ。明るい年配女性の案内人、地図を広げて道しるべの横に立つ、顔と全身、羊皮紙風背景、文字なし。生成画像を目視確認。
- `travel-garden.webp`: 組み込み imagegen。`travel-forge.webp` を絵柄の参照に、星形の花と天球儀のある石の東屋を透明背景で生成。縮小し透過を保持。
- `travel-observatory.webp`、`travel-tailor.webp`、`travel-guide.webp`: 組み込み imagegen。`travel-forge.webp` を絵柄の参照とし、望遠鏡のある観測所、布を飾った仕立て屋、道しるべのある案内所をそれぞれ透明背景で生成。縮小し透過を保持。
- `four-garden.webp`、`four-observatory.webp`、`four-tailor.webp`、`four-guide.webp`: 組み込み imagegen。`forest-library.png` の画風を参照し、それぞれ星花の庭園、雲の観測所、仕立て屋の室内、旅人の案内所を新規生成。目視確認。
- `travel-island.webp`: 組み込み imagegen。`travel-terrain-mobile.webp` を絵柄の参照に、元の地図の海の向こうに重ねず継ぎ足す島の地形を新規生成。既存地形自体は描き直していない。
- `travel-island-desktop.png`: 組み込み imagegen。`travel-terrain.webp` の画風を参照し、海に囲まれた横長の島を生成。PC の下部地図で縦横比を保って表示する。
