# NC-Routing：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.199–200。[既存の調査](nc-routing.md)と依頼・テストを照合。状態は[追跡方法](coverage-status.md)に従う。固定模型は実ネットワークの実装・運用や自由な説明を直接評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | KA Core | 経路制御の方式と階層 | 部分 | 48で固定経路、481で同期距離ベクトル、482でリンクステート、483で AS 経路を操作。集中・分散の一般比較、送信元経路、仮想回線や QoS は未評価。 |
| 2 | KA Core | 転送表と照合方法 | 部分 | 48で次の塔、61で８ビットの架空宛先と文書用 IPv4 の固定表の最長接頭辞を操作。実網の転送表は未評価。 |
| 3 | KA Core | IP と規模拡張、NAT・CIDR・BGP・IP の版 | 部分 | 320で変換、480で集約、483で AS 経路、484で IPv4・IPv6 の長さと省略表記の固定例。実網や一般の規模拡張は未評価。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | KA Core | 経路制御の方式と階層を説明 | 部分 | 481・482で距離ベクトルとリンクステート、483で AS 経路を操作。多様な方式や自由な説明は未評価。 |
| 2 | KA Core | IP 網でのパケット転送を説明 | 部分 | 48の次の塔と回数制限、61の最長接頭辞を操作。IP ヘッダー、実網の転送と自由な説明は未評価。 |
| 3 | KA Core | インターネットの規模拡張への対応を説明 | 部分 | 480で経路集約と例外を操作。一般の規模拡張や自由な説明は未評価。 |

`tests/routes.test.js`、`tests/prefix.test.js`、`tests/route-aggregation.test.js`、`tests/distance-vector.test.js`、`tests/link-state.test.js` 等は各模型の一部を検査する。前提・出典と限界は[既存の調査](nc-routing.md)を参照。
