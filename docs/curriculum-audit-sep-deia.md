# 分母照合：SEP-DEIA

[CS2023 印字 pp.285–286](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=285) と[候補台帳](coverage-sep-deia.md)を 2026-11-11 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core トピック 1〜6 はアイデンティティと計算技術・環境の相互作用、多様な開発チームと不足の影響、包摂的な言葉と問題のある用語、包摂的行動、アクセシビリティを考慮した設計、多様性・公平・包摂・アクセシビリティへの専門家の影響。KA Core 7〜9 は多様な専門家の実践、歴史的な周縁化・構造的な社会機構・技術と世界の基盤に関する課題、異文化間の違いと DEIA の必要性。番号付き子はなく 9 行。原典の導入は構造的な不公平に単一の即効策はないことも記す。

CS Core 成果 1〜7 は DEIA に関わる概念の区別、包摂的な言葉と行動、教室・実習室・Web のアクセシビリティ評価、異なるアイデンティティを持つ人との敬意ある協働、所属機関の構成と格差要因、設計に埋め込まれた前提、多様なチームの利点と不足の費用。KA Core 8〜11 は多様な専門家の業績、権力・特権の影響、身近・未知の文脈における構造的な改善例、所属機関と地域社会の構成・格差要因の比較。成果 11 行を別に追跡する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の SEP-DEIA 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実際の個人・集団の参加、実環境の評価や自由な分析は固定模型だけで直接評価しない。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
