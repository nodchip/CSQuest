# 少ない枚数の品札：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字90〜91頁 AL-Strategies 1e-iv（動的計画法）と成果６（貪欲法の最適性評価）に関連する固定例。旧依頼76 `src/coins.js` の額面と表作成を現行の街へ接続した。現行の品札整列教材とは、合計と枚数の最適化を扱う点が異なる。
- [Cornell の硬貨問題の解説](https://www.cs.cornell.edu/courses/JavaAndDS/files/greedyAlgorithm.pdf) は大きい額面から選ぶ方法が額面によって最適とは限らないことを説明する。
- １・３・４の札はそれぞれ十分あり、合計６を作る。残りを超えない最大の札を毎回取ると４＋１＋１の３枚。D(0)=0 とし、n 以下の額面 c について D(n−c)+1 の最小を記録すると D(0..6)=[0,1,2,1,1,2,2]、６は３＋３の２枚。価値５の候補１と４は同数であり、どちらも受理する。単体テストは各小計を独立に全組合せで照合する。
- 少数の固定額面と金額を扱い、任意の額面・金額、有限枚数、一般の貪欲法の成否、計算量の証明や実言語での実装は評価しない。旧教材・本教材の存在を原典全体の完成とはしない。
