# AR-Logic：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.102–103。[既存の調査](ar-logic.md)と関連する依頼・テストを照合。状態は[追跡方法](coverage-status.md)に従う。すべて KA Core。親項目にのみある FPGA・高位合成も追跡し、子項目と数える際は重複させない。固定模型は実ハードウェアの設計能力を証明しない。
