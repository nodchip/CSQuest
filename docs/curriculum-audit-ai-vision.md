# 原典との範囲照合：AI-Vision

[CS2023 印字 pp.82–83（PDF 82〜83ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-ai-vision.md)を2026-11-05に照合した。トピック１〜６と子項目は Non-core。コンピュータビジョンとパターン認識の親項目１・６を追加した。成果１〜11には原典で個別の区分見出しがないため、区分を推測しない。台帳はトピック13行、成果11行で、親子の重複は集計時に検討する。

範囲と区分の照合であり、教材の正確性や成果の達成は別途評価する。画像認識の実応用の自由な列挙は未評価で、固定画素や小規模なデータは一般の認識性能を証明しない。
