# FPL-Constructs・FPL-Pragmatics の対応状況

出典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.144–145。いずれも Non-core。既存依頼との限定的な関連を示し、一般的な能力や自由な説明・プログラム作成の達成を意味しません。

## FPL-Constructs

| 原典のトピック | 対応と不足 |
| --- | --- |
| 1 カプセル化 | 依頼65で状態と振る舞いの固定例。一般の機構は未対応 |
| 2 遅延評価と無限列 | 依頼325で有限の先頭部分の取り出しと全体の事前生成を比較。一般の評価機構は未対応 |
| 3 遅延評価と先行評価の比較 | 依頼325で有限列、326・327で値・名前・必要呼びと副作用・発散の固定例を比較。一般の評価戦略は未対応 |
| 4 単一化・表明・式評価 | 依頼146で有限の項の単一化、依頼281で式の評価。３者の比較は未対応 |
| 5 例外・継続・モナド | 依頼250で例外時の後始末。継続とモナドは未対応 |
| 6 多重継承・ミックスイン・トレイト・多重メソッド | 未対応 |
| 7 マクロ・生成・モデルに基づく開発 | 未対応 |
| 8 正規表現による文字列処理 | 依頼154で固定のパターンの一致。一般の処理は未対応 |
| 9 動的なコード評価 | 未対応 |
| 10 表明・不変条件・事前事後条件の検査 | 依頼69・223で固定の不変条件と事前事後条件。言語の検査機能は未対応 |
| 11 領域固有言語 | 未対応 |
| 12 大規模並列計算のモデルと言語 | 依頼285で並列走査の固定例。実際の言語や大規模環境は未対応 |

| 例示学習成果 | 対応と不足 |
| --- | --- |
| 1 高度な構成と慣用法を正しく使う | 各依頼は固定例の操作。実際のプログラムを書く能力は未評価 |
| 2 構造・品質・生産性への効果を論じる | 未対応 |
| 3 他の言語機能の定義・実装との相互作用を論じる | 未対応 |

## FPL-Pragmatics

| 原典のトピック | 対応と不足 |
| --- | --- |
| 1 技術とソフトウェア要件が言語の発展に与える影響 | 未対応 |
| 2 問題領域と言語パラダイム | 未対応 |
| 3 言語設計の基準：直交性、制御・反復、モジュール化 | 依頼224でモジュール境界の固定例。言語設計の基準は未対応 |
| 4 評価順序・優先順位・結合性 | 依頼156で操作順序、依頼310で引き算の結合の固定例。一般の比較は未対応 |
| 5 先行評価と遅延評価 | 依頼325で有限列・無限列、326・327で未使用・二重参照と副作用の固定模型を比較。一般の評価戦略は未対応 |
| 6 制御・反復の構成 | 依頼03・198で反復の固定例。構成の定義は未対応 |
| 7 外部呼出しとシステムライブラリ | 未対応 |

| 例示学習成果 | 対応と不足 |
| --- | --- |
| 1 直交性や既定値の役割を論じる | 未対応 |
| 2 言語設計上の判断を評価し根拠を述べる | 未対応 |
| 3 評価順序・優先順位・結合性で結果が変わるプログラムを実装 | 依頼156・310で固定例を操作。プログラムの実装は未評価 |
| 4 遅延評価の利用例を示す | 依頼325で無限列から有限個を取り出す模型。利用例全般は未対応 |
| 5 外部呼出しとシステムライブラリの必要性・実装への影響を論じる | 未対応 |

依頼325は、無限列の全体を取り出し前に生成する方法が完了しない一方、先頭から必要な個数を順に生成できる場合を扱います。発散する要素、共有、記憶使用量や実処理系の性能は扱いません。参考：[GHC Prelude: Infinite lists](https://downloads.haskell.org/ghc/9.10.0.20240413/docs/libraries/base-4.20.0.0-0f99/Prelude.html)。

依頼326は、副作用のない固定の引数を使わない場合と二度使う場合に、値呼び・名前呼び・必要呼びの計算回数を比べます。発散、副作用、例外や実際の処理系は扱いません。参考：[Cornell: Lazy Evaluation](https://www.cs.cornell.edu/courses/cs3110/2009fa/Lectures/lec25.html)。

依頼327は、未使用の発散する引数、副作用のない二重参照、状態を増やす引数の二重参照を固定順序と明示的な共有規則で比較します。実言語の副作用や評価順序、一般のプログラムは扱いません。参考：[Cornell: Lazy Evaluation](https://www.cs.cornell.edu/courses/cs3110/2009fa/Lectures/lec25.html)。
