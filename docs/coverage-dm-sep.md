# DM-SEP：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.123。[追跡方法](coverage-status.md)に従う。未照合は未実装の証拠ではない。原典の 2 と子項目 2a は内容を区別して記し、集計時に親子を重複して数えない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | CS Core | 規模に関わる問題 | 未照合 | 規模の社会的影響の教材は未確認。 |

| 2a | CS Core | 設計段階からの法令順守 | 未照合 | 194は架空の手順であり法令適合は扱わない。 |
| 3 | CS Core | データの匿名性 | 部分 | 27・196・332・333で番号、集計と準識別子を比較。一般の匿名性は未評価。 |
| 4 | CS Core | データの所有・管理責任 | 部分 | 331で本人・管理係・利用者の固定の立場を比較。一般の所有権や法的責任は未評価。 |
| 5 | CS Core | 意図した用途と意図しない用途 | 部分 | 196・331で集計からの推測と宣伝利用を比較。一般の用途や影響は未評価。 |
| 6 | KA Core | データの信頼性 | 部分 | 330で元記録の訂正と報告の再集計を追う。元の値の真偽・一般の品質は未評価。 |
| 7 | KA Core | 来歴・系譜・メタデータの管理 | 部分 | 330で２畑の版と集計処理を追う。一般の管理・表現は未評価。 |
| 8 | KA Core | データセキュリティ | 部分 | 194・195・329で閲覧・監査・設定の固定例。実システムは未評価。 |
