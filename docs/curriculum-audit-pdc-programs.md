# 分母照合：PDC-Programs

[CS2023 印字 pp.219–220](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=219) と[候補台帳](coverage-pdc-programs.md)を 2026-11-11 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core の台帳は 1a〜1d（並列可能な作用、順序と DAG、独立性、必要な順序と不要な制約の緩和）、2a〜2d（場所、スケジューリング、主体の識別、場所間の通信）、3a〜3e（資源・通信の準備、手続き的・反応的・依存する活動開始、粒度と費用）、4a〜4d（順序のない活動の非決定性、一貫性・安全性・原子性・合意、故障耐性、トレードオフ）。親 1〜4 の並列性・分散・活動開始・実行特性という文脈を各子に保持し、親と子を重複して数えない。

KA Core 5a〜5f は CPU の命令・データ並列、SIMD と異種データ並列、マルチコア・タスク・アクター、クラスタ・クラウドと弾力的な提供、ネットワーク分散システム、量子・分子等の新技術。原典の親 5 は **1 つ以上を選ぶ**構成であり、6 行すべてが必修という意味ではない。台帳トピックは計 23 行。

CS Core 成果 1・2 は数値式の並列化を DAG で示すこと、純粋な逐次プログラムにおける一貫性・耐障害性の位置付けの説明。KA Core 3〜5 は効率的なイベント計数関数、複数方式での filter/map/reduce、要求ごとに活動を作るサービスの記述。成果 5 行をトピックと別に追跡する。原典の逐次抽象モデルと故障し得る実装装置は区別する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の PDC-Programs 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実プログラム作成・実測・自由な説明は固定模型だけで直接評価しない。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
