# 原典との範囲照合：HCI-Accountability

[CS2023 印字 pp.176–177](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の HCI-Accountability を [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)と照合した。トピック１〜３は CS Core、４・５は KA Core。欠けていた親５行を追加し、親子20トピック行・８成果行とした。親子は重複するため、行数を独立項目数や完成率としない。

原典の４は価値を考慮した設計、５は設計による説得を含む。説得を設計目標に用いる５bは未照合のままとし、操作的な設計との区別に関する固定例だけでその成果を満たしたと判断しない。３bの法的枠組みは特定の法制度の固定例であり、適用判断・法令適合・実際の組織での責任履行は評価しない。

この作業は原典の範囲と区分の照合であり、各教材の正確性、実際の関係者との検討、自由な設計能力や全教材の完成を証明しない。
