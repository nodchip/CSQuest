# GIT-Fundamentals の対応

原典: CS2023 pp.155–156。依頼83では５×５画素の左上を原点とし、頂点 (0,0)、(4.7,0)、(0,4.7) の三角形を表示する。中心標本では10画素が内側。右上画素の４標本 (4.25,0.25)、(4.75,0.25)、(4.25,0.75)、(4.75,0.75) のうち１点が内側で、単純平均は25%。実際の被覆面積は 0.7×0.7÷2 = 24.5% であり、標本平均が常に正確な面積になるわけではない。

| 分類・番号 | 内容と状態 |
|---|---|
| CS Core 1 | グラフィックス・対話技術の用途、悪用とリスク。未対応 |
| CS Core 2 | 出力装置、解像度、縦横比、フレームレート。依頼83で５×５の画素のみ。他は未対応 |
| CS Core 3 | 視覚、色、投影、時間、コントラスト、アクセシビリティ。依頼64で投影の固定例、依頼22で色以外の手がかりの固定例。視覚モデルは未対応 |
| CS Core 4 | ラスタ・ベクタ画像と形式。未対応 |
| CS Core 5 | ラスタ化、解像度、標本化、量子化。依頼83で固定図形の標本、依頼221で４区間の量子化、依頼222で時間間隔による読み取りの固定例。連続波形や一般の量子化・解像度は未対応 |
| CS Core 6–9 | 色モデル、保存と再計算、座標、静止画列としての動画。依頼26・64で座標の固定例。その他は未対応 |
| KA Core 10–11 | 対話的グラフィックスの実装、表示装置の特性。未対応 |

CS Core の例示学習成果2・10は、依頼83で固定図形の標本化と境界の見え方を比較する一例のみ。他のCS Core成果1、3–9、11–12と KA Core成果13–14は未対応。実際の描画プログラムや自由な説明を評価しない。
