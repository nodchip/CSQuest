# NC-Fundamentals の対応

原典: CS2023 p.198。依頼78は、送り手・二つの口を持つ中継塔・受け手による２区間の単純化した通信。アプリケーションの伝言にトランスポート層とネットワーク層の封を重ね、区間ごとにデータリンク層の封を選ぶ。物理層は区間を通して送るという説明に留める。ネットワーク層の端点を保ちつつ、各区間の送り元・次の受け手を変える例である。参考: [RFC 791](https://www.rfc-editor.org/rfc/rfc791)、[RFC 894](https://www.rfc-editor.org/rfc/rfc894)。IP の TTL などは中継で変化するため、すべてのネットワーク層の情報が不変だとは示していない。

例示学習成果は CS Core。1 インターネットの組織、2 通信の用語、4 エッジやコア等の複雑さは未対応。3 の階層構造は依頼78の固定例に限り、一般的な説明能力やプロトコル実装を評価しない。

依頼271は空の行列の容量２通、到着を先に処理し各刻１通送る模型。時刻０に３通が来ると最後の１通が落ち、１刻ごとなら全３通が届く。到着順は固定で、伝搬遅延、再送、可変長パケットや輻輳制御は扱わない。参考：[MIT、通信路と待ち行列](https://ocw.mit.edu/courses/6-02-introduction-to-eecs-ii-digital-communication-systems-fall-2012/950e349a9779e491000426ccb218746e_MIT6_02F12_chap16.pdf)。

依頼272は３通を、各１刻の２区間と蓄積転送の中継塔を通して４刻で届ける固定模型。中継塔は刻の始めに保持する伝令のみを送る。２区間を異なる伝令で同時に使えるが、伝搬遅延、処理時間、消失、可変長や他の通信は扱わない。参考：[MIT、通信ネットワーク](https://ocw.mit.edu/courses/res-6-004-principles-of-computer-system-design-an-introduction-spring-2009/e962408d900226fef264fd1cd1b81468_part_ii_open_5_0.pdf)。
