# SF-Resource：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.294。[追跡方法](coverage-status.md)に従い、「部分」は記した限定例の存在であり完成を示さない。原典はこの単位に Non-core を列挙していない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | CS Core | CPU、メモリ、記憶装置、帯域などの有限資源 | 部分 | 依頼14で炉を仕事に割り当て、40で頁の行き先を確認。資源の種類全体や一般の管理は未評価。 |
| 2 | CS Core | 先着・優先度・公平・中断などの割当方式 | 部分 | 依頼14で先着とラウンドロビン、176で中断、177で優先度と待ち時間を操作。一般の方式や公平性は未評価。 |
| 3 | KA Core | 一般的な方式の長所・短所 | 部分 | 依頼176で応答と切替費用、177で優先度と飢餓を比較。広い負荷・方式の比較は未評価。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | CS Core | 有限資源を割り当てて管理することを定義 | 部分 | 依頼14・40で固定の炉・頁を扱う。資源全般と自由な定義は評価しない。 |
| 2 | CS Core | 一般的な割当・スケジューリング方式を説明 | 部分 | 依頼14・176・177の固定規則を操作する。一般の方式と自由な説明は評価しない。 |
| 3 | CS Core | 方式を開発し性能を評価 | 部分 | 依頼14で２方式の実行順を操作し完了時刻を比較。実コードの開発、実測や任意の負荷の評価は対象外。 |
| 4 | KA Core | 各方式の利点・欠点を説明 | 部分 | 依頼176の応答と切替費用、177の待ち続ける仕事と優先度の固定例。一般の説明は評価しない。 |

実装と検証は `src/scheduling.js`・`tests/scheduling.test.js`、`src/os-tradeoff.js`・`tests/os-tradeoff.test.js`、`src/starvation.js`・`tests/starvation.test.js` を参照。実際のコードを書く成果はゲーム内操作で直接評価しない。
