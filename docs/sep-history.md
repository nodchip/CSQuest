# SEP-History: 計算の歴史

出典：[CS2023 印字 pp.282–283](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf)。三つの出来事の固定例は、計算の歴史全体や複数の文化的視点を網羅しない。

| 区分・トピック | 対応と不足 |
|---|---|
| CS Core 1 ハードウェア・ソフトウェア・人や組織の歴史 | 依頼363で解析機関の注記、ENIAC を準備した女性たち、CERN での Web 提案を時系列で扱う。歴史全体は未対応 |
| CS Core 2 現在・異なる社会的文脈・将来における歴史の役割 | 依頼363で人々の仕事と組織の目的に触れる。複数の社会的文脈と現在・将来への影響の比較は未対応 |
| KA Core 3 デジタル以前 | 依頼363で1843年の解析機関の注記を紹介。他の古代・機械式・理論史は未対応 |
| KA Core 4 初期の現代計算機 | 依頼363で1945年の ENIAC の仕事を紹介。他の機械・組織・文脈は未対応 |
| KA Core 5 PC の時代 | 未対応 |
| KA Core 6 インターネットの時代 | 依頼363で1989年の Web 提案を紹介。ネットワーク、標準、ブラウザーなどの発展は未対応 |
| KA Core 7 モバイル・クラウドの時代 | 未対応 |
| KA Core 8 AI の時代 | 未対応 |

| 区分・例示学習成果 | 対応と不足 |

| CS Core 2 現在の見方が歴史から形作られることや異なる視点を議論 | 未対応 |

依頼363の年と内容は、[Computer History Museum のラブレスの注記](https://www.computerhistory.org/babbage/adalovelace)、[Smithsonian の ENIAC と女性たち](https://womenshistory.si.edu/human-computer-project)、[CERN の Web の歴史](https://home.cern/science/computing/the-birth-of-the-web) を参照した。Web の1989年は提案の年であり、インターネットそのものの発明年ではない。
