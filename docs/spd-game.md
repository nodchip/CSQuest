# SPD-Game の対応

原典: CS2023 pp.306–308。依頼94は１次元の点を位置０から10へ動かし、閉区間 [4,6] の壁について、更新後の位置のみと移動区間全体の交差を比べる。速度10では位置だけの判定が壁を見落とし、区間判定は位置４で検出する。速度２なら位置だけの判定でも４に触れる。端の接触を含み、静止壁と点の模型である。

| KA Core トピック | 内容と状態 |
|---:|---|
| 1 | ゲームプラットフォームの歴史、種類、制約、入出力と競技環境。未対応 |
| 2 | 実時間シミュレーションと描画。依頼94で衝突検出とトンネリング、799で描画と固定時間更新の固定例。CPU/GPU、描画パイプライン、空間分割やその他のアルゴリズムは未対応 |
| 3 | ゲーム開発言語、シェーダー、API、道具。未対応 |
| 4 | エンジンと開発手法。未対応 |
| 5 | ゲームデザイン、ジャンル、利用者、応用。未対応 |

例示学習成果 9 は接触判定を比較する固定例に留まり、実装や最適化は評価しない。1–8・10–15 は未対応。実ゲームの形状、反射や移動体同士の衝突は扱わない。

依頼799は描画の頻度と固定時間刻みの更新を比較する固定例。実時間・処理落ちやゲームループの実装は評価しない。[項目別台帳](coverage-spd-game.md)を参照。
