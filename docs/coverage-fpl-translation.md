依頼787は [GCC のホスト・対象](https://gcc.gnu.org/install/configure.html) と [Oracle のバイトコードの説明](https://docs.oracle.com/javase/tutorial/getStarted/intro/definition.html)を参考に、Ａ上でＡまたはＢ向け機械語、仮想機械１向け中間コードを作る固定模型。機械語は対象が一致すると直接動き、中間コードは対応する仮想機械が必要とする。互換性はあらかじめ定めた仮定で、一般の VM の版や実機の互換性を主張しない。`tests/cross-target.test.js` は全12組合せと生成前・誤答・保存復元を検査する。実際のコンパイラや成果物の実行は含まない。

依頼788は [Cambridge の EBNF の説明](https://www.cl.cam.ac.uk/~mgk25/iso-ebnf.html)を参考に、１つの構文図について省略・繰り返し・順序を規則札に写し、６種類の巻物で図と規則を比較する。`tests/syntax-rail.test.js` は長さ５までの列を独立した正規表現と比較し、18通りの候補を６例で区別できること、途中記録を検査する。固定の記法・図であり、６例が任意の文法の等価性を証明するわけではない。

依頼789は [Rust の折り返し加算](https://doc.rust-lang.org/core/primitive.i8.html#method.wrapping_add) と [CompCert の意味保存](https://compcert.org/doc/)を参考に、符号付き８ビットの折り返し算術を持つ固定の門の条件を比較する。常に開く翻訳は127で元の条件と異なり、最大値だけ閉じる候補はこの模型の全256入力で一致する。`tests/compiler-wrap.test.js` は全入力の結果と誤予想・途中記録を検査する。実言語ごとにオーバーフロー規則は異なり、検査は一般のコンパイラの正しさ・安全性の証明ではない。

依頼790は [GNU ld のオブジェクトとシンボル](https://www.sourceware.org/binutils/docs/ld/Basic-Script-Concepts.html)を参考に、未定義・一つの定義・強い定義の重複を比較し、相対位置に開始位置を足す簡略模型で２つの配置と呼出し・復帰を操作する。`tests/link-load.test.js` は２配置・全４組合せ、誤操作、復元を検査する。実際の形式や弱い定義、動的リンク、再配置方式全般は評価しない。
