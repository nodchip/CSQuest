# FPL-Translation：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 139–140。[追跡方法](coverage-status.md)に従い、10トピックと７例示学習成果を記録する。固定例の操作は実言語での文法記述や一般的な説明・実装能力を示さない。[関連する構文・翻訳の一覧](fpl-syntax.md)も参照。

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | CS Core | コンパイル・JIT・解釈の違いと利点・限界 | 部分 | 311・312で固定の翻訳タイミングと費用を比較。実装全般や自由な説明は未評価。 |
| 2 | CS Core | 構文解析と意味・評価の区別 | 部分 | 315で構文・型の誤りを区別し、75で固定の構造と値を比較。一般的な区別は未評価。 |
| 3 | CS Core | BNF・拡張 BNF による構文指定 | 部分 | 309で既定の規則を用いた導出。文法を自由に記述する能力や拡張 BNF は未評価。 |
| 4 | CS Core | 文・算術式の構文木を例示 | 部分 | 75・309で固定の木を構築。具体構文木と任意の文は未評価。 |
| 5 | CS Core | 構文図から BNF・拡張 BNF への変換 | 未照合 | 構文図から規則への変換を未確認。 |
| 6 | CS Core | 曖昧な構文解析と優先順位による解消 | 部分 | 75・310で算術式の優先順位と引算の結合を比較。一般の曖昧性や条件文は未評価。 |
| 7 | KA Core | 到達可能性を含む GC の利点と限界 | 部分 | 201・202・774で到達可能性と参照カウントの循環を操作。一般の費用・停止時間や自由な説明は未評価。 |

依頼787は [GCC のホスト・対象](https://gcc.gnu.org/install/configure.html) と [Oracle のバイトコードの説明](https://docs.oracle.com/javase/tutorial/getStarted/intro/definition.html)を参考に、Ａ上でＡまたはＢ向け機械語、仮想機械１向け中間コードを作る固定模型。機械語は対象が一致すると直接動き、中間コードは対応する仮想機械が必要とする。互換性はあらかじめ定めた仮定で、一般の VM の版や実機の互換性を主張しない。`tests/cross-target.test.js` は全12組合せと生成前・誤答・保存復元を検査する。実際のコンパイラや成果物の実行は含まない。
