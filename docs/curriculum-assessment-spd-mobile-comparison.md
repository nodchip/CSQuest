# SPD-Mobile の比較教材の個別評価

[原典の範囲照合](curriculum-audit-spd-mobile.md)を踏まえ、2026-11-05 に [SPD-Mobile 台帳](coverage-spd-mobile.md)の KA Core 例示学習成果１を依頼1325の画面、実装とテストに照らして評価した。原典はモバイルプログラミングと汎用プログラミングの比較を求めている。判定は **部分** とする。

依頼1325では、共通の道順計算、画面の中断、位置情報の利用拒否という３つの固定状況から対応を選び、共通する考え方と利用状況による要件を振り返る。携帯・据置の両模型で、メモリーだけの状態と、成功した保存からの再起動後の復元を比較する。中断や権限をモバイルだけに限定せず、保存失敗や実 OS の挙動は評価しない。

`tests/mobile-general-compare.test.js` は３状況と３選択の正誤、保存の復元を検査する。`tests/mobile-session-recovery.test.js` は２端末・２方式の結果と段階、途中記録を検査する。画面の選択と保存は `src/app.js`、`src/mobile-platform-choice.js` と[進捗記録](progress.md)に記したローカル・公開版の操作で確認した。

固定された状況・選択肢の理解を扱う代替体験であり、一般の開発環境・端末・言語・アーキテクチャの網羅的な比較や、自由な言葉で説明する能力を直接評価しない。追加課題は元の依頼の達成条件に含まれないため、依頼を達成しただけでは追加課題を終えた証拠にならない。
