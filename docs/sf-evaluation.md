# SF-Evaluation の対応状況

出典: [CS2023, SF-Evaluation](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 295–296。原典を要約した作業用一覧。依頼66は理想化した固定例で、実システムの性能を測定しない。

| 1 | CS Core | 性能指標 | 依頼66で完了時間、依頼254で固定負荷の平均遅延と処理量を比較。他の指標は未対応 |
| 2 | CS Core | ワークロード、代表的ベンチマーク、測定と分析 | 未着手 |

| 5 | CS Core | 漸近的な規模の分析 | 未着手 |
| 6 | CS Core | 遅い経路と速い経路の分析 | 未着手 |

## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | CS Core | 構成要素が性能改善にどう寄与するか説明 | 未着手 |
| 2 | CS Core | 指標が有用な状況を説明 | 未着手 |
| 3 | CS Core | ベンチマークの利用と限界を説明 | 未着手 |
| 4 | CS Core | アムダールの法則と限界を説明 | 固定の２例と理想化の限界を提示。自由な説明は未対応 |
| 5 | CS Core | 簡単な計算・限界検討による概算 | 依頼66で８条件の所要時間を選択。一般の概算は未対応 |
| 6 | CS Core | ツールで性能を測定・分析 | 未着手 |
| 7–8 | KA Core | システムや階層の性能実験を設計・実施 | 未着手 |

依頼254は、時刻０に到着した４通の完了時刻を `[1, 2, 3, 4]` と `[3, 3, 3, 3]` で比較する固定模型。平均遅延はそれぞれ2.5刻と３刻、４通を終えるまでの処理量は４通／４刻と４通／３刻。継続負荷の定常性能や実測値ではない。
