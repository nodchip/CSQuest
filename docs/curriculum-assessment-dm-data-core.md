2026-11-04 に [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.115–116、対象の実装・試験・配信用ビルドを照合した。ここでの「完成」は元の能力全体の保証ではなく、原典の例示成果について作品の入力制約に沿った代替体験と検証を完了したことを意味する。未評価の範囲は各項目に示す。対象以外の台帳行は今回評価していない。

- 原典・教材：５段階のライフサイクル。`src/lifecycle-expedition.js` の依頼1224は架空の２事例・14場面で、作成、処理、確認・報告、保管・検索、廃棄を扱い、再集計や保管継続も示す。依頼122も固定例である。
- 内容の検証：５段階の名称・範囲は CS2023 の分類に対応する。保管継続や再利用は固定の前提であり、実際の保存義務や安全な削除の一般論とはしない。NIST は６段階の別分類である。
- 操作の検証：`tests/lifecycle-expedition.test.js` の２件が成功。390px 幅のブラウザで段階の誤答・再挑戦、途中再開、14場面と振り返りによる達成を確認した。
- 残る範囲：固定例を超えるデータ管理と実データの保護・法的義務の判断は未評価。広いトピックの完成条件を満たしたとは判定しない。

- 限界：自由記述、実務の個別判断、実際の廃棄の安全性は評価しない。識別の代替体験に限った完成判定である。

## DM-Core：トピック５ — 部分対応

- 原典・教材：取引管理。`src/acid-workshop.js` の依頼1225は４性質を８条件で操作し、停止・規則違反・同時更新を比較する。これだけで取引管理全般は扱わない。
- 内容の検証：[Microsoft の ACID の説明](https://learn.microsoft.com/en-us/windows/win32/cossdk/acid-properties)と [PostgreSQL の分離水準](https://www.postgresql.org/docs/current/transaction-iso.html)を照合。一貫性の規則は与えられた業務制約、分離は固定の順序、永続性は仮定した停止と復元である。過去の参考である IBM のページは今回 403 のため再確認できなかった。
- 操作の検証：`tests/acid-workshop.test.js` の２件と `scripts/check-acid-workshop.py` が成功。SQLite の再接続は電源断時の耐久性を証明しない。390px 幅のブラウザで誤答、途中再開、８条件と振り返りによる達成を確認した。
- 残る範囲：実 DB の保証、分離水準の全挙動、故障・復旧と運用全般は未評価。広いトピックとしては部分対応である。

- 限界：自由な列挙、実際の DB システムの保証、電源断時の耐久性や一般の障害対応は評価しない。原典の能力そのものの証明ではなく、合意された操作型代替に限った完成判定である。
