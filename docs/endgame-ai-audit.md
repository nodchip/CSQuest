# 観測所の AI 評価依頼の範囲

CS2023 の AI-ML（印字ページ 71–72、74–75）に基づく二つの固定例。事前に決めた二つの予測規則を未使用の架空記録で比べ、比較に使った記録を独立した最終評価とみなせないこと、少数例では将来の性能が保証されないことを扱う。規則は訓練されたモデルではなく、実際の機械学習を実施しない。

別の依頼は予測と実際の四つの組み合わせと、見逃しゼロを最優先にする条件での選択を扱う。10件の内訳は A が的中9・見逃し1、B が的中8・空振り2・見逃し0。条件や損失が変われば選択も変わり得る。

独立レビューで数値、分離と条件の説明、各依頼の自己完結性を確認した。正答の情報が読み上げでも分かるよう状態通知を修正した。`tests/endgame-ai.test.js` と `scripts/endgame-ai.playwright.js` で固定例、誤答、保存、達成を検証する。実データ、一般の性能指標や訓練手法、実際の利用場面での評価は未対応。

2026-11-10 に実装担当と別の game_audit が原典の AI-ML と画面・模型を再照合した。６例と追加２例の比較、10例の分類、達成条件と各依頼内の説明を確認した。規則は手作りで、訓練、適合率・再現率の計算、具体的なデータ分割、交差検証や実データでの評価は行わない。今回の独立レビューではブラウザ操作を実施していない。
