# 原典との範囲照合：NC-Reliability

[CS2023 印字 p.199（PDF 199ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-nc-reliability.md)を2026-11-05に照合した。

原典のトピックは１〜６、例示学習成果は１〜４で、すべて KA Core。親子項目はなく、台帳の10行にそれぞれ対応する。列挙された例や他分野への参照は別の項目として数えない。

これは項目の範囲と区分の照合であり、教材の正確性や成果の達成を検証したものではない。特に成果４の実際のプロトコル設計・実装能力は固定模型の操作では直接評価できない。
