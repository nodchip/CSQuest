# SF-Foundations：システムの基本概念

出典：[CS2023 SF-Foundations](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 293–294。すべて CS Core。以下の固定例は一般的な構築・説明能力を保証しない。

## トピック

| 番号 | 内容 | 現状と限界 |
|---:|---|---|
| 1 | デジタルとアナログ、離散と連続 | 依頼221・222で量子化と標本化の固定例。一般的な区別は未対応 |
| 2 | 論理ゲート、論理式、簡単化 | 依頼06でゲートの固定例。一般の簡単化は未対応 |
| 3 | クロック、状態、順序 | 依頼73で命令の段階、158でパイプラインの固定例。一般のクロック設計は未対応 |
| 4 | 初期・終端を含む状態と遷移 | 依頼31で有限の状態と遷移。一般化は未対応 |
| 5 | 有限状態機械、NFA と DFA | 依頼31で固定の決定的な状態遷移。NFA と一般的な比較は未対応 |
| 6 | 組合せ・順序論理、レジスタ、メモリ | 依頼06・37で組合せ回路。順序回路は未対応 |
| 7 | 状態機械としての計算機とネットワークプロトコル | 依頼73は固定の命令処理、263は番号付き伝令の状態。実際のプロトコル全般は未対応 |
| 8 | 逐次処理と並列処理 | 依頼130・254で固定の分担と処理時間の比較。一般の比較は未対応 |
| 9 | アプリケーションの単一スレッドの逐次処理 | 依頼14で作業順序の固定例。実行環境の一般的な説明は未対応 |
| 10 | 要求単位の並列、サーバー・スレッド、パイプライン | 依頼51・254で段階と受付の固定例。実際のサーバーやスレッドは未対応 |

## 例示学習成果

| 番号 | 内容 | 現状と限界 |
|---:|---|---|
| 1 | デジタル・アナログ、離散・連続の違いと例を説明 | 依頼221・222で一部を操作。自由な説明と一般の例は未対応 |
| 2 | 計算を状態と遷移で説明 | 依頼31・73で固定例。一般の説明は未対応 |
| 3 | 状態を持つシステムと持たないシステムの違い | 依頼109で記憶の有無を比較。一般の説明は未対応 |
| 4 | 単純な問題の状態機械を構築 | 依頼31で状態遷移を操作。任意の問題の構築は未対応 |
| 5 | 機械命令を解釈する状態機械として計算機を説明 | 依頼73で架空命令の取出し・解読・実行。一般の説明は未対応 |
| 6 | プログラムやプロトコルの状態機械と別表現を説明 | 依頼263は番号付き伝令の固定例。別表現との比較は未対応 |
| 7 | 状態機械から時系列を導く | 依頼31で固定遷移を操作。一般の導出は未対応 |
| 8 | 同一問題の逐次・並列プログラムを書く | 未対応。実際のコードを書く演習は対象外 |
| 9 | 異なる規模で逐次・並列版を評価し高速化を説明 | 依頼130・254は固定模型。異なる規模の実プログラムの評価は未対応 |
| 10 | 実行時系列上の同時性と経過時間の短縮を説明 | 依頼254で固定の並行受付と完了時刻を比較。一般の時系列や自由な説明は未対応 |
