# 完成率の分母の照合：SPD-Mobile

[CS2023 印字 pp.303–304（PDF 303〜304ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の SPD-Mobile と[項目別台帳](coverage-spd-mobile.md)を2026-11-05に照合した。

原典の１〜６および８は子項目を束ねる見出しとして扱い、独立した子項目を数える。７は子を持たない独立項目として数える。括弧内の例は個別の分母にせず、各項目の対象範囲に含める。

トピックの分母候補は22件（1a〜1b、2a〜2b、3a〜3c、4a〜4b、5a〜5d、6a〜6d、7、8a〜8d）。1a〜3c は KA Core、4a〜8d は Non-core。例示学習成果は５件（1〜5）で、すべて原典では KA Core。

これは原典と台帳の項目の範囲・区分を照合した記録であり、個々の教材の完成・正答判定・正確性や、CS2023 全体の完成率を示さない。成果２〜４にある実アプリの設計・開発や API・センサーの統合は、固定模型を試したことだけでは証明できず、代替体験と限界を個別に評価する必要がある。
