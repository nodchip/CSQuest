# AR-Representation：UTF-8 の伝言（部分対応）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.103、AR-Representation 5・6 の文字の表現に関連する入口。現行文庫は文字の分割・置換を扱う。旧依頼93 `utf8.js` は UTF-8・符号位置・複数バイトの例を既に扱うため、その固定文字のバイト列を再利用し、重複を新しい完成範囲として二重計上しない。

英字 A（U+0041）は 41、あ（U+3042）は E3 81 82。Aあは 41 E3 81 82、あAは E3 81 82 41 で、ともに４バイトだが順は異なる。16進２桁が１バイト。`tests/endgame-utf8-message.test.js` は Node の `Buffer.from` と独立の明示値で照合する。参考：[RFC 3629, UTF-8](https://www.rfc-editor.org/rfc/rfc3629)。

A・あはそれぞれ１符号位置、Aあ・あAはそれぞれ２符号位置だが、見た目の文字数と符号位置・バイト数が常に同じとはしない。結合文字・絵文字・不正な列・任意の変換や実際のファイルの実装は評価しない。

実装担当とは別の `review_candidate` が原典・Unicode・RFC 3629、符号位置と固定例のバイト、各画面、誤答・履歴、分類と開放、旧記録の既定値を確認した。単独文字も２符号位置と読める監査の表現を指摘し、各単独文字は１、２文字列は２と修正後に再確認した。関連11テストも成功した。一般の符号化・実装を検証したものではなく、レビュー担当自身はブラウザを操作していない。

`scripts/endgame-utf8-message.playwright.js` は集いと４地域の達成状態を用意した検証用記録から、213・390・1200 px 幅で分類経由の到達、キーボード操作、誤答案内、途中保存・再開、段階開放と達成後の再開を確認した。新規開始からこの依頼への通し操作、実際のスクリーンリーダー音声や利用者による面白さの評価は未確認。

公開確認：`43bc6f3` の Pages run 42873021637 が成功し、2026-11-11 に公開サイトで同 Playwright スクリプトを隔離したブラウザの 213・390・1200 px 幅で実行、分類からの操作、途中保存・再開と達成を確認した。検証用に進捗を用意した記録からの操作であり、新規開始からの通し確認や利用者評価ではない。
