# 原典との範囲照合：AL-Strategies

[CS2023 印字 pp.90–91（PDF 90〜91ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-al-strategies.md)を2026-11-05に照合した。トピック１〜３は CS Core、４は KA Core、５は Non-core。手法とその縮小統治・変換統治、追加手法の親項目１・1b・1e・４と、成果１の親項目を補った。例示成果１〜７は CS Core。台帳はトピック21行、成果９行で、親子の重複は集計時に検討する。

範囲と区分の照合であり、教材の正確性や成果の達成を証明しない。固定例は一般的な最適性の証明、自由な説明や実装能力を直接評価しない。
