# FPL-Formalism：形式意味論

出典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 145–146。以下は原典の項目の要約と現状で、すべて Non-core。依頼の達成は自由な定義や証明の能力を示さない。

## トピック

| 項目 | 内容 | 対応状況 |
|---|---|---|
| 1 | 構文と意味の違い | 依頼281で命令と遷移規則を区別する固定例。一般的な比較は未対応 |
| 2 | 公理的・操作的・表示的・型による意味 | 依頼281の操作的意味の一例のみ。他のアプローチとの比較は未対応 |
| 3 | 事前・事後条件、ループ不変条件による公理的意味 | 依頼69で不変条件の固定例。形式的な一般規則は未対応 |
| 4 | 環境と記憶を使った代入・式・分岐・反復の操作的意味、記号実行、制約検査 | 依頼281で具体値の代入・条件分岐と残り命令、282で記号の条件と式の固定例。変数環境と記憶の区別、反復、一般の記号実行や制約検査は未対応 |
| 5 | 表示的意味とラムダ計算 | 依頼283で束縛名の変更とβ簡約の固定例。表示的意味論と一般の簡約は未対応 |
| 6 | 言語の意味に関する帰納的証明 | 未対応 |
| 7 | 型体系の形式的定義と証明、命題と型、依存型、パラメトリシティ | 未対応 |

## 例示学習成果

| 項目 | 内容 | 対応状況 |
|---|---|---|
| 1 | 小言語の形式意味論の構築 | 依頼281では与えられた規則を適用するだけで、規則の構築は未対応 |
| 2 | ラムダ計算プログラムと正規形までの評価 | 依頼283で与えられた２式のα変換とβ正規形を選択。プログラムの自由な構築は未対応 |
| 3 | 操作的・表示的・公理的意味論の比較 | 依頼281で操作的な固定例のみ。他との比較は未対応 |
| 4 | 言語内の全プログラムの性質を帰納法で証明 | 未対応 |
| 5 | 適切に型付けされた全プログラムの性質を帰納法で証明 | 未対応 |
| 6 | 型とパラメトリシティからコードの振る舞いを確立 | 未対応 |

依頼281は、２つの初期値について、代入を一段階、条件分岐をプレイヤーが選ぶ代入への置換として一段階、その代入を一段階として扱う。これは教材独自の小さな規則であり、実在言語の完全な意味論ではない。

依頼282は整数に対する固定の２分岐で、経路条件と式を選び、具体値と照合する。機械整数の桁あふれや制約ソルバーは扱わない。

依頼283は２つの式を使い、捕捉を避けるα変換とβ簡約の候補を選ぶ。[Cornell の講義](https://www.cs.cornell.edu/courses/cs3110/2014sp/recitations/25/lambda-calculus.html)を参照。一般的な置換アルゴリズムや任意の式の評価は未対応。
