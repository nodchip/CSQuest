# FPL-Formalism：形式意味論

出典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 145–146。以下は原典の項目の要約と現状で、すべて Non-core。依頼の達成は自由な定義や証明の能力を示さない。

## トピック

| 項目 | 内容 | 対応状況 |
|---|---|---|
| 1 | 構文と意味の違い | 依頼281で命令と遷移規則を区別する固定例。一般的な比較は未対応 |
| 2 | 公理的・操作的・表示的・型による意味 | 281で操作、771で操作・表示・公理的な見方を有限例で比較。体系的な比較は未評価 |
| 3 | 事前・事後条件、ループ不変条件による公理的意味 | 69で不変条件、771で２操作と最弱事前条件を有限状態から構成。形式的な一般規則は未評価 |
| 4 | 環境と記憶を使った代入・式・分岐・反復の操作的意味、記号実行、制約検査 | 依頼281で具体値の代入・条件分岐と残り命令、282で記号の条件と式の固定例。変数環境と記憶の区別、反復、一般の記号実行や制約検査は未対応 |
| 5 | 表示的意味とラムダ計算 | 283で束縛名の変更とβ簡約、771で有限状態の関数と合成。一般の領域・非停止や一般の簡約は未評価 |
| 6 | 言語の意味に関する帰納的証明 | 依頼284で整数と加算のみの式の非負性を構造的帰納法で組み立てる固定例。他の言語や性質は未対応 |
| 7 | 型体系の形式的定義と証明、命題と型、依存型、パラメトリシティ | 766・767で型安全性、768で命題と型、769で依存型、770でパラメトリシティの固定課題。一般の型体系や実言語は未評価 |

## 例示学習成果

| 項目 | 内容 | 対応状況 |
|---|---|---|
| 1 | 小言語の形式意味論の構築 | 依頼281では与えられた規則を適用するだけで、規則の構築は未対応 |
| 2 | ラムダ計算プログラムと正規形までの評価 | 依頼283で与えられた２式のα変換とβ正規形を選択。プログラムの自由な構築は未対応 |
| 3 | 操作的・表示的・公理的意味論の比較 | 771で同じ有限状態の仕掛けを遷移・状態関数・事前事後条件で比較。一般の比較や自由な議論は未評価 |
| 4 | 言語内の全プログラムの性質を帰納法で証明 | 依頼284で小さな式言語の非負性に関する証明の部品を選択。自由な証明の構築や一般のプログラムは未対応 |
| 5 | 適切に型付けされた全プログラムの性質を帰納法で証明 | 767で小言語の進行と保存の各場合を選択。自由な証明構築は評価しない |
| 6 | 型とパラメトリシティからコードの振る舞いを確立 | 770で２入力から１つを返す型の固定の射影を推論。一般の型・実言語は未評価 |

依頼281は、２つの初期値について、代入を一段階、条件分岐をプレイヤーが選ぶ代入への置換として一段階、その代入を一段階として扱う。これは教材独自の小さな規則であり、実在言語の完全な意味論ではない。

依頼282は整数に対する固定の２分岐で、経路条件と式を選び、具体値と照合する。機械整数の桁あふれや制約ソルバーは扱わない。

依頼283は２つの式を使い、捕捉を避けるα変換とβ簡約の候補を選ぶ。[Cornell の講義](https://www.cs.cornell.edu/courses/cs3110/2014sp/recitations/25/lambda-calculus.html)を参照。一般的な置換アルゴリズムや任意の式の評価は未対応。

依頼284は有限の数・加算の式について、数の場合と二つの部分式を用いた帰納段階を選ぶ。[Cornell の式の構造的帰納法](https://www.cs.cornell.edu/courses/cs411/2004fa/lectures/lec02.pdf)を参照。負数・減算や一般のプログラムは対象外。

依頼770は [Cornell の論理関係とパラメトリシティ](https://www.cs.cornell.edu/courses/cs4110/2025fa/lectures/lab33.pdf) を参考に、２入力から１つを返す道具について、変換と適用の順を比較する。２種類から３種類への有限の全写像と入力を試せるが、有限例の一致は一般のパラメトリシティの証明ではない。全型・全関係のパラメトリシティ、停止、純粋性を仮定し、２要素の型から任意の２値への写像を使って、常に同じ側の入力を返すことを選択肢で推論する。`tests/parametricity.test.js` は４道具・全写像・入力、反例と保存復元を検査する。例外・非停止・型検査などを含む実言語や一般の型の定理は未評価。[項目別台帳](coverage-fpl-formalism.md)も参照。

依頼771は [Cornell の公理的意味論](https://www.cs.cornell.edu/courses/cs4110/2020fa/lectures/lecture09.pdf) と [最弱事前条件](https://www.cs.cornell.edu/courses/cs4160/2020sp/sf/plf/full/HoareAsLogic.html) を参考に、０〜３の輪で３種類から選んだ２操作を一手ずつ実行し、初期状態から最終状態への関数合成と、事後条件を満たす最弱事前条件を比較する。`tests/semantics-comparison.test.js` は全９操作列・４初期値・２事後条件と全16事前条件の組合せを検査する。必ず２手で停止する有限模型で、無限状態・非停止・一般の意味論や自由な議論は未評価。
