# AL-Foundational：二分探索木の削除（固定例）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.88–90、AL-Foundational の探索木（9a）に関する３依頼。文庫の現行依頼は探索・挿入・形による探索回数を扱う。旧依頼 794 は葉・子１つ・子２つと根の削除を６固定例ですでに扱っており、今回はそのうち３例を現行冒険に移す。新しい範囲と数えず旧教材との重複を明示する。

後継に置き換える場合、右部分木の最小鍵を選び、鍵を写した後に元の後継を取り除き、その右の子を失わずにつなぐ。写してから取り除く途中では一時的に同じ鍵が二つある。各完了後に残る鍵と全子孫の左右の順序を検証する。参考：[Cornell: Binary Search Trees](https://www.cs.cornell.edu/courses/cs2110/2026sp/lectures/lec17/)。有限の決められた木のみで、一般の削除コード・重複鍵・任意の木や平衡化・計算量の証明・自由な説明は未評価。
