# 集いの後：霧の関所の確認

原典：[CS2023 最終報告書](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印刷ページ257–258、SEC-Foundations。二つの依頼は、明示した模型の中で考え方を試す部分対応です。

| 依頼 | 操作 | 限界 |
| --- | --- | --- |
| 本人確認と権限を確かめる | 確認結果、閲覧と更新の個別の権限、期限を確かめ、七つの場面で許可・拒否を選ぶ。 | 確認結果が正しいという仮定であり、現実の認証方式、秘密の盗難、権限管理や安全なシステムの実装は扱わない。 |
| 二つの入口を確かめる | 無確認の裏口からの閲覧を観察し、二つの入口で権限の有無を試す。 | 二つの入口と正確な確認所を仮定する。同じ確認を両入口に置くことだけで独立した防御を重ねる多層防御や現実の安全性全体を証明しない。 |

2026-11-10、実装担当と別の catalog が原典・模型・画面をレビューしました。期限前・期限到来後と更新権限の肯定例を加える指摘、二入口模型の仮定と多層防御を混同しない指摘に従い修正し、同担当が再確認しました。独立担当自身によるブラウザ操作は行っていません。

進行済みの検証用記録を用い、390・1,200 CSS px と、幅320px・150%表示を213 CSS pxで模擬したブラウザで、誤答、途中保存と再開、両依頼の達成を確認しました。実際のブラウザ倍率、スクリーンリーダー実機、利用者本人の評価、公開後の確認は未実施です。
