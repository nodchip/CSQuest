# DM-Internals：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.119–120。[追跡方法](coverage-status.md)に従う。原典の親項目に子がある場合、子を追跡し重複計上しない。未照合は未実装の証拠ではない。固定模型は実 DBMS の実装・運用を評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | KA Core | DB のバッファ管理 | 部分 | 89でバッファ管理の役割を選択。プールの固定・置換・書出しの実際の管理は未評価。 |
| 2a | KA Core | 分離水準 | 部分 | 38で未確定値を読む例と確定済み値を返す例を比較。水準全般・実 DBMS は未評価。 |
| 2b | KA Core | ACID | 部分 | 35で原子性と永続性、38で分離の一例、123で制約を扱う。４性質全体と一般の説明は未評価。 |
| 2c | KA Core | 直列化可能性 | 部分 | 39で２作業の競合順を比較。一般のスケジュールと他の定義は未評価。 |
| 2d | KA Core | 分散トランザクション | 部分 | 293で二相コミットの準備・決定・停止を操作。障害全般や実装は未評価。 |
| 3a | KA Core | 二相ロック | 未照合 | 排他の模型はあるが、二相ロックの成長・縮小の確認は未照合。 |
| 3b | KA Core | デッドロック対策 | 部分 | 30で待ちの循環の固定例。DB の一般的な検出・予防は未評価。 |
| 3c | KA Core | クォーラムによる整合性 | 部分 | 193で３複製に対する２書込み・２読取りの重なりを操作。同時更新・障害や一般の保証は未評価。 |
| 4a | KA Core | 復旧とバッファ管理の関係 | 部分 | 136で先行ログと一部書出し後の復旧を扱う。一般のバッファ管理と復旧の関係は未評価。 |
| 5a | Non-core | 楽観的並行性制御 | 部分 | 451で版確認と競合時の拒否を比較。一般の DBMS の検証・確定手順は未評価。 |
| 5b | Non-core | タイムスタンプによる制御 | 未照合 | 対応する DB の操作と検証は未確認。 |
| 6a | Non-core | 先行ログ | 部分 | 136で完全なログと単一取引の前後値による復旧を操作。実 DBMS や並行取引は未評価。 |
| 6b | Non-core | ARIES | 未照合 | 分析・REDO・UNDO を含む ARIES の教材は未確認。 |
