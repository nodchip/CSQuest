# SDF-Algorithms の対応状況

出典: [CS2023, Software Development Fundamentals, SDF-Algorithms](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p. 232。原典を要約した作業用一覧。固定された操作例はプログラムを書く能力や一般的な解析を評価しない。

## トピック

| 1 | CS Core | アルゴリズムと効率の概念 | 依頼29・88で線形探索と二分探索の比較回数を操作。一般的な効率の解析は未対応 |
| 2 | CS Core | 整列、探索、木やグラフの走査 | 依頼５・８・21・55・57などで固定例を操作。一般の入力と実装は未対応 |

## 学習成果

| 番号 | 分類 | 要約 | 現状と限界 |
|---:|---|---|---|
| 1 | CS Core | プログラムにおけるアルゴリズムの役割を説明 | 個別の操作例はあるが、一般的な役割の自由記述は未対応 |
| 2 | CS Core | 異なる性質のアルゴリズムで同じ問題を解く例を示す | 依頼29で同じ番号を線形・二分探索する固定例。多様な問題や実装は未対応 |
| 3 | CS Core | 代表的なアルゴリズムを説明 | 整列・探索などの固定例を操作。一般的な説明や証明は未対応 |
| 4 | CS Core | アルゴリズムの時間・空間への影響を説明 | 依頼88で比較回数、369で待機候補の最大数を確認。全メモリ量、実測や自由記述は未評価 |

依頼369の追加試験では同じ迷宮・同じ探索順について、候補袋の上限が４・８・３件の場合、上限を守る中から調査回数の少ない方法を選ぶ。実測された模型の回数は幅優先14・候補最大８、反復深化25・候補最大４なので、４件では反復深化、８件では幅優先、３件ではどちらも不可。候補以外の記録、実メモリや別の探索手順は含まない。
