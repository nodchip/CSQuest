# 分母照合：DM-Data

[CS2023 印字 p.115](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf)の DM-Data と[台帳](coverage-dm-data.md)を2026-11-04に照合した。原典に親子構造はなく、CS Core のトピック１件（１）、例示学習成果１件（１）を各々追跡する。例示学習成果とトピックは別々の分母に入れる。

原典が採るのは作成、処理、確認・報告、保管・検索、廃棄の５段階である。これは CS2023 の分類であり、参考の [NIST 研究データフレームワーク](https://nvlpubs.nist.gov/nistpubs/SpecialPublications/1500-18/NIST.SP.1500-18r2.html) は６段階の別の分類を使う。NIST を５段階の出典とは扱わない。

分母照合は教材全体の完成を保証しない。個々の内容・操作の点検は[項目別評価](curriculum-assessment-dm-data-core.md)に記録する。
