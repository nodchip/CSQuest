# 各地の冒険と集い：文言レビュー

## 対象と方法

前回の[工房までのレビュー](workshop-wording-review.md)に続き、公開中の冒険について、水辺・街・港・文庫・風車、山・谷・塔・関所・鍛冶街・駅、物語の集いと区切り後の四地域を対象にした。ゲーム本編の `src/workshop-preview.js` と、地域ごとの依頼データ・操作処理を機械的に検索し、会話、目的、手がかり、失敗時の案内、結果、および表示条件を対応づけた。

確認した依頼データには、文庫・風車４件、山３件と山・谷の追加６件、塔・関所６件、鍛冶街・駅８件、四地域16件、追加の入口10件（うち工房１件は前回対象）、集いの13段階がある。街・港・水辺の専用画面と共通の地図・進捗案内も照合した。旧教材の別画面を、現在の冒険から到達できる依頼として数えていない。

３つの `gpt-6-luna` サブエージェントが地域ごとに分担し、原文と表示条件、操作・正解・結果のつながりを読み取りレビューした。指摘をソースと実際の進行に照らして採否を判断した。機械的な抽出はテンプレートの条件分岐を完全には再現しないため、個々の表示も併せて確認する必要がある。

## 主な修正

- 水辺では、水かさによって通れなくなる場所を地図の木で表していることを補った。文庫の名前を地図と同じ「森の文庫」にそろえ、橋の修理に必要な薬草の記録を探す理由を明確にした。
- 風車の安全灯では、「橋が丈夫」と「向こうからの合図」を区別し、両方が必要なことを説明する。街の荷物も、依頼中に祭りの飾りや品物だと分かるようにした。
- 山では「山の集落」の名前と、矢印一本を道一本として数える説明をそろえた。鍛冶街と駅の進捗がどの依頼の件数かを明らかにし、誤操作時には操作の順番を確認できる案内を出す。
- 塔と関所の出来事では、依頼の中で確かめていない原因の断定を避け、実際に行った転送先と送り主の確認につなげた。新しい土地をまだ訪ねられない時点で訪問を促す表現も改めた。
- 集いでは、レンの家族が水辺の村に住むことと、中継所で運ぶ荷物にレンの手紙が含まれることを示した。観測所の依頼では、観測場所を「庭」ではなく「観測所」とした。

## 限界

レビューと動作確認は文言の分かりやすさや実装との整合を確かめるもので、すべてのプレイヤーに伝わることやゲームの面白さを証明するものではない。場面ごとの文章は、今後のプレイ感想に応じて再検討する。
