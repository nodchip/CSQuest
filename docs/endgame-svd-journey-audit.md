# 庭園の鏡と特異値：照合記録

[CS2023 印字191–192頁 MSF-Linear](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 8h は SVD の具体例を扱う。[MIT の SVD 教材](https://ocw.mit.edu/courses/18-642-topics-in-mathematics-with-applications-in-finance-fall-2024/mit18_642_f24_lec02_1.pdf)は特異値を AᵀA の固有値の非負平方根として定義する。旧依頼302 `src/svd-axis.js` を現行冒険に再利用し、新たな範囲達成を主張しない。

A=[[0,-1],[2,0]] は東→(0,2)、北→(-1,0)、AᵀA=diag(4,1) で特異値２・１。A=[[1,0],[0,0]] は東→(1,0)、北→(0,0)、AᵀA=diag(1,0) で特異値１・０。単位 v=(x,y) に対し前者は |Av|²=4x²+y²∈[1,4]、後者は x²∈[0,1]。東と北が端に達し、有限の例以外にも上下界が成り立つ。０特異値で Av/σ を使わない。任意の行列の分解・実装や応用は未評価。
