# 集いの後：鍛冶街の記録の入れ替え

原典：[CS2023 最終報告書](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印刷ページ230–231、SDF-Fundamentals。三つの箱を使い、二つの箱の印を失わず入れ替える操作を組み立て、異なる三組の初期値で一歩ずつ試します。「写す」操作は元を保ち、先を上書きします。

一時的な箱を含む具体例で代入と状態変化を練習します。箱の「空」は模型中の一つの印であり、実言語の未初期化変数や未定義の値を示しません。一般の型・式・状態、実際の言語での実装や条件と繰り返しを含むプログラムの開発は、この依頼で確認できません。

2026-11-10、実装担当と別の search_review が模型のコピー・上書き・三組の結果、原典と部分対応の範囲を照合しました。画面接続後の再レビューで、操作後の箱の状態の読み上げと札数上限のフォーカスを指摘し、実装担当による修正後にコードと検証スクリプトを再確認しました。独立担当自身によるブラウザ操作は行っていません。

作業コピーでは、390・1,200 CSS px、および幅320px・150%表示を213 CSS pxで模擬したブラウザで、誤った手順の修正、途中保存と復帰、三場面と達成表示を確認しました。実際のブラウザ倍率、スクリーンリーダー実機、利用者本人の評価、公開後の確認は未実施です。
