# SEP-IP：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.277–278。[追跡方法](coverage-status.md)に従う。未照合は未実装の証拠ではない。法制度は地域と事情により異なり、固定例は個別の法的判断を評価しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | CS Core | 知的財産権 | 未照合 | ライセンスの固定例はあるが、権利一般の教材は未確認。 |
| 2 | CS Core | 無形のデジタル知的財産 | 未照合 | 無形性を区別する教材は未確認。 |
| 3 | CS Core | 法的基礎 | 未照合 | 法域ごとの基礎は未確認。 |
| 4 | CS Core | 代表的なライセンス | 部分 | 269で MIT・GPL-3.0、399で CC BY・BY-NC の固定条件を比較。他の条項・利用形態は未評価。 |
| 5 | CS Core | 剽窃と著作者 | 部分 | 270で引用・言換え・合意した共同執筆者を扱う。一般の判断は未評価。 |
| 6 | KA Core | 哲学的基礎 | 未照合 | 関連体験は未確認。 |
| 7 | KA Core | 著作権・特許・営業秘密・商標 | 未照合 | 保護対象の体系的比較は未確認。 |
| 8 | KA Core | 著作権の限界 | 未照合 | fair use・first sale の条件の教材は未確認。 |
| 9 | KA Core | 著作権執行に関わる法律・条約 | 未照合 | 関連体験は未確認。 |
| 10 | KA Core | 海賊版・DRM 等 | 未照合 | 関連体験は未確認。 |
| 11 | KA Core | オープンソース運動の道徳・法的基礎 | 未照合 | ライセンス比較は運動の基礎を評価しない。 |
| 12 | KA Core | 他者のデータを用いるシステム | 未照合 | 関連体験を原典の範囲と照合していない。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |
|---|---|---|---|---|
| 1 | CS Core | デジタル著作権侵害の法令・判例を説明し批評 | 未照合 | 法域と判例の教材は未確認。 |
| 2 | CS Core | 無形のデジタル知的財産の例を特定 | 未照合 | 無形性の特定は未確認。 |
| 3 | CS Core | 目的に合うソフトウェアライセンスを選択 | 部分 | 269は改変ソース配布の２条件を比較。399は販売用の画像素材であり、ソフトウェアライセンスの選定ではない。一般の選定は未評価。 |
| 4 | CS Core | 著作物の合法的・倫理的利用を擁護 | 未照合 | 固定例は法域に応じた擁護を評価しない。 |
| 5 | CS Core | ライセンスの意図と実装を解釈 | 部分 | 269で表示・変更明示・許諾の３条件を比較。全条項と自由な解釈は未評価。 |
| 6 | CS Core | fair use の可能性を議論 | 未照合 | 法域と事実関係に応じた教材は未確認。 |
| 7 | CS Core | 剽窃検出の倫理問題を分析 | 未照合 | 検出方法そのものの分析は未確認。 |
| 8 | CS Core | 言換え・著者偽装・不適切な出典等を特定 | 部分 | 270で４つの固定例を比較。一般の判定は未評価。 |
| 9 | KA Core | 適切な文脈で哲学的基礎を議論 | 未照合 | 関連体験は未確認。 |
| 10 | KA Core | ソフトウェア特許の対立点を区別 | 未照合 | 関連体験は未確認。 |
