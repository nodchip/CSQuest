# 原典との範囲照合：HCI-Evaluation

[CS2023 印字 pp.178–179](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と [ACM 公開版](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)を照合した。トピック１は CS Core、２〜４は KA Core、５・６は Non-core。原典の親６行と子28行を含む34トピック行と、例示学習成果８行を記録した。親と子は重複するため独立した項目数や完成率としない。

研究倫理の事前承認（３c）、素材への影響（４b）、統計・可視化の実ツール（５a・５b）は未照合のまま。成果７は提示データの有意性を調べる検定と原典に沿って明確化した。依頼60の可視化評価計画を成果５の部分例に加えたが、固定選択肢であり、自由な研究計画の作成や承認・実利用者による実施を示さない。

この照合は原典の範囲と区分を確認するもので、教材ごとの正確性、学習効果、実際の評価の実施や教材全体の完成を証明しない。

同日、依頼532に架空の研究計画の提出・修正・承認通知をたどる例を追加し、３cを部分対応とした。実際の申請や審査は未評価。

同日、依頼536に修理と交換の架空の材料量を比較する例を追加し、４bを部分対応とした。実材料とライフサイクル全体は未評価。

同日、依頼529に対応のある t 検定の固定例を追加。５cの部分対応を広げたが、他の検定や一般的な手法選択は未評価。
