# CS Quest：街への旅の操作設計

[city-shaping.md](city-shaping.md) の S を実装するための設計。既存の `workshop-preview.html` → `src/workshop-preview.js` の `title` / `render` / `choices` / `travel` / `river` と `src/workshop-journey-data.js` の `unlocked` / `completeQuest` が接点。以下の N は必要な処理であり、特記した既存名以外は新たな関数名を決めるものではない。2026-11-07 時点で V1–V4 をローカルで実装・検証し、V5 の公開と公開先確認は別途行う。

## Places

| ID | 場所 | 操作の範囲 |
| --- | --- | --- |
| P1 | タイトル・設定 | 開始、続き、設定。既存画面 |
| P2 | 工房周辺 | 周辺の依頼、人物への相談、旅先選択。既存画面を拡張 |
| P3 | 旅先選択 | 水辺の村・街を選ぶ、工房へ戻る。既存画面を拡張 |
| P4 | 水辺の村 | 既存の村・依頼、工房へ戻る |
| P5 | 街の入口 | 風景と祭りの紹介、ギルド・市場・工房への帰路 |
| P6 | ギルド | 人物紹介・会話、２依頼の紹介と受諾、相談、街へ戻る |
| P7 | 市場 | 人物紹介・会話、整列依頼の受諾、相談、街へ戻る |
| P8 | 街の依頼 | 目標・背景・ヒントを確認し、品札交換または荷物受付と取出しを操作 |
| P9 | 達成ダイアログ | 達成を確認し、記録を見直すか結果へ進む。背後の操作は不可 |
| P10 | 依頼結果・祭りの準備 | 達成後の人物の反応、学んだ内容、１件以上で見られる祭り、街への帰路 |

## Data stores と外部作用

| ID | 内容 | 読み手 |
| --- | --- | --- |
| S1 | 既存の１冒険の localStorage `csquest-workshop-journey-v1`：場所、工房・村・街の依頼状態、共有された達成、祭りとおすすめ紹介済み状態 | N1、N3–N8 |
| S2 | 既存の表示設定 `csquest-workshop-preview-settings-v1` | N2 |

S1 の旧形式を受け入れ、既存の工房・村の達成と途中記録を保つ。既存本編や旧体験版の保存は消さない。破損・保存不可時は未検証のデータを上書きせず警告する。新規開始は上書き前に確認。ページ URL と公開先は GitHub Pages の既存体験版で、既存トップページは保つ。

## 実装単位と検証

| 単位 | 見せられる成果 | 該当する主な接続 |
| --- | --- | --- |
| V1 | 既存の旅先条件を満たした記録から、街と村を選び、街の入口・ギルド・市場を巡って戻れる。旧記録と村の依頼が維持される。 | P1–P7、U1–U7、N1–N6、N9、S1–S2 |
| V2 | 市場の整列依頼を受けて操作・失敗・修正・達成。ギルドと市場の両入口で同一の進行が見える。 | P5–P10、U5–U10、N3、N6–N9、S1 |
| V3 | ギルドの荷物の依頼を独立して達成。どちらを先に選んでも祭りの準備と、もう一つの依頼が利用できる。 | P5–P10、U5–U10、N3、N6–N9、S1 |
| V4 | 未達成に応じておすすめを１回紹介し、後から相談できる。どの依頼も自由に選べる。 | P2、P4、P6、P7、U2、U4、U6、U7、U11、N3–N4、N9、S1 |
| V5 | 街までの通し体験・教材・保存を検証し、既存トップを維持して変更をまとめて公開、公開 URL でも確認する。 | P1–P10、U1–U11、N1–N9、S1–S2 |

実際のプレイヤーの面白さの評価は公開後に確かめる。正解・誤り・修正、両方の依頼順と入口、祭り、１度だけの紹介と相談、全依頼達成後、途中再開、旧記録、破損・保存不可、狭い画面とキーボードを確認する。
