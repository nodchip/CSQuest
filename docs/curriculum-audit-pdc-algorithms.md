## トピック

CS Core 1a・1b・1c：データ並列と map/reduce、チャネル・ソケット・RPC による送受信、競合を避け進行を保つロック・バリア・同期。原典の親 1 は、所与の言語と枠組みでアルゴリズムを表現・実装し、スレッド等の活動開始、共有メモリ、通信 API を使う文脈を含む。この親の文脈を子の解釈に保持し、親と子を重複して数えない。

CS Core 2：マルチコア、リアクティブ、データ並列、クラスタ、クラウド、オープン分散システムの代表的な実行主体、通信機構、応用領域、工学上の目的を原典の比較表とともに概観する。表は一つのトピックの範囲として保持し、行や列を独立した番号として数えない。

KA Core 3a〜3h：線形代数、データ処理、グラフ・探索・組合せ、モデル化・シミュレーション、計算論理、グラフィックス・計算幾何、資源管理、サービス。原典の親 3 はこれらのアルゴリズム領域から **1 つ以上を選ぶ**構成であり、すべてを必修と読み替えない。候補台帳では選択肢ごとに範囲を追跡するため 8 行とし、親を別行にして重複させない。3g は処理装置・メモリ・通信路・ホストの割当・配置・回収・スケジューリング、共有と排他、静的・動的・弾力的な方式、リアルタイム制約、バッチ・優先・分割、仕事の横取り等を含む。

## 例示学習成果

CS Core 1〜6：既知のアルゴリズムによる並列・分散部品の実装、配列の平均などのデータ並列プログラム、生産者・消費者による平均と小さい値・多倍長値での速度改善の測定、イベントハンドラによる新たな活動、逐次部品の並列化・分散化による性能改善、所与のシステムの設計選択。KA Core 7〜9：列挙領域の一つにおける部品・アプリケーションの設計・実装・分析・評価、既存または他者の設計と実装の批評、複数実装の性能とエネルギー効率の比較。
