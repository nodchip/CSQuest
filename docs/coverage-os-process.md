# OS-Process：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.210。[既存の調査](os-process.md)、依頼の実装と個別テストを照合した。状態は[追跡方法](coverage-status.md)に従う。トピックと例示学習成果はいずれも KA Core。ゲーム内の模型は実 OS の操作や実プログラムを書く能力を直接評価しない。

## トピック

| 番号 | 要約 | 状態 | 対応例と残る範囲 |
|---|---|---|---|
| 1 | プロセス・スレッド、仮想化、保護、状態、メモリ分離 | 部分 | 依頼53で状態、179・627で共有と分離、385で仮想頁と共有、386で親子を操作。一般の実装やすべての保護境界は未評価。 |
| 2 | メモリの構成・区分 | 部分 | 依頼388で呼出しの局所領域と明示的に確保する領域の寿命を比較。コード・静的領域など全構成や言語別の実配置は未評価。 |
| 3 | 実行ファイルの作成と読込み、共有ライブラリ、動的リンク | 部分 | 依頼386で子の実行内容の置換え、392で共有部品とシンボル解決を操作。実ファイル、検索順や遅延結合は未評価。 |
| 4 | ディスパッチとコンテキスト切替え | 部分 | 依頼390で割込み後の保存・選択・復元を操作。実 CPU・OS の全状態と実際の処理費用は未評価。 |
| 5 | 共有メモリ、メッセージ、シグナル、環境変数などのプロセス間通信 | 部分 | 依頼385で共有枠、389でパイプの終端と３用途の手段を比較。シグナル・環境変数の該当例と、一般の IPC・実 API は未確認。 |

## 例示学習成果

| 番号 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|
| 1 | 並行性を用いるプロセス・スレッドと制御の仮想化 | 部分 | 依頼53・390・627で仕事の交代とスレッド・プロセスの固定例。一般の仮想化機構は未評価。 |
| 2 | 並行性と仮想化を支える割込み・ディスパッチ・切替えの理由 | 部分 | 依頼390でタイマー後の保存と復元、623で鐘による制御の回復を比較。一般の割込みや実装は未評価。 |
| 3 | タスクの状態と多数のタスクを管理するデータ構造 | 部分 | 依頼391で３仕事の実行待ち列と入出力待ちを操作。一般の状態遷移や管理構造の実装は未評価。 |
| 4 | タスクのメモリ割当てと長所・短所 | 部分 | 依頼387で先頭適合・最小適合と外部断片化を比較。仮想メモリを含む方式全般と実測は未評価。 |
| 5 | 目的に応じた IPC を選びプログラムに適用 | 部分 | 依頼389でパイプの操作と３用途の手段・注意点を選択。実プログラムや一般の設計・API は対象外。 |

依頼385〜392等の前提・出典と限界は [プロセスの記録](os-process.md) を参照。`tests/process-pages.test.js`、`tests/process-fork.test.js`、`tests/pipe.test.js`、`tests/ipc-choice-lab.test.js`、`tests/context-switch.test.js` 等は固定模型と復元を検査する。関連する依頼の存在や有限のテストは知識単位全体の習得を証明しない。
