# SEC-Crypto：署名の検証と鍵の確認（部分対応）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.260–261、SEC-Crypto 11 の署名による完全性・認証に関連する入口。現行の塔の依頼は AES-GCM とハッシュを扱う。旧依頼128 `signatures.js` は署名検証と公開鍵の対応を固定模型で扱うため、その判定を再利用し重複を新しい範囲として二重計上しない。

同じ本文と対応する鍵で成功、本文の変更や別の鍵では失敗する固定例を操作。別人ノノの鍵での成功はミラの署名を意味せず、提示鍵とミラとの対応を独立に確認していなければ成功だけで本人を判断できない。鍵の名簿を正しいと仮定する場合と未確認の場合を分ける。検証成功は本文の内容が真であること、鍵が安全に管理されたことや本人が意図した行為を一般に保証しない。

参考：[NIST FIPS 186-5 Digital Signature Standard](https://csrc.nist.gov/pubs/fips/186-5/final)。今回の判定はあらかじめ定めた一致模型で実際の署名生成・検証は行わず、実鍵・証明書・失効・侵害・汎用の認証や自由な実装は評価しない。

実装担当とは別の `review_candidate` が原典・NIST、固定例の検証結果と鍵・人物の区別、各画面の前提、誤答・履歴、分類と開放、旧記録の既定値を確認した。関連８テストも成功した。実暗号演算・鍵管理を検証したものではなく、レビュー担当自身はブラウザを操作していない。

`scripts/endgame-seal-signature.playwright.js` は集いと４地域の達成状態を用意した検証用記録から、213・390・1200 px 幅で分類経由の到達、キーボード操作、誤答案内、途中保存・再開、段階開放と達成後の再開を確認した。新規開始からこの依頼への通し操作、実際のスクリーンリーダー音声や利用者による面白さの評価は未確認。

公開確認：`d6d05b7` の Pages run 42871213342 が成功し、2026-11-11 に公開サイトで同 Playwright スクリプトを隔離したブラウザの 213・390・1200 px 幅で実行、分類からの操作、途中保存・再開と達成を確認した。検証用に進捗を用意した記録からの操作であり、新規開始からの通し確認や利用者評価ではない。
