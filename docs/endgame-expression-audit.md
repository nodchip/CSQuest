# 文庫の計算札と抽象構文木

[CS2023 FPL-Translation（印字139ページ）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の CS Core 5・6 に関連する固定例。１桁の数、＋・−・×・括弧を使う規則を説明し、隣接する札を組んで抽象構文木を作る。掛け算の優先順位、括弧、左結合を異なる式で確かめ、子から親へ計算する。括弧自体は木の点として残さず、構造に反映する。

誤った組み合わせも試せ、式に合わない木は達成できず場面を作り直せる。自由な文法の設計、一般の文脈自由文法、具体構文木、実言語の字句解析や構文解析、任意の式やコンパイラの実装は未評価で、部分対応である。

実装担当と別の coverage_next が原典と模型の構造、優先順位、左結合、正答と誤答、表示、保存・開放をコード上で独立確認し、演算札を試しに選べることの説明を追加後に再確認した。独立担当自身は実ブラウザーを操作していない。`tests/endgame-expression.test.js` は期待値、余分な括弧、誤った木、子からの評価を検証する。`scripts/endgame-expression.playwright.js` は物語と４地域の達成状態を用意した別ブラウザー記録から誤答、途中保存、再挑戦、開放と達成を確認する。実際のスクリーンリーダー音声は未確認。
