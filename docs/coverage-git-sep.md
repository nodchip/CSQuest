# GIT-SEP：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.165–166。[既存調査](git-society.md)と依頼を照合。すべて KA Core。細目を分けた場合、親と子は重複計上しない。実環境の倫理・安全・法的評価は固定例で証明しない。

## トピック

| 番号 | 区分 | 要約 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1a | KA Core | 運動に制約がある人のアクセス | 部分 | 351で操作方法の固定例。没入・物理環境での評価は未対応。 |
| 1b | KA Core | 視覚・聴覚に制約がある人のアクセス | 部分 | 22・117・350で文字、字幕、読み上げ名の固定例。多様な利用者による実評価は未対応。 |
| 2a | KA Core | 室内・身体・カメラ等の私的データ取得 | 部分 | 352で室内の位置と私物の取得範囲を比較。実スキャンや身体寸法は未評価。 |
| 2b | KA Core | 没入時に目をそらしにくい問題 | 未照合 | 対応例を要照合。 |
| 2c | KA Core | 没入時の本人・周囲の危険 | 未照合 | 対応例を要照合。 |
| 2d | KA Core | 顔認識の倫理的問題 | 未照合 | 利用条件と影響を要照合。 |
| 2e-i | KA Core | 不正確なデータ処理による誤解 | 未照合 | 補間・平滑化等の誤りによる例を要照合。 |
| 2e-ii | KA Core | 正確なデータから生じる誤解 | 部分 | 111・112で棒の下端と集計範囲の固定例。原典のエイリアシング例は未評価。 |
| 2f | KA Core | 健康情報などのプライバシー | 未照合 | 352は室内の例であり、健康情報は未評価。 |
| 2g-i | KA Core | 偽画像 | 未照合 | 対応例を要照合。 |
| 2g-ii | KA Core | 肌色・髪型等による誤認識 | 未照合 | 対応例を要照合。 |
| 3a | KA Core | 生成 AI の訓練画像と知的財産 | 部分 | 1267で架空の絵の作者・来歴と学習・公開の条件を確認。実際の権利や法域の分析は未評価。 |
| 3b | KA Core | 生成画像と知的財産 | 部分 | 1267で元の絵に似た出力と記録された条件を分けて確認。実際の生成物の法的判断は未評価。 |
| 4 | KA Core | この分野の現在・過去の貢献者 | 未照合 | 対応例を要照合。 |

## 例示学習成果

| 番号 | 区分 | 要約 | 状態 | 代替と限界 |
|---|---|---|---|---|
| 1 | KA Core | 位置タグに内在する安全性の問題 | 部分 | 352で室内の位置が機微になりうると扱う。位置タグ固有の攻撃や自由な議論は未評価。 |
| 2 | KA Core | 顔認識の倫理と利用条件 | 未照合 | 対応例を要照合。 |
| 3 | KA Core | 透かし画像を使う訓練と著作権 | 未照合 | 法域や条件を含む議論を要照合。 |

各固定例の前提と出典は[既存調査](git-society.md)を参照。

依頼1267は他者の絵を学習資料にする架空例で、来歴と明示された条件、似た出力を区別する。一般的な画像生成の技術、著作権・契約や法域の適用、実際の生成物の合法性は評価しない。出典と検証は [AI-ML](coverage-ai-ml.md) を参照。
