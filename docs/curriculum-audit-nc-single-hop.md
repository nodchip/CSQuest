# 原典との範囲照合：NC-SingleHop

[CS2023 印字 p.200（PDF 200ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-nc-single-hop.md)を2026-11-05に照合した。

原典のトピックは１〜６、例示学習成果は１〜６で、すべて KA Core。親子項目はなく、台帳の12行にそれぞれ対応する。例示の媒体や技術は別の番号付き項目として数えない。

これは項目の範囲と区分の照合であり、教材の正確性や成果の達成を検証したものではない。各行の部分対応と限界は別途確認が必要。
