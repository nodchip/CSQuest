# SEC-Governance: セキュリティガバナンス

出典：[CS2023 印字 p.263](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf)。すべて KA Core。固定模型の達成は、実組織のガバナンスや法令対応の能力を保証しない。

| トピック | 対応と不足 |
|---|---|
| 1 重要資産の脅威からの保護 | 依頼328で三つの架空の資産と経路、353で避難路の地図帳と倉庫損失の固定例。一般の資産特定や脅威は未対応 |
| 2 組織の目標・リスク評価とガバナンス | 依頼353で１日以内の業務上の要望と方針を照合。一般のリスク評価、方針策定と監督は未対応 |
| 3 機密性・完全性・可用性・説明責任・真正性・信頼性の管理 | 依頼195で監査、353で復旧可能性と訓練。各性質を体系的に管理する内容は未対応 |
| 4 組織・課題・システムに関する方針 | 依頼353で一つの復旧目標を選択。方針の種類や策定・運用の全体は未対応 |
| 5 基盤へのリスクの特定・軽減 | 依頼328・329で固定の脅威と対策、353で単一倉庫の損失を比較。一般的な評価や対策の導入は未対応 |
| 6 データの収集・バックアップ・保存期間、クラウド、漏えい通知の方針 | 依頼181・353で固定のバックアップと復旧。保存期間、クラウド、漏えい通知の方針は未対応 |

| 例示学習成果 | 対応と不足 |
|---|---|
| 1 重要資産と保護を説明 | 依頼328・353の固定例のみ。一般的な説明は未評価 |
| 2 ガバナンス、管理、対策を例で区別 | 依頼353で方針、訓練、別の保管先を比較。役割の重なりや一般的な区別は未評価 |
| 3 特定脅威を軽減する技術的対策の説明・実装 | 依頼328・353で対策を選ぶ模型。実装は未評価 |
| 4 プログラム・DB の漏えいリスクを特定・評価 | 依頼329で固定の公開設定を試す。一般の評価は未対応 |
| 5 方針に沿ったバックアップ戦略の設計・実装 | 依頼353で固定の配置・訓練と目標を比較。実際の設計・実装は未評価 |
| 6 法的要件に基づく漏えい通知方針の議論・実施 | 未対応 |
| 7 クラウド外部委託のリスク・利点 | 未対応 |

依頼353は、領主が避難路を１日以内に再開したいという固定の要求を与える。原本と写しが同じ倉庫にある場合は共通の倉庫損失で両方失われる。別の倉庫の写しは、訓練を選ぶとこの模型に限り12時間で復元できる。訓練なしでは手順が未確認と表示し、実際の復旧時間や攻撃耐性は保証しない。組織のリスク許容、役割、方針のガバナンス上の位置づけは [NIST CSF FAQ](https://www.nist.gov/cyberframework/faqs) を参照。
