# 案内所の調査窓口：範囲と未完了

[CS2023 印字 178 ページ（PDF 178 ページ目）HCI-Evaluation](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の評価と参加者に関する項目の入口。既存の案内所では、使いやすさの依頼が形成的・総括的評価、プライバシー依頼が受取帳、倫理依頼が案内の影響を扱う。今回の３依頼は、架空の案内板調査における参加者への説明、記録の保護、窓口の審査・指摘と募集の順番を扱う。

[米国 HHS の研究倫理教育資料](https://www.hhs.gov/ohrp/education-and-outreach/online-education/human-research-protection-training/lesson-4-irb-review-of-research/index.html) は、非免除の人を対象とする研究の例で、募集を含む活動の前に審査があり、指摘による修正を求められる場合を説明する。[NIH の募集資料](https://irbo.nih.gov/protocol-development/recruitment/)は、同機関の研究募集に関する承認、自由な判断、プライバシーの保護を扱う。これらをすべての調査・地域・所属先にそのまま適用するものではない。

本教材では、この架空の調査に窓口の承認を求める規程があると明示している。窓口の承認と参加者それぞれの自由な同意は別であり、断る・途中でやめる選択も示す。実際の法令適合、審査の実施、同意取得、記録保護、調査設計の十分性を証明しない。一般の制度、対象ごとの判断、危険・利益の詳細や実際の参加者との説明は未対応であり、関連成果は部分対応である。

`guide-study-explain` と `guide-study-protect` の２件を終えると `guide-study-review` が開く。案内所の依頼分類から選び、地図の全達成判定にも含まれる。

実装担当とは別の `review_candidate` が原典、上記 HHS・NIH の資料、架空の規程の限定、参加者の自由な同意・中止、記録保護と窓口の手続き、正答、分類と保存をコード上で確認した。実際の制度適用、審査・同意取得や調査の実施は評価しない。レビュー担当自身はブラウザを操作していない。

`tests/endgame-study-review.test.js` は必要な説明と記録保護の選択、指摘の修正・再提出・承認通知の前に募集できないこと、誤答からの修正と途中履歴を確認する。`tests/late-region-quest-groups.test.js` は分類と開放を確認する。`scripts/endgame-study-review.playwright.js` は集いと４地域などの達成を用意した検証用記録から、213・390・1200 px 幅で分類からの到達、キーボードによる依頼と回答、誤答の案内、途中復元、段階開放、３依頼の達成と達成後の再開を確認した。新規開始からこの依頼群までの通し操作、実際のスクリーンリーダー音声、利用者による面白さの評価は未確認。
