# 原典との範囲照合：AI-Agents

[CS2023 印字 p.79（PDF 79ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-ai-agents.md)を2026-11-05に照合した。トピック１〜８と子項目は Non-core。合理性、ソフトウェア主体、認知システム、複数主体、人との相互作用およびその応用の親項目を追加した。例示学習成果１〜５には原典で個別の区分見出しがないため、区分を推測しない。台帳はトピック29行、成果５行で、親子の重複は集計時に検討する。

範囲と区分の照合であり、教材の正確性や成果の達成は別途評価する。実際の主体の構築や人との相互作用、法域に応じた規制は固定例から証明しない。
