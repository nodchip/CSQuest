# 原典との範囲照合：AL-Foundational

[CS2023 印字 pp.88–90（PDF 88〜90ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-al-foundational.md)を2026-11-05に照合した。トピック１〜13は CS Core、14〜16は KA Core、17〜22は Non-core。複数番号が混在していた行を分け、配列・連結リスト・木・探索・整列・グラフ・照合・量子アルゴリズムの親項目を補った。成果１〜７は CS Core、８は KA Core、９は Non-core。成果１と８の親・子を別に記録した。台帳はトピック49行、成果13行で、親子の重複は集計時に検討する。

原典11cには深さ・幅優先木探索と O(log_b n) の記述があるが、一般の探索では調べる節数に依存する。原典の複雑さを一般保証として扱わず、教材との関係を別途分析する。範囲と区分の照合であり、教材の正確性や成果の達成を証明しない。
