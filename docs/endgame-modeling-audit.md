# 谷の記録所の関係の整理

[CS2023 DM-Modeling、印字116〜117ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=116) のデータモデリングと関係モデルに関連する固定例。荷物と村の１対多、人と依頼の多対多をそれぞれ２通りの条件で記録する。別の依頼では中間表から手伝う人を選び、組の重複と存在しない人への参照を、それぞれ固定例で拒否する。

番号は必須で、同じ人と依頼の組は一度しか記録しないという模型の仕様。組の主キーと両方の外部キーは別の制約である。制約の一般的な説明には [PostgreSQL 公式文書](https://www.postgresql.org/docs/18/ddl-constraints.html) も参照した。固定例の拒否表示は汎用の制約エンジンではない。１対１、一般の設計、完全参加、NULL、参照中の削除、実際の SQL や DB の操作は評価しておらず、関連項目は部分対応である。

実装担当と別の coverage_next が原典、例と制約、誤答、保存・開放をコード上で確認した。各依頼で状況を変えるよう求められたため２場面を用意し、再確認を受けた。独立担当自身のブラウザー操作は行っていない。`tests/endgame-modeling.test.js` は対応の変更、誤った組、参照結果と再設定を検証し、`scripts/endgame-modeling.playwright.js` は集いと４地域の達成状態を用意した記録から誤答、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
