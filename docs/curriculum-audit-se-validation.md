# 分母照合：SE-Validation

[CS2023 印字 pp.246–249](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=246) と[候補台帳](coverage-se-validation.md)を 2026-11-11 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core のトピックは 1a・1b（検証と妥当性確認）、2（変更後の試験）、3a〜3e（使用性・信頼性・仕様適合・性能・セキュリティ）、4a〜4d（単体・統合・妥当性確認・システム）、5（試験と製品コードのスタイル）。KA Core は 6a・6b-i〜iii・6c（試験生成・マトリクス・コードと環境の網羅・入力）、7a〜7d（テスト駆動、モック等、ブラック／ホワイトボックス、ツール）、8a〜8e（レビュー・自動化・コミット前後・時間との兼合い・欠陥追跡）、9a〜9d（性能、並行性、安全性が重要な領域、数値）。

Non-core は 10a〜10e（解析・網羅・ファジング・動的解析と障害封じ込め・記録）、11a・11b（欠陥推定と乱数）、12a・12b・12c-i〜iii・12d・12e-i〜iii・12f-i・ii・12g・12h（性能、スケーリング、ボトルネック、不確実性、図示、計時）、13・14（並行システムとコード外成果物）。原典の親 1・3・4・6〜12、さらに 6b・12c・12e・12f は共通文脈と列挙として子に保持し、親子を重複して数えない。台帳トピック 53 行。

CS Core 成果 1〜4 は試験の重要性、検証と妥当性確認、試験目的、試験方式・段階の比較。KA Core 5〜17 は試験計画・生成・実施、テスト駆動、オブジェクト指向とモック、レビュー、ツール・自動化、コミット前後、網羅と時間の兼合い、欠陥追跡、分野別の限界。Non-core 18〜31 はツール、自動化、乱数、欠陥推定、処理量・遅延・スケーリング・ボトルネック、統計・計時・ベンチマーク、並行系とコード外成果物の検証。31 行を別に追跡する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行の仕立て屋には検証と妥当性、境界、回帰の一部評価があるが、実際のコードや利用者の評価・一般的な試験計画の完成を意味しない。各現行行の到達・正確性・操作・保存・独立レビューは別途確認する。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。 原典3eの security と9cの safety-critical を区別するよう指摘し、修正後に再確認した。 これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
