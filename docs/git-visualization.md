# GIT-Visualization の対応状況

原典: [CS2023 GIT-Visualization](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.156–157。以下は KA Core。固定の図の操作は一般の設計能力や利用者による評価の完了を意味しない。

| 番号 | 内容と現状 |
|---|---|
| 1 | 科学データと情報の可視化。依頼111は架空の２数値の情報表示のみ。両者の比較は未対応 |
| 2a | 統計的可視化。依頼111で棒と点、依頼113で３区間のヒストグラムの固定例。散布図・折れ線などは未対応 |
| 2b–f | テキスト、地理、スカラー場、ベクトル場、ボリューム。依頼721で４×４のスカラー値を濃淡と数値で表示。他の種類や一般の場は未対応 |
| 3a–c | データ構造、視覚への対応、表示変換。依頼111で固定値の棒・点と尺度、依頼112で全体・道別の集計を切り替える固定例。データ取込や一般のフィルターは未対応 |
| 4 | データ形式。未対応 |
| 5 | 高次元データの統計・知覚的表現。未対応 |
| 6 | 光学、色、ゲシュタルトなどの知覚・認知。未対応 |
| 7 | 目的、アクセシビリティ、符号化の適否、誤解を招く可視化。依頼111で棒の下端、依頼112で集計範囲と割合の固定例。利用者評価や一般の設計は未対応 |

| 例示学習成果 | 内容と現状 |
|---|---|
| 1–3 | データ可視化の種類の比較、アルゴリズムの利用、精度と性能の比較。未対応 |
| 4 | データ・目的・対象者に合った図の設計。依頼111で表示と尺度の固定例を操作。一般の設計は未対応 |
| 5 | 特定の目的に対する可視化の有効性を分析。依頼111で棒の長さの比と軸範囲を比較する固定例。一般の分析は未対応 |
| 6–7 | 可視化の評価方法や応用例。未対応 |

依頼111は東80・西90の架空の点数を棒または点で表示し、縦軸を０–100または70–100に切り替える。棒の長さの比は０基準で90/80、70基準では20/10。元の値と差10は変わらない。点表示の拡大も軸を明記する。２値と２範囲に限る固定例で、実利用者の評価やすべての図に０基準を要求する主張ではない。数値から描画位置への対応、４組合せと判定をテストし、棒・点の図を画面で目視した。

依頼721は４×４の各地点に０〜６の架空値を割り当て、値の濃淡と数字で表示する。２以上は13地点、４以上は６地点。各しきい値について全65,536部分集合の判定を検査した。色だけに依存しないよう数値と選択状態も表示する。地点間の補間、実際の温度計測や３次元の場は扱わない。参考：[ParaView の色対応](https://docs.paraview.org/en/latest/ReferenceManual/colorMapping.html)。

依頼112は A の短い道９/10・長い道20/100、B の短い道80/100・長い道１/10の架空記録を、０からの棒グラフと分子・分母で表示する。両道では A が高いが、全体では A 29/110・B 81/110 となり B が高い。道の構成が異なるため、全体割合だけから能力の因果関係を断定しない。参考: [Penn State の条件付き集計の解説](https://online.stat.psu.edu/stat504/Lesson05)。
