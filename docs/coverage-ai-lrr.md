| 3 | 導出原理で質問に回答 | 部分 | 540で２命題の肯定・否定の組から空の札を導く。一般の節導出は未評価。 |

依頼537〜540の前提・出典は [AI の追加単位](ai-additional.md) を参照。`tests/ontology-garden.test.js`、`tests/default-bird.test.js`、`tests/quantifier-garden.test.js`、`tests/chaining-trail.test.js` は各固定例を検査する。

依頼1035は [Toronto の状況計算の説明](https://www.cs.toronto.edu/~alexei/ig-oaa/indigolog1.htm)を参考に、扉・鍵・灯りの３事実と５行動の前提条件、変化と維持を操作する。３初期状態の目標を行動列で達成し、各後続状況を表示する。対象が既知で完全に観測可能な有限模型であり、一般の述語論理による証明、未知の行動やイベント計算を評価しない。`tests/situation-door.test.js` は整合する全状態の各行動、前提条件、関係しない事実の維持、３目標と途中記録を検査する。

依頼1036は [Miami の離散イベント計算](https://tptp.cs.miami.edu/Seminars/EventCalculus/EventCalculus.html)を参考に、時点 t の点灯開始・終了が t+1 から効き、それ以外では状態を維持する模型を操作する。４つの出来事の３通りずつの81列を直前の有効な出来事から独立に照合し、３目標と保存を検査する（`tests/event-timeline.test.js`）。１時点に１出来事、既知の初期状態に限り、同時の衝突、連続時間や一般の形式的証明は評価しない。

依頼1048は [W3C RDF 入門](https://www.w3.org/TR/rdf11-primer/)を参照し、２つの固定記録を主語・関係・目的語になぞらえた札で結び、関係の方向、２関係をたどる質問、記録から真偽が決まらない質問を比較する。実際の RDF 識別子や Web 上のデータ、一般的な知識表現・推論の操作は扱わないため、セマンティック Web 全体の対応とはしない。`tests/semantic-trail.test.js` は判定と途中記録を検査する。

依頼1055は [W3C RDF 概念](https://www.w3.org/TR/rdf-concepts/)、[N-Triples](https://www.w3.org/TR/n-triples/) と [SPARQL のグラフパターン](https://www.w3.org/TR/sparql11-query/#BasicGraphPatterns)を参照。２つの IRI のみの RDF 三つ組を N-Triples 形式で表示し、同一 IRI による固定の２条件の結合と、異なる IRI では一致しない例を比較する。異なる IRI が必ず異なる実体を示すとは主張しない。例示ドメインへの通信、汎用パーサー、SPARQL 実行や推論は扱わない。`tests/rdf-join.test.js` は２条件の結合、順序・重複と途中記録を検査する。

依頼1056は [Aamodt・Plaza の事例ベース推論](https://www.cs.auckland.ac.nz/~ian/CBR/AICom.pdf)と [UBC の模型に基づく診断](https://www.cs.ubc.ca/tr/1990/tr-90-08)を参照。２つの固定規則、２つの過去事例への症状の完全一致、３部品の動作模型を使い、１故障と２故障までの最小候補を比較する。追加検査と修理は正確に作用する仮定で、事例の適応・保存や一般の診断は扱わない。`tests/diagnosis-methods.test.js` は全４出力の最小候補と保存・達成を検査する。

依頼1057は [Aamodt・Plaza](https://www.cs.auckland.ac.nz/~ian/CBR/AICom.pdf)を参照し、既知の特徴で事例を取り出して試し、追加観測で修正して新しい事例を保存し、次の固定例で再利用する。事例帳は依頼内の途中記録で、同じ特徴でも同じ原因とは限らない。一般の類似度・事例の適応や実際の機器は未評価。`tests/case-cycle.test.js` は検索条件、操作順、保存と復元を検査する。

依頼1058は [Dung の抽象的議論の理論](https://cse-robotics.engr.tamu.edu/dshell/cs631/papers/dung95acceptability.pdf)を参照。３主張の２つの反論関係で、衝突のない組、反論への防御、基礎と安定の組を比較する。与えられた矢印の妥当性や現実の真偽は扱わない。`tests/argument-boards.test.js` は２例の安定・基礎と、３主張の反論関係512通りの基礎の組・防御を独立に列挙して検査する。

依頼1059は [Allen の時間区間の研究](https://cse.unl.edu/~choueiry/Documents/Allen-CACM1983.pdf)を参照。０〜６の整数を端点とする区間を使い、時間と地図の横方向で「接する」「前から重なる」の合成を比較する。空間は１軸への投影であり、２次元以上の形の関係は判定しない。`tests/interval-reasoning.test.js` は13関係の具体例・逆関係と、この有限範囲での３区間の合成を検査する。

依頼1060は [Cornell の論理表現と推論](https://www.cs.cornell.edu/courses/cs4700/2016fa/slides/CS4700-knowl-repr-reas_part_1_v1.pdf)を参照。３つの命題論理式で部分式を選び、含意除去・ド・モルガン・二重否定・分配を操作し、連言標準形と８通りの同値性を確認する。量化や一般の述語論理の節形式変換は扱わない。`tests/clause-workshop.test.js` は各変形の同値性、３例の到達と履歴の復元を検査する。

依頼1061は [Dubois・Lang・Prade の可能性と必然性](https://www.ijcai.org/Proceedings/87-2/Papers/084.pdf)と [可能性分布からの尺度](https://ijcai.org/proceedings/2005/10)を参照。３候補に独立に与えた確率分布と可能性分布で、集合の確率・可能性・必然性を比較する。確率は排他的候補の和、可能性は最大、必然性は補集合の可能性の双対として計算する。分布は固定例であり、一般の変換・更新や実際の頻度推定は扱わない。`tests/possibility-measures.test.js` は全設定・集合について和、補集合と最大の性質を検査する。

依頼1062は [Minsky のフレーム](https://courses.media.mit.edu/2004spring/mas966/Minsky%201974%20Framework%20for%20knowledge.pdf)と [RDF Schema の種類の関係](https://www.w3.org/TR/rdf-schema/)を参考に、１つの種類の階層について関係網・既定値つきフレーム・条件規則を比較する。表現に与えた知識は異なり、規則と個別指定が衝突しても自動解決しない例を含む。一般の表現形式・推論・衝突解決は扱わない。`tests/knowledge-reps.test.js` は９条件と保存を検査する。
