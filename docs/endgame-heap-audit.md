# 駅の荷物と最小ヒープ

[CS2023 AL-Foundational（印字88〜89ページ）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の CS Core 6a・9b と学習成果 7 に関連する固定模型。優先度付きキューで小さい数を優先する例を操作し、最小ヒープに荷物を加える際の親との交換と、根を取り出して末尾を移した後の小さい子との交換を確かめる。左詰めの二分木で親が子以下という条件を示し、兄弟や同じ段全体が整列するとは主張しない。

優先度は固定例ごとにすべて異なる。空のキュー、同値時の扱い、任意のヒープや一般の実装、計算量の証明と自由な説明は未評価であり、項目は部分対応である。

実装担当と別の coverage_next が原典、各場面の親子交換と結果、誤答、保存と開放をコード上で独立確認した。優先度付きキュー一般と本模型の数字の規則の区別を説明に追記し、独立担当が再確認した。独立担当自身は実ブラウザーを操作していない。`tests/endgame-heap.test.js` は正しい交換と誤答、期待される配列を検証する。`scripts/endgame-heap.playwright.js` は物語と４地域の達成状態を用意した別ブラウザー記録から誤答、途中保存、再挑戦、開放と達成を確認する。実際のスクリーンリーダー音声は未確認。
