# 導入から旅立ちまでの文言レビュー

## 対象と方法

タイトル、世界紹介、人物紹介、灯りの依頼、工房、薬草・木立・水路のお手伝い、最初の旅先選択を対象にした。`src/workshop-preview.js` の各画面を関数ごとに区切り、HTML の表示文と引用文字列を機械的に抽出した。`src/workshop-journey-data.js` と `src/engine.js` の依頼内容、操作、ヒント、達成条件も照合した。テンプレート内の条件分岐や動的なデータは抽出だけでは完全に表せないため、ソースの前後と実画面で補った。

`gpt-6-luna` の３つのサブエージェントが、導入、工房の依頼、旅立ちと地図をそれぞれ読み取りレビューした。修正案は統合した上で、実際の操作・状態遷移と CS の説明を照合して採否を判断した。レビューは対象を絞った試行であり、サイト全体の全表示を確認したものではない。

## 主な修正

- 工房での最初の案内に、違うお手伝いを二つ終えると旅立てることを示し、１件後は別のお手伝いがあと一つ必要だと伝える。達成後は、川向こうの灯りと地図を選ぶ次の行動につなぐ。
- 矢印がノノの位置と向きを示すこと、お願いを選んで並べてから実行ボタンを押すことを明記する。木と地図の外を「壁」として扱うことも説明する。
- カエデが薬草を置いてきた場所と、ノノに手伝ってほしい理由を具体化する。木立の依頼では、届け先が旅人であることと、地図上の目的地を揃える。
- 地図の行き先を選んで詳細を確認し、「ここへ旅立つ」を押す流れを説明する。世界の進捗では、12地域のうち数えているのが二つのお手伝いを終えた地域だと示す。
- 「プログラム」は順番に並べることだけに限られないため、導入の説明を考え方の一例として表す。工房画面での同じ説明の繰り返しは省く。

## 残る範囲

他地域の依頼や物語の区切り以降の文言は、この試行のレビュー対象外。抽出に漏れうる動的な文章や表示されない古い教材については、対象を広げる際に改めて整理する。
