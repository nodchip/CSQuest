# GIT-Visualization：散布図（部分対応）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.156–157、GIT-Visualization 2a 統計的可視化の入口。旧依頼111は棒・点の尺度、113はヒストグラムを扱い、旧画面には花弁データの散布図表示も存在する。今回の固定例は２項目を同じ観測の組として点に置く操作と、周辺の値が同じでも組を変えると点の配置が変わる比較を扱う。重複を独立した全範囲の達成として数えない。

風車の里の架空観測で、横軸は風の強さ、縦軸は回転の速さをそれぞれ模型上の１〜３の値とする。上向きの例は (1,1)、(2,2)、(3,3)、下向きは (1,3)、(2,2)、(3,1)。比較の別例は (1,3)、(2,1)、(3,2) で、縦の値の集合は同じでも組が異なる。配置された点は互いに区別された３件の観測を表す。[NIST: Scatter Plot](https://www.itl.nist.gov/div898/handbook/eda/section3/scatterp.htm) の２変数の関係を調べる用途を参考にした。

固定した少数の架空例であり、関係の存在や向き自体を一般化できず、散布図だけで因果関係や介入の効果を証明しない。軸の尺度の変更、同じ座標に重なる観測、実データ、一般の可視化設計・実装・自由な説明は未評価。

実装担当とは別の `review_candidate` が原典と NIST の説明、固定例の座標と因果の限界、誤答・不正履歴、分類と開放、旧記録の既定値を確認した。関連７テストも成功した。一般の可視化能力を確認したものではなく、レビュー担当自身はブラウザを操作していない。

`scripts/endgame-scatter.playwright.js` は集いと４地域の達成状態を用意した検証用記録から、213・390・1200 px 幅で分類経由の到達、キーボード操作、誤答案内、途中保存・再開、段階開放と達成後の再開を確認した。新規開始からこの依頼への通し操作、実際のスクリーンリーダー音声や利用者による面白さの評価は未確認。
