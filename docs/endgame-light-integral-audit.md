# 速さと定積分：教材監査

[CS2023 MSF-Calculus 印字192–194頁](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=192) の一変数の積分の固定例。旧 `src/integral-area.js` の依頼474を再利用して現行の観測所へ接続する。現行の差商の依頼は位置から瞬間の速さを求める別の固定例。

区間 t=0〜2、速度 v(t)=2t、初期位置０。２等分の幅１では左端高さ０・２で和２、右端高さ２・４で和６。４等分の幅0.5では左端高さ０・１・２・３で和３、右端高さ１・２・３・４で和５。t² の導関数が 2t なので積分は 2²−0²=４。この区間で速度は非負だから変位と道のりは一致する。有限和は近似で、極限と厳密な積分を区別し、左端・右端の上下関係を増加するこの関数に限定する。

固定関数・区間・２種類の分割に限り、一般の関数・負の速度・数値誤差・自由な積分計算・極限の厳密な証明は未評価。[OpenStax Calculus Volume 1](https://assets.openstax.org/oscms-prodcms/media/documents/CalculusVolume1-OP.pdf) の Riemann sums と微積分学の基本定理を参照。
