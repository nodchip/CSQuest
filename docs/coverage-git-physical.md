219 は暗・中・明の３値に対し、それぞれ０・90・180度を目標とする模型。各依頼の参照資料と前提は[既存の調査](git-physical.md)を参照。

依頼1298は [Arduino のボタンの例](https://docs.arduino.cc/built-in-examples/digital/Button)を参考に、仮想の入力・制御・出力を組み合わせてボタンと灯りを選ぶ。押す・離すと入力信号と点灯状態が変化する。電源と配線は仮定で、実物の LED・抵抗・回路やプログラム作成は評価しない。

依頼219は [Arduino の可変抵抗を使うアナログ入力](https://docs.arduino.cc/built-in-examples/analog/AnalogInput/)を参考に、つまみ左・中央・右の理想電圧０・2.5・５ V を扱う。模型では０〜1023に比例させて最も近い整数に丸め、０・512・1023とし、目標角度０・90・180度へ対応づける。丸めと角度は教材の規則で、実機の誤差や変換方式を保証しない。実際の配線・回路・コードや安全性は未評価。

依頼807では３列の断面の高さ２・３・１を、空から積み重ねる方法と高さ３の塊から削る方法で作り、別の覆いを板の加熱・型への密着・冷却で成形する。各方法と３列の全64高さを検査した。断面の段や成形順は模型で、実際の立体形状、素材、支持材、工具、廃棄物、精度、費用や安全性は評価しない。参考：[NIST: 積層造形](https://www.nist.gov/additive-manufacturing/what-additive-manufacturing)、[UC Davis: 真空成形](https://techfoundry.ucdavis.edu/vacuum-forming)。

同じ依頼の見積もりでは、仮定した段取りと１個あたりの費用・時間を足し、製作数１個・10個で積層と切削を比較する。数値は教材用で、現実の費用や加工時間を予測するものではない。

予定と結果の比較では、積層した１個を作り直す場合と切削の段取りが延びる場合を仮定し、費用と時間の差を求める。実製作、試作品の品質評価、実際の費用や時間は扱わない。
