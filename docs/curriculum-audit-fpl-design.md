# 完成率の分母の照合：FPL-Design

[CS2023 印字 pp.146–147（PDF 146〜147ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の FPL-Design と[項目別台帳](coverage-fpl-design.md)を2026-11-05に照合した。トピックと例示学習成果はいずれも Non-core。

原典１は言語設計の原則を束ね、単純さから実装戦略まで８つの子項目を挙げる。子を１a〜１hとして数え、親を重複して数えない。２〜６は独立したトピックとして追跡する。トピックの分母候補は13件、例示学習成果は１件。

これは原典との範囲・区分の照合であり、個々の教材の正確性や単位全体の完成を意味しない。学習成果１が求める実在言語の評価に対し、依頼355は架空の規則の固定例であり、実在言語全体の評価は未対応である。
