# 分母照合：FPL-Parallel

[CS2023 印字 pp.135–136](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=135) と[候補台帳](coverage-fpl-parallel.md)を 2026-11-10 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core の台帳行は 1a〜1d（競合、依存と前提、故障モデル、停止）、2a〜2d（アクター、手続き・リアクティブ、同期・非同期、データ並列）、3ai・3aii・3bi・3bii（可換性、独立性、原子性、合意）、4a〜4c（async/await、promise、スレッド）、5a〜5h（mutex、メッセージ、共有メモリ、cobegin/coend、モニタ、チャネル、スレッド、ガード）。原典 1 は safety と liveness という親文脈を含む。2 は列挙モデルから **1 種類以上**を扱う構成であり、台帳の `CS Core・例` は全選択肢が必修という意味ではない。3 の a・b は順序と一貫性の性質を表し、i・ii をそれぞれ追跡する。4・5 を含め親と子を単純に重複計上しない。

KA Core 6〜13 は future、言語によるデータ並列、メモリ整合性モデルの意味論と正しいコード生成への影響、REST API、クラウド等の技術、メッセージ通信のオーバーヘッド、粒度、他のパラダイムとの並行性。以上トピック台帳 31 行。

CS Core 成果 1〜6 は競合時の逐次一貫性と言語上の対策、複数モデルでの正しい並行プログラムの実装、通信プロトコルの分析、同期構文の利用、変数の読み書きによるデータ依存、選択・反復による制御依存。KA Core 7・8 は REST API の統合・自動化と並行・分散の利益・制約・課題。成果 8 行をトピックとは別に追跡する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の FPL-Parallel の項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実言語での実装や自由な分析は固定模型だけで直接評価しない。
