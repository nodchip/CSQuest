依頼119の巻物は５冊で、薬に関係するのは A・C・E。題名に「月草の薬」を含む A・C を返す条件では適合率２/２・再現率２/３。「月草」を含む全５冊を返す条件では適合率３/５・再現率３/３。関連性の判定を正しいと仮定し、順位や実データの検索は扱わない。

依頼120は４冊の架空の単語列から転置索引を作り、月草と解毒の TF×IDF を加算して２冊を比較する固定例。単語分割は与えられ、実コーパスの作成や検索手法の一般的な設計は扱わない。[値と限界](dm-unstructured.md)

依頼121は「竜 が 騎士 を 助ける」と「騎士 が 竜 を 助ける」を比較。各単語の回数は同じだが、順序を保った２語の組「竜・が」と「騎士・が」は異なる。単語の分割は所与で、バイグラムだけで一般の意味や文脈を捉えることはできない。

依頼230は４×４の４値画像で、中央４画素を正解の領域とする。しきい値１・２・３以上の抽出で、誤検出と見逃しはそれぞれ (3, 0)、(1, 1)、(0, 3)。両者を等しく数えると２が最小だが、紋章と背景に同じ明るさがあり、この規則では完全に分けられない。実画像や異なる誤りの重みは扱わない。

依頼231は２枚の４×４画像の中央４画素を正解として、明るさ２以上の全体抽出、左上の正解画素から上下左右への領域拡張、明るさのみを使う２平均法を比較する。２平均法の初期中心は０と３、同距離は小さい中心側に割り当て、明るい群を抽出する。離れた光の画像では全体と２平均法は誤検出１・見逃し０、領域拡張はどちらも０。暗い欠けと隣の光の画像では３手法とも誤検出１・見逃し１。固定した始点・しきい値・４近傍・初期中心の例で、実画像や初期値を変えた分析は未対応。

依頼232は４×４の像３枚から画素数、画素位置、外接する長方形の幅・高さを取り出して比較する。平行移動した２×２の紋章２枚と４×１の別の印は、画素数ではすべて４、位置では３枚とも異なり、幅・高さは前者がともに２×２、後者が４×１。外接長方形の一致は形の一致を保証せず、回転や拡大にも一般には不変でない。対象の抽出は所与で、実画像や一般の物体認識は未評価。

依頼233は１次元画像の中央３画素を、次の像の左・中央・右の候補と画素ごとの絶対差の合計で比較する。特徴的な模様の差は左から４・５・０、繰り返す模様では０・３・０。後者は最小の候補が２つあり、ブロック照合だけでは真の動きが特定できない。照明、遮蔽、２次元の動きは扱わない。

依頼457は２つの問いについて、前に選んだ言葉に応じて２つの候補を４/６・２/６に割り当てる固定表から、プレイヤーが札の目を選んで２語を作る。最高確率の候補は架空のギルド記録と食い違い、別の目では一致する。２問いの全36通りの札の組と照合結果を検査した。[Google の言語モデル入門](https://developers.google.com/machine-learning/crash-course/llm)を参照。この模型は実際の言語モデル・検索・学習を行わず、画像生成や実応用での失敗の分析は未対応。

依頼458では３×３の星と月の二候補に対し、各画素が独立に確率１/４で反転する模型を使う。２候補と７画素ずつ一致する像では、事前の重み３：１に従い事後の重みも３：１となり、手がかりを反転すると１：３になる。全512像・２手がかりで画素ごとの独立確率と重みを照合。[拡散確率モデルの論文](https://arxiv.org/abs/2006.11239)を参考にした入門用の条件付き推定であり、固定２候補・一回の反転の模型は学習済み拡散モデルや逐次的な生成の実装ではない。実画像、権利や真偽の評価は未対応。

依頼459は key=[ln 3,0]、value=[4,0]、１次元 query=1,−1,0 の３例で、点数の softmax と value の加重和を選ぶ。重みはそれぞれ (3/4,1/4)、(1/4,3/4)、(1/2,1/2)、出力は３・１・２。[Attention Is All You Need](https://arxiv.org/abs/1706.03762)を参照。１次元でスケール係数は１。数値を独立に検査した。固定された単一 attention の模型であり、多頭化、位置情報、訓練や言語モデル全体は扱わない。

依頼459の追加実験は位置１の query を−２〜２、２位置の value を０・２・４から選び、位置２を隠すか切り替える。隠した位置は softmax の対象から除き、残りの重みを正規化する。５×３×３×２通りを検査し、マスク中は未来の value を変更しても位置１の出力が変わらないことを確認した。[Hugging Face の causal attention](https://huggingface.co/docs/transformers/en/attention_interface)を参照。１行２位置の固定模型で、一般の系列長や実モデルの訓練は扱わない。
