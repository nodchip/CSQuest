# 風の港町：知らせを届ける依頼

港から中継地点をたどり、家まで知らせを届ける操作は、情報が接続された地点を経由して届くという考え方の導入である。行き止まりから戻り、別の道を選べる。２通りの道で達成できる。

参考： [CS2023 最終報告書：Networking and Communication](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm) の NC-Fundamentals および NC-Routing。ネットワーク要素と経路選択に関連するが、この依頼は固定の地図の比喩であり、IP パケット、実際の転送処理、経路制御プロトコル、障害検知、信頼性や安全性の理解・習得を評価しない。大学水準の該当分野を網羅した教材でもない。

風の港町の風景は「水彩風の明るいファンタジーの港、帆船と飛行船、旗、文字や人物なし」、レンは「親しみやすい若い男性伝令役、青と茶の服、手紙かばん、葉や花の飾りなし」という指示で、それぞれ既存の風景・人物絵を参考に組み込み画像生成ツールで制作した。
