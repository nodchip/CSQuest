# 原典との範囲照合：OS-Memory

[CS2023 印字 p.210〜211（PDF 210〜211ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) と[台帳](coverage-os-memory.md)を2026-11-05に照合した。

原典のトピック１〜７と成果１〜５は KA Core、トピック８と成果６は Non-core。トピック５の arena や slab 等は例示であり親行に含める。成果５はプログラムの開発を含み、ゲーム内操作の代替と限界を別途評価する。 台帳はトピック 8 行、成果 6 行。

これは項目の範囲と区分の照合であり、教材の正確性や成果の達成を検証したものではない。各行の対応と限界は別途確認が必要。
