# 二人の記録棚：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字220〜222頁の PDC-Communication 3b（階層・局所性・偽共有）への固定例。旧依頼505 `src/false-sharing.js` の模型を現行冒険の鍛冶街へ接続した。既存の排他や記憶の棚の依頼は別々の値が同じ行にある場合の持ち替えを比較していない。
- [Linux kernel documentation: False Sharing](https://kernel.org/doc/html/latest/kernel-hacking/false-sharing.html) は異なる値でも同じキャッシュ行への並行アクセスと書込みにより性能が低下する場合や配置変更のトレードオフを説明する。
- 固定模型はＡ・Ｂが別々の値を２回ずつ書き、各棚の初期所有者はなし。初めての取得は数えず、同じ棚の所有者が別人に変わるたび１回とする。Ａ・Ｂ・Ａ・Ｂの同じ棚は３回、別棚は０回。Ａ・Ａ・Ｂ・Ｂの同じ棚は１回。順序をまとめられることはこの例の前提。
- 実際のキャッシュ無効化、通信量、実行時間、全プロトコル、並列処理の一般的性能や実コードは測定・評価しない。別の配置や順序が常に望ましいとも主張しない。旧教材や本教材をもって原典の全体完成とはしない。
