# OS-Memory：ページ置換（部分対応）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.210–211 の OS-Memory 4（ページング・置換）に関する入口。現行の駅の依頼は共通窓口での記録と利用を扱う。旧依頼34・487は FIFO、LRU などのページ置換をすでに扱っており、今回の３依頼との重複を新たな範囲に数えない。

空の３枠でＡ・Ｂ・Ｃ・Ａ・Ｄの順に参照し、Ａの再利用で FIFO の読込順は変わらず、LRU の最終利用は更新する。Ｄを要求すると FIFO はＡ、LRU はＢを置換する。両者ともヒット１・不在４で、置換される札は異なる。この固定列の結果だけで一般的な性能の優劣は決められない。[OSTEP: Beyond Physical Memory](https://pages.cs.wisc.edu/~remzi/OSTEP/vm-beyondphys-policy.pdf) の FIFO・LRU の定義を参考にした。

入出力遅延、書戻し、ページテーブルの更新、実OSの近似LRU、複数仕事、任意の列・性能評価・実装・自由な説明は評価していない。OS-Memory 全体の完成は意味しない。

実装担当とは別の `review_candidate` が原典・OSTEP・固定列の結果、画面の説明、保存履歴、分類と開放を確認し、比較終了後の UI にないリセット履歴を受け入れる問題を指摘した。修正とテスト追加後に再確認し、関連８テストが成功した。作業中に既存のページ変換教材とファイル名が衝突したため元の２ファイルを復元し、新教材を別名で作成した。旧教材の接続と差分がないことも確認した。レビュー担当自身はブラウザを操作していない。

`scripts/endgame-page-replacement.playwright.js` は集いと４地域の達成状態を用意した検証用記録から、213・390・1200 px 幅で分類経由の到達、キーボード操作、誤答案内、途中保存・再開、段階開放と達成後の再開を確認した。新規開始からこの依頼への通し操作、実際のスクリーンリーダー音声や利用者による面白さの評価は未確認。

公開確認：`04a1e9b` の Pages run 42855650962 が成功し、2026-11-11 に公開サイトで同 Playwright スクリプトを隔離したブラウザの 213・390・1200 px 幅で実行、分類からの操作、途中保存・再開と達成を確認した。検証用に進捗を用意した記録からの操作であり、新規開始からの通し確認や利用者評価ではない。
