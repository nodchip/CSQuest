# 中盤：文庫と風車の里

## 対応する考え方と限界

基準は [CS2023 最終報告](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm)。以下は関連のある入門的な体験であり、知識単位全体の修得や大学水準の能力を保証するものではない。

| 依頼 | 対応・体験 | 未評価の例 |
| --- | --- | --- |
| 番号で記録を探す | AL-Strategies の探索。順序づけられた棚で比較し、候補を狭める。中央を選べば二分探索の考え方に近づくが、任意の候補を選べる。 | 二分探索の一般的な実装、計算量の証明、存在しない値の探索。 |
| 届ける本を選ぶ | DM-Querying、DM-Processing の選択操作に関連する入門。「本」と「山向け」の両条件で四件の記録を絞る。 | SQL の記述、データベースの定義・更新・結合、一般的な問い合わせの設計。 |
| 安全灯を直す | SF-Foundations、AR-Logic の論理ゲート。AND・OR・NAND を四入力の組み合わせで比べる。 | 回路構築の一般的能力、順序回路、物理機器の安全性。 |
| 橋の準備を進める | AL-Foundational のトポロジカル順序に関連。四つの依存する作業について、可能な二つの順番を許す。 | 一般的なグラフでのアルゴリズムや閉路検出、作業時間・資源配分の推定。 |

判定には既存の `circuit.js` の論理ゲートと `estimate-schedule.js` の作業依存関係を利用する。番号検索は七件の固定例であり、必ず中央を選ばせるものではない。表示される絞り込みは固定データに対する論理条件で、実際のデータベースや SQL の実行ではない。文字入力・コード入力を行わないため、実言語による作成能力は直接評価しない。

## 制作した画像

組み込み画像生成ツールで、既存の風景・人物絵を画風の参考として使用した。原寸画像は `data/art/` に保存し、生成時の指示は次のとおり。

- `forest-library.png`：大木の中の小さな森の文庫、本を載せた荷車、木漏れ日、人物と文字なしの水彩風の風景。
- `windmill-village.png`：山の緑の丘の風車、石造りの工房、小川と橋、人物と文字なしの水彩風の風景。
- `aoi-mid.png`：本とかばんを持った、親しみやすい大人の司書。全身と顔が分かり、透過背景。
- `toma-mid.png`：灰色の髪と穏やかな表情の年配の風車職人、道具入れ、葉や花の飾りなし。全身と顔が分かり、透過背景。
- `connected-bridge.png`：森の文庫と風車の里を結ぶ、新しく開いた橋。灯りと祝いの飾り、人物と文字なしの水彩風の風景。

## ゲームの節目

港で知らせを届けると二地域を旅先に選べる。文庫と里のそれぞれで少なくとも一つの依頼を達成すると橋の開通を見届けられる。開通後は両地域の画面から「つながりの道」で直接行き来でき、残りの依頼も遊べる。旧形式の保存データには `midActive`、`midDrafts`、`bridgeOpen`、`bridgeFrom` がなくても読み込める。
