# 集いの後：森の文庫の探索

原典：[CS2023 最終報告書](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の AL-Complexity と SDF-Algorithms。森の文庫では、同じ昇順の七つの番号から、左から順に探す方法と範囲の中央から探す方法を操作する。60・存在しない25・先頭の10の三つを両方の方法で探し、番号の照合回数を数える。

一つの固定された棚で操作と回数を比べる練習であり、一般の入力長に関する計算量、最良・平均・最悪の場合の導出、実際の実行時間や空間量、プログラム作成の学習成果を満たしたことにはならない。整列済み・重複なし、偶数個なら左寄りの中央、左からは見つかるか最後まで調べるという、この依頼の約束は画面内に示す。
