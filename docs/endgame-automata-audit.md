# 関所の合図機と有限状態機械

[CS2023 AL-Models、印字93〜95ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=93) の有限状態機械と正規言語に関連する固定例。赤い札の個数の偶奇、末尾が青かどうかをそれぞれ２状態で記録し、状態と札ごとの遷移を登録する。空の列を含む４例を試し、応用では両機械を同時に動かして両方の受理条件を満たすか判定する。

指定された２機械と有限の試験例に限定し、任意の DFA の構築、非決定性、プッシュダウン機械、形式言語全般、一般の等価性や証明は評価しない。有限の試験だけで全入力への正しさを証明したとは扱わず、指定した遷移表も確認する。関連項目は部分対応である。

実装担当とは別の coverage_next が原典、遷移・空列・受理・共通条件、保存と開放を確認した。独立担当によるブラウザ操作は行っていない。`tests/endgame-automata.test.js` は空列・誤った判定・遷移変更時の試験破棄を検証し、`scripts/endgame-automata.playwright.js` は集いと４地域の達成状態を用意した記録から、誤操作、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
