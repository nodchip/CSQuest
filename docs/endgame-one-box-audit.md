# 一つ箱の巻物：教材監査

- [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字222〜223頁の PDC-Coordination 2b（生産者・消費者）と4j（セマフォによる資源制御）に関連する固定例。旧依頼178 `src/semaphore-buffer.js` の容量１模型を現行の港に接続した。既存の条件変数教材とは、空き・到着を示す印の受取りを扱う点が異なる。
- [OSTEP: Semaphores](https://pages.cs.wisc.edu/~remzi/OSTEP/threads-sema.pdf) は１つの箱で生産者が空き、消費者が到着を待つ例を説明する。本模型は１人ずつ、初期空き１・到着０、月・星の順である。
- １操作ずつ進める。印があれば受取時に減算し次の作業へ進む。印が０なら待ち、相手が対応する印を渡すと、この模型では待機者に直接許可を渡しその人の分として確保し、次の作業へ進める。空のとき消費者が、満杯のとき生産者が待つ例と、２巻物の順序・空箱への復帰を試す。
- 直接引渡しや起床の扱いは固定模型の規則であって実 API の唯一の実装ではない。複数の送り手・受け手、取消し・エラー・公平性、実 API・実コードや一般の並行プログラムの正しさは評価しない。旧教材・本教材の存在を原典全体の完成としない。
