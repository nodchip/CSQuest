# 完成率の分母の照合：FPL-Constructs

[CS2023 印字 p.144（PDF 144ページ目）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) および [ACM の同報告書](https://csed.acm.org/wp-content/uploads/2025/11/CS2023-Report.htm) の FPL-Constructs と[項目別台帳](coverage-fpl-constructs.md)を2026-11-05に照合した。PDF の取得が一時的にタイムアウトしたため、ACM 版の本文を併用した。トピックと例示学習成果はいずれも Non-core。

原典のトピック１〜12は番号付きの子項目を持たない。５の例外・継続・モナドや６の多重継承・ミックスイン・トレイト・多重メソッドなどは、同じ番号の列挙例として行内で対応と不足を区別し、分母では親を１件と数える。例外の教材だけで継続やモナドの対応が確認されたとは扱わない。原典の区分を明確にするため全行に Non-core 列を追加した。

トピックの分母候補は12件、例示学習成果は３件。これは範囲と区分の照合であり、各教材の正答・内容の個別検証や分野全体の完成を意味しない。実際の言語での実装や自由な議論は固定模型で直接評価しない。
