# SPD-Robot：項目別の対応状況

出典は [CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 304–305。[追跡方法](coverage-status.md)の状態を用い、既存の[ロボット分野の記録](spd-robot.md)と依頼を照合した。以下の原典項目と学習成果はいずれも KA Core。`部分` は例があることを示し、全体の達成や検証完了を示さない。`未照合` は未実装と同義ではない。

## トピック

原典 7 の子項目は別行にし、親の 7 を独立した項目数として足さない。

| 原典番号 | 内容の要約 | 状態 | 既存の例と残る範囲 |
|---|---|---|---|
| 1 | ロボットのプラットフォームと機器の種類 | 部分 | 依頼691で架空の車輪型・飛行型と観測器を比較。実際の機器全般は未確認。 |
| 2 | センサー、組込み計算、動作器 | 部分 | 依頼28・690・691で観測と移動の固定模型を操作。実機の計算・信号処理は扱わない。 |
| 3 | ロボット用言語とライブラリ | 部分 | 依頼690で Python と rclpy、C++ と rclcpp の組を選ぶ。実言語・ライブラリの利用や一般のロボット用言語は未評価。 |
| 4 | ロボットのソフトウェア構成 | 部分 | 依頼690で送信・購読の名前と型、目的に応じたトピック・サービス・アクションの選択を扱う。実際の ROS 実装や構成全般は未評価。 |
| 5 | プラットフォームの制約と設計 | 部分 | 依頼71・691で移動、力、地形などの架空の制約を比較。現実の制約や設計全般は未確認。 |
| 6 | 物理系や模擬系との接続 | 部分 | 依頼28・71の格子模型を操作。外部システムや実機との接続は扱わない。 |
| 7a | 順運動学 | 部分 | 依頼183で２関節の角度から関節・先端位置を計算。90度刻みの平面模型で、一般の姿勢や実機は未対応。 |
| 7b | 逆運動学 | 部分 | 依頼184で２目標それぞれの２姿勢と、長さによる到達不能を調べる。限られた角度・平面模型で、一般の解法や関節制限は未対応。 |
| 7c | 動力学 | 部分 | 依頼395で一定の制動力と質量から減速度・停止距離を比較。１次元の固定模型で、関節トルク、重力、摩擦や実機の動力学は未対応。 |
| 7d | ナビゲーションと経路計画 | 部分 | 依頼28・71で固定された格子を移動。一般の経路計画や連続空間は未確認。 |
| 7e | 把持と操作 | 部分 | 依頼691で２接触の摩擦上限、荷物の重さと破損限界を比べる。静止時の固定模型で、接触形状・動作中の力や実機は未対応。 |
| 8 | 安全性と相互作用 | 部分 | 依頼395で静止した人と観測器の遮蔽に関する固定条件を比較。実環境の安全性は評価しない。 |

## 例示学習成果

| 原典番号 | 内容の要約 | 状態 | 既存の例と残る範囲 |
|---|---|---|---|
| 1 | 所与のロボットでアプリを設計・実装する | 未照合 | 依頼28はゲーム内の固定模型。実機上のアプリ実装は扱わない。 |
| 2 | Arduino ロボットを組み立て迷路走行をプログラムする | 未照合 | 実機の組立てや実言語によるプログラミングは扱わない。 |
| 3 | ロボット用の言語・技法と汎用開発を比較する | 未照合 | 対応する教材・検証を確認できていない。 |
| 4 | ロボット設計と物理系・模擬系への接続の理由を説明する | 部分 | 固定格子の模擬を操作する例がある。接続の設計や自由な説明能力は評価しない。 |
| 5 | ROS の構成要素と接続を設計する | 部分 | 依頼690で２つの係の話題・型と、３目的に対する通信方法を選ぶ固定模型。実際の ROS の構成・実装は評価しない。 |
| 6 | プラットフォームが課す制約を議論する | 部分 | 依頼71・691で力や通行の制約を体験。現実の制約全般や自由な議論は評価しない。 |

実機操作、実際のコードや自由記述は本作の操作方針に含まれない。ゲーム内の代替を設けた場合も、それらの能力を直接評価したとみなさない。各依頼の模型の前提と検証範囲は[既存の記録](spd-robot.md)を参照。
