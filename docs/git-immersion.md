# GIT-Immersion: 没入型技術

参照：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.161–162。依頼216の平行な２視点の投影と視差は [MIT Foundations of Computer Vision, Stereo Vision](https://visionbook.mit.edu/3d_scene_understanding_stereo.html) の幾何を参考にした固定模型です。以下の項目の一覧化や固定例の達成は、単位全体の修了を意味しません。

依頼217は、[AR の実景・仮想像の遅延に関するシミュレーション実験](https://www.frontiersin.org/journals/ict/articles/10.3389/fict.2016.00034/full) の重ね合わせと遅延の問題を参考にした一次元の固定模型です。実験や装置の挙動を再現・評価するものではありません。

依頼218は、[Apple の現実物体による仮想物体の遮蔽例](https://developer.apple.com/documentation/visionOS/obscuring-virtual-items-in-a-scene-behind-real-world-items) を参考に、距離による前後と測定誤りを１方向で比較する固定模型です。AR・MR の分類や実装全体を表すものではありません。

| KA Core トピック | 対応と不足 |
| --- | --- |
| 1 VR・AR・MR の没入の段階 | 依頼218で現実の柱と仮想の印の重ね合わせと遮蔽を比較。VR・AR・MR の範囲や没入の段階全体は未対応 |
| 2 没入とプレゼンスの定義・違い | 未対応 |
| 3 360度映像 | 未対応 |
| 4 立体視表示：頭部装着型ディスプレイ、立体視眼鏡 | 依頼216で２視点の投影位置と視差を比較。表示機器と実際の立体画像は未対応 |
| 5 利用者追跡：内向き・外向き、頭・体・手 | 依頼217で古い・新しい視点位置による重ね合わせを比較。実際の追跡方式と頭・体・手の追跡は未対応 |
| 6 動作から表示までの遅延と時間制約：詳細度、画像ベース VR、分岐映像 | 依頼217で古い視点情報によるずれの固定例。遅延の計測・最適化と詳細度等は未対応 |
| 7 ネットワークを介した分散 VR・共同作業 | 未対応 |
| 8 プレゼンスと没入に影響する要因 | 未対応 |
| 9 ３次元の操作 | 未対応 |
| 10 医療・シミュレーション・訓練・可視化への応用 | 未対応 |
| 11 没入型アプリの安全：酔い、現実世界が見えないことによる転倒等 | 未対応 |
