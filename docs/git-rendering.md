# GIT-Rendering の対応状況

出典: [CS2023 GIT-Rendering](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 157–158。原典を要約した作業用一覧。すべて KA Core。小さな図形操作の達成はグラフィックスのプログラムを作る能力全体を示さない。

## トピック

| 番号 | 要約 | 状況 |
|---:|---|---|
| 1 | 物体表現、アフィン・座標変換、シーングラフ | 依頼26：２次元三角形の固定された平行移動・90度回転と操作順。その他の表現とシーングラフは未対応 |
| 2 | カメラ、投影モデル、射影幾何 | 依頼64で奥行きの異なる点の平行・透視投影と投影面の距離を比較。一般のカメラモデルは未対応 |
| 3 | 放射測定と光のモデル、レンダリング方程式 | 未着手 |
| 4 | ラスタ化、描画 API、遮蔽、テクスチャ、レイトレーシング、標本化 | 未着手 |

依頼26は、固定された２次元三角形の頂点に、右へ１の平行移動と原点周りの反時計回り90度回転を順に適用する。目標２例を比較し、変換順序で結果が変わることを扱う。任意の変換、行列の記述、３次元、投影、描画 API は評価しない。

依頼64では横位置８、奥行き４・８の２点を、平行投影および投影面までの距離１・２の透視投影で比べる。透視の横位置は距離×横位置÷奥行きで計算し、相似な三角形の関係をテストで検証。上から見た図は確認後に実際の投影線を表示する。高さ、クリッピング、任意のカメラや描画プログラムは未対応。
