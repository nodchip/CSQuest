固定例の検査には `tests/hash.test.js`、`tests/min-heap.test.js`、`tests/merge-sort.test.js`、`tests/odd-even-sort.test.js`、`tests/quantum-order.test.js` などがある。個別テストの成功は原典全体の網羅や一般的な説明・設計能力の証明ではない。

依頼911は A・B・C の双方向の輪で、X の挿入と B の切離しに必要な前後の参照を選んで変更する。途中の参照の不一致と A からの両方向の到達を表示し、目標状態では外した B の参照を消す。各場面４変更の全24順序、途中状態、両方向の巡回、保存の再生を `tests/circular-list.test.js` で検査。全手紙を名前で直接選べる固定模型で、一般の実装、番兵、並行操作やメモリ管理は未評価。参考：[Open Data Structures: Doubly-Linked List](https://opendatastructures.org/ods-cpp/3_2_Doubly_Linked_List.html)。

依頼910は２つの連結な無向グラフで、A から木の内外を結ぶ最小費用の辺を選ぶ。５頂点の最小費用は10、同重みを含む４頂点の最小費用は５。`tests/prim-tree.test.js` で同重みの選択を含む全ての正しい選択順を探索し、各結果を全域木の総当たり計算と照合した。不適切な辺と保存時の履歴も検査する。一般の正しさの証明、優先度付きキューや非連結グラフは未評価。参考：[Princeton: Minimum Spanning Trees](https://algs4.cs.princeton.edu/43mst/)。

依頼909は基準より小・同・大の３組を別に作り、小・大の２組を左から再び分ける。整列済み７個は先頭基準で21回、中央位置基準で10回、重複のある７個は先頭基準で８回比較する。ここでの比較は基準以外の各値を分類する回数であり、他の分割実装の比較回数とは限らない。`tests/quick-partition.test.js` で最終列・各組・比較回数・途中記録を検査。一般の入力や平均計算量の証明は未評価。参考：[Princeton: Quicksort](https://algs4.cs.princeton.edu/23quicksort/)。

20a・20c は原典の例示と、[量子教材の操作・検証記録](ar-quantum.md)および `tests/bernstein-vazirani.test.js`、`tests/simon-period.test.js`、`tests/grover-search.test.js`、`tests/grover-scale.test.js` を照合した。いずれも限定例のため「部分」であり、量子アルゴリズム全般や高速化の証明の達成を意味しない。

依頼908は親 (0,0)、基点 (2,1)、差を取る２個体 (4,1)・(1,5) を固定し、変異候補を基点＋F×差で作る。F＝0.5・1 と横のみ・両成分の交叉を比較し、試行候補の二乗誤差を親と比べて選択する。４条件の変異・交叉・選択と途中保存を `tests/differential-evolution.test.js` で検査した。集団の乱択、複数世代、他の目的関数や収束は扱わない。参考：[SciPy の差分進化](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.differential_evolution.html)。

依頼794は、葉２、右の子９.５を持つ節９、および両方の子を持つ根８の削除を操作する。根を削除する際は後継９の鍵を写し、元の節９を取り除いて右の子９.５を節10の左へつなぐ。途中の重複は削除が終わるまでの一時的な状態である。各完成後の鍵と順序を `tests/bst-delete.test.js` で照合した。固定木の例であり、一般の入力、重複鍵、平衡化や自由な証明は扱わない。参考：[Princeton: Binary Search Trees](https://algs4.cs.princeton.edu/32bst/)。

依頼794ではさらに、右の子自身が後継で右の子孫を持つ場合、根を一つの子で置き換える場合、最後の根を削除して空になる場合を扱う。節と左右の枝を入れ子で表示し、６固定例の途中復元と削除後の順序・残る鍵を検査する。旧版の途中記録は既存の３場面を維持し、新３場面を未着手として再開する。旧版のクリア記録は維持されるため、新場面の達成を意味しない。参考：[Cornell: Binary Search Trees](https://www.cs.cornell.edu/courses/cs2110/2026sp/lectures/lec17/)。
