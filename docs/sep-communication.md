# SEP-Communication：コミュニケーション

出典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 279–280。以下は原典の要約と現在の対応状況。選択式の固定例は、実際の文章作成・発表・対話の能力を直接評価しない。

## トピック

| 番号 | 区分 | 内容 | 対応状況 |
|---|---|---|---|
| 1 | CS Core | 口頭、文章、電子的なチーム・集団内の連絡 | 依頼295で架空の報告の札を選ぶ固定例。実際の連絡は未対応 |
| 2 | CS Core | ソース、文書、チュートリアル、参照・API 文書等 | 未対応 |
| 3 | CS Core | 顧客、管理者、一般の人など異なる相手への伝達 | 依頼295で旅人と修理係の必要を聞き、報告を選ぶ固定例。他の相手・状況は未対応 |
| 4 | CS Core | ツールを含むチーム協働と対立解決 | 未対応 |
| 5 | CS Core | 対象者に向けたアクセシビリティと包摂 | 未対応 |
| 6 | CS Core | 自然言語の違いを含む文化的配慮 | 未対応 |
| 7 | KA Core | 伝達手段や選択に関わる要因のトレードオフ | 未対応 |
| 8 | KA Core | 倫理やアクセシビリティ等の懸念を伝え、問題を解く・提案する | 未対応 |

## 例示学習成果

| 番号 | 区分 | 内容 | 対応状況 |
|---|---|---|---|
| 1 | CS Core | 簡潔・正確な技術文書と形式、図表、参照の重要性 | 依頼295で事実・範囲と未確認事項の札を選ぶ固定例。実際の文書構成は未対応 |
| 2 | CS Core | 技術文書の正確性、簡潔さ、明確さと対象者への配慮を分析 | 依頼295で不確かな断定・不要な個人情報を除き相手に必要な情報を選ぶ固定例。自由な分析は未対応 |
| 3 | CS Core | 対象者に配慮したアクセシブルな正式発表 | 未対応 |
| 4 | CS Core | 多様な意見と参加を尊重する交流の計画 | 未対応 |
| 5 | CS Core | 効果的な伝達の性質の特定と説明 | 依頼295で２人の必要を聞き、限定された情報を選ぶ固定例。一般的な説明は未対応 |
| 6 | CS Core | チーム内の効果的な伝達と対立解決 | 未対応 |
| 7 | CS Core | 多様で異文化のチームの成果に影響する方法 | 未対応 |
| 8 | KA Core | 多様な遠隔チームで働く際の自身の強みと弱みの評価 | 未対応 |
| 9 | KA Core | 繊細な倫理的懸念を伝える適切な方法の選択 | 未対応 |

依頼295は、３台の点検で２台に古い時刻があったという架空の事実を用い、旅人と修理係の必要を聞いて報告の札を選ぶ。原因と未点検の状態は不明であり、全台正常という断定や無関係な個人情報を避ける。実際の調査、文書の自由作成や外部への連絡は行わない。
