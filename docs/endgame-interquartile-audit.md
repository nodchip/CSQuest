# MSF-Statistics：四分位範囲（部分対応）

[CS2023 原典](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.190–191、MSF-Statistics 例示学習成果 1d の四分位範囲に関する入口。現行の観測所には平均との差と母分散の固定依頼があるが、四分位範囲を扱っていない。旧依頼114 `quartiles.js` は10件の固定例と外れ値の柵を扱うため、重複を独立した完成範囲として二重計上しない。

この模型では小さい順に並べ、奇数件の中央を上下どちらにも含めず、上下それぞれの中央値を Q1・Q3 とする。８件１〜８では Q1＝2.5、Q3＝6.5、IQR＝４。７件１〜７では Q1＝２、Q3＝６、IQR＝４。８を20に変えた８件では IQR は４のまま、最大と最小の差は７から19に変わる。四分位点には複数の流儀があるので、この結果をすべての方法の定義としない。[NIST: Box Plot](https://www.itl.nist.gov/div898/handbook/eda/section3/boxplot.htm) の四分位範囲 Q3−Q1 とばらつきの説明を参考にした。

固定された少数の異なる値を用いる。任意のデータ、別の四分位点の定義、一般的な計算・自由な説明、実データや推論は未評価。分散と四分位範囲を扱うだけで原典分野全体の完成を意味しない。

実装担当とは別の `review_candidate` が原典・NIST と模型の定義、固定例の数値、各画面の説明、誤答・不正履歴、分類と開放、旧記録の既定値を確認した。関連９テストも成功した。一般のデータや自由な説明を検証したものではなく、レビュー担当自身はブラウザを操作していない。

`scripts/endgame-interquartile.playwright.js` は集いと４地域の達成状態を用意した検証用記録から、213・390・1200 px 幅で分類経由の到達、キーボード操作、誤答案内、途中保存・再開、段階開放と達成後の再開を確認した。新規開始からこの依頼への通し操作、実際のスクリーンリーダー音声や利用者による面白さの評価は未確認。
