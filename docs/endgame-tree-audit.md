# 文庫の枝分かれ棚と二分探索木

[CS2023 AL-Foundational、印字88〜90ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=88) の木と二分探索木に関連する固定例。根から大小を比較して番号を探索し、空の枝への挿入を操作する。応用では同じ１〜７の番号からなる枝分かれした木と一方向の木で、発見・不在の比較経路を比べる。

重複のない固定の木に限定し、削除、平衡化、多分木、一般の実装や計算量の証明、自由な説明は扱わない。該当項目は部分対応である。

実装担当と別の coverage_next が原典、探索・挿入・不在、比較回数、保存と開放を確認し、部分木の順序の説明を指摘した。修正後に再確認した。独立担当によるブラウザ操作は行っていない。`tests/endgame-tree.test.js` は経路、挿入後の構造、不在と比較回数を検証し、`scripts/endgame-tree.playwright.js` は集いと４地域の達成状態を用意した記録から、誤操作、途中保存、再挑戦、開放と達成を確認する。実スクリーンリーダー音声は未検証。
