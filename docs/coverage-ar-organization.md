# AR-Organization：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 p.106。[既存の調査](ar-organization.md)と依頼を照合した。状態は[追跡方法](coverage-status.md)を参照。2 は子項目で追う。

## トピック

| 番号 | 区分 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | KA Core | 単純なデータパスとパイプライン、ハザード検出・解決 | 部分 | 158 で１つの依存と待機・転送を比較。一般の設計や他のハザードは未評価。 |
| 2a | KA Core | 固定回路による制御 | 未照合 | 73 は命令の実行順序を扱うが、制御回路の実装は要照合。 |
| 2b | KA Core | マイクロプログラムによる制御 | 未照合 | 制御方式の教材を要照合。 |
| 3 | KA Core | 命令パイプライン | 部分 | 158 は３段階の固定例。一般の段階構成や分岐は未評価。 |
| 4 | KA Core | 命令レベル並列性の導入 | 部分 | 158 で命令の段階を重ねる。一般の並列性と制約は未評価。 |

## 例示学習成果

| 番号 | 区分 | 内容 | 状態 | 対応例と限界 |
|---|---|---|---|---|
| 1 | KA Core | データパスの代替実装を比較 | 部分 | 158 は待機と転送の固定例。実機の構成一般は未評価。 |
| 2 | KA Core | 加算の制御信号を固定回路とマイクロプログラムで作る | 未照合 | 両方式の制御信号を扱う教材を要照合。 |
| 3 | KA Core | パイプラインとハザードにより命令レベル並列性を論じる | 部分 | 158 は１つのデータ依存。一般のハザードと自由な説明は未評価。 |
| 4 | KA Core | データパスと制御を含むプロセッサを設計 | 未照合 | 全体設計に相当する教材を要照合。 |
| 5 | KA Core | 所定のプロセッサ・メモリ系の平均 CPI を計算 | 部分 | 158 は２命令の拍数を比較。一般の命令列、メモリ系と平均 CPI は未評価。 |
