| 番号 | 区分 | 要約 | 状態 | 体験と残る範囲 |

| 1 | KA Core | データ可視化と情報可視化を比較 | 未照合 | 両者の体系的比較は未確認。 |

| 3 | KA Core | 可視化アルゴリズムの精度・性能のトレードオフを比較 | 部分 | 111で時系列の全点と１点おきの表示点数・最大値の保持を比較。実行速度や一般の精度は未評価。 |
| 4 | KA Core | データ・課題・対象者に合う可視化を設計 | 部分 | 111で棒・点と尺度を選ぶ。一般の設計や対象者の評価は未対応。 |
| 5 | KA Core | 目的に対する可視化の有効性を分析 | 部分 | 111で棒の長さと軸範囲を比較。一般の課題や利用者による検証は未評価。 |

関連検査には `tests/visualization.test.js`、`tests/histogram.test.js`、`tests/clustering.test.js`、`tests/color-mixing.test.js` がある。各模型の範囲を検査し、可視化全体の有効性や実利用者による評価を保証しない。

依頼1162は [MIT のベクトル解析](https://ocw.mit.edu/courses/res-18-001-calculus-fall-2023/mitres_18_001_f17_ch15.pdf)を参考に、外向き・回転・鞍の３場を格子上の矢印で表示し、オイラー法で粒の有限ステップを計算する。正規化は描画だけに適用する。`tests/vector-field-map.test.js` は各場の値・移動・復元と達成を検査。実データや一般の積分精度は未評価。

依頼1164は [Cheng らの多変量可視化](https://www.cs.umd.edu/~varshney/papers/Cheng2018Winnow.pdf)を参考に、４台・４属性の架空データで平行座標の軸順と条件の絞り込みを操作する。`tests/parallel-coordinates.test.js` は８種類の条件集合と保存・達成を検査。線種・値の表を併記するが、実利用者によるアクセシビリティ評価は未実施。

依頼1170は [PROJ の球面メルカトル](https://proj.org/en/stable/operations/projections/merc.html)と [USGS の投影解説](https://www.usgs.gov/faqs/how-are-different-map-projections-used)を参考に、２緯度帯を同じ縮尺で比較する。`tests/map-projection.test.js` は既知座標、対称性、極の拒否、帯の高さ、保存・達成を検査。球面模型で実データ・楕円体・測地距離は未評価。

依頼1172は [Stanford の単語頻度と文章長](https://nlp.stanford.edu/IR-book/html/htmledition/maximum-tf-normalization-1.html)を参考に、依頼120の札から２つの固定単語列を作り、回数と総単語数に対する割合を棒・表で比較する。割合は総数で割る本教材の尺度で、リンク先の最大頻度正規化とは異なる。`tests/text-frequency-visual.test.js` は元データ、頻度・割合・順位、保存と達成を検査。実文章の分割・意味解析は未評価。

依頼1173は [Levoy の前からの合成式](https://graphics.stanford.edu/papers/volume-dissertation/levoy-dissertation-may89.pdf)を参考に、３つの固定サンプルを２通りの転送関数と２方向で合成する。`tests/volume-ray.test.js` は各条件の手計算値、途中の保存・達成を検査。実３次元データや間隔補正は扱わない。

依頼111の追加例は [Purdue University の近さと類似](https://www.psych.purdue.edu/~gfrancis/Experiments/VisLab/Gestalt/gestalt1.html)を参考に、４印の距離と形による２種類の群化を比較する。`tests/perceptual-grouping.test.js` は４配置の幾何と形、旧記録の復元を検査する。競合時の知覚を一意に断定せず、一般の群化・認知や実利用者による評価は扱わない。

依頼111の時系列表示は [IEEE VIS の時系列の点数削減に関する研究](https://ieeexplore.ieee.org/document/10360915/)を背景に、２種類の８点のデータで全点と１点おきを比べる独自の模型。`tests/visual-sampling.test.js` は表示点数、最大値と旧記録の復元を検査する。実際の速度・通信量や研究のアルゴリズム自体は評価しない。
