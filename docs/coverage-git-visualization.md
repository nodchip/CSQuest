# GIT-Visualization：項目別の対応状況

原典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp.156–157。すべて KA Core。[追跡方法](coverage-status.md)に従い、原典の子項目と例示学習成果を区別する。既存例の前提は [記録](git-visualization.md) を参照。固定した図の操作は、一般の設計能力や実利用者による評価の完了を意味しない。
