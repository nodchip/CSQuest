# 谷の二相コミット：照合記録

[CS2023 印字122頁 DM-Distributed](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 1c は分散トランザクションを扱う。[PostgreSQL の PREPARE TRANSACTION](https://www.postgresql.org/docs/current/sql-prepare-transaction.html) は準備後の確定・取消しと外部管理者の役割を説明する。旧依頼293 `src/two-phase-commit.js` を現行冒険に再利用し、新たな範囲達成を主張しない。

固定模型では両係の回答後に調整役が決定を記録し、個別に配送する。停止例は両係の準備後・決定前に停止し、準備の記録と回答が残り、Ａは決定を知らず待つ。調整役の復旧後に確定を記録し両係に届ける。拒否例はＢが拒否し、両回答後に取消しを記録して両係に届ける。実際の障害・永続化・ログや復旧・通知重複・ネットワーク分断・並行取引・非停止性を評価しない。固定模型は実システムや一般の原子性を証明しない。

実装担当と別の担当が準備・保持・停止・待機・決定記録・配送の固定手順と拒否時の取消し、保存・開放・焦点を確認。ローカルで集いと４地域の達成状態を用意した記録から、幅 213・390・1200 px で誤操作、キーボード、途中保存・再開と達成を確認した。冒険開始からの通し到達は含まない。
