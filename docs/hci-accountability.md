# HCI-Accountability：設計の説明責任と責任

出典：[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) 印字 pp. 176–177。以下は原典の要約と現在の対応状況。架空の画面操作は実際の利用者への影響や法的な同意の評価を証明しない。

## トピック

| 番号 | 区分 | 内容 | 対応状況 |
|---|---|---|---|
| 1 | CS Core | 設計の持続可能性、包摂、安全・セキュリティ・プライバシー、被害と影響の差 | 依頼22・63・91・289でアクセシビリティ、情報公開、装置と選択画面の固定例。広範な影響分析は未対応 |
| 2 | CS Core | 設計手法・解決策における倫理、AI、関係者と人間要因、利用者の必要 | 依頼63・118・188・289で関係者、指標と画面の固定例。一般的な倫理分析は未対応 |
| 3 | CS Core | 設計の所有責任、法的枠組み、直接の必要を超える問題分析・デジタルウェルビーイング | 未対応 |
| 4 | KA Core | 価値に配慮する設計、直接・間接の関係者と多様な価値 | 依頼63・188で架空の関係者の声。他の価値や影響の体系的分析は未対応 |
| 5 | KA Core | 説得的な設計の内容・目的と、操作的な設計との区別 | 依頼289で初期設定と選択肢の見せ方の固定比較。一般の意図や実際の行動を判定するものではない |

## 例示学習成果

| 番号 | 区分 | 内容 | 対応状況 |
|---|---|---|---|
| 1 | CS Core | 設計の社会・共同体への影響を特定し批判的に検討 | 依頼63・289の固定例のみ。実社会の広範な分析は未対応 |
| 2 | KA Core | 設計に関わる人間要因の特定 | 依頼289で初期設定と選択肢の見え方を体験。一般の人間要因分析は未対応 |
| 3 | KA Core | 直接・間接の関係者の特定と理解 | 依頼63・188で固定の関係者の声。間接の関係者の網羅は未対応 |
| 4 | KA Core | 利用期間全体と直接・間接の関係者を考慮するシナリオ | 未対応 |
| 5 | KA Core | 透明性、持続可能性、信頼、AI 等の影響要因を検討 | 依頼289で任意記録の設定表示の固定例。広範な分析は未対応 |
| 6 | KA Core | 説得的な内容と利用者の利益に対する意図の評価 | 依頼289で設定と見せ方の固定例。実際の意図・利益の評価は未対応 |
| 7 | KA Core | 設計の意図と結果の批判的検討 | 依頼289で事前設定と登録結果を比較。実際の結果は未対応 |
| 8 | KA Core | 設計上の判断による影響の理解 | 依頼289で初期値・選択肢の配置と結果の固定例。一般化は未対応 |

依頼289は架空の登録画面で任意の記録の初期値と変更操作を比較する。実データを送信せず、個々の行動、実際の同意、法令への適合を判定しない。
