# 風車の里の模様と可逆圧縮

[CS2023 AR-Memory（印字104〜105ページ）](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の CS Core 9b に関連する、ランレングス符号の固定例。同色の最大連続区間を色と個数にまとめ、順序と個数を守って元に戻す。８色の列で、元の色を１ビット、札を色１ビットと個数−１の３ビットとする共有済みの規則の下、符号が４・８・32ビットになる場合を比べる。規則や元の長さ、ヘッダー等の付帯情報は比較に含めない。

任意の圧縮方法、８個を超える連続、実ファイルの形式、ハフマン符号、実装効率や一般の圧縮比は評価していない。対象項目は部分対応である。

実装担当と別の coverage_next が原典、符号化と復元、固定のビット数の比較、誤答、保存・開放をコード上で独立確認した。独立担当自身は実ブラウザーを操作していない。`tests/endgame-rle.test.js` は色・個数・順序、サイズ、リセットを検証する。`scripts/endgame-rle.playwright.js` は物語と４地域の達成状態を用意した別ブラウザー記録から誤答、途中保存、再挑戦、開放と達成を確認する。実際のスクリーンリーダー音声は未確認。
