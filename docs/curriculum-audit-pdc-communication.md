# 分母照合：PDC-Communication

[CS2023 印字 pp.220–222](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=220) と[候補台帳](coverage-pdc-communication.md)を 2026-11-11 に照合した。範囲照合は教材の完成・正確性・操作・保存や独立レビューの証明ではない。

CS Core の 1a・1b は媒体と基盤への依存、2a〜2c は通信路と API、3a〜3c は共有・異種メモリ、階層・局所性、一貫性、4a・4b は協調データ構造と所有・共有・複製等。親 1〜4 の媒体・通信路・メモリ・データストアという文脈を子に保持する。

KA Core 5a〜5q は、接続形態、順序と冪等性、通信性能、安全性、データ形式、通信路の方針、多重化、形式解析、待ち行列、メモリモデルと管理、配置と転送、共有メモリの模倣、データストアの整合性、分断と合意、CAP の兼合い、ビザンチン障害と信頼。原典の親 5 は列挙項目から **1 つ以上を選ぶ**構成であり、17 選択肢すべてが原典上の必修という意味ではない。台帳は選択肢を個別に追跡し、親子を重複して数えない。トピック 27 行。

CS Core 成果 1 は伝言・共有変数・分散共有 map の比較。KA Core 2〜13 は分担・集約と複数拠点取得、生産者消費者の性能、安全性、逐次一貫性、送信待ち・ロックの進行不能、順序変更、楽観的・保守的制御と進行、データストアの変更、故障下の複製ストア利用プログラム。成果 13 行を別に追跡する。

旧台帳の番号付き依頼は現行冒険への到達を示さない。現行冒険の PDC-Communication 項目別評価は記録時点で未作成だが、教材不存在の証明ではない。実際の API や並行・分散プログラムの記述、実測と一般的保証は固定模型だけで直接評価しない。

2026-11-11、照合担当とは別の `review_candidate` が原典の番号・区分・親子関係と候補台帳を確認した。 これは原典範囲のレビューであり、教材の正確性、現行の冒険からの到達やブラウザ操作を確認したものではない。整合性検査の範囲ハッシュは候補 ID と台帳要約を対象とし、監査文書や学習内容の正しさを保証しない。
