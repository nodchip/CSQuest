# 庭の道しるべと矢印

[CS2023 MSF-Linear、印字191ページ](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf#page=191) の固定した２次元例。２本の移動をつないで和を作り、倍率２・−１・０による変化を試す。異なる２依頼の達成後、２組の基準の矢印を係数倍して同じ移動を作り、係数を比較する。格子と元の矢印、現在作っている矢印を表示し、座標でも操作結果を示す。

２次元の少数例であり、内積・角度、一般の次元や独立性、任意の基底、証明、自由な説明は未対応。各項目は部分対応である。零ベクトルの向きは定義しない。矢印の操作範囲と係数の範囲は模型の制限であり、数学一般の制限ではない。

実装担当と別の curriculum_next が原典・計算・保存・進行を照合し、座標や係数の説明、元の矢印と格子、誤答と操作範囲の案内を指摘。修正後に再確認した。独立担当自身によるブラウザ操作は行っていない。`tests/endgame-vectors.test.js` は結果、誤答、負・零の倍率と境界を検証し、`scripts/endgame-vectors.playwright.js` は集いと４地域の達成状態を用意した記録から、対象依頼の誤答、途中保存、開放、達成と復帰を確認する。実際のスクリーンリーダー音声は未検証。
