# CS Quest

冒険しながら情報科学を学ぶ、制作途中のブラウザゲームです。[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の全17分野を対象とした学習体験を目指しています。

現在は、命令の順序・条件分岐・繰り返し、整列と幅優先・深さ優先探索、ハッシュ表の衝突、論理回路、戦闘、通信の再送、アクセス制御、データの選択と結合、スケジューリング、並行更新と排他、最近傍分類と評価、条件付き確率、アクセシビリティの設計、試験の選択、型と操作、キャッシュ、図形の変換、情報の収集と公開などを扱う試作です。CS2023 の全範囲は未収録です。ゲーム内の操作は、実際にプログラミング言語や文章を書く練習の代わりに、その能力を直接評価するものではありません。

## ローカルで遊ぶ

このフォルダーで `python -m http.server 8000` を実行し、ブラウザで `http://localhost:8000/` を開きます。達成記録はブラウザ内に保存します。森の探索、山道の最短路、スケジューリング、守護者との戦闘、伝令、並行更新、鍵による排他、書庫のハッシュ表、灯りの鑑定、遺跡の深さ優先探索、案内板の改善、門の試験、魔法の道具の型、書庫のキャッシュ、紋章の変換、受取台帳の設計の16依頼は、途中経過も同じブラウザで再開できます。他の依頼の途中経過はまだ保存されません。

テストは Node.js を使って `npm test` で実行できます。外部パッケージのインストールは必要ありません。
