# CS Quest

冒険しながら情報科学を学ぶ、制作途中のブラウザゲームです。[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の全17分野を対象とした学習体験を目指しています。

現在は、命令の順序・条件分岐・繰り返し、整列と探索、論理回路、戦闘、通信の再送などを扱う試作です。CS2023 の全範囲は未収録です。ゲーム内の操作は、実際にプログラミング言語や文章を書く練習の代わりに、その能力を直接評価するものではありません。

## ローカルで遊ぶ

このフォルダーで `python -m http.server 8000` を実行し、ブラウザで `http://localhost:8000/` を開きます。進捗はブラウザ内に保存します。

テストは Node.js を使って `npm test` で実行できます。外部パッケージのインストールは必要ありません。
