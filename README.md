# CS Quest

冒険しながら情報科学を学ぶ、制作途中のブラウザゲームです。公開中の試作: https://nodchip.github.io/CSQuest/ 。[CS2023](https://ieeecs-media.computer.org/media/education/reports/CS2023.pdf) の全17分野を対象とした学習体験を目指しています。

世界地図から行き先を選ぶと、その場所の依頼が並びます。学びの道しるべでは、関連する依頼を順番の目安として選べ、各道で最初の未達成の依頼をおすすめします。どの依頼からでも始められ、すべての依頼も一覧できます。各地の依頼を達成すると、ギルドの塔の灯りを巡る物語が進みます。８か所から知らせが届いたら、塔の光の道をつなげて物語の結末へ進めます。

「精霊と始める」では、順番・条件・繰り返しから、変数や関数の操作へ進みます。学びの道はテーマに沿って依頼を並べる目安で、途中を飛ばして選ぶこともできます。

「精霊と薬師の道具作り」では、命令と状態から、関数・データ構造・保存・API・入力検証・契約の確認へ進みます。

「森と塔のネットワーク」の道では、宛先と経路から、名前解決、信頼性、安全な通信へ進みます。

「王城を守る道」では、守る性質や権限から、暗号と安全な通信、防御、復旧、記録の保護へ進みます。関連する依頼は他の道と共有され、順番を飛ばして選ぶこともできます。

「灯火の変化と微積分」の道では、変化率と積分から、近似、勾配、制約付き最適化や円の座標へ進みます。

「薬師の台帳を設計する」の道では、関係の基本操作からキー、分解、正規形、多値従属性へ進みます。

「記録と推測」の道では、代表値・分布・確率から、推定、信頼区間、仮説検定、主成分分析の例へ進みます。関連する依頼は他の道と共有されます。

「支える仕組み」の道では、頁の参照列を組み立て、棚の数と置換方式による取寄せ回数の違いを調べられます。表の走査順を変えて頁の取寄せを比べたり、限られた予算で速い棚を選んだりできます。

「精霊と人工知能」の道では、AI の基礎から探索、機械学習、確率や対戦へ進めます。一つの依頼が複数の道に現れることがあり、達成状態は共通です。

依頼一覧では、選択中の地域を名前・学ぶ内容・番号や達成状況で絞り込めます。番号だけを入力すると、その番号に一致する依頼を探します。「途中記録あり」を選ぶと、このブラウザに途中経過が残っている依頼を見つけられます。達成後に再び遊んだ依頼にも途中記録が残る場合があります。検索条件は同じページを使っている間、依頼から戻った後も保持します。

現在は、命令の順序・条件分岐・繰り返し・再帰、整列、線形・二分探索、幅優先・深さ優先・A* 探索、ミニマックス、制約充足、最小全域木、ハッシュ表の衝突、論理回路と加算器、４ビットの整数表現、戦闘、通信の転送と再送、アクセス制御、データの選択と結合、送金とトランザクションの分離・競合直列化、スケジューリング、ページ置換と仮想住所の変換、並行更新と排他・デッドロック、最近傍分類と評価、集合操作、内積、条件付き確率・期待値・平均と中央値、アクセシビリティの設計、試験の選択、型・関数の組合せ・クロージャ、キャッシュ、図形の変換、情報の収集と公開、センサーと移動、有限状態機械などを扱う試作です。CS2023 の全範囲は未収録です。ゲーム内の操作は、実際にプログラミング言語や文章を書く練習の代わりに、その能力を直接評価するものではありません。

## ローカルで遊ぶ

このフォルダーで `python -m http.server 8000` を実行し、ブラウザで `http://localhost:8000/` を開きます。達成記録、最後に選んだ行き先と学びの道、および現在の584依頼の途中経過は同じブラウザ内に保存します。各依頼の途中経過は消去して最初からやり直せます。

Node.js で `npm ci` を実行すると、`npm test` でテストできます。公開用ビルドは `npm run build` を実行すると `dist` に生成されます。`python -m http.server 8000 --directory dist` で公開用ビルドも確認できます。GitHub Actions がテスト・ビルド・Pages へのデプロイを行います。
